Unit II — Exam Sheet

Physical layer and data link layer on one page. This is the numerical unit — every formula that can be asked is here, with the sanity check that catches the arithmetic slip.

Where the marks are

In order of certainty: Nyquist / Shannon · CRC · Hamming code · sliding-window efficiency · ALOHA throughput · Ethernet frame format. Six topics, and between them they carry most of Unit II.

Signals and impairment definitions

Sine wave f = 1/T  ·  λ = c/f  ·  three attributes: amplitude, frequency, phase
Bandwidth of a composite signal = fhighest − flowest

Frequency = rate of change with time. No change → frequency 0. Instant change → frequency ∞.

Impairments: attenuation (loses energy), distortion (changes shape, affects composite signals), noise (thermal, induced, crosstalk, impulse).

dB = 10 log10(P2/P1). Halving power = −3 dB. SNRdB = 10 log10 SNR.

Data rate limits always a numerical

Nyquist — noiseless BitRate = 2 × B × log2L
Shannon — noisy Capacity = B × log2(1 + SNR)   (no L, no factor of 2)

Choosing: SNR mentioned → Shannon. Signal levels mentioned → Nyquist. Both given → Shannon for the ceiling, then Nyquist for the number of levels.

Unit trap: if SNR is in dB, convert first: SNR = 10(SNRdB/10). Shortcut for large SNR: C ≈ B × SNRdB/3.

Sanity check: examiners pick SNR = 3, 7, 15, 31, 63 so that log2(1+SNR) is exact. If yours is not, re-read the question.

Multiplexing and spread spectrum

Synchronous TDM Frame rate = input data rate ÷ bits per slot  ·  Frame duration = input bit duration
Output rate = n × input rate (+ framing bits)  ·  Output bit duration = input bit duration ÷ n

FDM: divides frequency, analog, every user transmits all the time, needs guard bands — n channels need n−1 guard bands. WDM = FDM on fibre. TDM: divides time, digital, whole bandwidth per slot, needs framing bits.

Statistical TDM: slots on demand, no empty slots, but every slot needs an address.

FHSS hops the carrier pseudorandomly (Bluetooth). DSSS multiplies each bit by a chip code (802.11b, CDMA).

Transmission media & switching

Twisted pair — twisted so both wires get equal noise and it cancels. UTP (cheap, LANs, RJ-45) vs STP (shielded, Token Ring). Coaxial — core, insulation, outer conductor/shield, jacket; BNC. Fibre — total internal reflection, core denser than cladding; single-mode (laser, longest) vs multimode step/graded index.

Unguided: radio (omnidirectional, penetrates walls), microwave (unidirectional, line of sight, no walls), infrared (short range, blocked by walls — which prevents inter-room interference).

Packet-switching delay Total time = (L + p − 1) × t   (L links, p packets, t per-packet transmission time)

Circuit switching: dedicated path, 3 phases (setup, transfer, teardown), physical layer, telephone network. Datagram: no setup, full address per packet, may arrive out of order, network layer, the Internet. Virtual circuit: setup phase, short VCI (local significance), in order, data link layer, Frame Relay/ATM.

Error detection and correction two numericals

Hamming distance Detect s errors: dmin ≥ s + 1  ·  Correct t errors: dmin ≥ 2t + 1
CRC Append (n−1) zeros (n = divisor bits) → divide by XOR → remainder is the CRC
Receiver: divide again; zero remainder = accept
Check: the remainder has exactly one fewer bit than the divisor.

Worked reference: dataword 1001, divisor 1011 → CRC 110 → codeword 1001110.

Hamming code Redundancy bits: 2r ≥ m + r + 1
Parity bits at positions 1, 2, 4, 8 …  p1: 1,3,5,7 · p2: 2,3,6,7 · p4: 4,5,6,7
Syndrome read as c4c2c1 gives the error position; 000 = no error

Worked reference: data 1011 → codeword 0110011. Received 0110111 → syndrome 101 = 5 → flip bit 5.

Checksum: one's complement addition, complement the sum. Receiver's sum before complementing must be all 1s.

Framing, flow and error control efficiency numerical

Byte stuffing: insert ESC before any flag or ESC byte in the data (the ESC case is the one students forget). Bit stuffing: insert a 0 after five consecutive 1s; flag is 01111110.

The efficiency framework Tt = frame size / bandwidth  ·  Tp = distance / speed  ·  a = Tp/Tt
Stop-and-Wait: η = 1/(1+2a)  ·  GBN and SR: η = N/(1+2a), capped at 1
Throughput = η × bandwidth  ·  Optimal N = 1 + 2a

HDLC and PPP

HDLC — bit-oriented, ISO. Modes: NRM (unbalanced, secondary needs permission) and ABM (balanced, either may start). Frame: Flag(1) | Address(1+) | Control(1–2) | Info | FCS(2–4) | Flag. Types by control bits: 0 = I-frame (data + piggybacked ACK), 10 = S-frame (control only), 11 = U-frame (link management).

PPP — byte-oriented, point-to-point only. Frame: Flag(0x7E) | Address(0xFF constant) | Control(0x03 constant) | Protocol | Payload | FCS | Flag. No flow control, no error correction. Phases: Dead → Establish (LCP) → Authenticate (PAP/CHAP) → Network (NCP) → Open → Terminate.

PAP: 2-step, password in plain text, once. CHAP: 3-step challenge–hash–verify, password never sent, repeats during the session.

Multiple access ALOHA numerical

ALOHA throughput Pure: S = G e−2G → max 0.184 at G = 0.5  ·  vulnerable time 2Tfr
Slotted: S = G e−G → max 0.368 at G = 1  ·  vulnerable time Tfr
CSMA/CD minimum frame size Tfr ≥ 2 × Tp  →  Lmin = 2 × Tp × Bandwidth
10 Mbps, Tp = 25.6 µs → 51.2 µs slot time → 512 bits = 64 bytes

Persistence: 1-persistent (send at once when idle; keep sensing when busy — Ethernet, most collisions), non-persistent (random wait when busy — fewer collisions, wasted bandwidth), p-persistent (probability p on a slotted channel — the compromise).

Back-off: after the kth collision, wait a random number of slots from 0 to 2k−1; discard after 16 attempts.

CSMA/CA (wireless) exists because detection needs full duplex, signals attenuate, and there is the hidden station problem. Strategies: IFS, contention window, ACK, optionally RTS/CTS.

Controlled access: reservation (minislot per station), polling (primary polls to receive, selects to send), token passing (only the token holder transmits). Channelization: FDMA (frequency), TDMA (time, needs synchronisation), CDMA (code).

CDMA Composite = Σ(di × ci)  ·  Decode: di = (Composite · ci) ÷ N
bit 1 = +1 · bit 0 = −1 · silent = 0

Ethernet frame diagram

IEEE 802.3 frame — byte counts Preamble 7 | SFD 1 | Dest addr 6 | Src addr 6 | Length/Type 2 | Data 46–1500 | CRC 4

Overhead = 18 bytes. Minimum frame 64 bytes (CSMA/CD round-trip rule; shorter payloads are padded). Maximum frame 1518 bytes. Preamble and SFD are added by the physical layer and are not part of the frame.

MAC address: 6 bytes = 48 bits = 12 hex digits. Unicast if the second hex digit is even, multicast if odd; broadcast = FF:FF:FF:FF:FF:FF.

IEEE 802 sublayers: LLC (802.2, flow and error control, common to all LANs) and MAC (framing, addressing, access method, specific to each LAN).

Generations: 10 Mbps 802.3 · 100 Mbps 802.3u · 1 Gbps 802.3z/ab · 10 Gbps 802.3ae (full-duplex only, no CSMA/CD).

Domains: hub/repeater break neither; switch/bridge break collision domains; only a router breaks broadcast domains.

Final scan — ten minutes before you go in

  1. Nyquist = 2B log₂L. Shannon = B log₂(1+SNR). No factor of 2 in Shannon.
  2. Halving power is −3 dB. Convert dB SNR before substituting.
  3. Manchester: mid-bit transition = data. Differential Manchester: start-of-bit transition = data.
  4. n channels need n−1 guard bands. TDM frame duration = input bit duration.
  5. Fibre: core denser than cladding, total internal reflection.
  6. Packet switching total time = (L + p − 1) × t.
  7. CRC: append (n−1) zeros, remainder has one fewer bit than the divisor.
  8. Hamming: 2^r ≥ m+r+1, parity at powers of 2, syndrome c₄c₂c₁ is the position.
  9. a = Tp/Tt. η = 1/(1+2a) or N/(1+2a). Optimal N = 1+2a.
  10. ALOHA 18.4% at G=0.5, slotted 36.8% at G=1. Ethernet min frame 64 bytes, max 1518.
  11. Modulation: ASK (amplitude), FSK (frequency), PSK (phase, QPSK = 2 bits/baud), QAM (both; highest bandwidth efficiency). AM ($B = 2B$), FM ($B = 2(1+\beta)B$, Carson's rule).
  12. Media & Switching: Baseband coax (50 Ω, digital) vs Broadband (75 Ω, analog FDM). SVC (dynamic setup/teardown) vs PVC (permanently provisioned).
