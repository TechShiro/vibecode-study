Unit III — Exam Sheet

The network layer on one page. Addressing is the whole unit — if the mask table and the subnetting procedure are automatic, most of Unit III answers itself.

Where the marks are

Subnetting and VLSM first, by a distance. Then the IPv4 header, fragmentation, distance vector vs link state, and IPv4 vs IPv6. Subnetting alone is worth more than the rest of the unit combined in most papers.

Network layer duties

Packetizing (encapsulate / decapsulate; routers must not change addresses, and may decapsulate only to fragment) · Routing (build the table — global, background, slow) · Forwarding (use the table — local, per-packet, fast).

IP is unreliable, connectionless and best-effort. No flow control, no payload error control (header checksum only), no congestion control, no security in the original design.

Three deliveries: data link = hop to hop · network = source to destination · transport = process to process.

Forwarding: AND the destination with each row's mask; among matches, longest prefix wins. Default route 0.0.0.0/0 always loses.

An IP address defines a connection, not a device — a router has one per interface.

Rebuild the table with: mask byte + block size = 256. /30 is the router-to-router link.

Three block rules: contiguous · a power of two · first address divisible by the block size.

Fastest method: find the byte the prefix falls in, count up in steps of the block size (0, N, 2N…). Bytes before are copied; bytes after become 0 (first) or 255 (last).

Supernetting: combine contiguous blocks, prefix shortens. Four /24s → one /22.

Subnetting and VLSM highest value

The formulas Subnets = 2s (s = bits borrowed)  ·  Addresses per subnet = 2h  ·  Usable = 2h − 2
New prefix = old prefix + s

Procedure: 1. find s (or h) → 2. new prefix and mask → 3. block size = 256 − last mask byte → 4. count up in block-size steps → 5. write network / first host / last host / broadcast for each.

Worked reference — 192.168.1.0/24 into 4 subnets: s = 2, /26, mask 255.255.255.192, block 64, 62 hosts each. Subnets at .0 · .64 · .128 · .192, broadcasts at .63 · .127 · .191 · .255.

Two sanity checks

Each subnet's broadcast is one less than the next subnet's network address. The last broadcast must equal the last address of the original block. And subnets × addresses per subnet must equal the original block size.

VLSM — the one rule: allocate the LARGEST requirement first, then work down. Any other order breaks the divisibility rule.

Worked reference — 192.168.10.0/24 for 100, 50, 25, 10, 2, 2 hosts:
100 → .0/25 · 50 → .128/26 · 25 → .192/27 · 10 → .224/28 · 2 → .240/30 · 2 → .244/30 · spare .248/29.
Check: 128+64+32+16+4+4+8 = 256. ✓

IPv4 header and fragmentation

Header — 20 to 60 bytes Version(4) | HLEN(4) | ToS(8) | Total Length(16)
Identification(16) | Flags(3) | Fragment Offset(13)
TTL(8) | Protocol(8) | Header Checksum(16)
Source(32)  ·  Destination(32)  ·  Options + Padding (0–40)

HLEN counts 4-byte words (5 = 20 bytes, 15 = 60). Total Length includes the header, max 65,535. TTL is a hop count. Checksum covers the header only and is recomputed at every router. Protocol: ICMP 1, IGMP 2, TCP 6, UDP 17.

Flags: reserved · DF (discard + ICMP error if too big) · MF (1 = more follow, 0 = last).

Fragmentation rules Data per fragment = MTU − header, rounded DOWN to a multiple of 8
Offset = (preceding data bytes) ÷ 8  ·  MF = 1 on all but the last  ·  identification is the same in all

Worked reference — 4000 bytes (20 + 3980), MTU 1500: three fragments — 1480 data / offset 0 / MF 1; 1480 / offset 185 / MF 1; 1020 / offset 370 / MF 0.

Only the destination reassembles (fragments may take different routes). One lost fragment loses the whole datagram.

NAT, ARP and RARP

NAT maps private addresses to public ones; the table records port numbers too (PAT / NAT overload), because two internal hosts may contact the same server. Types: static, dynamic, PAT. Breaks end-to-end connectivity and protocols carrying addresses in the payload (FTP, SIP, IPsec).

Fix the direction first ARP: IP → MAC   |   RARP: MAC → IP

ARP: request is BROADCAST, reply is UNICAST. Mappings are held in the ARP cache with a timeout. When the destination is on another network, ARP resolves the router's address, not the destination's.

RARP is obsolete — its broadcasts cannot cross a router, so every segment needs a server. Replaced by BOOTP then DHCP.

ICMP and IGMP

ICMP (protocol 1) compensates for IP having no error reporting and no query mechanism. Error messages: destination unreachable (3), source quench (4, deprecated), redirection (5), time exceeded (11), parameter problem (12). Queries: echo request/reply (8/0), timestamp (13/14), router solicitation/advertisement (10/9).

Data section carries the original IP header + first 8 bytes of data (the ports and sequence number).

No ICMP error for: an ICMP error message · a non-first fragment · a multicast address · a special address such as 127.0.0.0.

ping = echo request/reply. traceroute = increasing TTL, collecting time-exceeded replies.

IGMP (protocol 2) manages multicast group membership between a host and its local router — it is not a routing protocol. Messages: membership query (router), membership report (host joins), leave report (host leaves). Efficiency: delayed response and report suppression.

Count to infinity fixes: infinity = 16 in RIP · split horizon (do not advertise a route back where it came from) · poison reverse (advertise it back as infinite) · hold-down timers. Split horizon does not fix loops of three or more routers.

RIP = interior, distance vector, hop count, max 15. OSPF = interior, link state, cost by bandwidth, areas. BGP = exterior, path vector (carries the AS path, so loops are visible and policy is possible), the Internet backbone.

Multicast

Source-based tree (one per source-group pair, optimal paths, high state — DVMRP, MOSPF, PIM-DM) vs group-shared tree (one per group at a core/RP, sub-optimal, low state — CBT, PIM-SM).

RPF stops loops (forward only if it arrived on the shortest path back to the source) → RPB stops duplicates (one parent router per network) → RPM stops waste (pruning and grafting). Learn the progression in that order.

Dense mode floods then prunes; sparse mode sends nothing until a router joins. PIM-SM is what is deployed.

IPv6

128 bits, eight groups of four hex digits. Drop leading zeros; collapse one run of zero groups with ::, only ONCE.

Header: fixed 40 bytes, 8 fields — Version(4), Traffic Class(8), Flow Label(20), Payload Length(16), Next Header(8), Hop Limit(8), Source(128), Destination(128).

Removed from IPv4: header checksum (redundant) · identification/flags/offset (routers never fragment) · HLEN (fixed size) · options (moved to extension headers).

Address types: unicast, multicast, anycast — NO broadcast. Anycast = delivered to the nearest member.

Extension headers: hop-by-hop (the only one every router reads), routing, fragmentation, authentication, ESP, destination option.

Transition: dual stack (run both) · tunnelling (wrap IPv6 inside IPv4 to cross an IPv4 region) · header translation (rewrite the header outright). Tunnelling keeps the packet; translation destroys the original header.

Final scan — ten minutes before you go in

  1. First byte: 1–126 A, 128–191 B, 192–223 C, 224–239 D, 240–255 E. 127 is loopback.
  2. N = 2^(32−n). Usable = N − 2. Mask byte + block size = 256.
  3. Subnetting: bits borrowed → new prefix → block size → count up → four columns per subnet.
  4. VLSM: largest first, always. Check the allocations sum to the block size.
  5. /30 = router-to-router link, 2 usable addresses.
  6. IPv4 header 20–60 bytes; HLEN in 4-byte words; TTL is hops; checksum covers the header only.
  7. Fragment data = MTU − 20, rounded DOWN to a multiple of 8. Offset = bytes before ÷ 8. MF = 0 on the last.
  8. ARP is IP → MAC; request broadcast, reply unicast; resolves the router if the destination is remote.
  9. Distance vector = Bellman-Ford, whole table to neighbours. Link state = Dijkstra, own links to everyone.
  10. IPv6: 128 bits, 40-byte header, no broadcast, no router fragmentation, no checksum, :: only once.
