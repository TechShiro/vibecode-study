Definitions to state verbatim recall

Data communication

The exchange of data between two devices via some form of transmission medium such as a wire cable. The devices must be part of a communication system made of a combination of hardware and software.

Network · Topology · Protocol

Network: a set of devices (nodes) connected by communication links.
Topology: the geometric representation of the relationship of all the links and nodes to one another.
Protocol: a set of rules that govern data communication — defining what, how and when.
OSI: Open Systems Interconnection — a reference model by ISO (1984); a model, not a protocol.

Performance formulas numerical

Latency Latency = Propagation time + Transmission time + Queuing time + Processing delay
Propagation & transmission Propagation time = Distance ÷ Propagation speed   (usually 2 × 108 m/s in wire)
Transmission time = Message size ÷ Bandwidth
Bandwidth-delay product BDP = Bandwidth × Delay   = the number of bits that fill the link

The trap: propagation time does not use message size; transmission time does not use distance. Write both formulas down before substituting.

Bandwidth vs throughput: bandwidth is capacity (potential), throughput is what actually gets through. Throughput ≤ bandwidth, always.

Point-to-point = dedicated link, two devices, full capacity reserved. Multipoint = more than two share one link, capacity shared spatially or temporally.

Broadcast reaches everyone whether they want it or not; multicast reaches only those who joined the group.

WAN types: point-to-point WAN (two devices, one medium) and switched WAN (many endpoints, built from switches).

Two one-liners: bus is the only multipoint topology; mesh is the only one with no single point of failure. Bus needs terminators to stop signal reflection. Dual ring solves the ring's single-break problem.

Sample: n = 8 mesh → 28 duplex links, 7 ports each, 56 ports total. Reverse: 66 links → n(n−1) = 132 = 12 × 11 → n = 12.

Mnemonic: All People Seem To Need Data Processing (7→1). PDUs: Segment, Packet, Frame, Bit — only the bottom four have distinct names.

The three deliveries: data link = hop to hop · network = source to destination · transport = process to process.

Grouping: layers 1–3 network support · layer 4 links the two groups · layers 5–7 user support.

Encapsulation: Data → +H4 = Segment → +H3 = Packet → +H2 and trailer = Frame → Bits. Reverse at the receiver = decapsulation. Only the data link layer adds a trailer.

Four traps

Encryption = presentation (6), not application. Checkpoints/dialog = session (5), not transport. Flow and error control exist at both data link (per hop) and transport (end to end). Router = 3, switch/bridge/NIC = 2, hub/repeater = 1.

Similarities (do not omit): both layered, both use protocol stacks, both encapsulate down and decapsulate up, comparable transport and network layers.

Why OSI lost: bad timing, bad technology, bad implementations, bad politics.

Four addresses: MAC 48-bit (data link) · IP 32-bit (network) · port 16-bit (transport) · specific/URL (application).

Final scan — ten minutes before you go in

  1. Five components: message, sender, receiver, medium, protocol.
  2. Four characteristics: delivery, accuracy, timeliness, jitter.
  3. Three criteria: performance, reliability, security.
  4. Propagation = distance/speed. Transmission = size/bandwidth. Do not swap them.
  5. Simplex one way · half-duplex takes turns · full-duplex at once.
  6. Mesh links = n(n−1)/2, ports = n−1. Star = n links, 1 port. Ring = n links, 2 ports.
  7. Bus is the only multipoint topology. Mesh is the only one without a single point of failure.
  8. Seven layers, top down: Application, Presentation, Session, Transport, Network, Data Link, Physical.
  9. Segment, Packet, Frame, Bit. Router 3, switch 2, hub 1. Encryption 6, checkpoints 5.
  10. TCP/IP merges OSI's top three and bottom two. Model-first vs protocols-first is the root difference.
