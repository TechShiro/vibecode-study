Switching

Circuit switching, packet switching (datagram and virtual circuit) and message switching. One comparison table carries this topic, plus a delay numerical that shows exactly why packet switching won.

Exam strategy

"Compare circuit switching and packet switching" is a certainty — 5 to 10 marks, answered as a table of 8–10 rows. The sub-question that separates good answers from average ones is datagram vs virtual circuit, so keep three rows for it. Draw the three phases of circuit switching (setup, data transfer, teardown) as a timeline; it is quick and it is worth a mark.

What switching is

A network is a set of connected devices. Connecting every device to every other is impractical (mesh: n(n−1)/2 links), so instead we use switches — devices capable of creating temporary connections between two or more devices linked to them. A switched network is a series of interlinked nodes; some are connected to end systems, others are used only for routing.

Circuit switching

A dedicated communication path is established between sender and receiver for the entire duration of the conversation, and held whether or not data is actually flowing.

The three phases

Circuit switching timeline 1. Setup phase — a request travels to the destination and a circuit is reserved hop by hop; an acknowledgement returns.
2. Data transfer phase — data flows continuously along the reserved circuit, with no addressing or routing decisions.
3. Teardown phase — a disconnect signal releases the reserved resources.
  • Resources are reserved during setup and stay reserved until teardown, even during silent periods — which is the central inefficiency.
  • Because the path is fixed, data arrives in order and delay is constant. There is no per-packet addressing, no routing decision at each hop, and no reordering at the receiver.
  • The classic example is the traditional telephone network.

Message switching

Also called store-and-forward. The entire message is sent to the first switch, which stores it completely, then forwards it to the next switch when a link becomes free, and so on to the destination.

  • No dedicated path is set up. Each hop is independent.
  • Advantages: efficient use of links (no reservation), messages can be prioritised, and a switch can hold a message if the destination is busy.
  • Disadvantages: each switch needs enough storage for a whole message, and the store-and-forward delay accumulates at every hop. Unsuitable for real-time or interactive traffic.
  • Effectively obsolete — but examiners ask for it as the third method, and the standard example is the old telegraph network.

Packet switching

The message is divided into fixed- or variable-size packets, each of which is switched independently. No resources are allocated in advance — they are granted on demand, first come first served. If a switch is busy, packets wait in a queue, which is why packet-switched networks have variable delay.

Datagram approach (connectionless)

  • Each packet is treated independently of all others, and is called a datagram.
  • Packets of the same message may travel by different routes and may therefore arrive out of order, or be lost, or be delayed.
  • Each packet must carry the full destination address, and each switch consults a routing table based on that address.
  • Reordering and recovery are the responsibility of a higher layer — typically TCP at the transport layer.
  • Works at the network layer. The Internet uses this approach.

Virtual circuit approach (connection-oriented)

  • A route is set up before any packet is sent, and all packets of the message follow the same route, arriving in order.
  • Packets carry a short virtual circuit identifier (VCI) rather than a full destination address. The VCI has only local significance — it changes at every switch, using each switch's own table.
  • Has setup, data transfer and teardown phases, like circuit switching — but resources are not physically reserved; they are still shared.
  • Works at the data link layer. Examples: Frame Relay, ATM, X.25, MPLS.

VCI Translation & The Virtual Circuit Switching Table

Unlike datagram routing where routers look up full 32-bit destination IP addresses, a Virtual Circuit switch routes packets using a compact Virtual Circuit Identifier (VCI) that is local to each physical link. To avoid global coordination of IDs across an entire network, each switch rewrites (swaps) the VCI on egress using an internal switching table:

The line that separates virtual circuit from circuit switching

Both have setup, data transfer and teardown phases, and both deliver packets in order — so students conflate them. The difference: circuit switching physically reserves a dedicated path and its bandwidth for the whole session; a virtual circuit only fixes the route, and the links along it remain shared with other traffic. Virtual circuit is packet switching with a plan, not circuit switching.

Worked numerical — why packet switching wins

Q. A message of 3000 bits is sent from source to destination through two intermediate switches (so three links). Each link is 1 Mbps. Setup time for a circuit is 5 ms; propagation is negligible. Compare the total time for (a) circuit switching, (b) packet switching with the message split into three packets of 1000 bits.

(a) Circuit switching. Once the circuit is set up, the bits stream through the whole path continuously — no store-and-forward at the switches.

Setup = 5 ms
Transmission of the whole message = 3000 / 106 = 3 ms
Total = 5 + 3 = 8 ms

(b) Packet switching. Each switch must receive a whole packet before forwarding it (store and forward). No setup phase.

Time per packet per link = 1000 / 106 = 1 ms
The first packet must cross all three links: 3 × 1 = 3 ms
The remaining 2 packets follow in a pipeline, one per millisecond on the last link: + 2 ms
Total = 3 + 2 = 5 ms

Conclusion: packet switching finished in 5 ms against circuit switching's 8 ms, and it did not tie up the links exclusively. The pipelining effect — later packets moving on earlier links while the first packet is still travelling — is the whole reason packet switching dominates.

The general formula, worth memorising: for p packets over L links with per-packet transmission time t,
Total time = (L + p − 1) × t. Here (3 + 3 − 1) × 1 ms = 5 ms. ✓

Check yourself

Retrieval practice

1. In circuit switching, resources are reserved:

Holding resources through silent periods is exactly what makes circuit switching wasteful, and exactly what guarantees its constant delay. The other three options describe packet switching or message switching.

2. Which is true of the datagram approach but not the virtual circuit approach?

Both are packet switching, so both split the message and allocate on demand. Independent routing with possible reordering is the datagram signature; a setup phase belongs to virtual circuits.

3. A virtual circuit identifier (VCI) differs from a destination address in that it:

The VCI is short precisely because it is local: each switch maps an incoming VCI to an outgoing one using its own table. That is why virtual circuits carry less per-packet overhead than datagrams.

4. Message switching is unsuitable for interactive traffic because:

Store-and-forward of a complete message means the full transmission delay is paid at every hop, and switches need storage for entire messages. That accumulated delay rules out real-time and interactive use.

5. Four packets travel over three links, each taking 2 ms per link. The total time is:

Total = (L + p − 1) × t = (3 + 4 − 1) × 2 = 12 ms. Multiplying packets by links (24 ms) ignores pipelining — later packets move along earlier links while the first is still in flight, and that overlap is the point.

Recall without looking

Name the three switching methods and the layer each works at.

Circuit switching — physical layer. Packet switching — network layer (datagram) or data link layer (virtual circuit). Message switching — application layer, now obsolete.

Describe the three phases of circuit switching.

Setup — a request travels to the destination reserving a circuit hop by hop, and an acknowledgement returns. Data transfer — data flows continuously along the reserved circuit with no addressing or routing decisions. Teardown — a disconnect signal releases the resources.

Give five differences between circuit and packet switching.

Dedicated path (yes/no); resource reservation (at setup/on demand); setup phase (required/not for datagram); addressing (none during transfer/full address per packet); delay (constant with long setup/variable due to queuing); efficiency (low/high); example (telephone network/the Internet).

Datagram vs virtual circuit — four differences.

Datagram: no setup, full destination address in each packet, packets may take different routes and arrive out of order, network layer, used by the Internet. Virtual circuit: setup/transfer/teardown phases, short locally significant VCI, all packets take the same route and arrive in order, data link layer, used by Frame Relay and ATM.

How does a virtual circuit differ from circuit switching?

Circuit switching physically reserves a dedicated path and its bandwidth for the whole session. A virtual circuit fixes only the route; the links along it stay shared with other traffic and nothing is physically reserved.

State the packet-switching delay formula.

Total time = (L + p − 1) × t, for p packets over L links with per-packet transmission time t. The −1 captures the pipelining of later packets behind the first.
