Bandwidth Utilization: Multiplexing and Spread Spectrum

Two opposite ideas with one name. Multiplexing shares a wide link between many users to save bandwidth; spread spectrum deliberately wastes bandwidth to buy security. FDM, WDM, TDM, FHSS and DSSS — with the TDM numericals that carry the marks.

Exam strategy

Two questions live here. (1) "Explain FDM and TDM with diagrams" — a 5-mark comparison; draw both, and be explicit that FDM divides frequency while TDM divides time. (2) A TDM numerical — frame size, frame rate, or bit duration. Learn the four TDM formulas; they are short and mechanical. Spread spectrum is usually a 3-mark "differentiate FHSS and DSSS".

The device that combines the streams is the multiplexer (MUX); the device that separates them at the far end is the demultiplexer (DEMUX).

Frequency-Division Multiplexing (FDM)

An analog technique, applied when the bandwidth of the link in hertz exceeds the combined bandwidths of the signals to be sent.

  • Each sending device's signal is modulated onto a different carrier frequency. The modulated signals are combined into a single composite signal.
  • The carrier frequencies are separated by unused bandwidth called guard bands, which stop adjacent channels overlapping and interfering.
  • At the receiver, each channel is separated by a filter tuned to its carrier, then demodulated.
  • Applications: AM and FM radio broadcasting, traditional analog television, first-generation cellular telephones.
FDM bandwidth Link bandwidth required = Σ (channel bandwidths) + Σ (guard bands)
Worked numerical — FDM

Q. Five channels, each of bandwidth 100 kHz, are multiplexed together. A guard band of 10 kHz is needed between adjacent channels to prevent interference. What is the minimum bandwidth of the link?

Channel bandwidth = 5 × 100 = 500 kHz

Guard bands: with 5 channels there are 4 gaps between them = 4 × 10 = 40 kHz

Minimum link bandwidth = 500 + 40 = 540 kHz

The trap: n channels need n − 1 guard bands, not n. Guard bands sit between channels, so the standard mistake is to add 50 kHz here and answer 550.

Wavelength-Division Multiplexing (WDM)

Conceptually identical to FDM, but applied to fibre-optic cable, where the signals are light waves and it is natural to speak of wavelength rather than frequency.

  • Several optical signals of different wavelengths are combined by a prism (or its modern equivalent) into a single beam, sent down one fibre, and split again by a prism at the far end.
  • Why it exists: a single fibre has enormous data-rate capacity — far more than any one source can use. WDM is how that capacity is actually harvested.
  • DWDM (Dense WDM) packs a very large number of closely spaced channels onto one fibre.

Time-Division Multiplexing (TDM)

A digital technique. Several connections share the high bandwidth of a link in time rather than in frequency — each gets the whole link, but only for a slice of time.

Synchronous TDM

  • Each input is given a fixed time slot in every frame, whether or not it has data to send.
  • If a source has nothing to send, its slot goes out empty — which is the scheme's central weakness.
  • Slots are grouped into frames; one frame contains one complete round of slots.
  • Interleaving is the switching action that visits each input in turn. It may be by bit or by character (byte).
  • Framing bits — usually one bit per frame, following an alternating pattern — let the receiver stay synchronised with the frame boundaries.
The four synchronous TDM formulas Frame rate = input data rate ÷ bits per slot   (= the rate of each input)
Frame duration = 1 / frame rate
Output data rate = n × input data rate  (plus framing bits)
Output bit duration = input bit duration ÷ n
Worked numerical — synchronous TDM

Q. Four 1 kbps connections are multiplexed together. One unit is one bit. Find (a) the duration of one bit before multiplexing, (b) the transmission rate of the link, (c) the duration of a time slot, (d) the duration of a frame.

(a) Each source sends 1000 bps, so one bit lasts 1/1000 = 1 ms = 0.001 s

(b) Link rate = 4 × 1000 = 4000 bps = 4 kbps

(c) A slot carries one bit at the link rate, so it lasts 1/4000 = 0.25 ms

(d) A frame is 4 slots = 4 × 0.25 ms = 1 ms

Sanity check that always works: the frame duration must equal the input bit duration. Both are 1 ms here. That has to hold — in the time one source produces a single bit, the multiplexer must complete exactly one full round of all sources. If your two numbers differ, you have made an error.

Worked numerical — TDM with framing bits

Q. Four sources, each producing 250 characters per second with 8 bits per character, are multiplexed by character-interleaved synchronous TDM. One framing bit is added per frame. Find the frame rate, frame size and output data rate.

Frame rate = 250 frames/s (one frame per character from each source)

Frame size = 4 sources × 8 bits + 1 framing bit = 33 bits

Output data rate = 250 × 33 = 8250 bps

Cross-check: the data alone is 4 × 250 × 8 = 8000 bps, and the framing adds 250 bps, giving 8250. ✓ Overhead is 250/8250 ≈ 3%.

Statistical (asynchronous) TDM

The fix for synchronous TDM's empty slots.

  • Slots are allocated dynamically, on demand — a source gets a slot only if it actually has data to send.
  • The number of slots in a frame is therefore less than the number of inputs, and frames need not be full.
  • The cost: because slots no longer belong to a fixed input, each slot must carry an address identifying whose data it holds. Synchronous TDM needs no such address.
  • Result: much better link utilisation, at the price of per-slot addressing overhead.

FDM vs TDM in one line each

FDM divides the frequency band; every user transmits all the time on their own frequency. TDM divides the time; every user transmits on the whole bandwidth, but only during their slot. FDM is analog, TDM is digital. FDM needs guard bands, TDM needs framing bits and synchronisation.

Spread spectrum

Used on wireless links, where the medium is shared with anyone within range. The idea is deliberately counter-intuitive: spread the signal over a bandwidth much wider than it needs, so that an eavesdropper cannot easily find it and a jammer cannot easily block all of it.

Two requirements the technique must satisfy:

  • The spread bandwidth BSS must be much greater than the original bandwidth B.
  • The spreading must be driven by something independent of the original signal — a code known to sender and receiver but not to an intruder.

FHSS — Frequency Hopping Spread Spectrum

  • The signal is transmitted on one carrier frequency at a time, but the carrier hops from frequency to frequency in a sequence determined by a pseudorandom code generator.
  • Sender and receiver share the same hopping sequence, so the receiver follows the hops; an intruder who does not know the sequence hears only fragments.
  • A jammer can block one frequency, but the signal has already moved on — hence the anti-jamming property.
  • Used in Bluetooth.

DSSS — Direct Sequence Spread Spectrum

  • Each data bit is replaced by a longer sequence of bits called a chip code (or chipping sequence), which spreads the signal over a wider band.
  • The spreading code is known to both ends; the receiver multiplies by the same code to recover the original bit.
  • The classic example is the Barker sequence of 11 chips used in the original 802.11.
  • Used in 802.11b Wi-Fi and in CDMA cellular systems.

Check yourself

Retrieval practice

1. Six channels of 200 kHz each are multiplexed with 20 kHz guard bands. Minimum link bandwidth is:

n channels have n − 1 gaps between them, so 6 channels need 5 guard bands: 1200 + 100 = 1300 kHz. Counting 6 guard bands is the standard mistake on this question.

2. In synchronous TDM, when a source has no data to send:

Fixed pre-assignment is what makes synchronous TDM simple and what makes it wasteful. Reallocating idle slots is precisely what statistical TDM does — and it pays for that with an address in every slot.

3. Statistical TDM requires an address in each slot because:

In synchronous TDM the third slot is always the third source's, so no address is needed. Once slots are handed out on demand, that positional guarantee is gone and each slot has to say who it belongs to.

4. Three 2 kbps sources are multiplexed by bit-interleaved synchronous TDM. The frame duration is:

Input bit duration = 1/2000 = 0.5 ms. In that time the multiplexer must take one bit from each of the three sources, i.e. complete exactly one frame — so frame duration equals input bit duration. That equality is the sanity check for every TDM numerical.

5. Which statement describes DSSS rather than FHSS?

DSSS spreads by multiplying each bit by a chip code and occupies the whole wide band continuously. FHSS spreads by hopping the carrier and is narrow at any instant — and Bluetooth is the FHSS example.

Recall without looking

Define multiplexing and name its three types.

Multiplexing lets several signals share one link when the link's bandwidth exceeds any single user's needs. Types: FDM (frequency division, analog), WDM (wavelength division, for fibre), TDM (time division, digital — synchronous and statistical).

What is a guard band, and how many are needed for n channels?

Unused bandwidth left between adjacent FDM channels to prevent them overlapping and interfering. n channels need n − 1 guard bands.

FDM vs TDM in one sentence each.

FDM divides the frequency band, so every user transmits all the time on their own carrier frequency; it is analog and needs guard bands. TDM divides time, so every user transmits over the whole bandwidth but only during their slot; it is digital and needs framing bits.

Write the synchronous TDM formulas.

Frame rate = input data rate ÷ bits per slot. Frame duration = 1/frame rate = input bit duration. Output data rate = n × input rate (plus framing bits). Output bit duration = input bit duration ÷ n.

Synchronous vs statistical TDM — three differences.

Slots fixed vs allocated on demand; empty slots sent vs never sent; no address needed vs an address required in every slot. Statistical TDM has fewer slots per frame than inputs, and higher efficiency.

What is spread spectrum, and what two conditions must it meet?

Deliberately spreading a signal over a bandwidth much wider than it needs, for privacy and anti-jamming on wireless links. The spread bandwidth must be much greater than the original, and the spreading must be driven by a code independent of the original signal and known only to sender and receiver.

FHSS vs DSSS — three differences, with the application of each.

FHSS hops the carrier frequency in a pseudorandom sequence, is narrow at any instant, and is simpler — used in Bluetooth. DSSS replaces each data bit with a longer chip code, occupies the whole band continuously, and is more complex — used in 802.11b Wi-Fi and CDMA.
