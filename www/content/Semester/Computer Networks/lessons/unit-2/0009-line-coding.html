Line Coding

Converting bits into signals. Eight schemes, the four characteristics used to judge them, and the one skill the exam actually tests: drawing the waveform for a given bit stream without making an error.

Exam strategy

The question is almost always "encode the bit stream 10110010 using NRZ-L, NRZ-I, Manchester and Differential Manchester" — a drawing question worth 5–10 marks. Marks come from the waveform being right, not from prose. Draw a labelled time axis, mark the bit boundaries with dotted vertical lines, and state your convention (which level is 1) before you start. An unstated convention is the commonest reason a correct-looking answer loses marks.

What line coding is

Line coding is the process of converting digital data into a digital signal. The sender encodes bits into signal elements; the receiver decodes signal elements back into bits.

The ratio that runs through the whole topic r = number of data elements (bits) carried by each signal element
Signal rate S = c × N × (1/r)    baud
N = data rate in bps  ·  c = case factor  ·  S = signal rate in baud

Data rate (bit rate, bps) is how many bits are sent per second. Signal rate (baud rate, baud) is how many signal elements are sent per second. The goal is always to increase the data rate while decreasing the signal rate, because the signal rate determines the bandwidth needed.

The four characteristics used to judge a scheme

CharacteristicWhat it meansWhy it matters
Baseline wanderingThe receiver averages the received signal power to form a baseline against which it decides 0 or 1. A long run of identical bits drifts this baseline.Drift causes the receiver to misread bits. A good scheme prevents it.
DC componentA constant (zero-frequency) component appears when the signal level stays unchanged for a long time.Some media — transformers, telephone lines — cannot pass DC. A scheme with a DC component cannot be used on them.
Self-synchronisationThe signal itself contains transitions that let the receiver re-align its clock with the sender's.Without it, a slight clock mismatch accumulates and the receiver reads the wrong number of bits.

The schemes

1. Unipolar NRZ

All signal levels are on one side of the time axis — either above or below it.

  • 1 → positive voltage  |  0 → zero voltage.
  • Problems: costly in power (twice the average power of a polar scheme), and it has a large DC component. Essentially obsolete, but it is asked as the baseline case.

2. Polar NRZ-L (Non-Return-to-Zero, Level)

  • The level of the voltage determines the bit. Typically 1 → negative (or high), 0 → positive (or low). State your convention.
  • Problem: a long run of 0s or 1s produces no transitions at all — so both baseline wandering and loss of synchronisation occur, and there is a DC component.

3. Polar NRZ-I (Non-Return-to-Zero, Invert)

  • The presence or absence of a transition at the start of the bit determines the bit, not the level.
  • 1 → invert (transition)  |  0 → no change.
  • Better than NRZ-L for a run of 1s (each 1 gives a transition, so synchronisation is kept), but still fails on a long run of 0s.
The NRZ-L vs NRZ-I distinction — state it exactly like this

In NRZ-L the level of the signal carries the bit; in NRZ-I the change of the signal carries the bit. NRZ-I therefore handles a long sequence of 1s well and a long sequence of 0s badly, while NRZ-L handles neither.

4. Return-to-Zero (RZ)

  • Three levels — positive, negative and zero. The signal returns to zero in the middle of every bit.
  • 1 → positive then zero; 0 → negative then zero.
  • Advantage: a transition in every bit, so synchronisation is guaranteed. Disadvantage: it uses two signal elements per bit, so it needs twice the bandwidth. That cost is why RZ was superseded by Manchester.

5. Manchester encoding

  • Combines the idea of RZ with NRZ-L: there is always a transition at the middle of the bit, and that middle transition carries the data.
  • Convention (IEEE 802.3, the one to use): 0 → high-to-low transition at mid-bit; 1 → low-to-high transition at mid-bit.
  • Advantages: self-synchronising, no DC component, no baseline wandering.
  • Disadvantage: needs twice the bandwidth of NRZ, because the signal rate is twice the data rate.
  • Used in standard 10 Mbps Ethernet (10BASE-T).

6. Differential Manchester

  • There is always a transition at the middle of the bit — but that one is used only for synchronisation. The data is carried by whether there is a transition at the start of the bit.
  • 0 → transition at the start of the bit; 1 → no transition at the start.
  • Same advantages as Manchester, and it is differential, so it survives a polarity reversal of the wires.
  • Used in Token Ring (IEEE 802.5).
Manchester vs Differential Manchester — the sentence to write

In Manchester, the mid-bit transition carries the data. In Differential Manchester, the mid-bit transition is only for synchronisation and the data is carried by the presence or absence of a transition at the beginning of the bit. If you write only one sentence about these two schemes, write that one.

7. Bipolar AMI and pseudoternary

  • Bipolar uses three levels: positive, negative and zero.
  • AMI (Alternate Mark Inversion): 0 → zero voltage; 1 → alternating positive and negative voltages. ("Mark" means 1 in telegraphy.)
  • Pseudoternary is AMI with the roles swapped: 1 → zero voltage, 0 → alternating positive and negative.
  • Advantage: no DC component, because consecutive 1s cancel each other out; and a broken alternation reveals an error. Disadvantage: a long run of 0s still loses synchronisation.

8. Scrambling: B8ZS and HDB3

The fix for AMI's long-run-of-zeros problem. Both replace a run of zeros with a deliberate violation of the alternation rule, which the receiver recognises and converts back.

SchemeRuleUsed in
B8ZS (Bipolar with 8-Zero Substitution)Eight consecutive zeros are replaced by 000VB0VB, where V is a violation (same polarity as the previous 1) and B is a normal, correct-polarity pulse.North America
HDB3 (High Density Bipolar 3-zero)Four consecutive zeros are replaced by a pattern containing a violation. Which pattern (000V or B00V) depends on the number of non-zero pulses since the last substitution — odd or even.Europe and Japan

Block coding: 4B/5B

The other approach to guaranteeing synchronisation. Block coding changes a block of m bits into a block of n bits, where n > m, adding redundancy.

  • 4B/5B: every 4-bit group is mapped to a 5-bit code chosen so that no code has more than three consecutive 0s. Combined with NRZ-I, this guarantees enough transitions.
  • Cost: 25% overhead — a 100 Mbps data rate needs a 125 Mbps signal rate. Used in 100 Mbps Fast Ethernet (100BASE-TX) and FDDI.
  • The three steps of block coding: division (into m-bit groups), substitution (m-bit to n-bit), combination (back into a stream).

Worked example — encode 0 1 0 0 1 1 0 0

Take the bit stream 01001100 and encode it four ways. Assume positive = high, negative = low, and that the signal starts at the low (negative) level.

NRZ-L (1 = low, 0 = high — state your convention):
bits  0  1  0  0  1  1  0  0
level  H  L  H  H  L  L  H  H
Transitions occur only where the bit value changes: after bits 1, 2, 4, 6.

NRZ-I (1 = invert, 0 = keep; start at low):
bit 1 = 0 → stay L
bit 2 = 1 → invert to H
bit 3 = 0 → stay H
bit 4 = 0 → stay H
bit 5 = 1 → invert to L
bit 6 = 1 → invert to H
bit 7 = 0 → stay H
bit 8 = 0 → stay H

Manchester (IEEE convention: 0 = high→low mid-bit, 1 = low→high mid-bit). Every bit has a mid-bit transition; the direction of that transition is the data:
0 → HL  |  1 → LH  |  0 → HL  |  0 → HL  |  1 → LH  |  1 → LH  |  0 → HL  |  0 → HL

Differential Manchester (0 = transition at start of bit, 1 = no transition at start; mid-bit transition always present):
bit 1 = 0 → transition at start, then mid-bit transition
bit 2 = 1 → no transition at start, then mid-bit transition
bit 3 = 0 → transition at start
bit 4 = 0 → transition at start
bit 5 = 1 → no transition at start
bit 6 = 1 → no transition at start
bit 7 = 0 → transition at start
bit 8 = 0 → transition at start

Sanity check that catches most mistakes: in both Manchester schemes every single bit must contain a mid-bit transition. If any bit in your drawing is a flat line for its whole duration, you have made an error. And in Differential Manchester, count the start-of-bit transitions — there must be exactly as many as there are 0s in the data.

Check yourself

Retrieval practice

1. In NRZ-I, a bit value of 1 is represented by:

NRZ-I encodes in the change, not the level: 1 inverts, 0 leaves the level alone. A mid-bit transition would be Manchester; a return to zero would be RZ.

2. Which scheme carries its data in the transition at the beginning of the bit?

This is the single distinction between the two Manchester schemes. Manchester: mid-bit transition = data. Differential Manchester: mid-bit transition = clock only, start-of-bit transition = data.

3. Manchester encoding requires twice the bandwidth of NRZ because:

Bandwidth is driven by the signal rate. A guaranteed mid-bit transition means two signal elements per bit, so S = N rather than N/2. Three levels describes bipolar; the 4-to-5-bit expansion describes 4B/5B block coding.

4. Bipolar AMI has no DC component because:

AMI's alternation means the positive and negative pulses average to zero, killing the DC component. What it does not fix is a long run of 0s — all at zero volts, no transitions, no synchronisation. That is exactly the gap B8ZS and HDB3 close.

5. HDB3 and B8ZS both work by:

Both are scrambling techniques: the run of zeros is replaced by a pattern containing an intentional violation of the alternation rule, which the receiver spots and reverses. B8ZS handles eight zeros, HDB3 four. Block coding (4B/5B) is the other, separate approach.

Recall without looking

Define line coding, data rate and signal rate.

Line coding converts digital data into a digital signal. Data rate (bit rate, bps) is bits per second. Signal rate (baud rate, baud) is signal elements per second: S = c × N × 1/r. The aim is to increase the data rate while decreasing the signal rate, because signal rate sets the bandwidth needed.

Name the four characteristics used to judge a line coding scheme.

Baseline wandering, DC component, self-synchronisation, and error detection/noise immunity.

Why is a DC component a problem?

Some media — transformers, telephone lines — cannot pass frequencies at or near zero, so a scheme with a DC component cannot be used on them.

NRZ-L vs NRZ-I in one sentence.

In NRZ-L the level of the signal carries the bit; in NRZ-I the change (inversion) of the signal carries the bit — 1 inverts, 0 does not.

Manchester vs Differential Manchester in one sentence.

In Manchester the mid-bit transition carries the data; in Differential Manchester the mid-bit transition provides only synchronisation and the data is carried by the presence (0) or absence (1) of a transition at the start of the bit.

State the AMI rule and its one weakness.

0 is zero voltage; 1 alternates between positive and negative. No DC component, and a broken alternation reveals an error. Weakness: a long run of 0s gives no transitions, so synchronisation is lost — fixed by B8ZS or HDB3.

What is 4B/5B and what does it cost?

A block coding scheme mapping each 4-bit group to a 5-bit code chosen so no code has more than three consecutive 0s; combined with NRZ-I it guarantees transitions. Cost: 25% overhead — 100 Mbps of data needs a 125 Mbps signal rate. Used in 100BASE-TX and FDDI.
