Ethernet

The IEEE 802 model, the Ethernet frame format field by field, MAC addressing, the minimum and maximum frame sizes and where they come from, and the four generations from 10 Mbps to 10 Gbps. The last lesson of Unit II.

Exam strategy

"Explain the Ethernet frame format" is the question — 5 to 10 marks. Draw the frame as a labelled box diagram with the byte count under every field, then one line per field. Then add the two derived facts that earn the extra marks: minimum frame 64 bytes (from the CSMA/CD round-trip rule) and maximum frame 1518 bytes. The generations table is a separate 3-mark question.

The IEEE 802 model

Ethernet is standardised as IEEE 802.3. The IEEE Project 802 split the OSI data link layer into two sublayers, and naming them is a reliable short question:

SublayerStandardResponsibilities
LLC — Logical Link ControlIEEE 802.2Flow control, error control, and part of the framing. It is common to all LAN protocols, which is the point: it gives one interface to the network layer regardless of the LAN underneath.
MAC — Media Access Control802.3 (Ethernet), 802.5 (Token Ring), 802.11 (Wi-Fi)Framing, physical addressing, and the access method — CSMA/CD for Ethernet. It is specific to each LAN.
Why the split exists

The access method changes from one LAN to another, but flow and error control do not. Putting the varying part (MAC) below the constant part (LLC) means the network layer sees the same interface whether it is running over Ethernet, Token Ring or Wi-Fi.

FieldSizePurpose
Preamble7 bytesAlternating 1s and 0s (10101010 × 7), used by the receiving system to synchronise its clock and to alert it that a frame is coming. It is added by the physical layer and is not formally part of the frame — a point worth stating, because it explains why frame-size calculations exclude it.
SFD1 byteStart Frame Delimiter, the pattern 10101011. Its last two bits are 11, breaking the alternating pattern to say "the next field is the destination address". Also added by the physical layer.
Destination address6 bytesThe MAC address of the destination station, or of the next router.
Source address6 bytesThe MAC address of the sending station.
Length / Type2 bytesIn IEEE 802.3 it is a length field (the number of bytes of data). In the original Ethernet II (DIX) format it is a type field naming the upper-layer protocol. The two are distinguished by value: ≤ 1500 means length, ≥ 1536 means type.
Data46 to 1500 bytesThe payload from the upper layer. If it is shorter than 46 bytes it must be padded up to 46.
CRC4 bytesCRC-32 error detection, covering the addresses, length/type and data fields.

The two frame-size limits — and why

Minimum and maximum Overhead = 6 + 6 + 2 + 4 = 18 bytes (addresses, length/type, CRC)
Minimum frame = 46 + 18 = 64 bytes = 512 bits
Maximum frame = 1500 + 18 = 1518 bytes
LimitReason
Minimum 64 bytesRequired by CSMA/CD. A station must still be transmitting when a collision signal returns to it, so the frame must take at least the round-trip propagation time. At 10 Mbps with a 51.2 µs slot time, that is 512 bits = 64 bytes. Frames shorter than this are padded.
Maximum 1518 bytesTwo reasons: memory was expensive when Ethernet was designed, and a very long frame monopolises the shared medium, delaying every other station unfairly.
Worked example — frame sizes

Q. An upper layer hands Ethernet 20 bytes of data. What is the transmitted frame size, and how much of it is useful? What if it hands over 1600 bytes?

Case 1 — 20 bytes. The data field must be at least 46 bytes, so 26 bytes of padding are added.
Frame = 46 + 18 = 64 bytes, of which only 20 bytes are useful data.
Efficiency = 20/64 = 31% — small frames are expensive.

Case 2 — 1600 bytes. This exceeds the 1500-byte maximum, so the upper layer must fragment it into two frames — for example 1500 + 100 bytes, giving frames of 1518 and 118 bytes.

The point to state: the padding is inserted by the MAC sublayer and removed at the receiver using the length field — which is precisely why 802.3 has a length field at all.

MAC addressing

Every station on an Ethernet has a 6-byte (48-bit) physical address, burned into its network interface card. It is written as 12 hexadecimal digits, byte by byte, separated by colons or hyphens:

A MAC address 4A:30:10:21:10:1A    — 6 bytes, 48 bits, 12 hex digits
First 3 bytes = OUI, the manufacturer's identifier  ·  Last 3 bytes = the card's serial number
TypeHow to recognise itReceived by
UnicastThe least significant bit of the first byte is 0 — so the second hex digit is even (0, 2, 4, 6, 8, A, C, E)One station only
MulticastThe least significant bit of the first byte is 1 — second hex digit oddA group of stations
BroadcastAll 48 bits are 1: FF:FF:FF:FF:FF:FFEvery station on the LAN — a special case of multicast

So 4A:30:... is unicast (A = 1010, least significant bit 0), while 47:20:... is multicast (7 = 0111, least significant bit 1). This test appears as a one-mark question.

Bridged, switched and full-duplex Ethernet

The three steps by which Ethernet outgrew its collision problem — a good closing paragraph for any Ethernet answer:

StageWhat changedEffect on collisions
Bridged EthernetA bridge divides the LAN into segments and forwards frames only where neededEach segment is a separate collision domain, so collisions fall sharply. Bandwidth per station rises.
Switched EthernetA switch gives each station its own dedicated port — effectively an N-port bridgeEach link is its own collision domain, with only two devices on it.
Full-duplex EthernetTwo separate paths, one each way, between station and switchCollisions become impossible, so CSMA/CD is no longer needed at all. Capacity doubles — 10 Mbps becomes 10 in each direction.
Collision domain vs broadcast domain — a classic short question

A collision domain is the set of devices whose transmissions can collide with one another. A broadcast domain is the set of devices that receive one another's broadcast frames.
Hubs and repeaters extend both. Bridges and switches break up collision domains but not broadcast domains. Routers break up both.

Check yourself

Retrieval practice

1. The minimum Ethernet frame size of 64 bytes is set by:

A station must still be transmitting when a collision signal returns, so the frame must last at least 2 × Tp. At 10 Mbps that is 512 bits = 64 bytes. Memory cost is the reason for the maximum, not the minimum.

2. The data field of an Ethernet frame is:

46–1500 is the data field; 64–1518 is the whole frame, which adds the 18 bytes of addresses, length/type and CRC. Keeping the two ranges apart is exactly what this question tests.

3. Which MAC address is a multicast address?

Check the least significant bit of the first byte — that is, whether the second hex digit is odd. 47: the 7 is odd → multicast. 4A, 02 and B4 all end in even digits → unicast. Broadcast would be all FFs.

4. Which device breaks up a broadcast domain?

Hubs and repeaters extend both domains. Bridges and switches split collision domains but pass broadcasts along, so the broadcast domain stays whole. Only a router — a layer-3 device — stops broadcasts.

5. In full-duplex switched Ethernet, CSMA/CD is:

With separate paths in each direction between station and switch, there is nothing to collide with, so the access method is redundant and capacity doubles. 10 Gigabit Ethernet abandons CSMA/CD entirely for this reason.

6. In the IEEE 802 model, the access method belongs to which sublayer?

MAC holds framing, physical addressing and the access method — the parts that differ between 802.3, 802.5 and 802.11. LLC holds flow and error control, which are the same everywhere, giving the network layer one consistent interface.

Recall without looking

Name the two data link sublayers of IEEE 802 and their responsibilities.

LLC (802.2) — flow control, error control and part of framing; common to all LANs, giving the network layer one interface. MAC (802.3, 802.5, 802.11) — framing, physical addressing and the access method; specific to each LAN.

Draw and label the Ethernet frame with byte counts.

Preamble 7 | SFD 1 | Destination address 6 | Source address 6 | Length/Type 2 | Data 46–1500 | CRC 4. Preamble and SFD are added by the physical layer and are not formally part of the frame.

What are the preamble and SFD for?

The preamble is 7 bytes of alternating 1s and 0s that let the receiver synchronise its clock and alert it that a frame is arriving. The SFD is one byte, 10101011, whose final two 1s break the pattern to signal that the destination address follows.

State the minimum and maximum frame sizes and the reason for each.

Minimum 64 bytes (46 data + 18 overhead), required by CSMA/CD so a frame lasts at least the round-trip propagation time — shorter payloads are padded. Maximum 1518 bytes (1500 + 18), because memory was costly and a long frame would monopolise the shared medium.

How do you tell unicast, multicast and broadcast MAC addresses apart?

Look at the least significant bit of the first byte: 0 → unicast (second hex digit even), 1 → multicast (second hex digit odd). Broadcast is all 48 bits set: FF:FF:FF:FF:FF:FF.

Name the four generations of Ethernet with their rates and standards.

Standard Ethernet 10 Mbps (802.3), Fast Ethernet 100 Mbps (802.3u), Gigabit Ethernet 1 Gbps (802.3z/ab), 10 Gigabit Ethernet 10 Gbps (802.3ae, full-duplex only, CSMA/CD abandoned).

How do you read the name 10BASE5?

10 = data rate in Mbps; BASE = baseband, the digital signal sent directly without modulation; 5 = the maximum segment length in hundreds of metres, so 500 m. 10BASE-T uses T for twisted pair, 10BASE-F for fibre.

Which devices break collision domains, and which break broadcast domains?

Hubs and repeaters break neither — they extend both. Bridges and switches break collision domains but not broadcast domains. Routers break both.
