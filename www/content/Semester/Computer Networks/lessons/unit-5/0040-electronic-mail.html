Electronic Mail

The three components, the push-versus-pull split that explains why three protocols are needed, SMTP, POP3 and IMAP4, and MIME. The last application-layer lesson before the security half.

Exam strategy

"Explain the architecture of e-mail" or "Compare SMTP, POP3 and IMAP" — 5 to 10 marks. The single insight that organises the whole answer is push versus pull: SMTP pushes, POP and IMAP pull. Draw the sender-to-receiver diagram showing where each protocol operates, and the answer writes itself. MIME is a separate 3-mark question — know what problem it solves.

Why three protocols and not one — the key idea

SMTP is a push protocol: the sender initiates the transfer. That works for the first two hops, where the sender has a message and wants it delivered onward.

The last hop cannot be a push, because the recipient's machine may be switched off, may be behind a firewall, or may not have a fixed address. So the last hop must be a pull: the recipient asks their own mail server for mail whenever they are ready. That is why POP3 and IMAP4 exist and why SMTP alone is not enough. Say this sentence; it is the whole architecture in one line.

The three phases

An SMTP session 1. Connection establishment — TCP connects to port 25; the server sends code 220 (service ready); the client sends HELO / EHLO; the server replies 250 (OK).
2. Message transfer — MAIL FROM (the sender), RCPT TO (each recipient, one command each), DATA, then the message, ended by a line containing only a full stop.
3. Connection termination — QUIT, and the server replies 221 (closing).

Two details that are asked: a separate RCPT TO is sent for each recipient, so the server can accept some and reject others; and the message body ends with a line containing a single dot, which is why a line of the message that is itself a single dot must be escaped.

Mail relaying and mail gateways

  • Relaying — an SMTP server forwarding mail towards another server rather than delivering it locally. Open relays (which relay for anyone) are now closed everywhere, because spammers abused them.
  • Mail gateway — a relay that also translates between different mail formats, connecting an SMTP world to a non-SMTP one.

MIME — Multipurpose Internet Mail Extensions

The problem: SMTP was designed for 7-bit ASCII text only. It cannot carry an image, a PDF, an executable, or text in a language whose characters are not in ASCII.

What MIME does MIME is not a mail protocol and does not replace SMTP. It is a supplementary protocol that converts non-ASCII data into ASCII at the sender and back again at the receiver, so that ordinary SMTP can carry it unchanged.

That framing — a converter wrapped around SMTP rather than a replacement for it — is the point examiners look for.

MIME headerPurpose
MIME-VersionThe version, currently 1.1
Content-TypeThe type and subtype of the data — text/plain, text/html, image/jpeg, audio/mpeg, video/mp4, application/pdf, multipart/mixed
Content-Transfer-EncodingHow the data was encoded into ASCII — 7bit, 8bit, binary, base64 (binary to printable ASCII, expanding by about 33%), quoted-printable (mostly ASCII with occasional non-ASCII characters escaped)
Content-IdA unique identifier for the message part
Content-DescriptionA human-readable description of what the part contains

Base64 versus quoted-printable is a common sub-question: base64 for data that is mostly non-ASCII (images, executables), quoted-printable for data that is mostly ASCII with a few special characters (European-language text). Choosing the wrong one wastes space rather than failing outright.

The one-line distinction

POP3 downloads and (by default) deletes; IMAP4 leaves the mail on the server and synchronises. Everything else in the table follows from that: multi-device support, server search, folders and partial download are all consequences of the mail staying on the server.

Web-based mail

In webmail (Gmail, Outlook.com), the last hop uses neither POP3 nor IMAP4 — it uses HTTP. The mail server also runs a web server; the browser fetches messages over HTTP and the mail never leaves the provider's storage. SMTP is still used for the first two hops. One line on this is a good modern addition, and it shows the architecture is understood rather than memorised.

Worked walkthrough — one message end to end

Q. Trace an e-mail with a JPEG attachment from alice@a.com to bob@b.com, naming the protocol and port at each step.

  1. Alice's UA prepares the message. The JPEG is not ASCII, so MIME encodes it with base64 and adds Content-Type: image/jpeg and Content-Transfer-Encoding: base64. The message is now entirely 7-bit ASCII.
  2. UA → a.com's mail server using SMTP, port 25 — a push. Commands: HELO, MAIL FROM, RCPT TO, DATA, the message, a lone dot, QUIT.
  3. a.com's server looks up b.com's mail server by asking DNS for the MX record of b.com.
  4. a.com → b.com using SMTP, port 25 — a push again. The message is placed in Bob's mailbox.
  5. Bob's UA ← b.com using IMAP4 port 143 (or POP3 port 110) — a pull, whenever Bob chooses to check.
  6. Bob's UA decodes the base64 back into the original JPEG using the MIME headers.

Three things worth pointing out in an answer: SMTP appears twice and always pushes; DNS is required in the middle, via the MX record, which is why Lesson 36 comes first; and MIME encodes at the very start and decodes at the very end, with everything in between handling plain ASCII.

Check yourself

Retrieval practice

1. SMTP cannot be used for the final hop to the recipient because:

A push requires the destination to be reachable and listening. A recipient's machine may be off, mobile or firewalled, so the last hop must be a pull the recipient initiates — which is exactly why POP3 and IMAP4 exist.

2. MIME's role is to:

MIME is a supplementary protocol, not a replacement: it encodes at the sender and decodes at the receiver, leaving SMTP to move plain ASCII as it always did. It provides no encryption at all.

3. The principal advantage of IMAP4 over POP3 is that IMAP4:

Server-side storage is the root difference, and multi-device sync, server search, folders and partial download all follow from it. Offline working is POP3's advantage, since the mail is already local.

4. Which SMTP command is sent once per recipient?

One RCPT TO per recipient, so the server can accept some and reject others individually. MAIL FROM names the single sender, DATA introduces the body, and HELO opens the session once.

5. Base64 rather than quoted-printable should be used when the data is:

Base64 expands everything by about a third but handles arbitrary binary. Quoted-printable leaves ASCII untouched and escapes only the occasional special character, so it is far more compact for European-language text. The wrong choice wastes space rather than failing.

6. Before delivering to another domain, a sending mail server must consult DNS for:

MX names the mail exchange server for a domain, with a preference value so several can be ranked. PTR does reverse lookups, CNAME defines aliases, and SOA carries zone parameters.

Recall without looking

Name the three e-mail components and the protocol each uses.

User Agent (UA) — composing and reading. Message Transfer Agent (MTA) — moves mail across the network, using SMTP. Message Access Agent (MAA) — retrieves mail from the mailbox, using POP3 or IMAP4.

Trace the path of an e-mail, naming the protocol at each hop.

Sender's UA —SMTP→ sender's mail server —SMTP→ receiver's mail server ←POP3/IMAP4— receiver's UA. The first two hops push; the last one pulls.

Why can the last hop not use SMTP?

SMTP is a push protocol, requiring the destination to be reachable and listening. The recipient's machine may be switched off, mobile or firewalled, so the last hop must be a pull that the recipient initiates whenever they are ready.

Describe the three phases of an SMTP session.

Connection establishment — TCP to port 25, server sends 220, client sends HELO/EHLO, server replies 250. Message transfer — MAIL FROM, one RCPT TO per recipient, DATA, the message, ended by a line containing only a full stop. Termination — QUIT, server replies 221.

What is MIME and what problem does it solve?

SMTP handles 7-bit ASCII only, so it cannot carry images, PDFs, executables or non-ASCII text. MIME is a supplementary protocol — not a replacement — that converts non-ASCII data into ASCII at the sender and back at the receiver, so ordinary SMTP carries it unchanged.

Name the five MIME headers.

MIME-Version, Content-Type (type/subtype), Content-Transfer-Encoding (7bit, 8bit, binary, base64, quoted-printable), Content-Id, Content-Description.

Give six differences between POP3 and IMAP4.

Port 110 vs 143; mail downloaded and usually deleted vs kept on the server; poor vs excellent multi-device support; no partial download vs partial download of headers or parts; no server-side search or folders vs both supported; simple with little server storage vs more complex needing substantial storage. POP3 works better offline.

Which protocol does webmail use for the last hop?

HTTP — the mail server also runs a web server and the browser fetches messages over HTTP, so the mail never leaves the provider. SMTP is still used for the first two hops.
