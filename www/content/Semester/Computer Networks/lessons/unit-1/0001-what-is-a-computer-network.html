What a Computer Network Is

Definitions, the five components, the four characteristics of data communication, the three network criteria, and the performance numericals. The definitions here are the ones every later answer in this subject is built out of.

Exam strategy

Three questions come out of this lesson. (1) "Define data communication and list its components" — 5 marks, pure recall, draw the five-box diagram. (2) "What are the criteria of a good network?" — 5 marks, three headings with sub-points. (3) A latency numerical — propagation + transmission delay. Learn the two formulas and you cannot lose those marks.

Data communication

Data communication is the exchange of data between two devices via some form of transmission medium such as a wire cable.

Write that sentence verbatim. It is Forouzan's definition, and Forouzan is the book this syllabus is built from. Two conditions are hidden inside it and are worth a line each: the devices must be part of a communication system made of a combination of hardware and software, and the communication is only successful if the data arrives at the correct destination, accurately, and in time.

The five components

ComponentWhat it isExample
1. MessageThe information (data) to be communicatedText, numbers, pictures, audio, video
2. SenderThe device that sends the messageComputer, workstation, telephone, video camera
3. ReceiverThe device that receives the messageComputer, workstation, telephone, television
4. Transmission mediumThe physical path the message travels alongTwisted pair, coaxial cable, fibre optic, radio waves
5. ProtocolThe set of rules governing the communicationTCP/IP, HTTP — without an agreed protocol the two devices are connected but not communicating
The line that earns the last mark

Finish the components answer with: "Two devices connected without a common protocol are like a person speaking Japanese to a person who understands only French — connected, but not communicating." That is the textbook's own analogy and examiners recognise it.

The four characteristics of data communication

The effectiveness of a data communication system depends on four fundamental characteristics. Learn them as a four-item list — this is a standard 4- or 5-mark question, one mark per item.

CharacteristicMeaningWhat breaks it
DeliveryThe system must deliver data to the correct destination — the intended device or user, and only that one.Wrong address, faulty routing
AccuracyThe system must deliver the data accurately. Data altered in transit and left uncorrected is unusable.Noise on the line, bit errors
TimelinessThe system must deliver data in time. For audio and video this means real-time delivery — delivered as produced, in the same order, without significant delay. This is called real-time transmission.Congestion, long queues
JitterThe variation in packet arrival time. Uneven delay between packets of a video or audio stream produces uneven quality even if nothing is lost.Variable queuing delay at routers

The jitter example that always appears: video packets sent every 30 ms. If some arrive 30 ms apart and others 40 ms apart, the video is uneven. Nothing was lost and nothing was corrupted — the spacing was wrong. That is jitter, and it is why it is listed separately from timeliness.

What a network is

A network is a set of devices (often called nodes) connected by communication links. A node may be a computer, printer, or any other device capable of sending and/or receiving data generated by other nodes on the network.

The three network criteria

Asked as "What are the criteria a network must meet?" or "What makes a good network?" Three headings, sub-points under each.

CriterionMeasured by / consists of
PerformanceTransit time and response time. Depends on: number of users, type of transmission medium, capability of connected hardware, efficiency of the software. Evaluated by throughput and delay — and these two pull against each other: sending more data raises throughput but also congestion, and therefore delay.
ReliabilityFrequency of failure, time taken to recover from a failure, and the network's robustness in a catastrophe.
SecurityProtecting data from unauthorised access, protecting data from damage and development, and implementing policies and procedures for recovery from breaches and data loss.

Performance: bandwidth, throughput, latency, jitter

These four terms are constantly confused in answer scripts, and the confusion is easy to avoid.

TermDefinitionUnit
Bandwidth (in hertz)The range of frequencies a channel can carryHz
Bandwidth (in bits per second)The number of bits a channel or link can transmit per second — its capacitybps
ThroughputHow fast data actually passes through a point. Always ≤ bandwidth.bps
Latency (delay)How long it takes an entire message to completely arrive at the destination from the moment the first bit is sent outseconds
JitterVariation in delay between packetsseconds
Bandwidth vs throughput in one sentence

Bandwidth is the road's number of lanes; throughput is how many cars actually get through per hour. A highway designed for 1000 cars/min might pass only 800 because of an accident. Bandwidth is potential, throughput is achieved.

The four components of latency

Latency Latency = Propagation time + Transmission time + Queuing time + Processing delay
Propagation time Propagation time = Distance ÷ Propagation speed
Transmission time Transmission time = Message size ÷ Bandwidth
Bandwidth-delay product BDP = Bandwidth × Delay   (the number of bits that can fill the link)

Propagation speed in a wire is usually taken as 2 × 108 m/s unless the question states otherwise; in free space it is 3 × 108 m/s. Say which one you assumed.

Worked numerical

Q. A message of 100,000 bits is sent over a 5 Mbps link of length 2000 km. Propagation speed is 2 × 108 m/s. Find the propagation time, the transmission time, the total latency (ignore queuing and processing), and the bandwidth-delay product.

Propagation time = distance / speed
= 2,000,000 m ÷ (2 × 108 m/s) = 0.01 s = 10 ms

Transmission time = message size / bandwidth
= 100,000 bits ÷ (5 × 106 bps) = 0.02 s = 20 ms

Total latency = 10 ms + 20 ms = 30 ms

Bandwidth-delay product = bandwidth × propagation delay
= (5 × 106) × 0.01 = 50,000 bits — the link can hold 50,000 bits "in flight" at once.

Sanity check: the message (100,000 bits) is larger than the bandwidth-delay product (50,000 bits), so transmission time dominates. That matches: 20 ms > 10 ms. If your two numbers ever disagree with this comparison, you have made an arithmetic slip.

The trap in every latency numerical

Propagation time does not depend on the message size. Transmission time does not depend on the distance. Students routinely divide the wrong pair. Write the two formulas at the top of your answer before substituting anything.

Applications of computer networks

A quick list question. Group them so the answer looks organised rather than random:

  • Resource sharing — printers, files, storage and programs shared among many users, regardless of physical location.
  • Communication — e-mail, instant messaging, VoIP, video conferencing.
  • Business — client-server applications, e-commerce, B2B transactions, cloud services.
  • Information access — the World Wide Web, remote databases, online education.
  • Reliability through replication — files copied on two or three machines, so one failure does not lose the data.
  • Cost saving and scalability — many small computers sharing a server instead of one mainframe; capacity grown incrementally.
  • Distributed computing — one task split across many machines.

Protocols and standards

A protocol is a set of rules that govern data communication. It defines what is communicated, how it is communicated, and when it is communicated. Its three key elements:

ElementMeaningExample
SyntaxThe structure or format of the data — the order in which it is presentedThe first 8 bits are the sender's address, the next 8 the receiver's, the rest the message
SemanticsThe meaning of each section of bits — how a pattern is to be interpreted and what action is taken on itDoes this address field mean the route to take, or the final destination?
TimingWhen data should be sent and how fast it can be sentA 100 Mbps sender talking to a 1 Mbps receiver will overwhelm it and lose data

Standards are agreed rules that make interoperability possible. Two kinds:

  • De facto ("by fact") — standards that have simply been adopted through widespread use, never formally approved. Example: the original TCP/IP suite.
  • De jure ("by law") — standards legislated by an officially recognised body. Example: the IEEE 802 series.

Check yourself

Retrieval practice

1. Video packets are sent every 30 ms but arrive 30, 40, 30, 45 ms apart. Nothing is lost. Which characteristic has failed?

Nothing was lost or corrupted, so delivery and accuracy are fine. The spacing varied — that is precisely the definition of jitter, and precisely why it is listed apart from timeliness.

2. A link's bandwidth is 10 Mbps but measured data flow is 6 Mbps. The 6 Mbps figure is the:

Bandwidth is capacity, throughput is what actually gets through. Throughput can never exceed bandwidth, so any figure below the rated capacity is throughput.

3. Doubling the length of the cable while keeping everything else fixed will double the:

Distance appears only in the propagation formula. Transmission time is message size over bandwidth — the cable could be a metre or a thousand kilometres and it would not change.

4. "The first 8 bits of the frame are the sender's address" is a statement about which element of a protocol?

Syntax is structure and order. Semantics would be the follow-up question — what that address means, e.g. the final destination or the next hop.

5. The IEEE 802.3 Ethernet standard is an example of a:

IEEE is an officially recognised standards body, so anything it approves is de jure ("by law"). De facto standards are those that spread by use alone before any body blessed them.

Recall without looking

Define data communication.

The exchange of data between two devices via some form of transmission medium such as a wire cable. The devices must be part of a communication system made of a combination of hardware and software.

List the five components of a data communication system.

Message, sender, receiver, transmission medium, protocol.

Name the four characteristics on which the effectiveness of data communication depends.

Delivery, accuracy, timeliness, jitter.

State the three network criteria and what each is measured by.

Performance (transit time, response time; measured by throughput and delay). Reliability (frequency of failure, recovery time, robustness in a catastrophe). Security (protection from unauthorised access, protection from damage, policies for recovery).

Write the propagation time and transmission time formulas.

Propagation time = distance ÷ propagation speed. Transmission time = message size ÷ bandwidth. Latency = propagation + transmission + queuing + processing.

What are the three elements of a protocol?

Syntax (format and order of the data), semantics (meaning of each section of bits and the action taken), timing (when data is sent and how fast).

Difference between de facto and de jure standards?

De facto = "by fact", adopted through widespread use without formal approval (original TCP/IP). De jure = "by law", legislated by an officially recognised body (IEEE 802 series).
