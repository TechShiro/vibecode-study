Network Topologies

Mesh, star, bus, ring, tree and hybrid — each with its link count, its advantages, its disadvantages, and the one formula that turns this descriptive topic into a numerical you can score on with certainty.

Exam strategy

Two questions live here. (1) "Explain any four network topologies with diagrams, advantages and disadvantages" — 10 marks, and the single most-asked question in Unit I. Draw every diagram; a topology answer without diagrams loses marks no matter how good the prose is. (2) The mesh link formula — n(n − 1)/2. Small, mechanical, and it appears as a 2-mark numerical constantly.

What topology means

Topology is the way in which a network is laid out physically or logically — the geometric representation of the relationship of all the links and linking devices (nodes) to one another.

TypeMeaning
Physical topologyHow the devices and cables are actually arranged in space
Logical topologyHow the data actually flows through the network, regardless of the physical layout

They need not match, and that mismatch is a favourite one-mark question: modern Ethernet is physically a star (every machine cabled to a central switch) but was logically a bus when hubs were used, because every frame reached every device.

1. Mesh topology

Every device has a dedicated point-to-point link to every other device. The link carries traffic only between the two devices it connects.

Mesh — number of links (duplex) Number of links = n(n − 1) / 2
Mesh — ports (I/O) per device Ports per device = n − 1     Total ports = n(n − 1)

If the links are simplex (one direction each), the count doubles to n(n − 1). Read the question — if it does not say, assume duplex and state that you did.

AdvantagesDisadvantages
Dedicated links mean no traffic sharing and no congestionHuge cabling and I/O port requirement — grows as n²
Robust — a failed link does not disable the whole system, traffic reroutesInstallation and reconnection are difficult
Privacy and security — a message travels on a dedicated line, so no other device can see itThe sheer bulk of wiring can exceed the space available (walls, ceilings, floors)
Fault identification and isolation are easy — traffic can be routed around a suspect linkVery high cost of hardware — every device needs n − 1 ports

Where it is actually used: a mesh's cost usually confines it to backbones — for example, the connections between regional telephone exchanges.

2. Star topology

Every device has a dedicated point-to-point link only to a central controller, usually a hub or a switch. Devices are not directly linked to each other. To send data, a device sends it to the controller, which relays it to the destination.

Star — counts Number of links = n     Ports per device = 1     Ports on the hub = n
AdvantagesDisadvantages
Cheaper than mesh — each device needs one link and one portThe central hub is a single point of failure — if it dies, the whole network dies
Easy to install and reconfigure — add or remove a device by changing one cableMore cable is needed than in bus or ring, because every device runs its own line back to the hub
Robust — a broken link affects only that one devicePerformance depends entirely on the capacity of the hub
Easy fault identification — the hub can monitor every link

Where it is actually used: the dominant topology of modern LANs — every Ethernet network built around a switch is a star.

3. Bus topology

A multipoint topology, unlike the previous two. One long cable, the backbone, links all the devices. Nodes connect to it by drop lines and taps. A terminator at each end absorbs the signal so it does not reflect back.

Bus — counts One backbone cable + n drop lines     Ports per device = 1

Signal strength falls as it travels along the cable and passes each tap, so there is a limit on the number of taps and the distance between them. This is the reason bus networks have a hard size ceiling.

AdvantagesDisadvantages
Easy installation — one backbone laid along the most efficient pathDifficult reconnection and fault isolation
Uses the least cabling of any topologyA fault or break in the backbone stops all transmission, even between devices on the same side of the break
Cheap for small networksSignal reflection at the taps degrades quality; adding new devices is limited
Only one device can transmit at a time — collisions occur, so a MAC protocol such as CSMA/CD is needed

Where it was used: early Ethernet LANs — 10BASE-5 (Thicknet) and 10BASE-2 (Thinnet). Largely obsolete now.

4. Ring topology

Each device has a dedicated point-to-point connection only to the two devices on either side of it. A signal passes around the ring in one direction, device to device, until it reaches its destination. Each device has a repeater: when it receives a signal intended for another device, it regenerates the bits and passes them on.

Ring — counts Number of links = n     Ports per device = 2 (one in, one out)
AdvantagesDisadvantages
Easy to install and reconfigure — adding or removing a device changes only two connectionsUnidirectional traffic — a break in the ring can disable the entire network
Fault isolation is simple — if a device does not receive a signal within a set period, it raises an alarmData must pass through every intermediate node, adding delay
No collisions — access is controlled by a tokenMaximum ring length and number of devices are limited

The break problem is solved by a dual ring, which adds a second ring running in the opposite direction as a backup. FDDI and SONET both use this. Mentioning it is worth a mark.

5. Tree (hierarchical) topology

A variation of the star: multiple star networks connected to a central backbone or root hub in a hierarchy of levels. Also called a hierarchical topology.

  • Advantages: supports expansion better than a plain star, groups can be isolated and prioritised, and fault identification is easy because the hierarchy narrows the search.
  • Disadvantages: heavily dependent on the root hub — if the backbone fails, the whole network segments; more cabling than a bus; harder to configure than a star.

6. Hybrid topology

A combination of two or more different topologies — for example a star backbone with each of its nodes being a separate bus or ring network. Nearly every real large network is a hybrid.

  • Advantages: flexible, scalable, and each part can use the topology that suits it best; a fault in one section can be isolated from the rest.
  • Disadvantages: complex to design and manage, and expensive.

Worked numerical 1

Q. Eight devices are connected in a mesh topology with duplex links. How many links are required, and how many I/O ports does each device need?

Links = n(n − 1)/2 = 8 × 7 / 2 = 56 / 2 = 28 links

Ports per device = n − 1 = 7 ports

Total ports in the network = 8 × 7 = 56

Sanity check: total ports must be exactly twice the number of links, because every duplex link has two ends. 28 × 2 = 56. ✓

Compare: the same eight devices in a star need 8 links and 1 port each. That gap — 28 versus 8 — is why mesh is rare and star is everywhere. Writing this comparison line earns marks in a "compare topologies" answer.

Worked numerical 2 — the formula run backwards

Q. A mesh network has 66 duplex links. How many devices does it have?

n(n − 1)/2 = 66  →  n(n − 1) = 132

Solve n² − n − 132 = 0  →  (n − 12)(n + 11) = 0  →  n = 12 or n = −11

A count of devices cannot be negative, so n = 12 devices.

Faster way in an exam: you are looking for two consecutive integers whose product is 132. 11 × 12 = 132, so n = 12. Do not set up the quadratic unless the numbers are ugly.

Sanity check: 12 × 11 / 2 = 66. ✓

Two facts that separate the topologies in one line each

Bus is the only multipoint topology — every other one is built from point-to-point links. Mesh is the only one with no single point of failure — star dies with its hub, bus dies with its backbone, ring dies with any break.

Check yourself

Retrieval practice

1. Six devices are fully connected in a mesh with duplex links. The number of links is:

n(n−1) = 30 is the count for simplex links, and also the total number of I/O ports. For duplex links, halve it: 15. Read the question for the word "duplex" or "simplex".

2. Which topology is the only multipoint one among mesh, star, bus and ring?

Star and ring look shared but are built entirely from dedicated point-to-point links. Only in a bus does one physical medium genuinely carry traffic for many devices at once — which is also why bus needs a MAC protocol and the others do not.

3. In a star topology, the failure of one connecting cable will:

Star's robustness is exactly this: one cable, one casualty. Its weakness is the hub — if the hub fails, everything fails. Keep the two cases straight, because questions test the difference.

4. A dual ring is used mainly to solve which problem?

Ring traffic is unidirectional, so one break stops everything. A second ring running the opposite way gives an alternative path. FDDI and SONET both do this.

5. Modern switch-based Ethernet is best described as:

Every machine has its own cable to a central switch — that is a star. Historically, when the centre was a hub rather than a switch, it was logically a bus, because every frame still reached every device. Physical and logical topology can differ.

Recall without looking

Define topology, and distinguish physical from logical.

Topology is the geometric representation of the relationship of all the links and nodes to one another. Physical topology = how devices and cables are actually arranged. Logical topology = how the data actually flows. They can differ — hub-based Ethernet was a physical star but a logical bus.

Mesh: links, ports and the two forms of the formula.

Duplex links = n(n−1)/2. Simplex links = n(n−1). Ports per device = n−1. Total ports = n(n−1), which is always twice the number of duplex links.

Give two advantages and two disadvantages of mesh.

Advantages: dedicated links so no congestion; robust, since one link failure does not stop the system; privacy and security; easy fault isolation. Disadvantages: cabling and ports grow as n²; installation and reconnection are difficult; the bulk of wiring may not fit; very high cost.

What is the single point of failure in star, bus and ring?

Star — the central hub or switch. Bus — the backbone cable; a break halts all transmission. Ring — any break, since traffic is unidirectional, unless a dual ring is used.

Why does a bus topology need terminators?

To absorb the signal at each end of the backbone so it is not reflected back along the cable and does not interfere with subsequent transmissions.

What is a hybrid topology, with one example?

A combination of two or more topologies — for example a star backbone where each node is itself a separate bus or ring network. Flexible and scalable, but complex and costly to design and manage.
