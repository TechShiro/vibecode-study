The OSI Reference Model

Seven layers, their functions, their PDUs, their devices and their protocols — plus encapsulation. This is the largest single question in Unit I and the model every later unit is organised around.

Exam strategy

"Explain the OSI reference model with a neat diagram" is a 10-mark question and near-certain. Structure it as: definition → why layering → the seven-layer diagram → two or three functions per layer → encapsulation. Do not write a paragraph per layer; write a heading plus bullets per layer. And draw the stack twice, sender and receiver, with the arrow going down one side and up the other — that diagram alone is worth two marks.

What OSI is

OSI stands for Open Systems Interconnection. It is a reference model introduced by the ISO (International Organization for Standardization) in 1984, which describes how information moves from an application on one computer to an application on another, through a network.

Two things it is not, and both are worth stating in the exam:

  • It is not a protocol. It is a model for understanding and designing network architectures. Protocols such as TCP and IP live inside the layers; OSI itself defines none of them.
  • "Open system" means a set of protocols that allows any two different systems to communicate regardless of their underlying architecture — the whole point is vendor independence.

Why layering at all

A short "advantages of layered architecture" question appears often. Four reasons:

  • Divides a complex problem into smaller, manageable pieces — each layer solves one well-defined part.
  • Modularity and independence — a layer can be changed or replaced entirely without touching the layers above or below, as long as the interface between them stays the same.
  • Standardisation — layers give clear boundaries at which standards can be defined, so equipment from different vendors interoperates.
  • Simplified troubleshooting and teaching — a fault can be traced to a layer and dealt with there.

Mnemonics

Top-down (7→1): All People Seem To Need Data Processing — Application, Presentation, Session, Transport, Network, Data link, Physical.
Bottom-up (1→7): Please Do Not Throw Sausage Pizza Away.
PDU order (7→1): Data, Data, Data, Segment, Packet, Frame, Bit. Only the bottom four have distinct names — that fact is itself a common one-mark question.

Layer by layer

Layer 1 — Physical

Coordinates the functions required to transmit a raw bit stream over a physical medium. It deals with the mechanical and electrical specifications of the interface and medium.

  • Physical characteristics of interfaces and medium — connectors, pins, cable type.
  • Representation of bits — encoding 0s and 1s into signals (voltage levels, light pulses).
  • Data rate — the number of bits sent per second, and therefore the duration of a bit.
  • Synchronisation of bits — sender and receiver clocks must be synchronised at the bit level.
  • Line configuration — point-to-point or multipoint.
  • Physical topology — how devices are connected: mesh, star, bus, ring.
  • Transmission mode — simplex, half-duplex or full-duplex.

Layer 2 — Data Link

Transforms the raw transmission facility into a reliable link. It makes the physical layer appear error-free to the network layer above. It works hop to hop — node to adjacent node.

  • Framing — divides the stream of bits from the network layer into manageable units called frames.
  • Physical addressing — adds a header with the MAC address of the sender and receiver. If the frame is destined for a system outside the sender's network, the receiver address is that of the next device, i.e. the router — not the final destination.
  • Flow control — prevents a fast sender from overwhelming a slow receiver.
  • Error control — detects and retransmits damaged or lost frames, using a trailer added to the frame. Also prevents duplication.
  • Access control — when several devices share one link, decides which one may transmit (the MAC sublayer).

Layer 3 — Network

Responsible for source-to-destination (end-to-end) delivery of a packet, possibly across multiple networks. This is the layer that makes internetworking possible.

  • Logical addressing — adds a header containing the IP addresses of sender and receiver. Physical addressing (layer 2) handles addressing within one network; when a packet crosses a network boundary, logical addressing is needed.
  • Routing — when independent networks are connected to form an internetwork, the connecting devices (routers) choose the path to the destination.
  • Fragmentation — splitting packets that are too large for the next network's MTU.
  • Congestion control — managing traffic load in the subnet.
The distinction examiners love

The data link layer delivers hop to hop; the network layer delivers source to destination; the transport layer delivers process to process. Write these three lines together and you have answered half of any "compare the layers" question.

Layer 4 — Transport

Responsible for process-to-process delivery of the entire message. Note the difference: the network layer gets individual packets to the right computer; the transport layer gets the whole message to the right process on that computer, in order and intact.

  • Service-point (port) addressing — the header carries a port number so the message reaches the correct process, not just the correct machine.
  • Segmentation and reassembly — the message is divided into segments, each with a sequence number; these numbers let the receiver reassemble correctly and identify lost segments.
  • Connection control — can be connectionless (each segment independent, as in UDP) or connection-oriented (a connection is established first, as in TCP).
  • Flow control — end to end, rather than the data link layer's single-link flow control.
  • Error control — end to end; ensures the entire message arrives without error, with retransmission on failure.

Layer 5 — Session

The network dialog controller. It establishes, maintains and synchronises the interaction between communicating systems.

  • Dialog control — allows two processes to enter into a dialog, in half-duplex or full-duplex mode.
  • Synchronisation — adds checkpoints to a stream of data. If a 2000-page file is being sent with a checkpoint every 100 pages and a crash occurs during page 523, only pages 501 onward need resending. This example is worth writing out; it is the standard illustration.
  • Session establishment, maintenance and termination.

Layer 6 — Presentation

Concerned with the syntax and semantics of the information exchanged between two systems. Sometimes called the translation layer.

  • Translation — converts between the sender's and receiver's data representations, via a common format (e.g. ASCII to EBCDIC).
  • Encryption and decryption — transforms data into an unreadable form for privacy in transit, and back at the receiver.
  • Compression and decompression — reduces the number of bits to be transmitted; especially important for text, audio and video.

Layer 7 — Application

Enables the user — human or software — to access the network. It provides the interfaces and support for services such as e-mail, remote file access and transfer, and shared database management.

  • Network virtual terminal — a software version of a physical terminal, allowing a user to log on to a remote host.
  • File transfer, access and management (FTAM) — accessing, retrieving and managing files on a remote computer.
  • Mail services — e-mail forwarding and storage.
  • Directory services — distributed database access for global information about objects and services.

Encapsulation and decapsulation

The mechanism that ties the seven layers together, and a guaranteed sub-question.

As data passes down the sender's stack, each layer adds its own header (and the data link layer also adds a trailer) containing the control information that layer's counterpart on the receiving machine needs. Adding this control information is called encapsulation. Each layer treats everything handed to it from above as pure data, whether or not it already contains headers.

Encapsulation, going down the stack Data → [H4 | Data] = Segment → [H3 | H4 | Data] = Packet
→ [H2 | H3 | H4 | Data | T2] = Frame → Bits on the wire

At the receiver the reverse happens: each layer strips off the header its counterpart added, acts on the control information in it, and passes the rest up. This is decapsulation.

Two supporting terms:

  • Peer-to-peer process — layer n on the sender communicates logically with layer n on the receiver. Physically the data still travels all the way down and back up, but each layer behaves as though it were talking directly to its peer.
  • Interface — between each pair of adjacent layers there is an interface defining what information and services the lower layer must provide to the upper. Clean interfaces are what allow one layer to be replaced without disturbing the others.

Grouping the layers

A neat two-line addition to any OSI answer:

Four traps that cost marks every year
  • Encryption is the presentation layer (layer 6), not the application layer.
  • Dialog control and checkpoints are the session layer (layer 5), not the transport layer.
  • Flow control and error control exist at two layers — data link (per hop) and transport (end to end). If the question asks "which layer", check whether it says hop-to-hop or end-to-end.
  • Devices: hub and repeater = layer 1; switch, bridge and NIC = layer 2; router = layer 3. Naming the wrong layer for a router is the single most common slip.

Check yourself

Retrieval practice

1. Which layer is responsible for adding the logical (IP) address of the source and destination?

Layer 2 adds physical (MAC) addresses, which only work within one network. Layer 3 adds logical (IP) addresses, which is what lets a packet cross network boundaries. Layer 4 adds port numbers.

2. A 2000-page file transfer crashes at page 523 and resumes from page 501. Which layer's service made this possible?

Checkpoints inserted into a data stream are the session layer's synchronisation service. Transport sequence numbers reorder segments; they do not create resumable checkpoints in a long transfer.

3. The PDU at the data link layer is called a:

Segment (4), packet (3), frame (2), bit (1). The data link layer is also the only layer that adds a trailer as well as a header, because that is where its error-checking field sits.

4. Encryption and compression are services of which layer?

Presentation handles syntax and semantics: translation, encryption/decryption, compression/decompression. Assigning encryption to the application layer is one of the most common errors in this question.

5. A router operates principally at which layer of the OSI model?

Router = layer 3 (IP addresses). Switch and bridge = layer 2 (MAC addresses). Hub and repeater = layer 1 (signals only). Learn the three-line list; it is asked directly and used inside larger questions.

6. Which statement about the transport layer is correct?

The three deliveries: data link = hop to hop (frames), network = source to destination (packets), transport = process to process (the whole message). The transport layer's extra job is getting it to the right process, via port numbers.

Recall without looking

Name the seven OSI layers from top to bottom.

Application, Presentation, Session, Transport, Network, Data Link, Physical. ("All People Seem To Need Data Processing.")

Give the PDU of each of the bottom four layers.

Transport = segment (TCP) or datagram (UDP); Network = packet or datagram; Data Link = frame; Physical = bit. Layers 5–7 all just carry data/messages.

State five functions of the data link layer.

Framing, physical (MAC) addressing, flow control, error control, access control.

State the main functions of the network layer.

Logical (IP) addressing and routing — source-to-destination delivery of packets, possibly across multiple networks. Also fragmentation and congestion control.

State five functions of the transport layer.

Service-point (port) addressing, segmentation and reassembly with sequence numbers, connection control (connectionless or connection-oriented), end-to-end flow control, end-to-end error control.

What are the three services of the presentation layer?

Translation (between different data representations), encryption and decryption, compression and decompression.

Define encapsulation.

As data moves down the sender's stack, each layer adds a header (and the data link layer a trailer) containing control information for its peer layer at the receiver. Each layer treats what it receives from above as pure data. The receiver reverses this — decapsulation.

Which layers are network support, and which are user support?

Network support: physical, data link, network (1–3). User support: session, presentation, application (5–7). The transport layer (4) links the two groups.

Which OSI layer does each of these work at: hub, switch, router, bridge, repeater, NIC?

Hub — 1. Repeater — 1. Switch — 2. Bridge — 2. NIC — 2. Router — 3.
