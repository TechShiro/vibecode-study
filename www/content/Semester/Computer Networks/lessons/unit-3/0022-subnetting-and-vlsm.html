Subnetting and VLSM

The highest marks-per-hour topic in the whole subject. Four worked numericals covering every shape the question takes: subnet-count based, host-count based, and a full VLSM allocation. Do not read this lesson — work it.

Exam strategy

Subnetting appears every year and is worth substantial marks. It is purely mechanical: there is nothing to understand once you have the procedure, only steps to execute without slipping. Always show the four lines — bits borrowed, new mask, block size, subnet table — because partial marks are awarded for each even if the arithmetic goes wrong later. And in a VLSM question, always allocate the largest requirement first; doing it in the order the question lists them is the single most common way to fail.

What subnetting is

Subnetting divides one large network into several smaller logical networks (subnets) by borrowing bits from the host portion and adding them to the network portion.

ReasonExplanation
Reduces wastageA department of 20 machines does not need a block of 254 addresses.
Reduces congestionEach subnet is a separate broadcast domain, so broadcast traffic stays local instead of flooding the whole network.
Improves securityTraffic between subnets must pass a router, where it can be filtered.
Simplifies managementFaults are isolated to one subnet; departments map onto subnets.
Smaller routing tablesOutside the organisation, all subnets still appear as one block — the internal structure is invisible.
The three subnetting formulas Number of subnets = 2s   (s = number of bits borrowed from the host part)
Addresses per subnet = 2h   (h = host bits remaining = 32 − new prefix)
Usable hosts per subnet = 2h − 2
New prefix = old prefix + s
The whole procedure, in five steps
  1. Decide s — the number of bits to borrow. If given a subnet count, find the smallest s with 2s ≥ required subnets. If given a host count, find the smallest h with 2h − 2 ≥ required hosts, then s = 32 − old prefix − h.
  2. Compute the new prefix = old prefix + s, and write its mask.
  3. Compute the block size = 2h = 256 − (last byte of the mask).
  4. List the subnets by counting up in steps of the block size.
  5. For each subnet write the network address, first host, last host, broadcast address.
Worked numerical 1 — given the number of subnets

Q. An organisation is given the block 192.168.1.0/24 and needs 4 subnets. Design the subnets, giving the mask, and for each subnet the network address, host range and broadcast address.

Step 1 — bits to borrow. Need 2s ≥ 4 → s = 2 (since 22 = 4).

Step 2 — new prefix. 24 + 2 = /26, mask = 255.255.255.192

Step 3 — block size. h = 32 − 26 = 6, so 26 = 64 addresses per subnet. (Check: 256 − 192 = 64. ✓)

Usable hosts per subnet = 64 − 2 = 62

Worked numerical 3 — given the number of hosts instead

Q. An organisation has the Class B block 172.16.0.0/16 and needs subnets of at least 1000 hosts each. Find the mask, the number of subnets obtained, and the hosts per subnet.

Step 1 — host bits needed. Need 2h − 2 ≥ 1000.
h = 9 → 512 − 2 = 510, not enough.
h = 10 → 1024 − 2 = 1022 ≥ 1000 ✓ So h = 10.

Step 2 — new prefix. 32 − 10 = /22, mask = 255.255.252.0

Step 3 — bits borrowed. s = 22 − 16 = 6, so 26 = 64 subnets

Addresses per subnet = 210 = 1024, of which 1022 are usable

Block size in the third byte = 256 − 252 = 4. So the subnets are:
172.16.0.0/22  (range 172.16.0.0 – 172.16.3.255)
172.16.4.0/22  (172.16.4.0 – 172.16.7.255)
172.16.8.0/22  (172.16.8.0 – 172.16.11.255)
… up to 172.16.252.0/22

Sanity check: 64 subnets × 1024 addresses = 65,536 = the whole /16 block. ✓ This total-adds-up check works for every subnetting problem and is the fastest way to confirm your mask.

VLSM — Variable Length Subnet Masking

Fixed-length subnetting gives every subnet the same size, which wastes addresses whenever the departments differ in size. VLSM allows subnets of different sizes within the same block by applying subnetting recursively — subnetting a subnet.

The one rule that makes VLSM work

Always allocate the largest requirement first, then the next largest, and so on down to the smallest. Working in descending order guarantees every block lands on a valid boundary (rule 3 of CIDR). Working in the order the question happens to list the departments will usually produce a block whose start address is not divisible by its size, and the whole answer fails.

How to actually learn this

Do twenty problems, not two. Subnetting is a motor skill, like long division — understanding the method does not make you fast or accurate at it under time pressure, and the exam tests speed and accuracy. r/ccna has endless free subnetting drills with answers. Twenty problems is roughly ninety minutes, and it is the best ninety minutes you can spend on this subject.

Check yourself

Retrieval practice

1. To create 8 subnets from a /24 block, how many bits must be borrowed, and what is the new mask?

2³ = 8, so s = 3 and the prefix goes from /24 to /27, mask 255.255.255.224, block size 32. Borrowing 2 bits gives only 4 subnets; borrowing 4 gives 16, more than needed.

2. In the subnet 192.168.1.64/26, the broadcast address is:

Block size 64, so the subnet spans .64 to .127 and the broadcast is the last address, .127. Note that .128 is the next subnet's network address and .126 is the last usable host — all three are one apart and easy to confuse.

3. A subnet must support 1000 hosts. The smallest suitable prefix is:

2¹⁰ − 2 = 1022 ≥ 1000, so 10 host bits and a /22 prefix. /23 gives only 510, which is short; /21 works but wastes over a thousand addresses, and "smallest suitable" rules it out.

4. In a VLSM design, allocations must be made:

Descending order guarantees every block starts at an address divisible by its own size. Any other order will usually place a large block at a boundary that cannot hold it, breaking CIDR's divisibility rule and invalidating the whole plan.

5. A point-to-point link between two routers is normally given which prefix?

Two ends need two addresses, and /30 is the smallest block that provides them after the network and broadcast addresses are removed. /29 would work but wastes four addresses on every link, which adds up quickly.

6. In fixed-length subnetting of a /24 into 6 subnets, how many addresses are wasted on unused subnets?

Six subnets need 3 borrowed bits, which produces 8 subnets of 32 addresses. Two go unused: 64 addresses wasted. Subnet counts must be powers of two, so this waste is unavoidable with fixed-length subnetting — which is why VLSM exists.

Recall without looking

Define subnetting and give four reasons for it.

Dividing one large network into smaller logical networks by borrowing bits from the host portion and adding them to the network portion. Reasons: reduces address wastage; each subnet is a separate broadcast domain so congestion falls; improves security since inter-subnet traffic passes a router; simplifies management and fault isolation; and the internal structure stays invisible outside, keeping external routing tables small.

Write the three subnetting formulas.

Number of subnets = 2^s where s is the bits borrowed. Addresses per subnet = 2^h where h = 32 − new prefix. Usable hosts = 2^h − 2. New prefix = old prefix + s.

State the five-step subnetting procedure.

1. Decide bits to borrow (from the subnet count: smallest s with 2^s ≥ subnets; from the host count: smallest h with 2^h − 2 ≥ hosts). 2. New prefix = old + s, and write the mask. 3. Block size = 2^h = 256 − last mask byte. 4. List subnets by counting up in block-size steps. 5. For each, write network address, first host, last host, broadcast.

Name the two sanity checks for a subnet table.

Each subnet's broadcast address is one less than the next subnet's network address; and the last subnet's broadcast must equal the last address of the original block. Also check that subnets × addresses per subnet equals the original block size.

What is VLSM, and what is the one rule for applying it?

Variable Length Subnet Masking — subnets of different sizes within one block, created by subnetting recursively. The rule: always allocate the largest requirement first and work down to the smallest, so every block starts at an address divisible by its own size.

Distinguish subnetting, supernetting and VLSM.

Subnetting splits one network into equal smaller ones — prefix increases, host bits become network bits. Supernetting combines several networks into one — prefix decreases, network bits become host bits, used for route aggregation. VLSM splits a network into subnets of differing sizes so each matches its actual requirement.
