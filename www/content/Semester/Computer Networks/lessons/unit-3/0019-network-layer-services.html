Network Layer: Functions and Services

What the network layer is responsible for, the difference between routing and forwarding, connectionless versus connection-oriented service, and the services this layer deliberately does not provide. The framing lesson for the whole of Unit III.

Exam strategy

Asked as "Explain the functions/services of the network layer" — 5 marks. Structure it as packetizing, routing and forwarding as the three main duties, then the secondary ones. Keep two lines for routing vs forwarding, which is the sub-question most often used to separate answers, and one line for what IP does not provide — that omission is deliberate and examiners like to see it named.

Where the network layer sits

The network layer is responsible for host-to-host (source-to-destination) delivery of packets, possibly across multiple networks. It is the layer that makes internetworking possible — the data link layer can only deliver within one network.

The network layer is present at hosts and at routers. At a router, the top layer present is the network layer — a router does not have transport or application layers, which is why it forwards packets without ever interpreting their contents.

The three main duties

1. Packetizing

  • Encapsulating the payload from the transport layer into a network-layer packet at the source, and decapsulating it at the destination.
  • The source adds the header containing the source and destination logical (IP) addresses.
  • Routers are not allowed to change either address, and are not allowed to decapsulate the packet unless it must be fragmented. Stating this restriction is worth a mark, because it is what makes end-to-end delivery meaningful.

2. Routing

  • Determining the best path from source to destination through an internet of many possible routes.
  • Done by routing protocols (RIP, OSPF, BGP) running in the background and building a routing table at each router.
  • Routing is a global, network-wide, comparatively slow process — it runs continuously and independently of any particular packet.

3. Forwarding

  • The action a router takes when a packet arrives: look up the destination in the forwarding table and send the packet out of the correct interface.
  • Forwarding is a local, per-packet, very fast process.
Routing vs forwarding — state it exactly like this

Routing is building the table; forwarding is using it. Routing is global, runs in the background, and involves every router exchanging information. Forwarding is local, happens once per arriving packet, and involves only one table lookup. A router does both, but they are different activities on different timescales.

The sentence that ties Unit III together

IP provides an unreliable, connectionless, best-effort delivery service. "Best effort" means it does its best but guarantees nothing — a packet may be lost, duplicated, delayed or delivered out of order, and IP will not notice. This is a design choice, not a defect: it keeps routers simple and fast, and pushes reliability to TCP at the endpoints, where it can be done once rather than at every hop.

The forwarding table

Each router keeps a table mapping destinations to next hops. In classless addressing every entry has four columns:

MaskNetwork addressNext-hop addressInterface
/26180.70.65.192—m2
/25180.70.65.128—m0
/24201.4.22.0—m3
/00.0.0.0 (default)180.70.65.200m2
The forwarding algorithm 1. Extract the destination address from the packet.
2. For each table row, AND the destination address with the row's mask.
3. If the result equals the row's network address, that row matches.
4. Choose the matching row with the longest prefix (largest mask).
5. Send the packet out of that row's interface, to that row's next hop.

Longest prefix matching is the rule to name: when several entries match, the most specific one — the one with the longest network prefix — wins. The default route 0.0.0.0/0 matches everything and therefore always loses to any other match, which is exactly what makes it a last resort.

Check yourself

Retrieval practice

1. The difference between routing and forwarding is that:

Routing is the slow, global, background process of exchanging information and building tables. Forwarding is the fast, local, per-packet act of looking up the table and choosing an interface. Both happen at routers.

2. A router may decapsulate a packet only when it needs to:

Fragmentation is the one legitimate reason. Routers must not alter the source or destination addresses, IP checksums cover only the header, and reordering is the transport layer's job at the destination.

3. IPv4's error control consists of:

IPv4 checksums only the header, because a corrupted header could misdeliver the packet entirely. Payload integrity is left to the transport layer, which checks it once end to end rather than at every hop. (IPv6 drops the header checksum altogether.)

4. A forwarding table has entries for 180.70.65.128/25 and 180.70.65.192/26, and a packet arrives for 180.70.65.200. Which entry is used?

Both entries match, so the most specific one wins — /26 is longer than /25. Longest prefix matching is also why the default route 0.0.0.0/0, which matches everything, is always the last resort.

5. "Best-effort delivery" means that IP:

Best effort means IP tries and gives up quietly. This is deliberate: keeping routers stateless and simple lets them be fast, and reliability is added once at the endpoints by TCP rather than at every hop.

Recall without looking

State the network layer's responsibility and its three main duties.

Source-to-destination (host-to-host) delivery of packets, possibly across multiple networks. Duties: packetizing (encapsulating and decapsulating), routing (determining the best path), and forwarding (acting on each arriving packet).

Distinguish routing from forwarding.

Routing builds the routing table — a global, background, comparatively slow process involving routing protocols and all routers. Forwarding uses the table — a local, per-packet, very fast table lookup that selects an outgoing interface.

What restrictions apply to routers during packetizing?

A router must not change the source or destination address of a packet, and must not decapsulate it unless the packet has to be fragmented for a network with a smaller MTU.

Which services does IPv4 not provide, and why?

No flow control, no payload error control (header checksum only), no congestion control directly, and no security in the original design. These are deliberately omitted to keep routers simple and fast; TCP supplies them once at the endpoints, and IPsec was added later for security.

Define best-effort delivery.

IP attempts delivery but guarantees nothing — packets may be lost, duplicated, delayed or delivered out of order, and IP will not detect or correct it. It is an unreliable, connectionless service by design.

Give five differences between connectionless and connection-oriented network service.

Setup phase (none/required); packets treated independently or as one connection; route may differ per packet or is fixed; arrival may be out of order or in order; header carries a full destination address or a short label; routers are stateless or stateful. Examples: IPv4/IPv6 versus ATM, Frame Relay and MPLS.

State the forwarding algorithm and the longest prefix rule.

For each table row, AND the destination address with the row's mask; if the result equals the row's network address the row matches. Among matching rows, choose the one with the longest prefix (largest mask) and send the packet out of its interface. The default route 0.0.0.0/0 matches everything and therefore always loses to a more specific entry.
