ICMP and IGMP

The two companion protocols of IP. ICMP reports errors and answers queries — it is what ping and traceroute are built from. IGMP manages multicast group membership. Both are descriptive, both are reliably asked, and both are short.

Exam strategy

Usually two 5-mark questions, or one 10-mark "explain ICMP and IGMP". For ICMP, structure the answer as error-reporting messages and query messages in two lists, then explain ping and traceroute — the applications are what make the answer concrete and they are frequently a sub-question in their own right. For IGMP, the three message types and the join/leave process carry the marks. Do not confuse the two: ICMP reports problems, IGMP manages groups.

ICMP — Internet Control Message Protocol

Why it exists

IP is an unreliable, connectionless, best-effort protocol. It has no error-reporting and no error-correcting mechanism of its own, and no mechanism for host or management queries. ICMP was designed to compensate for those two deficiencies. Say this sentence first in any ICMP answer; it frames everything that follows.

PointDetail
LayerA network layer protocol
EncapsulationICMP messages are encapsulated inside IP datagrams, with protocol number 1. So ICMP uses IP even though it is not a user protocol.
Message formatAn 8-byte header — Type (1 byte), Code (1 byte), Checksum (2 bytes), then 4 bytes specific to the message type — followed by the data section.
Data sectionFor an error message it carries the IP header of the original datagram plus its first 8 bytes of data. Those 8 bytes contain the port numbers and sequence number, which is exactly what the source needs to identify which process the failed datagram belonged to.

Error-reporting messages

MessageTypeSent when
Destination Unreachable3A router or the destination host cannot deliver the datagram. The code says why: network unreachable, host unreachable, protocol unreachable, port unreachable, fragmentation needed but DF set.
Source Quench4A router's buffer is overflowing — a primitive flow and congestion control request asking the source to slow down. Now deprecated, because it added congestion rather than relieving it.
Time Exceeded11Either the TTL reached zero (the datagram is discarded and this is reported), or the destination did not receive all fragments within its reassembly time limit.
Parameter Problem12Ambiguity or a missing value in a header field — the message includes a pointer to the offending byte.
Redirection5A host sent a datagram to the wrong router; the router forwards it anyway and tells the host to update its routing table with the better next hop.
The four rules on when ICMP is NOT sent — a classic 4-mark question

No ICMP error message is generated for:

  1. A datagram carrying an ICMP error message — otherwise errors could cascade endlessly.
  2. A fragmented datagram that is not the first fragment — only fragment zero triggers a report.
  3. A datagram having a multicast address.
  4. A datagram having a special address such as 127.0.0.0 (loopback) or 0.0.0.0.

Query messages

Message pairTypesPurpose
Echo Request / Echo Reply8 / 0Determine whether two systems can communicate. This is what ping uses.
Timestamp Request / Reply13 / 14Determine the round-trip time between two machines, and synchronise clocks.
Router Solicitation / Advertisement10 / 9A host discovers the routers on its network and learns whether they are alive.

The two tools built on ICMP

ToolUsesHow it works
pingEcho request and echo replySends echo requests and measures which return and how long they take. It reports reachability, round-trip time and packet loss.
traceroute (tracert)Time exceeded, and destination unreachableSends datagrams with deliberately small TTLs. TTL = 1 expires at the first router, which returns a time-exceeded message revealing its address; TTL = 2 reveals the second router; and so on. The destination is identified when a port unreachable or echo reply comes back instead. So the whole path is discovered, one hop at a time.

The traceroute mechanism is worth writing out fully — it is a favourite question because it shows whether TTL and ICMP are both properly understood.

IGMP — Internet Group Management Protocol

What it does

IGMP is not a multicast routing protocol. It is a protocol that manages group membership: it lets a host tell its local router which multicast groups it wants to receive, and lets the router keep that list current. The multicast routing protocols (DVMRP, MOSPF, PIM — next lesson) then use that information to build delivery trees.

PointDetail
LayerNetwork layer
EncapsulationIn IP datagrams, with protocol number 2
Addresses usedClass D multicast addresses, 224.0.0.0 to 239.255.255.255
BetweenA host and its local multicast router — IGMP messages never travel beyond the local network

The three message types

MessageSent byPurpose
Membership QueryThe routerPeriodically asks which groups still have members on this network. A general query asks about all groups; a special query asks about one specific group.
Membership ReportA hostAnnounces that the host wishes to join a group, or answers a query confirming continued membership.
Leave ReportA hostAnnounces that the host is leaving a group. The router then sends a special query for that group to check whether anyone else is still a member.

Joining and leaving

Joining A host sends a membership report naming the group. The report is sent twice, in case the first is lost. If the host is the first member on that network, the router starts forwarding that group's traffic here.
Leaving A host sends a leave report. The router responds with a special query for that group. If no membership report arrives before the timer expires, the router concludes there are no members left and stops forwarding that group's traffic onto this network.
Two mechanisms that make IGMP efficient — both worth a mark

Delayed response: when a host receives a query, it does not reply immediately. It sets a random delay timer for each group. This prevents every host answering at once and flooding the network.

Report suppression: a host that hears another host's report for a group it also belongs to cancels its own report. The router only needs to know that at least one member exists, not how many — so one report per group per network is sufficient.

Check yourself

Retrieval practice

1. ICMP exists because IP has no:

IP is unreliable, connectionless and best-effort, with no error reporting and no query mechanism. ICMP compensates for exactly those two gaps. IP does have logical addressing, fragmentation and a header checksum.

2. An ICMP error message carries, in its data section:

Those 8 bytes hold the port numbers and sequence number, which is what the source needs to identify which process the failed datagram belonged to. Carrying the whole datagram would waste bandwidth reporting a failure.

3. Traceroute discovers the path by:

TTL = 1 expires at the first router, which reports back and reveals itself; TTL = 2 reveals the second, and so on. The destination is recognised when a port-unreachable or echo reply arrives instead of a time-exceeded message.

4. For which of these IS an ICMP error message generated?

The rule suppresses reports for non-first fragments, but fragment zero does trigger one. The other three are exactly the cases suppressed — errors about errors would cascade, and multicast or special addresses would generate storms of replies.

5. IGMP is used to:

IGMP manages group membership on the local network only. Building the delivery tree across the internet is the job of the multicast routing protocols — DVMRP, MOSPF and PIM — which consume IGMP's membership information.

6. Report suppression in IGMP means that:

The router only needs to know that at least one member exists, not how many — so one report per group per network suffices. Combined with the random delay timer, this keeps a query from producing a flood of simultaneous replies.

Recall without looking

Why does ICMP exist, and how is it carried?

IP is unreliable, connectionless and best-effort, with no error-reporting mechanism and no host or management query mechanism; ICMP compensates for both. ICMP messages are encapsulated inside IP datagrams with protocol number 1.

Name the five ICMP error-reporting messages.

Destination unreachable (type 3), source quench (4, deprecated), redirection (5), time exceeded (11), parameter problem (12).

Name the ICMP query message pairs and their uses.

Echo request/reply (types 8/0) — used by ping to test reachability. Timestamp request/reply (13/14) — round-trip time and clock synchronisation. Router solicitation/advertisement (10/9) — discovering routers on the network.

State the four cases in which no ICMP error message is generated.

For a datagram carrying an ICMP error message; for a fragment other than the first; for a datagram with a multicast address; and for a datagram with a special address such as 127.0.0.0 or 0.0.0.0.

Explain how traceroute works.

It sends datagrams with deliberately small TTL values. TTL = 1 expires at the first router, which returns a time-exceeded message revealing its address; TTL = 2 reveals the second router, and so on. The destination is identified when a port-unreachable or echo reply returns instead, so the whole path is mapped one hop at a time.

What is IGMP, and what is it not?

It manages multicast group membership between a host and its local router, using Class D addresses and protocol number 2. It is not a multicast routing protocol — DVMRP, MOSPF and PIM build the delivery trees using the membership information IGMP collects.

Name the three IGMP messages and who sends each.

Membership query — sent by the router, either general (all groups) or special (one group). Membership report — sent by a host to join a group or confirm membership. Leave report — sent by a host leaving a group, after which the router sends a special query to check whether anyone remains.

Explain delayed response and report suppression.

Delayed response: a host receiving a query sets a random delay timer per group rather than replying at once, preventing a flood of simultaneous replies. Report suppression: a host that hears another host's report for a group it also belongs to cancels its own, since the router only needs to know at least one member exists.

Multicast routing itself — DVMRP, MOSPF and PIM — comes next, alongside unicast routing. IGMP feeds directly into it.
