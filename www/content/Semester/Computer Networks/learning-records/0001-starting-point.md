# Starting point: Unit I built cold, no prior knowledge measured

The six Unit I lessons were written on 29 August 2026 without any evidence of what is already
known. They assume **zero prior exposure** to networking and build from the definition of data
communication upward.

That assumption is probably too conservative — Unit I is the introductory unit and has almost
certainly been taught in class by now. Nothing in this workspace records demonstrated
understanding, only material covered, which does not itself count as learning.

**Implication for the next session:** measure before teaching again. Four checks that would
produce a real record:

- Reproduce the **OSI seven-layer table** from memory — layer, PDU, address, device (Lesson 5).
- Compute mesh links **backwards**: "a mesh has 45 duplex links, how many devices?" (Lesson 4).
- A **latency numerical** with the distance and message size both given, to see whether propagation
  and transmission get swapped (Lesson 1).
- **OSI vs TCP/IP**, six rows, from memory (Lesson 6).

**Also unmeasured:** whether Unit I even needed six lessons. It is the lightest unit in the
syllabus, and if the split felt over-granular that is a signal to build Unit II as fewer, larger
lessons rather than more.

**Open:** no test date was given for CN, and no past papers exist in the folder. Both would change
how the remaining units are weighted.
