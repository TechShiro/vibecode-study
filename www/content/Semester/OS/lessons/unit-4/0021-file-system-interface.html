File System Interface

The concept of a file, file attributes and operations, access methods (sequential, direct, indexed), directory structure (single-level, two-level, tree, acyclic graph, general graph), mounting, and protection.

Exam strategy

“Explain directory structures with diagrams” is a guaranteed 5–10 marker. “Compare sequential and direct access” is a standard short-note.

File concept

A file is a named collection of related information stored on secondary storage. Attributes: name, identifier, type, location, size, protection, timestamps.

Operations: create, open, read, write, reposition (seek), delete, truncate, close.

Access methods

MethodHowExample
SequentialRead/write in order, one record after anotherTape, editor
Direct (Random)Read/write any block by block numberDatabase
IndexedIndex maps key → block number, then direct accessLarge databases

Directory structures

StructureDescriptionPro/Con
Single-levelOne directory for all filesSimple but naming conflicts
Two-levelOne directory per userIsolates users but no grouping
TreeHierarchical subdirectoriesEfficient, natural. Most common
Acyclic graphTree + shared subdirs/files (links)Sharing but dangling pointers
General graphAllows cycles (needs garbage collection)Complex, rarely used

File system mounting

A file system must be mounted before use. The OS attaches the file system to a mount point (an empty directory) in the existing tree.

Protection

Access control list (ACL): each file lists users and their permissions. UNIX rwx bits: owner, group, others × read, write, execute.

Retrieval practice

1. A tree-structured directory allows:

Tree = no sharing, no cycles, but clean hierarchy. Acyclic graph adds sharing.

2. Direct access allows:

Direct = random access. Essential for databases. Sequential must read in order.

Recall without looking

Five directory structures.

Single-level, two-level, tree (most common), acyclic graph (sharing), general graph (cycles, needs GC).

Three access methods.

Sequential (in order), direct (by block number), indexed (key → block via index).
