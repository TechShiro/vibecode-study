Disk Scheduling and RAID

Disk structure (CHS), five scheduling algorithms (FCFS, SSTF, SCAN, C-SCAN, LOOK) with worked traces, swap-space management, and RAID levels.

Exam strategy

Disk scheduling is a guaranteed 10-mark numerical. Given a queue of cylinder requests and the current head position, trace FCFS, SSTF, SCAN, C-SCAN, LOOK and compute total head movement. RAID levels are a common short-note.

Disk structure

Disk = platters → tracks → sectors. Addressed by Cylinder-Head-Sector or logical block number. Access time = seek time + rotational latency + transfer time. Seek time dominates — minimise head movement.

Disk scheduling algorithms

Setup for all examples: Cylinder requests = 98, 183, 37, 122, 14, 124, 65, 67. Head at 53. Range 0–199.

FCFS (First Come First Served)

Serve in arrival order. Head: 53→98→183→37→122→14→124→65→67.

Movement: |98-53|+|183-98|+|37-183|+|122-37|+|14-122|+|124-14|+|65-124|+|67-65| = 45+85+146+85+108+110+59+2 = 640.

SSTF (Shortest Seek Time First)

Next request closest to current head. Head: 53→65→67→37→14→98→122→124→183.

Movement: 12+2+30+23+84+24+2+59 = 236. But can cause starvation.

SCAN (Elevator)

Move in one direction, serving all requests, then reverse. Head: 53→37→14→0→65→67→98→122→124→183.

Movement: 53 (to 0) + 183 = 236. (Goes to 0, then all the way to 183.)

C-SCAN (Circular SCAN)

Like SCAN but after reaching one end, jump to the other end without servicing (uniform wait time).

Head: 53→65→67→98→122→124→183→199→0→14→37. Service only while going right.

LOOK / C-LOOK

Like SCAN/C-SCAN but the head only goes as far as the last request in each direction (doesn’t go to 0 or 199).

Check yourself

Retrieval practice

1. SSTF can cause:

If new requests keep arriving near the head, distant requests may wait indefinitely.

2. SCAN differs from LOOK because:

LOOK saves unnecessary head movement by not going past the last request in each direction.

3. RAID 5 uses:

Parity is spread across all disks. Any one disk can fail and data is reconstructed from parity.

Recall without looking

Five disk scheduling algorithms.

FCFS (arrival order), SSTF (nearest, starvation), SCAN (elevator), C-SCAN (circular), LOOK (SCAN to last request only).

RAID 0, 1, 5 — one line each.

RAID 0: striping, no redundancy. RAID 1: mirroring, 50% capacity. RAID 5: striping + distributed parity, survives 1 failure.
