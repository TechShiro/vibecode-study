Unit IV — Exam Sheet

File Systems + Disk Scheduling + RAID.

Access methods

Sequential (in order), Direct (by block #), Indexed (key → block).

Directory structures memorise

Single-level, two-level, tree (most common), acyclic graph (sharing), general graph (cycles).

Allocation methods guaranteed

Contiguous: fast, external frag. Linked: no frag, no direct access. Indexed: direct access + no frag (UNIX inode).

UNIX inode

12 direct + 1 single-indirect + 1 double-indirect + 1 triple-indirect pointers.

Free-space management

Bit vector (1 bit/block), linked list, grouping, counting.

Disk scheduling guaranteed numerical

FCFS (arrival order, 640). SSTF (nearest, starvation). SCAN (elevator). C-SCAN (circular). LOOK (to last request).

RAID short note

0=stripe. 1=mirror. 5=stripe+distributed parity. 6=double parity. 10=mirror+stripe.

Five-minute scan

  1. File: name, attributes, operations. Access: sequential, direct, indexed.
  2. Directories: single → two-level → tree → acyclic → general.
  3. Allocation: contiguous, linked, indexed. Know pros/cons table.
  4. Free space: bit vector most common.
  5. Disk scheduling: trace FCFS/SSTF/SCAN/C-SCAN/LOOK, compute total movement.
  6. RAID: 0 stripe, 1 mirror, 5 parity, 10 combo.
