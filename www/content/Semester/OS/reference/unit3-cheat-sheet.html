Unit III — Exam Sheet

Deadlocks + Memory Management + Virtual Memory — the two guaranteed numericals (Banker’s Algorithm and Page Replacement) on one printable page.

Four necessary conditions for deadlock memorise

1. Mutual exclusion · 2. Hold and wait · 3. No preemption · 4. Circular wait. All four simultaneously.

Prevention break one condition

ME: share (impractical). H&W: request all upfront. NP: preempt. CW: total ordering.

Banker’s Algorithm guaranteed numerical

Need = Max − Allocation. Work = Available.
Find i where Need[i] ≤ Work, Finish[i]=false. Work += Alloc[i], Finish[i]=true. Repeat.
All finish ⇒ SAFE.

Detection & Recovery

Single-instance: cycle in wait-for graph. Multi: Banker’s with Request. Recovery: terminate all/one, preempt, rollback.

Memory allocation

First fit (fastest), best fit (tiny holes), worst fit (poor). Internal frag = fixed partitions. External frag = variable partitions. Paging eliminates external.

Paging address translation

p = ⌊address / page_size⌋, d = address mod page_size.
Physical = frame[p] × page_size + d. TLB caches translations.

Page replacement guaranteed numerical

FIFO: oldest page out (queue). OPT: farthest future use (benchmark). LRU: least recently used (past).

Belady’s anomaly: FIFO only — more frames can = more faults. LRU/OPT = stack algorithms, never.

EAT formula

EAT = (1−p) × m + p × f. Even p = 0.001 causes massive slowdown.

Thrashing

Too many processes, too few frames ⇒ constant paging. Fix: working set model, reduce multiprogramming.

Five-minute scan

  1. 4 conditions: ME, H&W, NP, CW.
  2. Banker’s: Need = Max − Alloc. Find safe sequence.
  3. Prevention vs avoidance vs detection.
  4. Paging: p = ⌊addr/page_size⌋, d = addr mod page_size.
  5. FIFO/OPT/LRU traces — count faults.
  6. Belady’s anomaly = FIFO only.
  7. EAT = (1−p)m + pf.
  8. Thrashing = working set > frames.
