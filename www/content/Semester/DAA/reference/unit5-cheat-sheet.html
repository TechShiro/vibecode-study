1. Complexity Classes: P, NP, NP-Hard, NP-Complete guaranteed definitions

ClassFormal DefinitionKey Example
PDecision problems solvable by a deterministic algorithm in polynomial time $O(n^k)$.Sorting, Shortest Path, MST
NPDecision problems verifiable by a deterministic verifier in polynomial time given a certificate.0/1 Knapsack, SAT, TSP
NP-HardProblems to which every problem in NP polynomial-time reduces ($Y \le_P X, \forall Y \in \text{NP}$).Halting problem, Opt-TSP
NP-Complete (NPC)Hardest problems in NP: 1. $X \in \text{NP}$ AND 2. $X$ is NP-Hard.3-SAT, Clique, Vertex Cover

P ⊆ NP: Proven (any poly-time solvable problem is trivially verifiable). P = NP vs P ≠ NP: Millennium open problem.

2. Polynomial-Time Reductions ($L_1 \le_P L_2$) rules

$L_1 \le_P L_2$ means $x \in L_1 \iff f(x) \in L_2$ where $f$ is computable in deterministic polynomial time.
Meaning: $L_2$ is at least as hard as $L_1$. If $L_2 \in P \implies L_1 \in P$. If $L_1 \notin P \implies L_2 \notin P$.
Transitivity: If $A \le_P B$ and $B \le_P C \implies A \le_P C$.

3. The 2-Step Recipe to Prove $X$ is NP-Complete

  1. Prove $X \in \text{NP}$: Specify polynomial certificate and write deterministic verifier running in $O(n^k)$ time.
  2. Choose known NPC problem $Y$ (e.g. 3-SAT, Clique, HC).
  3. Reduce $Y \le_P X$: Construct mapping $f$ in polynomial time.
  4. Prove equivalence: $y \in Y \iff f(y) \in X$ (both directions: YES ⇒ YES, and NO ⇒ NO).

4. The Cook-Levin Theorem (1971) milestone

Boolean Satisfiability (SAT) is NP-Complete. Cook proved from first principles that any non-deterministic Turing machine computation of length $p(n)$ can be encoded as an equivalent polynomial-sized boolean formula $\Phi$.

5. Classic NP-Complete Reductions Summary guaranteed proofs

Reduction StepSource ($Y$)Target ($X$)Gadget Construction & Target Parameter
SAT → 3-SAT CNF-SAT 3-CNF-SAT Break clauses with $>3$ literals using auxiliary variables: $(l_1 \lor l_2 \lor y_1) \land (\overline{y_1} \lor l_3 \lor l_4)$.
3-SAT → Clique 3-SAT ($m$ clauses) Clique in $G(V, E)$ $3m$ vertices (one per literal). Connect edges between different clause groups if literals are consistent. Target $k = m$.
Clique → Vertex Cover Clique ($G, k$) Vertex Cover in $\overline{G}$ Duality Theorem: $S$ is a Clique in $G \iff V \setminus S$ is a Vertex Cover in complement graph $\overline{G}$. Target $k' = |V| - k$.
Vertex Cover → Set Cover Vertex Cover ($G, k$) Set Cover Universe $U = E$. Subsets $S_v = \text{edges incident to } v$. Target $k$ subsets cover $U$.
HC → TSP Hamiltonian Cycle Decision TSP Complete graph $G'$: $w(u, v) = 1$ if $(u, v) \in E$; $w(u, v) = 2$ if $(u, v) \notin E$. Target cost $k = n = |V|$.

6. Coping with Hardness: Approximation Algorithms formulas

Approximation Ratio: $C / C^* \le \rho(n)$ (for minimization).

  • 2-Approximation for Vertex Cover (Maximal Matching):

    Find maximal matching $M$ of disjoint edges. Add both endpoints of all edges in $M$ to cover $C$. Since any cover needs $|C^*| \ge |M|$, and $|C| = 2|M|$, we have: $|C| \le 2 \cdot |C^*|$. Runs in $O(V + E)$ time.

  • 2-Approximation for Metric TSP (Using MST):

    Requires Triangle Inequality ($c(u, w) \le c(u, v) + c(v, w)$). Compute MST $T$ ($O(E \log V)$), double edges for Euler tour ($2 \cdot \text{weight}(T)$), shortcut duplicate vertices: $\text{cost}(\text{Tour}) \le 2 \cdot \text{cost}(T) < 2 \cdot \text{OPT}$.

Ten-Minute Exam Final Scan

  1. P vs NP: P = efficiently solvable ($O(n^k)$); NP = efficiently verifiable ($O(n^k)$ with certificate).
  2. NP-Hard vs NP-Complete: NP-Hard = all NP problems reduce to it. NP-Complete = NP-Hard AND in NP.
  3. Reduction direction: To prove $X$ is NPC, reduce KNOWN to NEW ($Y \le_P X$). Solvability flows back; hardness flows forward.
  4. Cook-Levin: SAT is the foundational first NP-Complete problem.
  5. Clique ⇔ Vertex Cover duality: $S$ is a Clique in $G \iff V \setminus S$ is a Vertex Cover in $\overline{G}$.
  6. HC to TSP: $w=1$ for existing edges, $w=2$ for non-edges. Tour cost $\le n \iff$ Hamiltonian cycle exists.
  7. Vertex Cover 2-approx: Maximal matching $M$; pick both endpoints. $|C| = 2|M| \le 2|C^*|$.
