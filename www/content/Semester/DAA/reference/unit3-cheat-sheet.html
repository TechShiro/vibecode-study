Unit III — Exam Sheet

Graph Traversal — BFS, DFS, connected components, topological sort, biconnected components, shortest paths.

Representations basics

Adjacency matrix: Θ(V²) space, O(1) edge lookup. Adjacency list: Θ(V+E) space, O(degree) lookup. Use list for traversals.

BFS memorise

Queue. Level-order. O(V+E). Gives shortest paths in unweighted graphs. d[v] = min edges from source.

DFS memorise

Stack/recursion. Θ(V+E). Discovery d[v] and finish f[v] times. Edge types: tree (white), back (grey = cycle), forward (black, d[u]<d[v]), cross (black, d[u]>d[v]).

Connected components

Undirected: BFS/DFS from each unvisited vertex. Directed (SCC): Kosaraju — DFS on G, transpose, DFS on GT in reverse finish order. Θ(V+E).

Topological sort guaranteed

DFS: reverse finish order. Kahn’s: repeatedly dequeue in-degree-0 vertices. Only on DAGs. O(V+E).

Biconnected components articulation points

low[v] = min(d[v], low of children, d of back-edge targets).
Root: AP if ≥2 DFS children. Non-root u: AP if child v has low[v] ≥ d[u].
Bridge: low[v] > d[u]. Time Θ(V+E).

Dijkstra guaranteed numerical

Greedy. Non-negative weights only. d[s]=0, rest ∞. Pick min d[u], relax neighbours.
O(V²) array | O((V+E) log V) binary heap | O(V log V + E) Fibonacci heap.

Bellman–Ford

Relax all edges V−1 times. V-th pass detects negative cycles. O(VE). Handles negative weights.

Five-minute scan

  1. Adjacency list for traversals, matrix for dense graphs.
  2. BFS = queue, shortest unweighted paths.
  3. DFS = stack, back edge = cycle.
  4. Topological sort: reverse DFS finish order or Kahn’s in-degree method.
  5. AP root: ≥2 children. Non-root: low[v] ≥ d[u]. Bridge: low[v] > d[u].
  6. Dijkstra: greedy, non-negative, O(V²).
  7. Bellman-Ford: V-1 passes, handles negatives, O(VE).
