Unit IV — Exam Sheet

Greedy (MST, Huffman, fractional knapsack) + DP (MCM, LCS, 0/1 knapsack) — the heaviest unit.

Greedy approach

Locally optimal → globally optimal. Needs: greedy-choice property + optimal substructure.

Fractional Knapsack

Sort by v/w ratio descending. Take greedily. O(n log n). Fractions allowed.

Kruskal’s MST guaranteed

Sort edges. Add if no cycle (Union-Find). V-1 edges. O(E log V). Best for sparse.

Prim’s MST guaranteed

Grow from vertex. Min crossing edge. O(V²) array, O(E log V) heap. Best for dense.

Huffman Coding guaranteed

Min-heap. Merge two smallest. Repeat. Prefix-free. O(n log n).

DP paradigm

Optimal substructure + overlapping subproblems. Table-fill (bottom-up) or memoisation (top-down).

MCM guaranteed numerical

m[i,j] = mink { m[i,k] + m[k+1,j] + pi-1·pk·pj }. O(n³). Fill by chain length.

LCS guaranteed numerical

Match: c[i,j] = c[i-1,j-1]+1. Mismatch: max(up, left). O(mn). Backtrack diagonal for string.

0/1 Knapsack guaranteed numerical

K[i,w] = max(K[i-1,w], v[i]+K[i-1,w-w[i]]). O(nW) pseudo-polynomial.

Five-minute scan

  1. Greedy: locally optimal, no revisit. DP: try all, store results.
  2. Fractional knapsack: sort v/w, greedy. 0/1 knapsack: DP table.
  3. Kruskal: sort edges, Union-Find. Prim: grow from vertex, min crossing edge.
  4. Huffman: merge two smallest, prefix-free codes.
  5. MCM: m[i,j], try all k splits. O(n³).
  6. LCS: match diagonal+1, mismatch max(up,left). O(mn).
  7. 0/1 Knapsack: take or skip. O(nW).
