Graph representation

Adjacency matrix

A V×V matrix A where A[i][j] = 1 if edge (i,j) exists, 0 otherwise (for unweighted). For weighted graphs, store the weight instead of 1.

  • Space: Θ(V²) — wasteful for sparse graphs.
  • Edge lookup: O(1).
  • Finding all neighbours: Θ(V).
  • Best for: dense graphs, quick edge existence checks.

Adjacency list

An array of V linked lists. List[i] contains all vertices adjacent to i.

  • Space: Θ(V+E).
  • Edge lookup: O(degree(v)).
  • Finding all neighbours: O(degree(v)).
  • Best for: sparse graphs, traversals (BFS/DFS).

Breadth-First Search (BFS)

BFS algorithm Input: Graph G = (V, E), source vertex s.
Data structure: Queue Q.

1. Mark all vertices white. Set d[s] = 0, π[s] = NIL. Enqueue s.
2. While Q is not empty:
   u = Dequeue(Q)
   For each neighbour v of u:
     If v is white: colour v grey, d[v] = d[u]+1, π[v] = u, Enqueue(v)
   Colour u black.

Time: O(V + E)    Space: O(V)
What BFS gives you

Shortest path (unweighted) from s to every reachable vertex. d[v] = minimum number of edges from s to v. The BFS tree is a shortest-path tree.

Depth-First Search (DFS)

DFS algorithm Data: Discovery time d[v], finish time f[v], global timer.

DFS(G):
   For each vertex u: colour u white
   time = 0
   For each vertex u: if u is white, DFS-Visit(u)

DFS-Visit(u):
   time++; d[u] = time; colour u grey
   For each neighbour v of u:
     If v is white: π[v] = u, DFS-Visit(v)
   colour u black; time++; f[u] = time

Time: Θ(V + E)    Space: O(V) (recursion stack)

Edge classification in DFS

Edge typeCondition when (u,v) is exploredMeaning

Back edgev is grey (ancestor)Indicates a cycle
Forward edgev is black, d[u] < d[v]Goes to a descendant (not via tree)
Cross edgev is black, d[u] > d[v]Goes to a different subtree
The cycle-detection rule

A directed graph has a cycle if and only if DFS produces a back edge. For undirected graphs, every non-tree edge is a back edge.

Check yourself

Retrieval practice

1. The time complexity of BFS and DFS on an adjacency list is:

Each vertex is processed once and each edge is examined once (twice for undirected). On an adjacency matrix, it would be O(V²).

2. BFS uses which data structure?

BFS explores level by level using a queue. DFS uses a stack (or recursion).

3. A back edge in DFS indicates:

A back edge connects a vertex to its ancestor in the DFS tree, forming a cycle.

4. Adjacency list representation uses space:

V list headers + E list entries total. Adjacency matrix uses Θ(V²) regardless of edge count.

5. BFS finds shortest paths in:

BFS gives shortest hop count. For weighted graphs, use Dijkstra (non-negative) or Bellman-Ford (general).

6. In DFS, a vertex coloured grey means:

White = undiscovered. Grey = in progress (on the recursion stack). Black = finished.

Recall without looking

Adjacency matrix vs adjacency list — when to use each.

Matrix: O(1) edge lookup, Θ(V²) space — use for dense graphs. List: O(degree) lookup, Θ(V+E) space — use for sparse graphs and traversals.

State the BFS algorithm in 4 lines.

Enqueue source. While queue not empty: dequeue u, for each unvisited neighbour v set d[v]=d[u]+1 and enqueue v. Time O(V+E). Gives shortest paths in unweighted graphs.

Name the four DFS edge types and what each means.

Tree (part of DFS tree), back (to ancestor = cycle), forward (to descendant via non-tree path), cross (to different subtree). Back edges detect cycles.

BFS vs DFS — three key differences.

BFS: queue, level-order, finds shortest unweighted paths. DFS: stack/recursion, deep-first, naturally detects cycles and does topological sort.
