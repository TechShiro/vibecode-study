Definitions

Articulation point (cut vertex) A vertex whose removal disconnects the graph (increases the number of connected components).
Bridge (cut edge) An edge whose removal disconnects the graph.
Biconnected component A maximal biconnected subgraph — a subgraph that has no articulation point. Equivalently, between every pair of vertices there exist two vertex-disjoint paths.

Tarjan’s algorithm

Uses DFS with two arrays:

  • d[v] = discovery time of v.
  • low[v] = the minimum discovery time reachable from the subtree rooted at v via one back edge.
Computing low[v] low[v] = min(
   d[v],
   low[w] for every child w of v in DFS tree,
   d[w] for every back edge (v, w)
)
Articulation point rules Root: the root of the DFS tree is an articulation point if it has ≥2 children.
Non-root: vertex u is an articulation point if it has a child v with low[v] ≥ d[u] — meaning v’s subtree cannot reach above u via a back edge.
Bridge rule Edge (u, v) where v is a child of u is a bridge if low[v] > d[u].

Computing low values:

  • F: no children, back edge (F,D) ⇒ low[F] = min(6, d[D]=4) = 4
  • E: child F (low=4), back edge none new ⇒ low[E] = min(5, 4) = 4
  • D: child E (low=4) ⇒ low[D] = min(4, 4) = 4
  • C: no children, back edge (C,A) ⇒ low[C] = min(3, d[A]=1) = 1
  • B: children C (low=1) and D (low=4) ⇒ low[B] = min(2, 1, 4) = 1
  • A: child B (low=1) ⇒ low[A] = min(1, 1) = 1

Articulation point check:

  • A (root): only 1 child (B) ⇒ NOT an articulation point
  • B (non-root): child C has low[C]=1 < d[B]=2 ⇒ no. Child D has low[D]=4 ≥ d[B]=2 ⇒ YES, B is an articulation point
  • D (non-root): child E has low[E]=4 ≥ d[D]=4 ⇒ YES, D is an articulation point
  • C, E, F: no children or low < d ⇒ not articulation points

Bridge check:

  • Edge (B,D): low[D]=4 > d[B]=2 ⇒ BRIDGE
  • All other tree edges: low ≤ d of parent ⇒ not bridges

Biconnected components: {A,B,C} and {D,E,F}, connected through articulation point B via bridge (B,D).

Time complexity

Tarjan’s algorithm runs in Θ(V + E) — a single DFS pass.

Strictly greater (>) for bridges; greater or equal (≥) for articulation points. The difference matters!

Recall without looking

Define articulation point, bridge, biconnected component.

Articulation point: vertex whose removal disconnects graph. Bridge: edge whose removal disconnects. Biconnected component: maximal subgraph with no articulation point.

State the low[v] formula and the two articulation point rules.

low[v] = min(d[v], low of children, d of back-edge targets). Root: ≥2 DFS children. Non-root u: has child v with low[v] ≥ d[u].

Bridge rule vs articulation point rule.

Bridge: low[v] > d[u] (strictly greater). Articulation: low[v] ≥ d[u] (greater or equal). The ≥ vs > distinction matters!
