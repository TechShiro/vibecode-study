The problem

Given a weighted graph G = (V, E, w) and a source vertex s, find the shortest path from s to every other vertex.

Dijkstra’s algorithm

Dijkstra’s algorithm Precondition: all edge weights ≥ 0.

1. Set d[s] = 0, d[v] = ∞ for all v ≠ s. S = ∅ (visited set).
2. While S ≠ V:
   u = vertex in V−S with minimum d[u]
   Add u to S
   For each neighbour v of u with v ∉ S:
     If d[u] + w(u,v) < d[v]: d[v] = d[u] + w(u,v), π[v] = u    (relax)

Time: O(V²) with array  |  O((V+E) log V) with binary heap  |  O(V log V + E) with Fibonacci heap

Bellman–Ford algorithm

Bellman–Ford Works with negative weights. Detects negative-weight cycles.

1. Set d[s] = 0, d[v] = ∞ for all v ≠ s.
2. Repeat V−1 times:
   For each edge (u,v) with weight w:
     If d[u] + w < d[v]: d[v] = d[u] + w, π[v] = u
3. For each edge (u,v): if d[u] + w < d[v], negative cycle exists.

Time: O(V · E)

Check yourself

Retrieval practice

1. Dijkstra’s algorithm fails when:

Dijkstra assumes once a vertex is selected, its distance is final. Negative edges can invalidate this assumption.

2. Dijkstra with a binary heap runs in:

Each of V extract-min and up to E decrease-key operations, each O(log V).

3. Bellman–Ford performs relaxation for:

A shortest path has at most V-1 edges, so V-1 passes suffice. If the V-th pass still relaxes, there's a negative cycle.

4. Dijkstra’s algorithm is classified as:

Greedy choice: the unvisited vertex with smallest d[v] is selected and never revisited.

5. Bellman–Ford’s time complexity is:

V-1 passes, each examining all E edges. Slower than Dijkstra but handles negative weights.

6. A negative-weight cycle is detected in Bellman–Ford when:

If after V-1 passes any distance can still decrease, the path has ≥ V edges, which means a cycle with negative total weight.

Recall without looking

State Dijkstra’s algorithm in four lines.

Set d[s]=0, rest ∞. Repeat: pick unvisited u with min d[u], mark visited, relax all edges from u. Time O(V²) or O((V+E)log V) with heap. Requires non-negative weights.

Why Dijkstra fails with negative edges.

Dijkstra assumes a vertex's distance is final once selected (greedy). A negative edge from a later vertex could provide a shorter path, violating this assumption.

State Bellman-Ford and how it detects negative cycles.

Relax all edges V-1 times. If a V-th pass still relaxes any edge, a negative cycle exists. Time O(VE). Works with negative weights.

Dijkstra vs Bellman-Ford — three differences.

Dijkstra: greedy, O(V²), no negative weights. Bellman-Ford: DP, O(VE), handles negative weights, detects negative cycles.
