Connected components (undirected)

A connected component is a maximal set of vertices such that there is a path between every pair.

Algorithm Run BFS or DFS from an unvisited vertex. All vertices reached form one component. Repeat until all vertices are visited.
Time: O(V + E)

Strongly Connected Components (directed)

In a directed graph, a strongly connected component (SCC) is a maximal set of vertices where every vertex is reachable from every other vertex (via directed paths).

Kosaraju’s algorithm 1. Run DFS on G, recording finish times.
2. Compute GT (transpose: reverse all edges).
3. Run DFS on GT in decreasing finish-time order.
4. Each DFS tree in step 3 is one SCC.

Time: Θ(V + E)

Topological sorting

A topological sort of a DAG (directed acyclic graph) is a linear ordering of vertices such that for every edge (u,v), u appears before v. Only possible if the graph has no cycle.

Method 1: DFS-based

DFS topological sort 1. Run DFS on the entire graph.
2. As each vertex finishes (turns black), prepend it to a list.
3. The list is a valid topological order.

Time: Θ(V + E)

Method 2: Kahn’s algorithm (BFS-based)

Kahn’s algorithm 1. Compute in-degree of every vertex.
2. Enqueue all vertices with in-degree 0.
3. While queue is not empty:
   u = Dequeue. Add u to output.
   For each neighbour v of u: in-degree[v]−−. If in-degree[v] = 0, enqueue v.
4. If output has fewer than V vertices, the graph has a cycle.

Time: O(V + E)

Both methods give valid orderings

A DAG may have multiple valid topological orderings. DFS-based and Kahn’s may produce different ones — both are correct.

Check yourself

Retrieval practice

1. Topological sorting is possible only on:

A cycle would make it impossible to put all vertices in a before-after ordering. If DFS finds a back edge, topological sort fails.

2. In DFS-based topological sort, vertices are ordered by:

The last vertex to finish is placed first. Reverse finish order ensures every source comes before its targets.

3. Kahn’s algorithm starts by enqueuing vertices with:

Vertices with no incoming edges can safely go first. As they are removed, other vertices' in-degrees drop to 0.

4. Kosaraju’s algorithm uses:

First DFS records finish times. Second DFS on G^T in reverse finish order identifies SCCs. Total time Θ(V+E).

5. The time complexity of finding connected components is:

Run BFS/DFS from each unvisited vertex. Each vertex and edge is processed once total.

6. If Kahn’s algorithm processes fewer than V vertices, it means:

Vertices in a cycle never reach in-degree 0, so they are never dequeued. The output is short.

Recall without looking

How to find connected components.

Run BFS/DFS from any unvisited vertex; all reached vertices form one component. Repeat. Time O(V+E).

Two methods for topological sorting.

DFS-based: reverse finish order. Kahn's: repeatedly remove in-degree-0 vertices. Both O(V+E). Only works on DAGs.

Kosaraju's algorithm for SCCs.

1. DFS on G, record finish times. 2. Transpose G. 3. DFS on G^T in decreasing finish order. Each tree = one SCC. Time Θ(V+E).
