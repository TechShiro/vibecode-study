Hamiltonian Cycle, TSP and Approximations

Eulerian vs Hamiltonian graphs, Hamiltonian cycle NP-completeness, reducing Hamiltonian cycle to Traveling Salesman (TSP), and polynomial-time approximation algorithms.

Exam strategy

“Prove that the Traveling Salesman Problem (TSP) is NP-Complete by reducing from Hamiltonian Cycle” is a guaranteed 7-to-10 mark question. “Explain the 2-approximation algorithm for Vertex Cover or Metric TSP” is the standard follow-up question.

Eulerian vs Hamiltonian: The Fine Line of Complexity

One of the most striking results in graph theory is how a slight phrasing change shifts an algorithm from linear time to NP-Complete:

Eulerian CircuitVisits every edge in $G$ exactly once and returns to start.$O(V + E)$ (Class P)Check if all vertex degrees are even (Euler's Theorem / Hierholzer's algorithm).

Hamiltonian Cycle Problem

Given an undirected graph $G = (V, E)$, does there exist a simple cycle that contains every vertex in $V$?

  • Verification in NP: Certificate is an ordered permutation $\langle v_1, v_2, \dots, v_n \rangle$. Verifier checks that all $n$ vertices are distinct, each $(v_i, v_{i+1}) \in E$, and $(v_n, v_1) \in E$. Runs in $O(V)$ time.
  • NP-Hardness: Proven by polynomial reduction from 3-SAT (using vertex-gadget chains) or from Directed Hamiltonian Cycle.

The Traveling Salesman Problem (TSP)

Given a complete graph $G = (V, E)$ with non-negative edge costs $c(u, v)$ between all pairs of vertices:

  • Optimization TSP: Find a tour (Hamiltonian cycle) of minimum total edge cost.
  • Decision TSP: Given threshold $k$, does there exist a tour with total cost $\le k$?
Proof: TSP is NP-Complete (Reducing Hamiltonian Cycle ≤_P TSP)

Step 1: TSP ∈ NP

Certificate is a sequence of $n$ vertices. The verifier sums the edge costs along the tour and checks if the sum is $\le k$. Takes $O(n)$ time → TSP ∈ NP.

Step 2: Reduction Construction from Hamiltonian Cycle

Let $G = (V, E)$ be an arbitrary unweighted graph with $n = |V|$ vertices. We construct a complete weighted graph $G' = (V, E')$ for TSP as follows:

  1. The vertex set of $G'$ is identical to $V$.
  2. For every pair of vertices $u, v \in V$: $$c(u, v) = \begin{cases} 1 & \text{if } (u, v) \in E \text{ (edge exists in } G) \\ 2 & \text{if } (u, v) \notin E \text{ (edge does not exist in } G) \end{cases}$$
  3. Set target threshold cost $k = n$.

This construction creates $\binom{n}{2}$ edges in $O(n^2)$ polynomial time.

Step 3: Correctness Proof (⇔)

  • Forward (⇒): Suppose $G$ contains a Hamiltonian cycle $C$. This cycle visits all $n$ vertices using $n$ edges from $E$. In $G'$, each of these edges has cost 1. The total cost of the tour in $G'$ is: $$\text{Cost} = n \times 1 = n \le k$$ Thus, $G'$ has a TSP tour of cost $\le n$.
  • Backward (⇐): Suppose $G'$ contains a TSP tour of cost $\le n$. A valid tour must visit all $n$ vertices, requiring at least $n$ edges. Since all edge costs in $G'$ are integers $\ge 1$, the only way for $n$ edges to sum to $\le n$ is if every single edge in the tour has cost exactly 1. By our definition, an edge in $G'$ has cost 1 if and only if that edge exists in $G$. Therefore, these edges form a valid Hamiltonian cycle in $G$.

Hence, TSP is NP-Complete.

Coping with NP-Completeness: Approximation Algorithms

When an optimization problem is NP-Hard, finding the exact optimal solution in polynomial time is impossible (assuming $P \ne NP$). Instead, we design polynomial-time approximation algorithms that deliver near-optimal solutions with a mathematically guaranteed bound.

Approximation Ratio $\rho(n)$ For a minimization problem, an algorithm has approximation ratio $\rho(n)$ if for all inputs of size $n$: $$\frac{C}{C^*} \le \rho(n)$$ where $C$ is the cost of the algorithm's solution and $C^*$ is the cost of the optimal solution. (A 2-approximation never costs more than twice the optimal).

1. 2-Approximation for Vertex Cover (Maximal Matching)

Algorithm Approx_Vertex_Cover(G): 
C = ∅
E' = E
while E' is not empty:
    Pick an arbitrary edge (u, v) from E'
    Add both u and v to C: C = C ∪ {u, v}
    Remove from E' all edges incident to either u or v
return C

Proof of 2-Approximation Bound:

  • Let $M$ be the set of edges selected by the loop. By construction, no two edges in $M$ share an endpoint; $M$ is a matching.
  • To cover the edges in $M$, any valid vertex cover (including the optimal cover $C^*$) must pick at least one distinct endpoint for each edge in $M$. Therefore: $$|C^*| \ge |M|$$
  • Our algorithm puts both endpoints of each edge in $M$ into $C$. Therefore: $$|C| = 2 \cdot |M| \le 2 \cdot |C^*|$$
  • The algorithm guarantees $|C| \le 2 \cdot |C^*|$ and runs in fast $O(V + E)$ time!

2. 2-Approximation for Metric TSP (Using Minimum Spanning Tree)

When edge costs satisfy the triangle inequality ($c(u, w) \le c(u, v) + c(v, w)$):

  1. Compute a Minimum Spanning Tree (MST) $T$ of $G$ using Kruskal's or Prim's algorithm ($O(E \log V)$).
  2. Double every edge of $T$ to create a graph where every vertex has even degree. This admits an Eulerian tour $W$.
  3. List the vertices in the order visited by $W$, and shortcut repeated visits directly to the next unvisited vertex (permitted by the triangle inequality).
$$\text{cost}(T) < \text{cost}(C^*) \quad \implies \quad \text{cost}(W) = 2 \cdot \text{cost}(T) < 2 \cdot \text{cost}(C^*)$$ By triangle inequality, shortcutting only reduces cost: $\text{cost}(\text{Tour}) \le \text{cost}(W) < 2 \cdot \text{cost}(C^*)$.

Check yourself

Retrieval practice

1. Why does the reduction from Hamiltonian Cycle to TSP set edge weights to 1 and 2?

If non-existing edges cost 2, choosing even a single non-existent edge pushes the tour cost to at least n+1.

2. In the 2-approximation algorithm for Vertex Cover, why are both endpoints of each picked edge added to C?

Since the edges in M are disjoint, the optimal cover must pick at least one endpoint from each; picking two gives at most 2× optimal.

3. What geometric property allows vertex shortcutting in the Metric TSP approximation without increasing total tour cost?

The triangle inequality guarantees that taking a direct shortcut between two nodes is never more expensive than routing through an intermediary.

Recall without looking

Contrast Eulerian circuit vs Hamiltonian cycle complexity.

Eulerian circuit visits every edge once and is solvable in linear time O(V+E) (Class P). Hamiltonian cycle visits every vertex once and is NP-Complete.

How does the Hamiltonian Cycle to TSP reduction assign weights?

Weight 1 for existing edges in G, weight 2 for non-existing edges. Target threshold cost k = n (where n = |V|).

How does the 2-approximation for Vertex Cover work?

Finds a maximal matching M of disjoint edges. Adds both endpoints of every edge in M to cover C. Since |C*| ≥ |M| and |C| = 2|M|, |C| ≤ 2|C*|.
