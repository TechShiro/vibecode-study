Classic NP-Complete Problems and Reductions

The grand tree of reductions: 3-SAT, the Clique decision problem, Vertex Cover, Set Cover, and step-by-step reduction gadget proofs.

Exam strategy

“Prove that the Clique Problem is NP-Complete by reducing from 3-SAT” and “Show that Vertex Cover is NP-Complete” are standard 10-mark examination proofs. Always write: (1) Certificate verification in polynomial time, (2) Gadget construction, and (3) Proof in both directions (if and only if).

1. 3-CNF Satisfiability (3-SAT)

  • Literal: A boolean variable $x_i$ or its negation $\overline{x_i}$.
  • Clause: A disjunction (OR $\lor$) of literals (e.g. $(x_1 \lor \overline{x_2} \lor x_3)$).
  • 3-CNF: A conjunction (AND $\land$) of clauses where each clause has exactly 3 distinct literals: $$\Phi = C_1 \land C_2 \land \dots \land C_m = (l_{11} \lor l_{12} \lor l_{13}) \land \dots \land (l_{m1} \lor l_{m2} \lor l_{m3})$$
  • Decision Problem: Does there exist a truth assignment to all variables that makes $\Phi$ evaluate to TRUE?
  • SAT → 3-SAT Reduction: Any general clause $(l_1 \lor l_2 \lor \dots \lor l_k)$ with $k > 3$ can be broken into 3-literal clauses using $k-3$ auxiliary variables $y_1, y_2, \dots$: $$(l_1 \lor l_2 \lor y_1) \land (\overline{y_1} \lor l_3 \lor y_2) \land \dots \land (\overline{y_{k-3}} \lor l_{k-1} \lor l_k)$$

2. The Clique Decision Problem (CDP)

Definition A clique in an undirected graph $G = (V, E)$ is a subset of vertices $V' \subseteq V$ such that every pair of vertices in $V'$ is connected by an edge (a complete subgraph).
Decision Problem: Given graph $G$ and integer $k$, does $G$ contain a clique of size at least $k$?
Proof: Clique is NP-Complete (Reducing 3-SAT ≤_P Clique)

Part 1: Show Clique ∈ NP

Certificate: A list of $k$ vertices $V'$. Verifier: Check that $|V'| = k$ and that for all pairs $u, v \in V'$, edge $(u, v) \in E$. This takes $O(k^2) = O(V^2)$ polynomial time. Hence, Clique ∈ NP.

Part 2: Reduction Construction from 3-SAT ($\Phi \to \langle G, k \rangle$)

  • Let $\Phi = C_1 \land C_2 \land \dots \land C_m$ be a 3-CNF formula with $m$ clauses.
  • For each clause $C_r = (l_r^1 \lor l_r^2 \lor l_r^3)$, create a group (triad) of 3 vertices in $G$. Total vertices $|V| = 3m$.
  • Place an undirected edge between two vertices $u$ and $v$ if and only if:
    1. $u$ and $v$ belong to different clause groups ($C_r \ne C_s$).
    2. $u$ and $v$ are consistent (they are not negations of each other, e.g. $x_1$ and $\overline{x_1}$).
  • Set target clique size $k = m$. Graph construction runs in $O(m^2)$ polynomial time.

Part 3: Correctness (⇔)

  • Forward (⇒): If $\Phi$ is satisfiable, pick one TRUE literal per clause. This gives $m$ vertices. Since they come from distinct clauses and none are contradictory, an edge exists between all of them → $G$ has a clique of size $m$.
  • Backward (⇐): If $G$ has a clique of size $m$, since no edges exist within the same clause triad, the clique must contain exactly one vertex from each clause triad. Because edges only connect consistent literals, we assign TRUE to these literals without contradiction → $\Phi$ is satisfied.

3. The Vertex Cover (VC) Problem

Definition A vertex cover of an undirected graph $G = (V, E)$ is a subset of vertices $V' \subseteq V$ such that every edge $(u, v) \in E$ has at least one endpoint in $V'$ ($u \in V'$ or $v \in V'$ or both).
Decision Problem: Given graph $G$ and integer $k$, does $G$ contain a vertex cover of size at most $k$?
Proof: Vertex Cover is NP-Complete (Reducing Clique ≤_P VC)

The Fundamental Duality Theorem:

For any graph $G = (V, E)$ with complement graph $\overline{G} = (V, \overline{E})$ where $(u, v) \in \overline{E} \iff (u, v) \notin E$:

$S \subseteq V$ is a Clique in $G \iff V \setminus S$ is a Vertex Cover in $\overline{G}$.

Reduction Algorithm:

  1. Given instance $\langle G, k \rangle$ of the Clique problem:
  2. Construct complement graph $\overline{G} = (V, \overline{E})$ in $O(V^2)$ polynomial time.
  3. Set target vertex cover size $k' = |V| - k$.
  4. Output instance $\langle \overline{G}, k' \rangle$.

Proof of Equivalence:

  • If $G$ has a clique $S$ of size $k$, then every pair in $S$ has an edge in $G$, so no pair in $S$ has an edge in $\overline{G}$. Therefore, any edge in $\overline{E}$ must have at least one endpoint outside $S$ (in $V \setminus S$). Thus, $V \setminus S$ covers all edges of $\overline{G}$, with size $|V| - k = k'$.
  • Conversely, if $\overline{G}$ has a vertex cover $V'$ of size $\le k'$, its complement $S = V \setminus V'$ has size $\ge |V| - k' = k$. Since $V'$ covers all edges in $\overline{G}$, no edge in $\overline{G}$ connects two vertices of $S$. Hence, all pairs in $S$ must be connected in $G$, forming a clique of size $\ge k$.

4. The Set Cover Problem

Given a universe $U = \{e_1, e_2, \dots, e_n\}$, a collection of subsets $S = \{S_1, S_2, \dots, S_m\}$ where each $S_i \subseteq U$, and an integer $k$. Can we choose at most $k$ subsets from $S$ whose union covers all of $U$?

Reduction: Vertex Cover ≤_P Set Cover
  • Let universe $U = E$ (all edges of graph $G$).
  • For each vertex $v \in V$, create subset $S_v = \{ e \in E \mid e \text{ is incident to } v \}$.
  • A set of $k$ vertices covers all edges in $G \iff$ the corresponding $k$ subsets cover universe $U$.

Check yourself

Retrieval practice

1. In the reduction from 3-SAT to Clique, how many vertices are created in graph G for a formula with m clauses?

Each clause contains 3 literals; a vertex is created for each literal position, totaling 3m vertices.

2. If S is a clique of size k in graph G with |V| vertices, what is V \ S in the complement graph Ḡ?

By the duality theorem, the complement of a clique in G is always a vertex cover in Ḡ.

3. In a vertex cover problem, an edge (u, v) is covered if:

A vertex cover requires at least one of the two incident endpoints of every edge to be in the subset.

Recall without looking

Define Clique and Vertex Cover.

Clique: a subset of vertices where every pair is connected by an edge. Vertex Cover: a subset of vertices that touches (covers) every edge in the graph.

State the duality theorem linking Clique and Vertex Cover.

S is a clique in G if and only if V \ S is a vertex cover in the complement graph Ḡ.

How are edges formed in the 3-SAT to Clique reduction graph?

Edges connect vertices in different clauses that are non-contradictory (do not represent x and ¬x).
