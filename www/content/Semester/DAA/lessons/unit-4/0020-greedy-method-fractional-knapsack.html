The greedy approach

At each step, make the locally optimal choice hoping it leads to a globally optimal solution. Unlike DP, greedy never reconsiders choices.

Two properties needed 1. Greedy-choice property: a globally optimal solution can be arrived at by making locally optimal choices.
2. Optimal substructure: an optimal solution contains optimal solutions to subproblems.
Greedy vs Dynamic Programming
GreedyDynamic Programming
ChoiceMake best local choice, never revisitTry all choices, pick best
SubproblemsOne subproblem after choiceOverlapping subproblems
GuaranteeOnly if greedy-choice property holdsAlways optimal if structure exists
EfficiencyUsually fasterUsually slower but more general

Fractional knapsack

Problem Given n items with weights wi and values vi, and a knapsack of capacity W.
Fractions allowed. Maximise total value.

Greedy strategy: sort items by vi/wi (value-per-unit-weight) in decreasing order. Take as much as possible of the most valuable-per-unit item.
Worked example

Capacity W = 50. Items:

ItemValueWeightv/w ratio
A60106.0
B100205.0
C120304.0

Sorted by ratio: A (6.0), B (5.0), C (4.0).

Step 1: Take all of A: weight = 10, value = 60. Remaining capacity = 40.

Step 2: Take all of B: weight = 20, value = 100. Remaining = 20.

Step 3: Take 20/30 of C: weight = 20, value = 120 × 20/30 = 80. Remaining = 0.

Total value = 60 + 100 + 80 = 240. Time: O(n log n) for sorting.

Why greedy fails for 0/1 knapsack

If fractions are NOT allowed, greedy by ratio can fail. Example: items (v=60,w=10), (v=100,w=20), (v=120,w=30), W=50. Greedy takes A+B = 160 leaving W=20. But optimal is B+C = 220 using W=50. The 0/1 version needs DP (Lesson 24).

Retrieval practice

1. The greedy method requires:

Both properties must hold for greedy to guarantee an optimal solution.

2. Fractional knapsack sorts items by:

Highest ratio = most value per unit weight. Take as much as possible of the best ratio item first.

3. The time complexity of fractional knapsack is:

Sort by ratio O(n log n), then one pass O(n). Total O(n log n).

4. Greedy fails for 0/1 knapsack because:

Without fractions, the greedy choice may waste capacity. DP explores all combinations.

Recall without looking

Two properties for greedy to work.

1. Greedy-choice property: locally optimal = globally optimal. 2. Optimal substructure: optimal solution contains optimal sub-solutions.

Fractional knapsack algorithm.

Sort by v/w ratio descending. Take full items greedily. Last item may be fractional. O(n log n). Greedy works because fractions are allowed.
