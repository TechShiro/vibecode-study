Dynamic Programming — LCS and 0/1 Knapsack

The Longest Common Subsequence problem and the 0/1 Knapsack problem — both with complete table-filling traces and backtracking to recover the solution.

Exam strategy

Both LCS and 0/1 Knapsack are guaranteed 10-mark numericals. Fill the table, show the recurrence at each cell, and trace back to find the solution. These are the two most-examined DP problems.

Longest Common Subsequence (LCS)

Recurrence Given X[1..m] and Y[1..n]:
c[i, j] = 0 if i=0 or j=0
c[i, j] = c[i−1, j−1] + 1 if X[i] = Y[j]
c[i, j] = max(c[i−1, j], c[i, j−1]) if X[i] ≠ Y[j]

Time: O(mn). Space: O(mn).

0/1 Knapsack

Recurrence Given n items with weights w[i] and values v[i], capacity W:
K[i, w] = 0 if i=0 or w=0
K[i, w] = K[i−1, w] if w[i] > w (item doesn’t fit)
K[i, w] = max(K[i−1, w], v[i] + K[i−1, w−w[i]]) otherwise

Time: O(nW). Space: O(nW). (Pseudo-polynomial)

Retrieval practice

1. LCS when X[i] = Y[j]:

Characters match, so the LCS extends from the diagonal cell by 1.

2. 0/1 Knapsack complexity is called:

W can be exponential in the number of bits needed to represent it, so O(nW) is not truly polynomial.

3. To recover the LCS string from the table:

Diagonal = character is in LCS. Up or left = character is skipped. Follow the path of choices.

4. In 0/1 knapsack, K[i,w] = max(K[i-1,w], v[i]+K[i-1,w-w[i]]) represents:

Either skip (value = previous row same capacity) or take (value of item + best with remaining capacity).

Recall without looking

LCS recurrence.

Match: c[i,j] = c[i-1,j-1]+1. Mismatch: c[i,j] = max(c[i-1,j], c[i,j-1]). O(mn) time.

0/1 Knapsack recurrence.

K[i,w] = max(K[i-1,w], v[i]+K[i-1,w-w[i]]) if w[i]≤w, else K[i-1,w]. O(nW) pseudo-polynomial.
