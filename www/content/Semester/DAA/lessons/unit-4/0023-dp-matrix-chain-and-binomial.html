Dynamic programming paradigm

Two properties 1. Optimal substructure: optimal solution contains optimal solutions to subproblems.
2. Overlapping subproblems: same subproblems are solved repeatedly — store results in a table (memoisation/tabulation).

Binomial coefficient

C(n, k) C(n, k) = C(n−1, k−1) + C(n−1, k)
C(n, 0) = C(n, n) = 1

Fill a table bottom-up. Time: O(nk). Space: O(nk) (or O(k) with rolling array).

Matrix Chain Multiplication

Given matrices A1(p0×p1), A2(p1×p2), …, An(pn−1×pn), find the parenthesisation that minimises the total number of scalar multiplications.

Recurrence m[i, j] = 0 if i = j
m[i, j] = mini≤k<j { m[i, k] + m[k+1, j] + pi−1 · pk · pj }

s[i, j] = the k that achieves the minimum (for recovering parenthesisation).
Time: O(n³). Space: O(n²).
Worked example

Dimensions: A1(10×30), A2(30×5), A3(5×60). So p = [10, 30, 5, 60], n=3.

Chain length 1: m[1,1] = m[2,2] = m[3,3] = 0.

Chain length 2:

m[1,2]: k=1 → m[1,1] + m[2,2] + 10·30·5 = 0 + 0 + 1500 = 1500. s[1,2]=1.

m[2,3]: k=2 → m[2,2] + m[3,3] + 30·5·60 = 0 + 0 + 9000 = 9000. s[2,3]=2.

Chain length 3:

m[1,3]: try k=1 and k=2:

  • k=1: m[1,1] + m[2,3] + 10·30·60 = 0 + 9000 + 18000 = 27000
  • k=2: m[1,2] + m[3,3] + 10·5·60 = 1500 + 0 + 3000 = 4500 ← min

m[1,3] = 4500. s[1,3] = 2.

Optimal parenthesisation: s[1,3]=2 ⇒ (A1A2)A3 = (10×30 · 30×5) · (10×5 · 5×60) = 1500 + 3000 = 4500 multiplications.

Without parenthesisation (A1(A2A3)): 9000 + 18000 = 27000. Optimal is 6× fewer!

Check yourself

Retrieval practice

1. MCM has time complexity:

Three nested loops: chain length (n), starting position (n), split point k (n).

2. The MCM recurrence is:

Split the chain at k: cost of left + cost of right + cost of multiplying the two resulting matrices.

3. DP differs from greedy because:

DP: exhaustive over subproblems, guaranteed optimal. Greedy: one choice, optimal only if greedy-choice property holds.

4. The s[i,j] table in MCM stores:

s[i,j] = k means split between A_k and A_{k+1}. Recurse on s to print the parenthesisation.

Recall without looking

MCM recurrence and complexity.

m[i,j] = min_k { m[i,k] + m[k+1,j] + p_{i-1}·p_k·p_j }. O(n³) time, O(n²) space. Fill table by increasing chain length.

Two properties of DP.

1. Optimal substructure. 2. Overlapping subproblems. Store results in table to avoid recomputation.
