Unit IV — Exam Sheet

Artificial Neural Networks — the heaviest unit in this paper.

Neuron model definition

net = Σwixi + b. y = f(net). Activation: step {0,1}, sigmoid (0,1), tanh (-1,1), ReLU [0,∞).

Learning paradigms memorise

Supervised (teacher + error), unsupervised (find patterns), reinforcement (reward/penalty).

Learning rules

Hebb: Δw = η·x·y. Delta: Δw = η(d-y)·x.

Perceptron guaranteed numerical

wi += η(d-y)xi. Converges if linearly separable. Cannot learn XOR (need MLP).

Back-propagation guaranteed numerical

Forward: o = σ(Σwx+b). Error: E = ½Σ(d-o)².
Output δ: (d-o)·o(1-o). Hidden δ: o(1-o)·Σδkwjk.
Update: Δw = η·δ·input. Sigmoid derivative: f' = o(1-o).

Hopfield guaranteed

Fully connected, symmetric wij=wji, wii=0. Energy: E = -½ΣΣwijsisj - Σθisi. Decreases → converges. Capacity ~0.15N.

Associative memory

Auto: noisy → original. Hetero: A → B (BAM).

Applications

Pattern recognition (OCR, speech, face). Forecasting (stock, weather). Image processing (compression, noise removal).

Five-minute scan

  1. Neuron: net = Σwx+b, y = f(net). Know 4 activation functions.
  2. 3 paradigms: supervised, unsupervised, reinforcement.
  3. Hebb: Δw=ηxy. Delta: Δw=η(d-y)x.
  4. Perceptron: converges if linearly separable. XOR fails.
  5. Back-prop: forward → error → δ_output → δ_hidden → Δw=ηδ·input.
  6. Hopfield: symmetric, energy decreases, auto-associative memory.
