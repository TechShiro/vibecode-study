Foundations definitions

Information System IS = (U, A)  —  U = objects (universe), A = attributes
Decision System DS = (U, A ∪ {d})  —  A = condition attributes, d = decision attribute
Indiscernibility Relation IND(P) = { (x, y) ∈ U × U | ∀a ∈ P, a(x) = a(y) }
An equivalence relation → partitions U into equivalence classes [x]P

More attributes → finer partition. Fewer attributes → coarser partition.

Approximations guaranteed question

Lower Approximation (Positive Region) R(X) = { x ∈ U | [x]R ⊆ X } — certainly in X
Upper Approximation R(X) = { x ∈ U | [x]R ∩ X ≠ ∅ } — possibly in X
Boundary Region BNR(X) = R(X) − R(X) — cannot be classified
Negative Region NEGR(X) = U − R(X) — certainly NOT in X
  • BN = ∅ ⇒ X is crisp (exact)
  • BN ≠ ∅ ⇒ X is rough
  • Fundamental containment: R(X) ⊆ X ⊆ R(X)

Accuracy and quality memorise

Accuracy of approximation αR(X) = |R(X)| / |R(X)|    (0 ≤ α ≤ 1)
Roughness ρR(X) = 1 − αR(X)
Quality of classification γR(Y) = |POSR(Y)| / |U|

Properties of approximations

#Property
1R(X) ⊆ X ⊆ R(X)
2R(∅) = R(∅) = ∅     R(U) = R(U) = U
3R(X) = complement of R(complement of X)
4X ⊆ Y ⇒ R(X) ⊆ R(Y) and R(X) ⊆ R(Y)
5R(X ∩ Y) = R(X) ∩ R(Y)
6R(X ∪ Y) = R(X) ∪ R(Y)

Attribute reduction high marks

Dispensable a is dispensable if IND(P) = IND(P − {a}) — removing it changes nothing
Indispensable a is indispensable if IND(P) ≠ IND(P − {a}) — removing it merges classes
Reduct Minimal subset R ⊆ P such that POSR(d) = POSP(d)
Core CORE = ∩ (all reducts) — attributes in EVERY reduct

CORE ⊆ every REDUCT ⊆ P

Discernibility matrix shortcut

  • For each pair (i, j) with different decisions: list attributes that differ.
  • Core = singleton entries — attributes that are the sole distinguisher.
  • A reduct must hit every entry (contain at least one attribute from each).

Five-minute scan before you walk in

  1. Pawlak, 1982. Fuzzy = vagueness in concept. Rough = indiscernibility in data.
  2. IS = (U, A). DS = (U, A ∪ {d}). IND(P) = equivalence relation on P.
  3. Lower = certainly in. Upper = possibly in. Boundary = uncertain.
  4. α = |lower| / |upper|. α = 1 means crisp. α < 1 means rough.
  5. Dispensable: removing doesn’t change partition. Indispensable: it does.
  6. Reduct: minimal sufficient subset. Core = ∩ all reducts.
  7. Discernibility matrix singletons = core.
  8. CORE ⊆ REDUCT ⊆ P.
  9. Sanity check: lower ⊆ target ⊆ upper. Lower ∪ boundary ∪ negative = U.
  10. Applications: feature selection, data mining, machine learning — name at least four domains.
