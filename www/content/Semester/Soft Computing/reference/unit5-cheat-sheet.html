1. Genetic Algorithm (GA) guaranteed cycle

Founders: John Holland (1975), David Goldberg. Based on Darwin's “survival of the fittest”.

Cycle: Initialize Population P(0) → Evaluate Fitness → Termination Test → Selection → Crossover (pc) → Mutation (pm) → Next Generation P(t+1).

Encodings: Binary (knapsack, bit strings), Real-valued (continuous optimization), Permutation (TSP, job sequencing), Tree (genetic programming).

2. Selection & Genetic Operators formulas

Roulette Wheel: Pi = fi / Σj=1N fj  |  Expected count: ei = fi / f̄
Tournament Selection: Pick k contestants randomly; fittest wins. Fast O(k), no global fitness sum required.
Rank Selection: Probability based on rank order (1 to N) rather than raw score — prevents premature stagnation.
Elitism: Directly copies top 1–2 best individuals into next generation without modification.
  • Crossover (Exploitation): Recombines parent schemas. Single-point (cut & swap), Two-point (middle swap), Uniform (bitmask coin toss). Typical p_c = 0.60 – 0.95.
  • Mutation (Exploration): Restores lost diversity; avoids local optima. Bit-flip (invert bit), Swap (exchange 2 alleles), Inversion (reverse segment). Typical p_m = 0.001 – 0.05.

3. Multi-Objective GA & NSGA-II definitions

Pareto Dominance: u ≺ v iff u is no worse than v in all objectives (f_k(u) ≤ f_k(v) ∀k) AND strictly better in at least one objective (∃j: f_j(u) < f_j(v)).

Pareto Front: Set of all non-dominated trade-off solutions plotted in objective space.

NSGA-II (Deb, 2002): 1. Fast non-dominated sorting into rank fronts (F₁, F₂, ...). 2. Crowding distance to preserve diversity along the front. 3. Crowded-comparison operator (≺n). 4. Elitist (2N → N) replacement.

4. Particle Swarm Optimization (PSO) guaranteed formula

Founders: James Kennedy & Russell Eberhart (1995). Inspired by bird flocking & fish schooling.

Velocity Update: vid(t+1) = w·vid(t) + c₁·r₁·[pbestid − xid(t)] + c₂·r₂·[gbestd − xid(t)]
Position Update: xid(t+1) = xid(t) + vid(t+1)  |  Clamping: −Vmax ≤ v ≤ Vmax
  • w = Inertia weight (momentum; controls exploration vs exploitation). Linearly decreased: 0.9 → 0.4.
  • c₁ · r₁ · (pbest − x) = Cognitive component (attraction to personal historical best; c₁ ≈ 2.0).
  • c₂ · r₂ · (gbest − x) = Social component (attraction to swarm global best; c₂ ≈ 2.0).
  • r₁, r₂ ∼ U(0, 1) = uniform random numbers injecting stochastic exploration.

5. Ant Colony Optimization (ACO) guaranteed formula

Founder: Marco Dorigo (1992). Based on stigmergic foraging & chemical pheromone trails.

State Transition Rule: Pijk(t) = [ τij(t)α · ηijβ ]  /  Σl ∈ allowedk [ τil(t)α · ηilβ ]
where heuristic visibility ηij = 1 / dij (inverse of edge distance).

Pheromone Evaporation & Deposition: τij(t+1) = (1 − ρ)·τij(t) + Σk=1m Δτijk(t)
where Δτijk = Q / Lk (if ant k used edge (i,j)), else 0. ρ ∈ (0, 1] is evaporation rate.
  • α = pheromone trail weight (memory influence; if 0 → purely greedy distance search).
  • β = heuristic visibility weight (distance influence; if 0 → purely pheromone-driven, rapid stagnation).
  • ρ = evaporation coefficient (prevents infinite pheromone accumulation on early sub-optimal paths).

7. Real-World Applications Summary

  • Routing & Logistics: Traveling Salesman Problem (TSP), Vehicle Routing Problem (VRP) — ACO/GA minimize delivery distance & fleet fuel costs.
  • Scheduling: Job Shop Scheduling (JSS), university exam timetabling — GA minimizes machine makespan and clashes.
  • Engineering Design: Truss weight minimization, aerodynamic airfoil shape optimization — PSO/GA optimize continuous structural parameters under stress constraints.
  • Telecommunications: Dynamic network packet routing (AntNet) — ACO deposits artificial pheromones on routers to balance bandwidth and relieve packet bottlenecks.
  • Machine Learning: Feature selection, neural network topology/weight training without gradient vanishing — PSO/GA.
  • Finance: Multi-objective portfolio optimization — NSGA-II balances maximum return vs minimum risk variance.

Ten-Minute Exam Final Scan

  1. GA cycle: Init → Fitness → Selection → Crossover (pc ≈ 0.8) → Mutation (pm ≈ 0.01) → Repeat.
  2. Roulette wheel: Pi = fi / Σf. Expected copies ei = fi / f̄.
  3. Elitism: Protects the all-time best chromosome from destructive crossover/mutation.
  4. Pareto dominance: u ≺ v iff u is ≤ in all objectives and < in at least one.
  5. NSGA-II: Uses fast non-dominated sorting, crowding distance, and (2N → N) elitist selection.
  6. PSO velocity: v = w·v + c₁r₁(pbest − x) + c₂r₂(gbest − x). Memory of pbest & gbest is unique to PSO.
  7. PSO inertia: High w (≈0.9) explores globally; low w (≈0.4) exploits locally. Linearly decreased over iterations.
  8. ACO transition rule: Pij ∝ τijα · ηijβ, where visibility ηij = 1 / dij.
  9. ACO pheromone update: τ ← (1 − ρ)τ + Σ(Q / Lk). Evaporation ρ prevents premature lock-in.
  10. Stigmergy: Indirect communication via the environment (ACO pheromones).
