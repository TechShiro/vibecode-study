Fuzzy sets definitions

  • Fuzzy set: A = {(x, μA(x)) | x ∈ X},   μ: X → [0,1]
  • Support: μ(x) > 0
  • Core: μ(x) = 1
  • Boundary: 0 < μ(x) < 1
  • Height: max μ(x)
  • Normal: height = 1; otherwise subnormal
  • Crossover point: μ(x) = 0.5
  • α-cut: Aα = {x | μ(x) ≥ α} — a CRISP set
  • Strong α-cut: uses > instead
  • Cardinality: |A| = ∑μ(x); relative = |A|/|X|
  • Convex: μ(λx₁+(1−λ)x₂) ≥ min(μ(x₁), μ(x₂))

Membership functions

Triangular (a,b,c):
max( min( (x−a)/(b−a), (c−x)/(c−b) ), 0 )

Trapezoidal (a,b,c,d):
max( min( (x−a)/(b−a), 1, (d−x)/(d−c) ), 0 )

Gaussian (c,σ): exp( −(x−c)² / 2σ² )

Bell (a,b,c): 1 / (1 + |(x−c)/a|2b)

Sigmoid (a,c): 1 / (1 + e−a(x−c))

The α-cut is the bridge between fuzzy and classical set theory — it turns a fuzzy set into a crisp one, and the α-cuts nest: as α rises the cut can only shrink.

The two laws that FAIL — guaranteed question

Law of excluded middle: A ∪ Ā ≠ X.    Law of contradiction: A ∩ Ā ≠ ∅.

Proof, one line: take μA = 0.3, so μĀ = 0.7. Then max(0.3, 0.7) = 0.7 ≠ 1 and min(0.3, 0.7) = 0.3 ≠ 0.

Everything else holds — including BOTH De Morgan laws. The two failures return only when A is crisp.

Relations and composition numerical

The three formulas Cartesian product:   μA×B(x,y) = min( μA(x), μB(y) )

Max–min composition:   μR∘S(x,z) = maxy[ min( μR(x,y), μS(y,z) ) ]

Max–product composition:   μR·S(x,z) = maxy[ μR(x,y) × μS(y,z) ]

Method: ordinary matrix multiplication with × → min and + → max.   Domain = row maxima · Range = column maxima · Inverse = transpose.

The check to run: since a·b ≤ min(a,b) on [0,1], every max–product entry must be ≤ the corresponding max–min entry. And an m×n composed with n×p must give m×p.

Tolerance relation = reflexive + symmetric.   Equivalence (similarity) = reflexive + symmetric + transitive. Transitive closure needs at most Rn−1.

Mamdani's five steps: fuzzify → apply the operator (min for AND) to get wi → clip each consequent at wi → aggregate by max → defuzzify by centroid.

Sugeno and Tsukamoto both finish with z* = ∑wizi / ∑wi. Sugeno underpins ANFIS. Tsukamoto needs monotonic consequents so that μ(z) = wi has a unique solution.

Fuzzy C-Means

Centres  |  Memberships cj = ∑(μij)mxi / ∑(μij)m

m = the fuzzifier; standard m = 2. m → 1 gives K-means; large m blurs every membership toward 1/c.
Steps: initialise U → compute centres → update memberships → stop when ‖ΔU‖ < ε.
Always check that each POINT's memberships sum to 1 across the clusters.

FCM vs K-means: graded membership in every cluster versus a single hard label. Both alternate centre and assignment updates, both are sensitive to initialisation, and both find only a local optimum.

Ten-minute final scan before you walk in
  1. Union = max, intersection = min. Do not swap them.
  2. A − B = min(μA, 1−μB) — never μA − μB.
  3. Algebraic sum keeps the −μAμB term.
  4. α-cut uses ≥, not >. The strong cut uses >.
  5. Composition = matrix multiply with min and max swapped in; max–product ≤ max–min everywhere.
  6. Centroid z* must land inside the support — check it.
  7. The two failing laws: excluded middle and contradiction. De Morgan holds.
  8. Knowledge base = rule base + database.
  9. Sugeno and Tsukamoto need NO defuzzification.
  10. FCM memberships sum to 1 across clusters, and m = 2 is standard.
