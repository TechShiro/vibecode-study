Architecture of a FIS

A Fuzzy Inference System is the complete machine that maps a crisp input to a crisp output using fuzzy rules. Four blocks — draw them as a left-to-right chain:

Block diagram — reproduce this crisp input → [ FUZZIFIER ] → [ INFERENCE ENGINE ] → [ DEFUZZIFIER ] → crisp output
                      ↑
               [ KNOWLEDGE BASE ]
          Rule Base + Database
BlockJob
Fuzzification moduleConverts each crisp input into degrees of membership in the input fuzzy sets
Knowledge baseTwo parts: the rule base (the IF-THEN rules) and the database (the membership functions those rules refer to)
Inference engineThe decision-making unit — computes each rule's firing strength, applies implication, aggregates the results
Defuzzification moduleCollapses the aggregated fuzzy output into one crisp number
Marks are lost here

The knowledge base has two components, not one. Students write "rule base" and stop. The database — the membership function definitions — is a separate component, and naming it is usually worth a mark.

The common setup for all three models

To see the differences cleanly, all three models below solve the same problem with the same firing strengths.

Shared premise

Two rules, two inputs. Crisp inputs x₀ = 3 and y₀ = 2 have already been fuzzified:

Ruleμ of antecedent 1μ of antecedent 2Firing strength w = min
R1: IF x is A₁ AND y is B₁ …μA₁(3) = 0.5μB₁(2) = 0.7w₁ = 0.5
R2: IF x is A₂ AND y is B₂ …μA₂(3) = 0.8μB₂(2) = 0.4w₂ = 0.4

AND is min; OR would be max. Everything up to this point is identical in all three models. The three models differ only in what comes after THEN.

1. Mamdani model

Ebrahim Mamdani, 1975, built to control a steam engine — the first real fuzzy controller. Its defining feature: the consequent is a fuzzy set.

Mamdani rule form IF x is A₁ AND y is B₁ THEN z is C₁   (C₁ is a fuzzy set)

The five steps

  1. Fuzzify the crisp inputs.
  2. Apply the fuzzy operator to combine antecedents — min for AND, max for OR — giving the firing strength wi.
  3. Implication: clip (truncate) each consequent set Ci at its wi, using min. Larsen's variant scales it by wi instead of clipping.
  4. Aggregation: combine all clipped consequents into one fuzzy set, using max.
  5. Defuzzify, normally by centroid.
Worked — Mamdani

Let the consequent sets on z = {0, 2, 4, 6, 8, 10} be
C₁ = 0/0 + 0.4/2 + 0.8/4 + 1.0/6 + 0.6/8 + 0.2/10
C₂ = 0.2/0 + 0.6/2 + 1.0/4 + 0.8/6 + 0.4/8 + 0/10

Step 3 — clip C₁ at w₁=0.5 and C₂ at w₂=0.4, i.e. take min(μ, w):

2. Sugeno model (Takagi–Sugeno–Kang)

Takagi, Sugeno & Kang, 1985. Defining feature: the consequent is a crisp mathematical function of the inputs, not a fuzzy set.

Sugeno rule form IF x is A₁ AND y is B₁ THEN z₁ = f(x, y) = p₁x + q₁y + r₁
  • Zero-order Sugeno: z = r, a constant. (This is a special case of Mamdani where every consequent is a singleton.)
  • First-order Sugeno: z = px + qy + r, a linear function.

Because each rule already produces a number, there is nothing to aggregate and nothing to defuzzify. The final output is simply the weighted average:

Sugeno output z* = ∑ wi zi / ∑ wi
Worked — Sugeno

Same firing strengths w₁ = 0.5, w₂ = 0.4, with inputs x₀ = 3, y₀ = 2 and consequent functions

R1: z₁ = x + y = 3 + 2 = 5      R2: z₂ = 2x − y = 6 − 2 = 4

z* = (0.5×5 + 0.4×4) / (0.5 + 0.4) = (2.5 + 1.6) / 0.9 = 4.1 / 0.9 = 4.56

Notice what did not happen: no clipping, no aggregation, no centroid integral. That is the whole point of Sugeno — and the reason it is the model used inside ANFIS, where the consequent parameters p, q, r can be tuned by least squares.

3. Tsukamoto model

Tsukamoto, 1979. Defining feature: the consequent of each rule is a fuzzy set with a monotonic membership function.

Monotonicity is what makes it work. Because the membership function is one-to-one, a firing strength wi can be inverted to give exactly one crisp zi:

Tsukamoto inference zi = μCi−1( wi )      then      z* = ∑ wi zi / ∑ wi
Worked — Tsukamoto

Same w₁ = 0.5, w₂ = 0.4. Let the monotonic consequents on z ∈ [0, 10] be

  • C₁, monotonically increasing: μ(z) = z / 10  →  z₁ = 10 × w₁ = 10 × 0.5 = 5
  • C₂, monotonically decreasing: μ(z) = 1 − z/10  →  z₂ = 10(1 − w₂) = 10(0.6) = 6

z* = (0.5×5 + 0.4×6) / (0.5 + 0.4) = (2.5 + 2.4) / 0.9 = 4.9 / 0.9 = 5.44

Why monotonic is essential. If the consequent had a peak, then μ(z) = 0.5 would hold at two different z values and the inversion would be ambiguous. Monotonicity guarantees exactly one solution — which is also the model's main limitation, since it restricts what shapes you may use.

The three models side by side

The results

Same inputs, same rules, same firing strengths — three different answers: Mamdani 5.13, Sugeno 4.56, Tsukamoto 5.44. The choice of model is a genuine design decision, not a formality.

The one-line summary

Mamdani is interpretable but slow; Sugeno is efficient and mathematically tractable but opaque; Tsukamoto is efficient but restricted to monotonic consequents. Write that as your concluding line and the comparison answer is complete.

Check yourself

Retrieval practice

1. The single defining difference of the Sugeno model is that its consequent is:

First-order Sugeno uses z = px + qy + r. The last option describes only zero-order Sugeno, which is a special case, not the definition.

2. Tsukamoto requires monotonic consequent membership functions because:

zi = μ−1(wi) is well defined only if μ is one-to-one. A non-monotonic MF would give two candidate values for zi and the inference would be ambiguous.

3. Firing strengths w = (0.6, 0.2) with rule outputs z = (10, 20). The Sugeno output is:

(0.6×10 + 0.2×20) / (0.6 + 0.2) = 10 / 0.8 = 12.5. Answering 15.0 means you took a plain average and ignored the weights; 14.0 means you forgot to divide by ∑w.

4. Which model requires both aggregation and defuzzification?

Mamdani alone produces a fuzzy set as output, so it must aggregate by max and then defuzzify. Sugeno and Tsukamoto both produce crisp per-rule values and finish with a weighted average.

Which inference model needs NO defuzzification step?

Both finish with the weighted average z* = ∑wizi / ∑wi. Only Mamdani aggregates clipped fuzzy sets and then defuzzifies, usually by centroid.

The knowledge base of a fuzzy inference system consists of:

The database holds the membership function definitions; the rule base holds the if–then rules. Saying only “rule base” loses the mark.

Tsukamoto requires its consequent membership functions to be monotonic because:

If the consequent had a peak, μ(z) = wi would hold at two different z values and the inverse would be ambiguous. That is the whole design constraint of the model.

Recall without looking

Name the four blocks of a FIS.

Fuzzification module; knowledge base (rule base + database); inference engine; defuzzification module.

List the five steps of Mamdani inference.

Fuzzify inputs; apply the fuzzy operator (min for AND) to get wi; implication — clip each consequent at wi; aggregate by max; defuzzify by centroid.

Write the Sugeno rule form and its output formula.

IF x is A AND y is B THEN z = px + qy + r. Output z* = ∑wizi / ∑wi.

Give four points of difference between Mamdani and Sugeno.

Consequent (fuzzy set vs crisp function); defuzzification (required vs not); cost (high vs low); interpretability (high vs low). Also: Sugeno guarantees a continuous output surface and underpins ANFIS.
