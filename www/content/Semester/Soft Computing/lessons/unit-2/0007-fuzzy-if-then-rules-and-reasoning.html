Linguistic variables

A linguistic variable is a variable whose values are words, not numbers. This is the mechanism that lets a machine compute with language.

Formal definition — a 5-tuple ( x , T(x) , U , G , M )

Linguistic hedges

A hedge is a modifier that transforms a fuzzy set — the operational meaning of words like "very" and "somewhat". These come straight from Lesson 5.

HedgeOperationEffect on μ = 0.64
very Aconcentration, μ²0.41 — memberships shrink, set becomes stricter
extremely Aμ³0.26 — stricter still
somewhat / more or less Adilation, μ0.50.80 — memberships grow, set becomes looser
slightly Aμ0.25 (further dilation)0.89
not Acomplement, 1 − μ0.36
intensify A2μ² if μ ≤ 0.5, else 1−2(1−μ)²0.74 — pushes values away from 0.5 toward 0 or 1
The pattern to remember

Powers above 1 concentrate ("very"); powers below 1 dilate ("somewhat"). Squaring 0.64 gives 0.41 — being very tall is harder than being tall, so the degree must fall. If your answer moves the wrong way, you have used the wrong exponent.

Fuzzy propositions

A fuzzy proposition has the form "x is A", where A is a fuzzy set. Its truth value is not true/false but a number in [0,1] — namely T(P) = μA(x).

Compound propositions combine using the standard operators:

ConnectiveFormTruth value
Negation (NOT)P̄1 − T(P)
Conjunction (AND)P ∧ Qmin( T(P), T(Q) )
Disjunction (OR)P ∨ Qmax( T(P), T(Q) )
Implication (IF…THEN)P → Qmax( 1 − T(P), T(Q) )  — classical form

Fuzzy if-then rules

The central object of the whole unit:

Fuzzy rule IF  x is A  THEN  y is B

A is the antecedent (premise), B is the consequent (conclusion). Critically:

The key insight

A fuzzy if-then rule IS a fuzzy relation R on X × Y. "If temperature is high then fan is fast" is not a program statement — it is a matrix of association degrees between every temperature and every fan speed. This is why everything in Lesson 6 immediately applies here.

Implication operators — how the rule becomes a matrix

Different authors turn A → B into a relation differently. Four you should know:

MethodμR(x, y) =Note
Mamdani (min)min( μA(x), μB(y) )By far the most used; it truncates the consequent
Larsen (product)μA(x) × μB(y)Scales the consequent instead of truncating it
Zadeh (max-min)max( min(μA, μB) , 1 − μA )The classical-logic-faithful version
Kleene–Dienesmax( 1 − μA(x) , μB(y) )Direct fuzzification of ¬P ∨ Q
Łukasiewiczmin( 1 , 1 − μA(x) + μB(y) )Bounded implication

Unless the question names one, use Mamdani min — and say so in your answer.

Fuzzy reasoning: the compositional rule of inference

Classical modus ponens says: given "P is true" and "P → Q", conclude "Q is true". It requires an exact match on P. Real observations never match exactly — the rule says "if temperature is high" and the sensor says 37°C.

Generalised Modus Ponens (GMP) removes that requirement:

Generalised Modus Ponens Premise 1 (observation):   x is A′
Premise 2 (rule):   IF x is A THEN y is B
————————————
Conclusion:   y is B′

and B′ is computed by the compositional rule of inference — which is exactly max–min composition:

Compositional rule of inference B′ = A′ ∘ R     i.e.    μB′(y) = maxx [ min( μA′(x) , μR(x,y) ) ]

Its mirror image, Generalised Modus Tollens (GMT), reasons backwards: given "y is B′" and the rule, conclude "x is A′" via A′ = R ∘ B′.

Worked example — GMP end to end

Given X = {x₁, x₂}, Y = {y₁, y₂}, with
A = 0.5/x₁ + 1.0/x₂    B = 0.4/y₁ + 0.9/y₂    observation A′ = 0.6/x₁ + 0.4/x₂

Step 1 — build R from the rule using Mamdani min, μR(x,y) = min(μA(x), μB(y)):

Ry₁ (0.4)y₂ (0.9)
x₁ (0.5)min(0.5,0.4) = 0.4min(0.5,0.9) = 0.5
x₂ (1.0)min(1.0,0.4) = 0.4min(1.0,0.9) = 0.9

Step 2 — compose the observation with R, B′ = A′ ∘ R, where A′ = (0.6, 0.4):

  • μB′(y₁) = max[ min(0.6, 0.4), min(0.4, 0.4) ] = max[0.4, 0.4] = 0.4
  • μB′(y₂) = max[ min(0.6, 0.5), min(0.4, 0.9) ] = max[0.5, 0.4] = 0.5

Conclusion: B′ = 0.4/y₁ + 0.5/y₂.

Read the result. The observation only partly matched A, so the conclusion is a weakened version of B — B had 0.9 at y₂, B′ has 0.5. That degradation is approximate reasoning: a partial match yields a partial conclusion, which classical modus ponens cannot express at all.

Decomposition and aggregation of rules

Two short-answer topics that close out this lesson.

Decomposition — compound rules into simple ones

Real rules have several clauses. Decomposition breaks them into canonical single-antecedent rules:

  • Multiple conjunctive antecedents: IF x is A₁ AND A₂ AND A₃ THEN y is B → combine the antecedents first by min into As = A₁ ∩ A₂ ∩ A₃, then apply the single rule.
  • Multiple disjunctive antecedents: IF x is A₁ OR A₂ THEN y is B → combine by max, As = A₁ ∪ A₂.
  • Conditional and unqualified: IF x is A THEN y is B, with no ELSE branch.
  • Nested-IF rules: IF x is A THEN (IF y is B THEN z is C) — flattened into a single conjunctive rule.

Aggregation — many rules into one output

A rule base fires several rules at once; their individual outputs must be merged.

SystemRules linked byAggregation
Conjunctive systemAND — all rules must hold togetherIntersection: μy = min over all rules
Disjunctive systemOR — any satisfied rule contributesUnion: μy = max over all rules

Disjunctive (max) aggregation is the standard in fuzzy control, and it is what a Mamdani FIS uses in Lesson 9.

3. In GMP, the conclusion B′ is obtained by:

B′ = A′ ∘ R — the compositional rule of inference. It is max–min composition applied to a 1×n row vector against an n×m relation matrix.

4. Rules combined disjunctively are aggregated using:

Disjunctive = OR = union = max. Conjunctive = AND = intersection = min. Disjunctive/max aggregation is the standard in Mamdani fuzzy control.

The hedge “very” is modelled as:

Concentration squares the membership, sharpening the set. μ0.5 is “somewhat” (dilation), μ³ is “extremely”, and 1 − μ is “not”.

The product is Larsen, max(1−μA, μB) is Kleene–Dienes, and the last is Łukasiewicz. Mamdani’s min is the default unless a question names another.

The generalised modus ponens computes B′ as:

First build R from the rule by an implication operator, then compose the observed input A′ with it: μB′(y) = maxx[ min(μA′(x), μR(x,y)) ].

Recall without looking

Give the 5-tuple defining a linguistic variable.

(x, T(x), U, G, M) — name, term set, universe of discourse, syntactic rule, semantic rule.

Name four implication operators with formulas.

Mamdani: min(μA, μB). Larsen: μA·μB. Zadeh: max(min(μA,μB), 1−μA). Kleene–Dienes: max(1−μA, μB).

State the compositional rule of inference.

B′ = A′ ∘ R, i.e. μB′(y) = maxx[min(μA′(x), μR(x,y))].

Conjunctive vs disjunctive rule aggregation?

Conjunctive: rules AND-ed, aggregate by min (intersection). Disjunctive: rules OR-ed, aggregate by max (union) — the standard choice.
