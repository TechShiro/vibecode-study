Crisp set vs fuzzy set

In a crisp set the characteristic function takes exactly two values:

Crisp / characteristic function μA(x) = 1  if x ∈ A     μA(x) = 0  if x ∉ A

A fuzzy set relaxes this to the whole interval. A fuzzy set A on universe of discourse X is the set of ordered pairs:

Fuzzy set — formal definition A = { ( x , μA(x) ) | x ∈ X } ,   where   μA(x) : X → [0, 1]

μA(x) is the membership function — the degree to which x belongs to A. A fuzzy set is completely and uniquely defined by its membership function; that sentence is worth a mark on its own.

The distinction examiners test

Fuzziness is not probability. "This bottle is 0.9 drinkable" (fuzzy) means it is somewhat drinkable — the vagueness is in the concept and does not disappear when you drink it. "This bottle is 90% likely to be drinkable" (probability) means it is either fine or poison and you do not yet know which — the uncertainty vanishes the moment you find out. Fuzziness is deterministic vagueness; probability is ignorance about a crisp fact.

Zadeh's notation

Two forms, and you must be able to read both.

Discrete universe — the summation form A = ∑ μA(xi) / xi  =  μ1/x1 + μ2/x2 + … + μn/xn
Continuous universe — the integral form A = ∫X μA(x) / x
Do not misread this

The "/" is not division and the "+" and "∫" are not arithmetic. The slash is a separator pairing a degree with its element; the plus and integral simply mean "collect these together". Writing 0.8/x₃ means "x₃ belongs with degree 0.8" — nothing is being divided.

So A = {0.2/x₁ + 0.5/x₂ + 0.8/x₃ + 1.0/x₄} and A = {(x₁,0.2), (x₂,0.5), (x₃,0.8), (x₄,1.0)} are the same set. Elements with μ = 0 are conventionally omitted.

The five standard membership functions

Learn the triangular and trapezoidal forms properly — they are the ones you will be asked to sketch, and the ones used in every Mamdani numerical.

Triangular — three parameters (a, b, c)

Triangular MF μ(x) = 0  (x ≤ a)  |  (x−a)/(b−a)  (a ≤ x ≤ b)
        (c−x)/(c−b)  (b ≤ x ≤ c)  |  0  (x ≥ c)

compactly:   μ(x) = max( min( (x−a)/(b−a) , (c−x)/(c−b) ) , 0 )

a and c are the feet, b is the peak. The membership rises linearly from a to b, falls linearly from b to c.

Trapezoidal — four parameters (a, b, c, d)

Trapezoidal MF μ(x) = max( min( (x−a)/(b−a) , 1 , (d−x)/(d−c) ) , 0 )

Same shape but with a flat top between b and c. Use it when a range of values is "fully" the concept — e.g. any temperature from 20°C to 26°C is completely comfortable.

Gaussian — two parameters (c, σ)

Gaussian MF μ(x) = exp( −(x − c)² / 2σ² )

c is the centre, σ controls the width. Smooth and non-zero everywhere — which means its support is the whole universe.

Generalised bell — three parameters (a, b, c)

Generalised bell MF μ(x) = 1 / ( 1 + | (x − c) / a |2b )

a sets the width, b the steepness of the sides, c the centre. One extra parameter over the Gaussian buys control of the shoulder shape.

Sigmoid — two parameters (a, c)

Sigmoidal MF μ(x) = 1 / ( 1 + exp( −a (x − c) ) )

Open on one side. Positive a gives a function that saturates at 1 for large x — right for concepts like "very large" that have no upper bound.

Discrete vs continuous

A discrete membership function is defined on a countable universe and is written as a list of pairs — nothing between the listed points exists. A continuous one is defined by a formula over an interval and has a value at every real point. Triangular and Gaussian are continuous; {0.2/1 + 0.6/2 + 1.0/3} is discrete.

The α-cut is the bridge

An α-cut converts a fuzzy set into a crisp set by keeping everything with membership at least α. This is the single most important idea in the unit: it is how fuzzy results become usable decisions, and it is the whole basis of the λ-cut defuzzification method in Lesson 8. A strong α-cut uses strict inequality, μ(x) > α.

Three more definitions worth two marks each

  • Convex fuzzy set: μ(λx₁ + (1−λ)x₂) ≥ min( μ(x₁), μ(x₂) ) for all x₁, x₂ and λ ∈ [0,1]. In plain terms: the membership function rises, then falls — it never dips in the middle. Every α-cut of a convex fuzzy set is a single interval.
  • Fuzzy singleton: a fuzzy set whose support is a single point, with membership 1 there. This is what a crisp measured input becomes in singleton fuzzification.
  • Cardinality: |A| = ∑ μA(x). For A = {0.2/x₁ + 0.5/x₂ + 0.8/x₃ + 1.0/x₄}, |A| = 2.5. Relative cardinality = |A| / |X| = 2.5 / 4 = 0.625.
Worked example — features of a fuzzy set

Given A = {0.1/1 + 0.4/2 + 1.0/3 + 1.0/4 + 0.6/5 + 0.0/6} on X = {1,2,3,4,5,6}. Find support, core, height, boundary, cardinality, and the 0.5-cut. State whether A is normal.

  1. Support = elements with μ > 0 = {1, 2, 3, 4, 5}. (6 is excluded — its membership is exactly 0.)
  2. Core = elements with μ = 1 = {3, 4}.
  3. Height = max μ = 1.0.
  4. Normal? Height = 1, so yes, A is normal.
  5. Boundary = elements with 0 < μ < 1 = {1, 2, 5}.
  6. Cardinality = 0.1 + 0.4 + 1.0 + 1.0 + 0.6 + 0.0 = 3.1.
  7. A0.5 = elements with μ ≥ 0.5 = {3, 4, 5}. Note 0.6 ≥ 0.5 so 5 is in; 0.4 < 0.5 so 2 is out.

Watch the ≥. An α-cut uses "greater than or equal to". Dropping an element whose membership equals α exactly is the most common slip in this question.

Two checks worth running. The α-cuts must nest: as α rises the cut can only shrink, and {3,4} ⊂ {2,3,4,5} ✓. And the strong cut at α is always a subset of the ordinary cut at the same α — here {3,4,5} ⊂ {2,3,4,5}, differing exactly at the crossover point. That single element is the whole reason ≥ and > must not be confused.

Recall without looking

Define a fuzzy set formally.

A = {(x, μA(x)) | x ∈ X} where μA: X → [0,1]. A fuzzy set is completely and uniquely defined by its membership function.

Write the triangular membership function.

μ(x) = max( min( (x−a)/(b−a), (c−x)/(c−b) ), 0 ) — feet at a and c, peak at b.

Define support, core, boundary, height and α-cut.

Support: μ>0. Core: μ=1. Boundary: 0<μ<1. Height: max μ. α-cut: {x | μ(x) ≥ α} — a crisp set.

Difference between fuzziness and probability?

Fuzziness is vagueness in the concept itself and persists after observation. Probability is ignorance about a crisp fact and vanishes once the fact is known.
