From crisp relations to fuzzy relations

A crisp relation R between X and Y is a subset of the Cartesian product X × Y. Its characteristic function answers a yes/no question: is x related to y?

A fuzzy relation replaces yes/no with a degree of association:

Fuzzy relation R = { ( (x,y) , μR(x,y) ) | (x,y) ∈ X × Y } ,   μR : X × Y → [0,1]

It is written as a matrix with rows indexed by X and columns by Y — the relation matrix. Everything you do with fuzzy relations is matrix work.

Cartesian product of two fuzzy sets

Given a fuzzy set A on X and B on Y, their Cartesian product is a fuzzy relation on X × Y:

Cartesian product — the MIN rule μA×B(x, y) = min( μA(x) , μB(y) )  =  μA(x) ∧ μB(y)
Worked example — building the relation matrix

Given A = 0.2/x₁ + 0.7/x₂ + 1.0/x₃   and   B = 0.5/y₁ + 0.9/y₂.

Take the minimum of the row's A-value and the column's B-value:

R = A × By₁ (0.5)y₂ (0.9)
x₁ (0.2)min(0.2, 0.5) = 0.2min(0.2, 0.9) = 0.2
x₂ (0.7)min(0.7, 0.5) = 0.5min(0.7, 0.9) = 0.7
x₃ (1.0)min(1.0, 0.5) = 0.5min(1.0, 0.9) = 0.9

Sanity check: no entry may exceed the smaller of the two set values that produced it, and a row whose A-value is 0.2 can never contain anything above 0.2. Scan for that before moving on — it catches most arithmetic slips instantly.

Operations on fuzzy relations

These are the Lesson 5 operations applied element-wise to matrices of the same size:

OperationRule
Union R ∪ Smax( μR(x,y), μS(x,y) )
Intersection R ∩ Smin( μR(x,y), μS(x,y) )
Complement R̄1 − μR(x,y)
Containment R ⊆ SμR(x,y) ≤ μS(x,y) everywhere
Inverse R−1μR−1(y,x) = μR(x,y) — simply the transpose of the matrix
λ-cut RλReplace each entry with 1 if μ ≥ λ, else 0 — gives a crisp relation matrix

Domain and range are asked as a short question:

  • Domain: μdom R(x) = maxy μR(x,y) — the maximum of each row.
  • Range: μran R(y) = maxx μR(x,y) — the maximum of each column.

For the R above: domain = {0.2/x₁, 0.7/x₂, 0.9/x₃}, range = {0.5/y₁, 0.9/y₂}.

Composition — the main event

Composition chains two relations. If R relates X to Y, and S relates Y to Z, then R ∘ S relates X to Z, with Y eliminated in between.

Max–min composition (Zadeh's, the default) μR∘S(x, z) = maxy [ min( μR(x,y) , μS(y,z) ) ]
Max–product composition (max–dot) μR·S(x, z) = maxy [ μR(x,y) × μS(y,z) ]
The trick that makes this easy

It is ordinary matrix multiplication with the operators swapped. Where you would multiply, take min (or the actual product, for max–product); where you would add, take max. Row of R against column of S, exactly as usual. Once you see that, composition stops being a new thing to learn.

Properties of fuzzy relations

For a relation R on X × X (same set both sides):

PropertyConditionIn the matrix
ReflexiveμR(x, x) = 1 for all xThe whole main diagonal is 1
SymmetricμR(x,y) = μR(y,x)The matrix equals its transpose
TransitiveμR(x,z) ≥ maxy min( μR(x,y), μR(y,z) )R ⊇ R ∘ R — check by composing R with itself

Two named combinations you will be asked to identify:

  • Fuzzy tolerance relation (proximity relation): reflexive + symmetric.
  • Fuzzy equivalence relation (similarity relation): reflexive + symmetric + transitive.
Useful fact

Any tolerance relation R on n elements can be converted into an equivalence relation by composing it with itself at most n−1 times: Rn−1 = R ∘ R ∘ … This is called the transitive closure, and "convert this tolerance relation into an equivalence relation" is a standard 5-mark problem.

The check to run every time: since a·b ≤ min(a,b) for any a, b in [0,1], every max–product entry must be less than or equal to the corresponding max–min entry. Here 0.30 ≤ 0.5, 0.56 ≤ 0.7, 0.54 ≤ 0.6, 0.30 ≤ 0.5 — all four hold. If any max–product entry exceeds its max–min counterpart, you have made an arithmetic error.

Also check the shape: R is 2×3 and S is 3×2, so the composition must be 2×2. Getting a differently shaped answer means the rows and columns were crossed.

Retrieval practice

1. R is 4×3 and S is 3×5. The size of R ∘ S is:

Exactly as in matrix multiplication: the shared dimension (3) is eliminated, leaving rows of R by columns of S.

2. Row of R = (0.3, 0.8); column of S = (0.9, 0.5). Max–min composition gives:

min(0.3,0.9)=0.3 and min(0.8,0.5)=0.5; the max of those is 0.5. Note the winner is the second pair even though it contains the smaller number 0.5 — always compute both mins before taking the max.

3. Same values as above, but by max–product composition:

0.3×0.9 = 0.27 and 0.8×0.5 = 0.40; the max is 0.40. Max–product results are generally lower than max–min, since a product of two numbers below 1 is smaller than either.

4. A fuzzy relation that is reflexive and symmetric but not transitive is called a:

Tolerance (or proximity) = reflexive + symmetric. Adding transitivity promotes it to an equivalence relation, also called a similarity relation — those two names mean the same thing.

The fuzzy Cartesian product μA×B(x,y) is:

It builds the relation matrix from two fuzzy sets. The product form belongs to max–product composition, not to the Cartesian product.

Max–min composition is computed by:

μR∘S(x,z) = maxy[ min(μR(x,y), μS(y,z)) ]. Keeping the row-by-column discipline of matrix multiplication is what stops errors.

A fuzzy relation that is reflexive and symmetric but NOT transitive is called:

Adding transitivity makes it an equivalence, or similarity, relation. A tolerance relation can be raised to it by taking the transitive closure, at most Rn−1.

Recall without looking

Write the Cartesian product rule for two fuzzy sets.

μA×B(x,y) = min(μA(x), μB(y)).

Write max–min and max–product composition.

Max–min: μ(x,z) = maxy[min(μR(x,y), μS(y,z))]. Max–product: μ(x,z) = maxy[μR(x,y) × μS(y,z)].

How do you find the domain and range of a fuzzy relation?

Domain = maximum of each row. Range = maximum of each column.

Define fuzzy tolerance and fuzzy equivalence relations.

Tolerance: reflexive + symmetric. Equivalence (similarity): reflexive + symmetric + transitive. Transitive closure Rn−1 converts the first into the second.
