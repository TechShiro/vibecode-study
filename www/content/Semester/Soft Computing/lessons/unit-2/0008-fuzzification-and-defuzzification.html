Fuzzification and Defuzzification

Crisp in, crisp out. Seven defuzzification methods with their formulas, and four fully worked numericals — centroid, weighted average, mean of maxima and centre of sums.

Why this matters tomorrow

Defuzzification is the highest-yield numerical in Unit II. "Find the defuzzified value using the centroid method" is close to guaranteed. The arithmetic is one division — the marks are lost on setting up ∑μ·z correctly, so do the worked examples with a pen, not by reading.

Visual Taxonomy: The 5 Primary Defuzzification Strategies
1. Centre of Gravity (COG) Balance point / center of area. Most popular, smooth, mathematically rigorous.
2. Bisector Method Vertical line dividing the aggregated membership area into two strictly equal halves.
3. Mean of Maxima (MOM) Arithmetic average of all points in the universe that achieve peak membership ($\mu_{\max}$).
4. SOM & LOM Smallest / Largest domain point achieving peak membership value. Fast, discontinuous.

Where these two steps sit

A fuzzy system talks to the real world, and the real world is crisp. Sensors give numbers; actuators need numbers. Fuzzy reasoning happens strictly in between:

The pipeline crisp input  →  FUZZIFICATION  →  fuzzy input
→  inference over the rule base  →  fuzzy output
→  DEFUZZIFICATION  →  crisp output

Fuzzification

Fuzzification is converting a crisp input value into degrees of membership in the relevant fuzzy sets. A temperature reading of 37°C might become warm to degree 0.3 and hot to degree 0.7 — one number becomes several partial memberships.

Methods of fuzzification

Asked as a list question. Seven methods, one line each:

MethodHow membership functions are obtained
IntuitionFrom human expertise and semantic understanding — the expert simply draws the shapes
InferenceDeduced from known facts and existing knowledge about the problem
Rank orderingBuilt from pairwise comparisons, polls or preference surveys
Angular fuzzy setsDefined on the unit circle; used for variables that are naturally cyclic or polar
Neural networksAn ANN learns the membership functions from training data
Genetic algorithmsA GA searches for the membership function parameters that maximise performance
Inductive reasoningDerived from data by minimising entropy — partitions chosen to be maximally informative

In practice, singleton fuzzification is most common in control: the crisp measurement x₀ becomes a fuzzy singleton with μ(x₀) = 1 and 0 everywhere else. It is cheap and it simplifies the inference arithmetic considerably.

Defuzzification

Defuzzification is the reverse: collapsing the aggregated output fuzzy set into a single crisp number the actuator can use. Every method is a different answer to "which single point best represents this shape?"

The seven methods

MethodFormula / ruleCharacter
1. Max-membership
(height method)		z* = the z at which μ(z) is maximumFastest; only valid when the peak is a single point
2. Centroid
(COG / centre of area)		z* = ∑μ(z)·z / ∑μ(z)  (discrete)
z* = ∫μ(z)·z dz / ∫μ(z) dz  (continuous)		Most widely used and most accurate; costliest to compute
3. Weighted averagez* = ∑μ(z̄i)·z̄i / ∑μ(z̄i)Fast, but valid only for symmetric output MFs; z̄i is each MF's centre
4. Mean of maxima (MOM)z* = (a + b) / 2, where [a,b] is the interval over which μ is maximumFast; ignores the shape entirely
5. First / Last of maxima
(SOM / LOM)		z* = a  (smallest z at max)  or  z* = b  (largest z at max)Used when a conservative or aggressive bias is wanted
6. Centre of sums (COS)z* = ∑Ai·z̄i / ∑Ai, where Ai is each output MF's areaMuch faster than centroid; overlapping regions counted twice
7. Centre of largest areaApply the centroid to the largest connected sub-region onlyFor output sets that come out disconnected
8. λ-cut methodTake Aλ = {z | μ(z) ≥ λ}, giving a crisp setProduces a crisp set, not a single value
If a question does not name a method

Use the centroid method and say so explicitly in your first line. It is the default in almost every textbook and in MATLAB's Fuzzy Logic Toolbox, and no examiner will mark it wrong.

Worked numerical 1 — centroid method

Centroid, discrete universe

Given the aggregated output fuzzy set:

z1234567
μ(z)0.10.30.61.00.80.40.2
μ·z0.10.61.84.04.02.41.4

Step 1: ∑μ·z = 0.1 + 0.6 + 1.8 + 4.0 + 4.0 + 2.4 + 1.4 = 14.3

Step 2: ∑μ = 0.1 + 0.3 + 0.6 + 1.0 + 0.8 + 0.4 + 0.2 = 3.4

Step 3: z* = 14.3 / 3.4 = 4.21

Sanity check: z* must lie inside the support (1 to 7) and be pulled toward the heavy side. The peak is at 4 and there is more mass to its right (0.8, 0.4, 0.2) than left (0.6, 0.3, 0.1), so an answer slightly above 4 is exactly right. Any result outside [1,7] means an arithmetic error.

Worked numerical 2 — weighted average

Weighted average, symmetric output sets

Given two symmetric output membership functions, fired to these degrees:

  • Medium, centred at z̄₁ = 4, clipped at μ = 0.8
  • High, centred at z̄₂ = 7, clipped at μ = 0.5

z* = (0.8 × 4 + 0.5 × 7) / (0.8 + 0.5) = (3.2 + 3.5) / 1.3 = 6.7 / 1.3 = 5.15

Note the shortcut being taken: the method uses only each MF's centre and its firing strength — the shapes are never integrated. That is why it is fast, and why it is only valid when the output MFs are symmetric. Say that in the exam; it is often a mark on its own.

Worked numerical 3 — mean of maxima

MOM, and its cousins SOM and LOM

Given:

z1234567
μ(z)0.20.50.81.01.00.60.3

Maximum membership is 1.0, attained over the interval [4, 5]. Therefore:

  • MOM = (4 + 5) / 2 = 4.5
  • SOM (smallest / first of maxima) = 4
  • LOM (largest / last of maxima) = 5

Why max-membership fails here. The height method needs a unique peak; this set has a plateau, so it cannot pick one. That ambiguity is exactly the reason MOM, SOM and LOM exist. If asked "when does the max-membership principle fail?", this is the answer.

Worked numerical 4 — centre of sums

COS, using areas

Given two triangular output sets after clipping:

  • Set 1: base from 1 to 5 (width 4), height 0.5 → A₁ = ½ × 4 × 0.5 = 1.0, centroid z̄₁ = 3
  • Set 2: base from 4 to 10 (width 6), height 0.8 → A₂ = ½ × 6 × 0.8 = 2.4, centroid z̄₂ = 7

z* = (A₁z̄₁ + A₂z̄₂) / (A₁ + A₂) = (1.0×3 + 2.4×7) / (1.0 + 2.4) = (3 + 16.8) / 3.4 = 19.8 / 3.4 = 5.82

COS vs centroid. COS takes the areas of the individual output sets before aggregation, so the region where they overlap (4 to 5 here) is counted twice. The centroid method aggregates first by max and therefore counts it once. That double-counting is the entire difference between the two methods — and it is the standard 2-mark follow-up question.

Choosing a method

CriterionBest choice
Accuracy and smooth control responseCentroid
Speed / real-time embedded controlMOM, max-membership, or COS
Symmetric output MFs, want speed without much lossWeighted average
Output set comes out disconnectedCentre of largest area
You need a crisp set rather than a single valueλ-cut method

Two properties a good defuzzifier should have, worth naming: continuity (a small change in the fuzzy set causes only a small change in z*) and plausibility (z* lies near the middle of the support and has a high membership).

Recall without looking

Write the centroid formula, discrete and continuous.

Discrete: z* = ∑μ(z)z / ∑μ(z). Continuous: z* = ∫μ(z)z dz / ∫μ(z) dz.

Name seven defuzzification methods.

Max-membership (height), centroid, weighted average, mean of maxima, first/last of maxima, centre of sums, centre of largest area. Plus the λ-cut method, which yields a crisp set.

Name the seven fuzzification methods.

Intuition, inference, rank ordering, angular fuzzy sets, neural networks, genetic algorithms, inductive reasoning.

When does the max-membership principle fail, and what replaces it?

When the maximum is attained over an interval rather than a single point. MOM, SOM or LOM resolve the plateau.
