The three core operations

Zadeh defined these in 1965 and they remain the standard.

Union — the MAX operator μA∪B(x) = max( μA(x) , μB(x) )  =  μA(x) ∨ μB(x)
Intersection — the MIN operator μA∩B(x) = min( μA(x) , μB(x) )  =  μA(x) ∧ μB(x)
Complement μĀ(x) = 1 − μA(x)
Never confuse these two

Union = MAX. Intersection = MIN. The mnemonic: union is generous — it takes the larger degree; intersection is strict — it takes the smaller. Swapping them wrecks every subsequent step of a numerical, so check it once before you start writing.

How the harder rows were computed

Difference A − B = A ∩ B̄ — "in A but not in B". At x₃: min(0.8, 1−0.9) = min(0.8, 0.1) = 0.1. Note it is not μA − μB. Subtracting directly is the single most common error here.

Algebraic sum at x₂: 0.5 + 0.3 − (0.5 × 0.3) = 0.8 − 0.15 = 0.65. The −μAμB term is what keeps the result inside [0,1]; forget it and you can produce 1.6, which is not a membership.

Disjunctive sum is the fuzzy XOR — "in one but not both". Compute the two halves first: A ∩ B̄ = {0.2, 0.5, 0.1, 0.4} and Ā ∩ B = {0.4, 0.3, 0.2, 0.0}. Then take the max at each point: at x₁, max(0.2, 0.4) = 0.4; at x₃, max(0.1, 0.2) = 0.2.

  • Equality: A = B iff μA(x) = μB(x) for every x ∈ X.

The two laws that FAIL

Guaranteed question

"Which properties of classical sets are not satisfied by fuzzy sets?" — the answer is exactly two, and you must be able to prove both with a one-line counter-example.

Law of excluded middle — FAILS A ∪ Ā ≠ X
Law of contradiction — FAILS A ∩ Ā ≠ ∅
Proof by counter-example — write exactly this

Take x₁ from our set A, where μA(x₁) = 0.2, so μĀ(x₁) = 0.8.

  • Excluded middle: μA∪Ā(x₁) = max(0.2, 0.8) = 0.8 ≠ 1. The union does not cover the universe.
  • Contradiction: μA∩Ā(x₁) = min(0.2, 0.8) = 0.2 ≠ 0. The set and its complement overlap.

Why, in one sentence: in classical logic a statement and its negation cannot both hold; in fuzzy logic an element can be partly in a set and partly in its complement at the same time. A man 175 cm tall is 0.6 Tall and 0.4 Not-Tall simultaneously — so "tall or not tall" is only 0.6 true, not certainly true.

The single exception: if A happens to be a crisp set (every μ is 0 or 1), both laws hold again.

The two failing laws, verified on this data at x₁:
Excluded middle: A ∪ Ā = max(0.3, 0.7) = 0.7 ≠ 1.    Contradiction: A ∩ Ā = min(0.3, 0.7) = 0.3 ≠ 0.

Three checks. Every result must lie in [0,1] ✓. Intersection ≤ union at every point ✓. And CON ≤ μ ≤ DIL everywhere, since squaring a number below 1 shrinks it and taking its root grows it — note that at x₃, where μ = 1, all three coincide.

Retrieval practice

1. μA(x) = 0.7 and μB(x) = 0.4. The value of μA−B(x) is:

A − B = A ∩ B̄ = min(0.7, 1−0.4) = min(0.7, 0.6) = 0.6. The tempting answer 0.3 comes from subtracting directly, which is wrong.

2. μA(x) = 0.6 and μB(x) = 0.5. The algebraic sum at x equals:

0.6 + 0.5 − (0.6 × 0.5) = 1.1 − 0.3 = 0.8. Choosing 1.10 means you dropped the product term — and 1.10 cannot be a membership at all.

3. Which pair of classical laws does fuzzy set theory violate?

Everything else survives, including both De Morgan laws. Only A ∪ Ā = X and A ∩ Ā = ∅ break, because partial membership lets an element sit in a set and its complement at once.

4. CON(A), the concentration of A, corresponds to which linguistic hedge?

Squaring memberships lowers every value below 1, so fewer elements qualify strongly — the set becomes more demanding, i.e. "very". Taking the square root (dilation) does the opposite: "somewhat".

The fuzzy difference A − B is:

A − B means A ∩ B̄, so it is min of μA and the complement of μB. Writing μA − μB can give a negative number, which is not a membership at all.

The algebraic sum of two fuzzy sets is:

The subtracted product is what keeps the result inside [0,1]. min(1, μA+μB) is the bounded sum, a different operation.

Which classical laws still hold for fuzzy sets?

With μA = 0.2: max(0.2, 0.8) = 0.8 ≠ 1 and min(0.2, 0.8) = 0.2 ≠ 0. Everything else — commutativity, associativity, distributivity, idempotence, De Morgan — survives.

Recall without looking

State union, intersection and complement for fuzzy sets.

Union = max(μA, μB). Intersection = min(μA, μB). Complement = 1 − μA.

Write the algebraic sum, algebraic product, bounded sum and bounded difference.

Algebraic sum: μA+μB−μAμB. Algebraic product: μAμB. Bounded sum: min(1, μA+μB). Bounded difference: max(0, μA+μB−1).

Prove the law of contradiction fails.

Let μA(x)=0.2, so μĀ(x)=0.8. Then μA∩Ā(x)=min(0.2,0.8)=0.2≠0. Hence A ∩ Ā ≠ ∅.

What is the disjunctive sum?

The fuzzy XOR: (A ∩ B̄) ∪ (Ā ∩ B) — in one set but not both.
