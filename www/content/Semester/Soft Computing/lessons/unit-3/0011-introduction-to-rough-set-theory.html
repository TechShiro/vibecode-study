What is a rough set?

Introduced by Zdzisław Pawlak in 1982, rough set theory deals with situations where a concept is crisp but the available data cannot separate its members from non-members perfectly. When this happens, the concept can only be approximated:

  • From below (lower approximation) — objects that certainly belong.
  • From above (upper approximation) — objects that possibly belong.

The gap between the two is the boundary region, and if the boundary is non-empty the set is called rough.

The one-line distinction examiners probe

Fuzzy sets handle vagueness in the concept — “tall” has no sharp boundary, so membership is graded. Rough sets handle indiscernibility in the data — the concept is crisp, but the attributes available cannot separate it precisely, so it is approximated. Vagueness in the concept versus insufficiency in the data.

Information System (IS)

Information System IS = ( U, A )

U = finite non-empty set of objects (the universe)
A = finite non-empty set of attributes
Each attribute a ∈ A defines a function   a : U → Va   where Va is the value set of a

In plain terms: an information system is a table — rows are objects, columns are attributes, cells are values.

Decision System (DS)

Decision System DS = ( U, A ∪ { d } )

A = condition attributes     d = decision attribute

A decision system is an information system with one distinguished column (the decision) that we want to predict from the rest. This is what makes rough sets useful for classification.

Indiscernibility Relation

The central idea: two objects are indiscernible with respect to a set of attributes P if they have identical values on every attribute in P.

Indiscernibility relation IND(P) = { (x, y) ∈ U × U  |  ∀a ∈ P,   a(x) = a(y) }

IND(P) is an equivalence relation — reflexive, symmetric, and transitive — so it partitions U into equivalence classes. The equivalence class of object x is written [x]P.

Key insight

More attributes → finer partition (smaller classes, each object is more distinguishable). Fewer attributes → coarser partition (larger classes, more objects become indistinguishable). This is why attribute reduction (Lesson 13) matters — it finds the smallest set of attributes that still keeps classes fine enough for correct classification.

Worked example — computing equivalence classes

Using the patient table above.

Case 1: P = {Headache, Temperature, Nausea} (all condition attributes)

Write each patient’s values as a tuple:

p1 = (Yes, High, No)   p2 = (Yes, High, Yes)   p3 = (Yes, Normal, No)
p4 = (No, High, Yes)   p5 = (No, High, No)   p6 = (No, Normal, No)

All six tuples are unique, so every equivalence class is a singleton:

U/IND(P) = { {p1}, {p2}, {p3}, {p4}, {p5}, {p6} }

Case 2: P = {Headache, Temperature} (two attributes)

p1 = (Yes, High)   p2 = (Yes, High)   p3 = (Yes, Normal)
p4 = (No, High)   p5 = (No, High)   p6 = (No, Normal)

Now p1 and p2 share the same values, and p4 and p5 share the same values:

U/IND(P) = { {p1, p2}, {p3}, {p4, p5}, {p6} }

Fewer attributes → coarser partition. p1 and p2 are now indistinguishable, as are p4 and p5.

Properties of the indiscernibility relation

  • Reflexive: every object is indiscernible from itself.
  • Symmetric: if x is indiscernible from y, then y is indiscernible from x.
  • Transitive: if x ∼ y and y ∼ z, then x ∼ z.
  • These three together make it an equivalence relation, which is what produces a partition.
  • IND(A) ⊆ IND(P) whenever P ⊆ A — fewer attributes give a coarser relation.

Check yourself

Retrieval practice

1. Rough set theory was introduced by:

Zadeh introduced fuzzy sets, Holland introduced genetic algorithms, McCulloch and Pitts introduced neural networks. Pawlak introduced rough sets in 1982.

2. The fundamental difference between fuzzy sets and rough sets is that:

Fuzzy = vagueness in the concept itself. Rough = the concept is crisp but the data cannot separate it precisely. This is the most tested distinction.

3. An information system IS = (U, A) consists of:

IS = (U, A) where U is the universe of objects and A is the set of attributes. A decision system adds a decision attribute d: DS = (U, A ∪ {d}).

4. The indiscernibility relation IND(P) is:

IND(P) groups objects that are identical on all attributes in P. It is reflexive, symmetric, and transitive — hence an equivalence relation.

5. When you remove attributes from P, the equivalence classes:

Fewer attributes means fewer ways to distinguish objects, so previously separate classes may merge. The partition becomes coarser.

6. A decision system differs from an information system by having:

DS = (U, A ∪ {d}). The decision attribute is what we want to predict; the condition attributes are what we use to predict it.

7. A set X is called “rough” with respect to an equivalence relation R when:

If the boundary region (upper minus lower approximation) is non-empty, the set cannot be precisely described with the available attributes, so it is rough.

Recall without looking

Define a rough set in one sentence.

A set is rough when the available attributes produce equivalence classes that straddle its boundary — some objects cannot be classified as certainly in or certainly out, only as possibly in.

State the indiscernibility relation formula.

IND(P) = { (x, y) ∈ U × U | ∀a ∈ P, a(x) = a(y) }. It is an equivalence relation that partitions U into classes of indistinguishable objects.

Information system vs decision system?

IS = (U, A) — objects and attributes. DS = (U, A ∪ {d}) — adds a decision attribute. A decision system is an IS set up for classification.

Fuzzy vs rough: what does each handle?

Fuzzy = vagueness in the concept (graded membership). Rough = indiscernibility in the data (crisp concept, imprecise data). Vagueness vs insufficiency.
