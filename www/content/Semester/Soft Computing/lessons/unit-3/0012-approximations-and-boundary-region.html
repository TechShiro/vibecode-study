Visual Geometry: The Four Fundamental Rough Set Regions
• Lower Approx $\underline{B}X$ (Positive Region) $\{x \in U \mid [x]_B \subseteq X\}$
Objects that certainly belong to target set $X$ based on knowledge $B$.
• Boundary Region $BN_B(X)$ $\overline{B}X - \underline{B}X$
Objects that cannot be decided (partially in $X$, partially outside). If empty → Crisp!
• Upper Approx $\overline{B}X$ $\{x \in U \mid [x]_B \cap X \ne \emptyset\}$
Objects that possibly belong to target set $X$ based on knowledge $B$.
• Negative Region $NEG_B(X)$ $U - \overline{B}X$
Objects that definitely do not belong to target set $X$.

The four regions

Given an equivalence relation R on universe U and a target set X ⊆ U (typically the set of objects with a particular decision value):

Lower Approximation (Positive Region) R(X) = { x ∈ U  |  [x]R ⊆ X }

The union of all equivalence classes entirely contained in X.
These objects certainly belong to X.
Upper Approximation R(X) = { x ∈ U  |  [x]R ∩ X ≠ ∅ }

The union of all equivalence classes that have any overlap with X.
These objects possibly belong to X.
Boundary Region BNR(X) = R(X) − R(X)

Objects that cannot be definitively classified as in or out of X.
Negative Region NEGR(X) = U − R(X)

Objects that certainly do not belong to X.
The decision rule

If BNR(X) = ∅, the set X is crisp (exact) with respect to R — every object can be classified with certainty. If BNR(X) ≠ ∅, the set X is rough — some objects sit in a grey area.

Accuracy and roughness

Accuracy of approximation αR(X) = |R(X)|  /  |R(X)|     where 0 ≤ α ≤ 1
  • α = 1 ⇒ X is crisp (boundary is empty, lower = upper)
  • α < 1 ⇒ X is rough
  • α = 0 ⇒ lower approximation is empty (nothing can be classified with certainty)
Roughness ρR(X) = 1 − αR(X)
Quality of classification γR(Y) = |POSR(Y)|  /  |U|

The fraction of the universe that can be correctly classified using attributes R.

Worked example 1 — with two condition attributes

Full worked example — approximations step by step

Decision table (same patient table from Lesson 11):

PatientHeadacheTemperatureNauseaFlu
p1YesHighNoYes
p2YesHighYesYes
p3YesNormalNoNo
p4NoHighYesYes
p5NoHighNoNo
p6NoNormalNoNo

Let R = IND({Headache, Temperature}).

Equivalence classes: {p1, p2}, {p3}, {p4, p5}, {p6}

Target set X = {p1, p2, p4} (patients with Flu = Yes).

Step 1 — Lower approximation. Check each class:

  • {p1, p2}: Is {p1, p2} ⊆ X? Both in X ⇒ YES ⇒ include
  • {p3}: Is {p3} ⊆ X? p3 ∉ X ⇒ NO
  • {p4, p5}: Is {p4, p5} ⊆ X? p5 ∉ X ⇒ NO
  • {p6}: Is {p6} ⊆ X? p6 ∉ X ⇒ NO

R(X) = {p1, p2}

Step 2 — Upper approximation. Check each class:

  • {p1, p2}: Does {p1, p2} ∩ X ≠ ∅? YES (both) ⇒ include
  • {p3}: Does {p3} ∩ X ≠ ∅? NO
  • {p4, p5}: Does {p4, p5} ∩ X ≠ ∅? YES (p4 ∈ X) ⇒ include
  • {p6}: Does {p6} ∩ X ≠ ∅? NO

R(X) = {p1, p2, p4, p5}

Step 3 — Boundary, negative, accuracy.

  • BNR(X) = {p1,p2,p4,p5} − {p1,p2} = {p4, p5}
  • NEGR(X) = U − {p1,p2,p4,p5} = {p3, p6}
  • αR(X) = |{p1,p2}| / |{p1,p2,p4,p5}| = 2/4 = 0.5
  • ρR(X) = 1 − 0.5 = 0.5
  • γR = |{p1,p2}| / |U| = 2/6 = 0.333

Interpretation: With only Headache and Temperature, we can certainly say p1 and p2 have flu, possibly p4 and p5 do, and certainly p3 and p6 do not. The set X is rough (α < 1).

Same table, all three attributes

Now let R = IND({Headache, Temperature, Nausea}).

All six rows are unique ⇒ equivalence classes are all singletons:
{p1}, {p2}, {p3}, {p4}, {p5}, {p6}

Target X = {p1, p2, p4}.

Lower approximation:

  • {p1} ⊆ X? Yes ⇒ include. {p2} ⊆ X? Yes ⇒ include. {p4} ⊆ X? Yes ⇒ include.
  • {p3} ⊆ X? No. {p5} ⊆ X? No. {p6} ⊆ X? No.

R(X) = {p1, p2, p4}

Upper approximation:

Same check — singletons either overlap X or don’t.

R(X) = {p1, p2, p4}

Results:

  • BN = {p1,p2,p4} − {p1,p2,p4} = ∅
  • α = 3/3 = 1.0 ⇒ X is crisp (exact)

Key insight: More attributes → finer partition → lower = upper → boundary shrinks to ∅ → accuracy rises to 1. This is why all three attributes together classify perfectly.

Properties of approximations

These are worth memorising — examiners sometimes ask you to state or verify them:

#Property
1R(X) ⊆ X ⊆ R(X) — the fundamental containment
2R(∅) = R(∅) = ∅
3R(U) = R(U) = U
4R(X) = complement of R(complement of X)
5X ⊆ Y ⇒ R(X) ⊆ R(Y) and R(X) ⊆ R(Y) — monotonicity
6R(X ∩ Y) = R(X) ∩ R(Y) — lower distributes over intersection
7R(X ∪ Y) = R(X) ∪ R(Y) — upper distributes over union
Quick sanity checks in an exam

After computing approximations, verify: (a) lower ⊆ target ⊆ upper, (b) lower ∪ boundary = upper, (c) lower ∪ boundary ∪ negative = U. If any of these fail, your arithmetic is wrong.

Check yourself

Retrieval practice

1. The lower approximation of X contains:

Lower = classes fully inside X (certain membership). Upper = classes with any overlap (possible membership). The difference is the boundary.

2. A set X is rough with respect to R when:

Non-empty boundary means some objects cannot be classified with certainty. When boundary = ∅, the set is crisp/exact.

3. The accuracy of approximation αR(X) is calculated as:

α = |R(X)| / |R(X)|. It ranges from 0 to 1, where 1 means exact/crisp.

4. The boundary region contains objects that are:

Boundary = upper − lower. These objects are in classes that partially overlap X but are not entirely inside it.

5. The negative region NEGR(X) is defined as:

Negative region = everything outside the upper approximation. These objects certainly do not belong to X.

6. Using more condition attributes generally causes the accuracy to:

More attributes → finer partition → classes become smaller → fewer straddle the boundary → accuracy rises.

7. Which property always holds for approximations?

The lower approximation is always a subset of X, and X is always a subset of the upper approximation. They are equal only when the set is crisp.

Recall without looking

Define lower and upper approximation.

Lower: union of equivalence classes entirely inside X (certain). Upper: union of equivalence classes with any overlap with X (possible). Boundary = upper − lower.

State the accuracy formula.

αR(X) = |R(X)| / |R(X)|. Equals 1 when crisp (exact), less than 1 when rough.

When is a set crisp vs rough?

Crisp: boundary = ∅, α = 1. Rough: boundary ≠ ∅, α < 1.

Give three properties of approximations.

(1) R(X) ⊆ X ⊆ R(X). (2) R(X ∩ Y) = R(X) ∩ R(Y). (3) R(X ∪ Y) = R(X) ∪ R(Y).
