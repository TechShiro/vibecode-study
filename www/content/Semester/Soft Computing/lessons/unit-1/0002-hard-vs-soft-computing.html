What hard computing is

Hard computing is conventional, von Neumann-style computing. Its defining requirement: it needs a precisely stated analytical model before it can produce anything. Given exact inputs and exact rules it returns an exact answer — and given anything less, it returns nothing useful at all.

It is not obsolete and it is not inferior. Payroll, banking, compilers and control loops with known dynamics should all be hard computing. The point of the comparison is knowing which tool the problem deserves.

If you can only remember one row

Hard computing demands precision and returns precision. Soft computing accepts vagueness and returns approximation. Every other row in the table is a consequence of that one.

The trap: "approximate" is not "wrong"

Students lose marks by writing that soft computing "gives incorrect answers". It does not. It gives an answer whose precision is matched to the precision of the question. If the input is "the water is fairly dirty", an output of "wash for about 34 minutes" is not an error — demanding "34.0000 minutes" from that input would be the error, because it claims a precision the data never contained.

Hybrid computing

A third term appears in this unit and is often a 2-mark add-on. Hybrid computing is the deliberate combination of hard and soft techniques, or of two soft techniques, so that one method's weakness is covered by another's strength.

HybridWeakness it fixes
Neuro-fuzzy (e.g. ANFIS)Fuzzy systems cannot learn; neural networks cannot explain themselves. The hybrid learns the membership functions from data and stays readable as rules.
Genetic-fuzzyDesigning fuzzy rules and membership functions by hand is guesswork. A GA searches for the best ones.
Neuro-geneticBackpropagation gets stuck in local minima. A GA does the global search for weights or architecture.

The general principle, worth one closing sentence in any comparison answer: the constituents of soft computing are complementary, not competitive. They are not rivals to pick between; they are parts that combine.

Check yourself

Retrieval practice

1. Which single property most directly causes soft computing's high fault tolerance?

When work is spread over many units, losing a few units loses a little accuracy rather than the whole answer. A sequential program has no such redundancy — one broken step ends it.

2. A hard computing program run twice on identical input will:

Hard computing is deterministic. Soft computing is often stochastic — a GA with a different random seed can end at a different near-optimum.

3. Neuro-fuzzy systems exist mainly because fuzzy systems:

Fuzzy = knowledge representation without learning. Neural = learning without knowledge representation. The hybrid supplies each what the other lacks. This exact sentence is worth writing in the exam.

The paired rows are: precise model vs none, binary vs fuzzy logic, exact vs approximate, deterministic vs stochastic, sequential vs parallel, low vs high fault tolerance, mathematics vs biology.

Combining hard and soft techniques in one system is called:

Neuro-fuzzy systems and genetic-fuzzy controllers are the standard examples — and ANFIS, met in Lesson 9, is exactly such a hybrid.

Soft computing tolerates noisy and incomplete data because:

This is the same property as its high fault tolerance. Hard computing, which needs exact data and an exact model, degrades badly when either is imperfect.

Recall without looking

Give five points of difference between hard and soft computing.

Model (precise vs none needed); logic (binary vs fuzzy); result (exact vs approximate); data (exact vs noisy); fault tolerance (low vs high). Also: sequential vs parallel, deterministic vs stochastic, programmed vs learned.

What is hybrid computing? Give one example.

Combining hard and soft, or two soft techniques, so one method's weakness is covered by another's strength. Example: neuro-fuzzy (ANFIS) — a neural network learns the membership functions of a fuzzy system.

Complete: "The constituents of soft computing are ______, not ______."

Complementary, not competitive.
