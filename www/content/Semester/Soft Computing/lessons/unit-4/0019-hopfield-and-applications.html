Hopfield network

  • Architecture: single layer, fully connected, recurrent (feedback).
  • Weights: symmetric (wij = wji), no self-connections (wii = 0).
  • Neurons: bipolar (+1 / −1) or binary (0 / 1). Update asynchronously.
  • Use: content-addressable (associative) memory, optimisation.

Energy function

Lyapunov energy E = −½ ΣiΣj wij si sj − Σi θi si
si = state of neuron i, θi = threshold/bias.

Key property: energy decreases or stays same at each update ⇒ network converges to a local minimum (stable state = stored pattern).

Storing patterns

Hebbian storage rule wij = Σp xi(p) · xj(p) (sum over all patterns p, i ≠ j)
Store M patterns in an N-neuron network. Capacity: ~0.15N patterns.

Applications of neural networks

  • Pattern recognition: character recognition (OCR), speech recognition, face detection.
  • Forecasting: stock market prediction, weather forecasting, demand planning.
  • Image processing: image compression, noise removal, edge detection, segmentation.
  • Other: medical diagnosis, robotics, natural language processing.

Recall without looking

Hopfield network properties.

Fully connected, recurrent, symmetric weights, no self-connections, bipolar. Energy function decreases → stable state = stored pattern. Capacity ~0.15N.

Energy function formula.

E = -½ΣΣ w_ij·s_i·s_j - Σθ_i·s_i. Decreases at each asynchronous update. Minima = stored patterns.

Three application areas of ANNs.

Pattern recognition (OCR, speech, face), forecasting (stock, weather), image processing (compression, noise removal).
