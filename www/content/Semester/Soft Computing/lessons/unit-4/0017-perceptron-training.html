Perceptron

Single-layer network with step activation. Output: y = 1 if Σwixi + b ≥ 0, else 0.

Perceptron learning algorithm

Algorithm 1. Initialise weights w and bias b (usually to 0 or small random).
2. For each training sample (x, d):
   Compute y = step(Σwixi + b).
   If y ≠ d: wi = wi + η(d − y)xi, b = b + η(d − y).
3. Repeat until no errors (convergence).

η = learning rate (typically 1 for simple examples).

Perceptron convergence theorem

If the training data is linearly separable, the perceptron algorithm is guaranteed to converge in a finite number of steps.

XOR limitation

XOR is NOT linearly separable

No single line can separate (0,0)→0, (1,1)→0 from (0,1)→1, (1,0)→1. A single perceptron cannot learn XOR. Solution: multi-layer perceptron with at least one hidden layer.

Retrieval practice

1. The perceptron weight update rule is:

Error-correcting: adjust weight by learning rate × error × input. If y = d, no change.

2. A single perceptron cannot learn XOR because:

Perceptron = linear classifier. XOR needs a non-linear boundary = multi-layer network.

Recall without looking

Perceptron algorithm in four steps.

Init weights. For each sample: compute y = step(Σwx+b). If error: w += η(d-y)x, b += η(d-y). Repeat until convergence.

Why perceptron fails on XOR.

XOR is not linearly separable. Need ≥1 hidden layer (MLP) to learn it.
