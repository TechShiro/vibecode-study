Multi-Layer Perceptron (MLP)

Input layer → one or more hidden layers (sigmoid) → output layer (sigmoid). Fully connected. Trained by back-propagation = generalised delta rule.

Algorithm

1. Forward pass

For each layer netj = Σ wij · oi + bj
oj = f(netj) = sigmoid(netj) = 1/(1 + e−netj)

2. Compute error

Total error E = ½ Σ (dk − ok)² over all output neurons k.

3. Backward pass — compute δ

Output layer δk = (dk − ok) · f′(netk)
For sigmoid: f′(net) = o(1 − o), so δk = (dk − ok) · ok(1 − ok)
Hidden layer δj = f′(netj) · Σ δk · wjk
= oj(1 − oj) · Σ δk · wjk

4. Update weights

Weight update Δwij = η · δj · oi
wij = wij + Δwij
Worked example (simplified) — 2-2-1 network

Inputs: x1=0.05, x2=0.10. Target: d=0.01. η=0.5. Sigmoid activation.

Weights: w1=0.15, w2=0.20, b1=0.35 (hidden1). w3=0.25, w4=0.30, b2=0.35 (hidden2). w5=0.40, w6=0.45, b3=0.60 (output).

Forward — hidden layer:

net_h1 = 0.15(0.05) + 0.20(0.10) + 0.35 = 0.3775. o_h1 = σ(0.3775) = 0.5933.

net_h2 = 0.25(0.05) + 0.30(0.10) + 0.35 = 0.3925. o_h2 = σ(0.3925) = 0.5969.

Forward — output:

net_o = 0.40(0.5933) + 0.45(0.5969) + 0.60 = 1.1059. o = σ(1.1059) = 0.7514.

Error: E = ½(0.01 − 0.7514)² = 0.2749.

Backward — output δ:

δo = (0.01 − 0.7514) × 0.7514 × (1 − 0.7514) = −0.7414 × 0.1868 = −0.1385.

Backward — hidden δ:

δh1 = 0.5933(1−0.5933) × (−0.1385)(0.40) = 0.2413 × (−0.0554) = −0.0134.

Update w5: Δw5 = 0.5 × (−0.1385) × 0.5933 = −0.0411. w5 = 0.40 − 0.0411 = 0.3589.

Repeat for all weights. After many epochs, E → 0.

Learning rate × error gradient × input to that weight. Gradient descent on the error surface.

Recall without looking

Back-propagation algorithm — four steps.

1. Forward pass (compute outputs). 2. Compute error E=½Σ(d-o)². 3. Backward: δ_output = (d-o)·o(1-o); δ_hidden = o(1-o)·Σδ_k·w. 4. Update: Δw = η·δ·input.

Sigmoid derivative.

f'(x) = f(x)(1-f(x)) = o(1-o). Computed directly from the output value.
