Visual Taxonomy: Classical ANN Learning Rules
1. Hebbian Learning (1949) $\Delta w_i = \eta \cdot x_i \cdot y$
Unsupervised correlation. If pre- and post-synaptic neurons fire simultaneously, connection strengthens.
2. Perceptron Rule (1958) $\Delta w_i = \eta \cdot (t - y) \cdot x_i$
Supervised error correction for binary threshold units. Provably converges if linearly separable.
3. Delta / LMS Rule (1960) $\Delta w_i = \eta \cdot (t - z) \cdot x_i$
Widrow-Hoff rule minimizing Mean Squared Error (MSE) via gradient descent on continuous activation.
4. Competitive Learning $\Delta w_{i^*} = \eta \cdot (x - w_{i^*})$
Winner-take-all unsupervised clustering. Only the closest output neuron adapts its weight vector.

Hebbian learning rule

Hebb’s rule Δwij = η · xi · yj
“Neurons that fire together, wire together.” If input and output are both active, strengthen the connection. η = learning rate.

Delta rule (Widrow-Hoff / LMS)

Delta rule Δwi = η · (d − y) · xi
d = desired output, y = actual output, (d−y) = error.
Adjust weight proportional to error × input. Basis for gradient descent.
From delta rule to back-propagation

The delta rule works for single-layer networks. For multi-layer networks, we need to propagate the error backward through hidden layers — that’s the generalised delta rule = back-propagation (next lesson).

Check yourself

Retrieval practice

1. Supervised learning requires:

Supervised = labelled data. Network learns by comparing its output to the desired output and adjusting weights.

2. The Hebbian rule formula is:

Hebb: correlation-based. Delta rule adds error (d-y) for correction. Both are fundamental.

3. The delta rule adjusts weights proportional to:

Error-correcting rule. Weight change = learning rate × error × input. Gradient descent on squared error.

Recall without looking

Three learning paradigms — one line each.

Supervised: teacher + error. Unsupervised: no teacher, find patterns. Reinforcement: reward/penalty signal.

Hebbian vs delta rule.

Hebb: Δw = η·x·y (fire together → wire together). Delta: Δw = η·(d-y)·x (error-correcting, gradient descent).
