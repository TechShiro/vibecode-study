# Starting point: Units I–II built cold, no prior knowledge established

This workspace was created the night before the Units I–II class test (test on 19 August 2026),
so all ten lessons were written without any evidence of what is already known. They assume
**zero prior exposure** to fuzzy set theory and build from the definition of a fuzzy set upward.

That assumption is almost certainly too conservative in places — the material has been taught in
class already. Nothing here records demonstrated understanding, only material covered, which per
the learning-record rules does not itself qualify as learning.

**Implication for the next session:** the first thing worth doing is measuring, not teaching.
Ask for answers to the four numericals below and write a real learning record from the results.
Until then, do not assume any topic is secure.

- Max–min composition of a 3×2 with a 2×2 relation (Lesson 6)
- Centroid defuzzification over a seven-point discrete set (Lesson 8)
- The hard-vs-soft comparison table, reproduced from memory (Lesson 2)
- The two classical laws that fail for fuzzy sets, with a counter-example (Lesson 5)

**Also unmeasured:** whether the exam-shaped framing is calibrated correctly. The stated goal is
9.5+ CGPA with explicitly no interest in mastery, so if any lesson felt like it went past what the
paper asks, that is a signal to compress rather than expand.
