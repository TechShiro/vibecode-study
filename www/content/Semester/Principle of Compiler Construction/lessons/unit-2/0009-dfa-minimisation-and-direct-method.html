DFA Minimisation and the Direct RE → DFA Method

Minimising a DFA by partitioning, worked to completion on the machine from Lesson 8; then the direct route from regular expression to DFA using a syntax tree with nullable, firstpos, lastpos and followpos — with both answers cross-checked against each other.

Exam strategy

Two more guaranteed, mechanical questions. “Minimise the given DFA” — the answer is a sequence of partitions Π0, Π1, Π2 … and you must show every partition and say which state split the group and why. “Construct a DFA directly from the regular expression” — draw the syntax tree with numbered leaves, build the nullable / firstpos / lastpos table, then the followpos table, then the DFA. The followpos table is where the marks are. Both methods are worked here on (a|b)*abb, and they are shown to agree — which is the best possible check on your own answer.

Part 1 — Minimising a DFA

Why it works — the idea in one sentence Two states s and t are equivalent if every input string takes them both to accepting states or both to non-accepting states — that is, no string can tell them apart. Equivalent states can be merged. A string that does tell them apart is called a distinguishing string.

The minimal DFA is unique — up to renaming states, there is exactly one smallest DFA for any regular language. That uniqueness is what makes “minimise this DFA” a question with one right answer.
The partitioning algorithm 1. Start with Π0 = { non-accepting states, accepting states } — two groups. The empty string distinguishes them.
2. Repeat: for each group G in the current partition, and each input symbol a, check where every state of G goes. If two states of G go to DIFFERENT groups on the same symbol, they are distinguishable — split G accordingly.
3. Stop when a full pass produces no split. The partition is then stable.
4. Each remaining group becomes one state of the minimal DFA. The start state is the group containing the old start; a group is accepting if it contains accepting states.
5. Finally, remove any dead state — a non-accepting state all of whose transitions loop back to itself — and any state unreachable from the start.

Part 2 — The direct method: regular expression straight to DFA

Why bother, when we already have a route?

The route of Lesson 8 goes RE → NFA → DFA → minimal DFA — three conversions, and the NFA is thrown away. The direct method skips the NFA entirely, building the DFA in one pass from a syntax tree. It is what Lex actually uses, and it often lands on a DFA that is already minimal — as it will below.

The five steps 1. Augment the regular expression with an end-marker: r → (r)#. The # marks “a complete match ends here”.
2. Build the syntax tree for (r)#. Leaves are symbols and are NUMBERED left to right — these numbers are the positions. Interior nodes are the operators cat, | and *.
3. Compute nullable, firstpos and lastpos for every node, bottom-up.
4. Compute followpos for every position, using the two rules.
5. Construct the DFA: the start state is firstpos(root), and from a state S on symbol a the next state is the union of followpos(p) over every position p in S whose symbol is a. A state is accepting if it contains the position of #.
The three functions nullable(n) — true if the subtree at n can generate the empty string.
firstpos(n) — the set of positions that can match the FIRST symbol of a string generated by the subtree at n.
lastpos(n) — the set of positions that can match the LAST symbol of such a string.
followpos(p) — for a position p, the set of positions that can follow p immediately in some string of the language.

The two followpos rules — there are only two RULE 1 — concatenation. If n is a cat node with children c1 and c2, then for every position i in lastpos(c1), add firstpos(c2) to followpos(i).

RULE 2 — star. If n is a star node, then for every position i in lastpos(n), add firstpos(n) to followpos(i).

There is no rule for the | node. Alternation never puts two positions next to each other, so it contributes nothing to followpos — a point examiners like to test.

Recall without looking

When are two DFA states equivalent, and why is the minimal DFA unique?

Two states are equivalent if no input string distinguishes them — every string takes both to accepting states or both to non-accepting states. A string that does separate them is a distinguishing string. Up to renaming of states there is exactly one smallest DFA for any regular language, which is why the question has a single right answer.

Give the five steps of the partitioning algorithm.

Start with Π₀ = {non-accepting, accepting}. Repeatedly, for each group and each symbol, split any group whose members go to different groups. Stop when a full pass causes no split. Each group becomes one state, the start group contains the old start, and a group is accepting if it contains accepting states. Finally remove any dead state and any state unreachable from the start.

Minimise the DFA for (a|b)*abb.

Π₀ = {{A,B,C,D},{E}}. On b, D goes to the accepting group while A, B and C do not, so Π₁ = {{A,B,C},{D},{E}}. On b, B goes to {D} while A and C stay inside, so Π₂ = {{A,C},{B},{D},{E}}. A and C behave identically, so the partition is stable. Result: four states, with A and C merged, since both mean nothing useful of abb has been seen.

Give the five steps of the direct RE → DFA method.

Augment r to (r)#. Build the syntax tree with leaves numbered left to right as positions. Compute nullable, firstpos and lastpos bottom-up. Compute followpos by the two rules. Construct the DFA: start state is firstpos(root); from state S on symbol a, the next state is the union of followpos(p) over all positions p in S whose symbol is a; a state is accepting if it contains the # position.

Give the nullable, firstpos and lastpos rules.

Leaf ε: nullable true, both sets empty. Leaf at position i: not nullable, both sets {i}. For c₁|c₂: nullable is the or, firstpos and lastpos are unions. For cat c₁c₂: nullable is the and; firstpos is firstpos(c₁) ∪ firstpos(c₂) if c₁ is nullable else firstpos(c₁); lastpos is lastpos(c₁) ∪ lastpos(c₂) if c₂ is nullable else lastpos(c₂). For c₁*: nullable always true, firstpos and lastpos are those of the child.

Give the two followpos rules and the table for (a|b)*abb#.

Rule 1, cat node: for every i in lastpos(c₁), add firstpos(c₂) to followpos(i). Rule 2, star node: for every i in lastpos(n), add firstpos(n) to followpos(i). The alternation node contributes nothing. Table: followpos(1) = followpos(2) = {1,2,3}; followpos(3) = {4}; followpos(4) = {5}; followpos(5) = {6}; followpos(6) = ∅.

Give the direct-method DFA for (a|b)*abb and its relation to the minimised one.

A = {1,2,3} start, B = {1,2,3,4}, C = {1,2,3,5}, D = {1,2,3,6} accepting. On a every state goes to B; on b, A→A, B→C, C→D, D→A. It is isomorphic to the minimised DFA under A′→A, B′→B, D′→C, E′→D — so the direct method produced the minimal machine in one pass, skipping both the NFA and the minimisation step. That is why Lex uses it.
