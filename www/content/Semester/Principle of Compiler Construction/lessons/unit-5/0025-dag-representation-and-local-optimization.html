What is a DAG for a basic block?

A Directed Acyclic Graph (DAG) is a directed graph without cycles that represents the structure of expressions within a single basic block:

  • Leaves: Labeled with variable identifiers (representing initial values on entry to the block) or constants.
  • Interior nodes: Labeled with an operator symbol (e.g., +, -, *, /).
  • Node labels / Variable attachments: Nodes have an attached list of variable identifiers indicating that those variables currently hold the value computed by that node.

Why use a DAG?

  1. Automatic Common Subexpression Detection: Before creating an interior node (op, left, right), check if such a node already exists. If yes, reuse it instead of creating a redundant node.
  2. Dead Code Elimination: Interior nodes with no outgoing edges (no parents) whose attached variables are not live upon block exit can be safely pruned.
  3. Algebraic Simplification: Identities like $x \times 1 = x$, $x + 0 = x$, and $x \times 0 = 0$ can be evaluated directly during construction.
Worked numerical — DAG construction & code generation

Given the following sequence of three-address statements in a basic block:

(1) t1 = 4 * i
(2) t2 = a[t1]
(3) t3 = 4 * i
(4) t4 = b[t3]
(5) t5 = t2 * t4
(6) t6 = prod + t5
(7) prod = t6
(8) t7 = i + 1
(9) i = t7

Trace of DAG construction:

  1. Statement (1) t1 = 4 * i: Leaf 4 and leaf i₀ created. Interior node Node1: (*, 4, i₀) created. Label t1 attached to Node1.
  2. Statement (2) t2 = a[t1]: Leaf a created. Interior node Node2: (=[], a, Node1) created. Label t2 attached to Node2.
  3. Statement (3) t3 = 4 * i: Operands are constant 4 and i₀. An identical node (*, 4, i₀) already exists (Node1)! We do not create a new node. We simply attach label t3 to Node1.
  4. Statement (4) t4 = b[t3]: Leaf b created. Interior node Node3: (=[], b, Node1) created. Label t4 attached to Node3.
  5. Statement (5) t5 = t2 * t4: Interior node Node4: (*, Node2, Node3) created. Label t5 attached.
  6. Statement (6) t6 = prod + t5: Leaf prod₀ created. Interior node Node5: (+, prod₀, Node4) created. Label t6 attached.
  7. Statement (7) prod = t6: Label prod attached to Node5 (updating the current definition of prod).
  8. Statement (8) t7 = i + 1: Constant leaf 1 created. Interior node Node6: (+, i₀, 1) created. Label t7 attached.
  9. Statement (9) i = t7: Label i attached to Node6.

Optimized Three-Address Code emitted from DAG:

t1 = 4 * i
t2 = a[t1]
t4 = b[t1]       /* Notice: t3 computation eliminated */
t5 = t2 * t4
prod = prod + t5
i = i + 1

Result: Reduced from 9 instructions to 6 instructions.

Handling array accesses in a DAG

Array assignments require care because an element write can alias subsequent reads:

  • x = a[i] creates an array read node (=[], a, i).
  • a[j] = y creates an array assignment operator node ([]=, a, j, y). Because j could equal i, this node invalidates previously cached elements of array a.

Check yourself

Retrieval practice

1. In a basic block DAG, leaves represent:

Leaves hold values available before the block executes; interior nodes compute new values using operators.

2. How does a DAG construction algorithm detect local common subexpressions?

Value numbering ensures that if (op, left, right) matches an existing node, that existing node is reused.

3. A node in a DAG can be safely eliminated as dead code if:

If nobody reads the computed value inside the block and no attached variable is live afterwards, the node has zero utility.

Recall without looking

What are the components of a basic block DAG?

Leaves: constants or initial values of variables entering the block. Interior nodes: operators. Variable labels: attached to nodes currently holding that variable's value.

What optimizations are performed directly on a DAG?

1. Local common subexpression elimination. 2. Dead code elimination. 3. Algebraic simplification and constant folding.
