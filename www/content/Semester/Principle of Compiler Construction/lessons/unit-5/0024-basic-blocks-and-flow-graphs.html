What is a basic block?

A basic block is a sequence of consecutive three-address statements in which:

  1. Flow of control enters only at the first statement of the block (no jumps into the middle of the block).
  2. Control leaves the block without halting or branching except possibly at the very last statement.

If the first statement of a basic block is executed, all subsequent statements in the block are guaranteed to execute in order.

Algorithm: Partitioning into basic blocks

Rules for Identifying Leaders Given a sequence of three-address statements:
  1. The first statement of the intermediate code is a leader.
  2. Any statement that is the target of a conditional or unconditional goto is a leader.
  3. Any statement that immediately follows a conditional or unconditional goto is a leader.
Forming blocks: For each leader, its basic block consists of the leader and all statements up to, but not including, the next leader or the end of the intermediate code.
Worked numerical — Partitioning TAC and CFG

Consider the three-address code for computing the dot product of two vectors a and b of length 20:

(1)  prod = 0
(2)  i = 1
(3)  t1 = 4 * i
(4)  t2 = a[t1]
(5)  t3 = 4 * i
(6)  t4 = b[t3]
(7)  t5 = t2 * t4
(8)  prod = prod + t5
(9)  i = i + 1
(10) if i <= 20 goto (3)
(11) halt

Step 1: Identify leaders

  • Statement (1) is a leader (Rule 1: first statement).
  • Statement (3) is a leader (Rule 2: target of goto in statement 10).
  • Statement (11) is a leader (Rule 3: statement immediately following goto in statement 10).

Leaders set: { (1), (3), (11) }.

Constructing the Control Flow Graph (CFG)

The nodes of a CFG are the basic blocks. Directed edges $(B_i \to B_j)$ indicate that control may transfer from the end of $B_i$ to the start of $B_j$:

  • There is a conditional or unconditional jump from the end of $B_i$ to the beginning of $B_j$.
  • $B_j$ immediately follows $B_i$ in the initial sequence, and $B_i$ does not end with an unconditional jump.

Predecessors & Successors:

  • succ(B1) = { B2 }, pred(B1) = { Entry }
  • succ(B2) = { B2, B3 }, pred(B2) = { B1, B2 }
  • succ(B3) = { Exit }, pred(B3) = { B2 }

Loops in Flow Graphs

A loop in a CFG is a collection of nodes $L$ such that:

  1. There is a unique node called the loop header (the only entry point into the loop from outside).
  2. All nodes in $L$ are strongly connected: there is a path from any node in $L$ back to the header.
  3. There exists at least one back edge (an edge whose head dominates its tail, such as $B2 \to B2$).

Rule 3 states that any statement immediately following a jump (conditional or unconditional) is a leader.

2. Which property defines a basic block?

A basic block permits no jumps into its middle and no exits except from its final statement.

3. In a CFG, an edge directed from a node back to a dominator header is called:

Back edges loop back to dominator nodes, defining the natural loops in a control flow graph.

Recall without looking

The three rules for identifying leaders.

1. The first statement of TAC is a leader. 2. Any target of a conditional/unconditional jump is a leader. 3. Any statement immediately following a conditional/unconditional jump is a leader.

How are edges formed in a Control Flow Graph?

An edge B1 → B2 exists if: 1. B2 is the target of a jump from B1, OR 2. B2 immediately follows B1 in sequential code and B1 does not end with an unconditional jump.
