What is data-flow analysis?

Data-flow analysis is a framework that proves properties about how values and definitions propagate along execution paths in a Control Flow Graph (CFG). Because determining exact runtime execution paths is undecidable, data-flow analysis computes safe static approximations across all possible paths.

The Data-Flow Framework

For each basic block $B$:

  • $\mathbf{gen}_B$: The information generated within block $B$.
  • $\mathbf{kill}_B$: The information from outside that is invalidated/killed within block $B$.
  • $\mathbf{In}[B]$: Information arriving at the entry boundary of block $B$.
  • $\mathbf{Out}[B]$: Information leaving the exit boundary of block $B$.
General Transfer Function $$\text{Out}[B] = \text{gen}_B \cup (\text{In}[B] - \text{kill}_B)$$ $$\text{In}[B] = \bigwedge_{P \in \text{pred}(B)} \text{Out}[P]$$ where $\wedge$ is the meet operator (either set union $\cup$ or set intersection $\cap$).

1. Reaching Definitions

A definition $d: x = y + z$ reaches a program point $p$ if there is an execution path from $d$ to $p$ along which $x$ is not killed (redefined). If a use of $x$ is reached by only one definition, it enables constant or copy propagation.

2. Available Expressions

An expression $x + y$ is available at point $p$ if every path from the entry node to $p$ evaluates $x + y$, and after the last such evaluation prior to reaching $p$, neither $x$ nor $y$ is redefined. If $x + y$ is available at $p$, its recomputation at $p$ can be replaced by a temporary holding the previous result (Global CSE).

3. Live Variable Analysis

A variable $x$ is live at point $p$ if there exists a path from $p$ to a subsequent use of $x$ along which $x$ is not redefined. Otherwise, $x$ is dead. If a variable is dead immediately after an assignment $x = \dots$, the assignment can be safely deleted (Dead Code Elimination).

Dominators and Natural Loops

Dominance Relation A node $d$ dominates a node $n$ (written $d \text{ dom } n$) if every path from the initial entry node of the flow graph to $n$ must pass through $d$.
  • Every node dominates itself: $n \text{ dom } n$.
  • The initial node dominates all nodes in the flow graph.

Natural Loops

A natural loop has two essential properties:

  1. It has a single entry point called the header, which dominates all nodes in the loop.
  2. It contains at least one back edge: an edge $m \to d$ where the destination $d$ dominates the source $m$ ($d \text{ dom } m$).

Constructing the natural loop of a back edge $m \to d$: It consists of $d$, together with all nodes that can reach $m$ without passing through $d$.

Loop Optimization Techniques

  • Loop-Invariant Computation: An instruction $x = y + z$ in loop $L$ is invariant if both operands $y$ and $z$ are either constants or have all their reaching definitions strictly outside of $L$. Such statements can be hoisted to the loop preheader.
  • Induction Variables: A variable $i$ is a basic induction variable if its only assignments in $L$ are of the form $i = i \pm c$. Any variable $j$ whose value is a linear function of $i$ ($j = c_1 \times i + c_2$) is also an induction variable.
  • Strength Reduction: Replaces the multiplication in $j = 4 \times i$ with addition ($j = j + 4$) inside the loop, saving CPU clock cycles on every iteration.

Retrieval practice

1. Available expressions analysis uses which direction and meet operator?

An expression is available only if it is computed on ALL paths reaching the point, requiring intersection (⋂).

2. Live variable analysis is performed in which direction and what is its primary use?

Liveness flows backward from uses to definitions; if a variable is not live after an assignment, that assignment is dead code.

A back edge points from a node back to one of its dominators, establishing a loop header.

Recall without looking

Contrast Reaching Definitions and Available Expressions.

Reaching definitions: Forward, Union (∪). Tests if a definition may reach along ANY path. Available expressions: Forward, Intersection (∩). Tests if an expression must be computed on ALL paths.

What is a dominator and a natural loop?

Node d dominates n (d dom n) if every path from entry to n passes through d. A natural loop is defined by a back edge m → d (where d dom m) and contains all nodes that reach m without going through d.
