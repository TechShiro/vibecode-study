1. Bottom-Up Parsing Principles

A bottom-up parser constructs a parse tree for an input string beginning at the leaves (input terminals) and working systematically upward toward the root (start symbol $S$).

This process corresponds to constructing a Rightmost Derivation in REVERSE — formally referred to as a canonical parse.

Reverse Rightmost Derivation w = γn ⇒rm γn-1 ⇒rm … ⇒rm γ1 ⇒rm S

At each step, the parser identifies a substring matching the right-hand side of a production and reduces it to the corresponding left-hand non-terminal.

2. Handles and Handle Pruning

Formal Definition of a Handle A handle of a right-sentential form $\gamma$ ($= \alpha \beta w$, where $w \in T^*$) is a production rule $A \to \beta$ and a position in $\gamma$ where the substring $\beta$ may be replaced by non-terminal $A$ to yield the previous right-sentential form in a rightmost derivation:

S ⇒rm* α A w ⇒rm α β w

Then $\beta$ at the specified position is a handle of $\alpha \beta w$ for production $A \to \beta$.
Handle Pruning

Handle pruning is the universal bottom-up parsing algorithm: start with the terminal string $w$, locate the handle $\beta_1$ in $w$, replace it with non-terminal $A_1$, find the next handle $\beta_2$, and repeat until the string is reduced to the start symbol $S$.

4. Shift-Reduce Parser Conflicts

Conflict CategoryConditionStandard Example
Shift/Reduce Conflict The parser cannot determine whether to shift the next input token or reduce the current symbols on top of the stack. Dangling-Else: When stack holds if E then S and input sees else, shifting binds else to inner if; reducing completes the outer if.
Reduce/Reduce Conflict The parser determines that a handle must be reduced, but cannot decide which of two distinct grammar productions to apply ($A \to \alpha$ vs $B \to \alpha$). Occurs when two different non-terminals derive identical terminal strings under identical contexts.

Recall Without Looking

Define handle and handle pruning.

A handle is a substring matching the right-hand side of a production whose reduction represents one step along the reverse rightmost derivation. Handle pruning is the iterative process of identifying and reducing handles from leaves to root.

Name and define the four actions of a shift-reduce parser.

1. Shift (push next token to stack). 2. Reduce (replace stack handle with production LHS variable). 3. Accept (parsing succeeds when stack has $S and input is $). 4. Error (trigger syntax error recovery).

Distinguish Shift/Reduce conflicts from Reduce/Reduce conflicts.

Shift/Reduce: parser cannot choose between shifting the next token or reducing the current stack handle. Reduce/Reduce: parser knows to reduce, but two distinct productions have matching right-hand sides and valid reductions on the same lookahead.
