1. Sources of Optimization guaranteed theory

  • Preservation Criteria: 1. Must preserve program semantics. 2. Must speed up execution. 3. Compilation time must remain reasonable.
  • Function-Preserving:
    • Common Subexpression Elimination (CSE): Reuses previously computed identical values.
    • Copy Propagation: Replaces x with y after x = y until redefinition.
    • Dead-Code Elimination: Prunes instructions whose outputs are never read.
    • Constant Folding: Evaluates compile-time operations directly (2 * 3.14 → 6.28).
  • Loop Transformations:
    • Code Motion / Hoisting: Moves loop-invariant computations to loop preheader.
    • Induction Variables: Variables changing by fixed amounts per iteration ($i = i + c$).
    • Strength Reduction: Replaces expensive ops ($t = i * 4$) with cheap ones ($t = t + 4$).

2. Basic Blocks & Control Flow Graphs (CFG) guaranteed rules

Three Rules for Finding Leaders:
1. Statement 1 is a leader.
2. Any statement that is the target of a conditional or unconditional goto is a leader.
3. Any statement immediately following a conditional or unconditional goto is a leader.

Block construction: A basic block starts with a leader and includes all statements up to (not including) the next leader or program end.

CFG Edges $B_i \to B_j$: Exists if $B_j$ is a jump target of $B_i$, or if $B_j$ immediately follows $B_i$ sequentially and $B_i$ does not end with an unconditional jump.

3. DAG for Basic Blocks guaranteed numerical

  • Leaves: Constants or entering variables (e.g. $i_0$).
  • Interior nodes: Operators ($+$, $-$, $*$, $/$, $[]=$). Attached labels: variable names currently holding that value.
  • Optimizations enabled: Detects local common subexpressions (reuses existing node $(op, l, r)$), eliminates dead code (nodes with no parents whose variables are dead), applies algebraic identities ($x*1=x$, $x+0=x$, $x*0=0$).

5. Dominators & Natural Loops definitions

Dominance ($d \text{ dom } n$): Every path from entry to $n$ must pass through $d$.

Back edge: An edge $m \to d$ where head $d$ dominates tail $m$ ($d \text{ dom } m$).

Natural Loop: Single loop header $d$ dominating all nodes in loop, containing back edge $m \to d$, and all nodes that reach $m$ without passing through $d$.

6. Code Generation & Register Allocation chaitin

  • Issues: Target language format, instruction selection, register allocation/assignment, evaluation order, memory management.
  • Register Allocation vs Assignment: Allocation decides which variables stay in registers; assignment chooses the specific hardware register ($R_0, R_1$).
  • Graph Coloring (Chaitin):
    1. Construct interference graph (nodes = live ranges, edge = overlapping liveness).
    2. Simplify: remove nodes with degree $< k$, push onto stack.
    3. Spill: if all degrees $\ge k$, pick candidate with low cost to spill to RAM.
    4. Select: pop stack and assign colors (registers).

7. Peephole Optimization guaranteed 5-marker

Examines a sliding window of target instructions and replaces inefficient sequences:

  1. Redundant Load/Store: MOV R0, a; MOV a, R0 → delete 2nd instruction.
  2. Unreachable Code: Instructions immediately following unconditional jumps without a label are deleted.
  3. Flow of Control (Jump Chaining): goto L1; ... L1: goto L2 → goto L2.
  4. Algebraic Simplification: x = x + 0 pruned; x = x * 2 → SHL x, 1.
  5. Machine Idioms: ADD R0, #1 → INC R0.

Ten-Minute Exam Final Scan

  1. Leader rules: 1 = first stmt; 2 = jump target; 3 = stmt immediately following jump.
  2. DAG interior node: Reused if (op, left, right) matches an existing node → eliminates local CSE.
  3. Available expressions: Forward + Intersection ($\cap$). Powers Global Common Subexpression Elimination.
  4. Live variables: Backward + Union ($\cup$). Powers Dead Code Elimination and Register Allocation.
  5. Dominance: $d \text{ dom } n$ means $d$ is on every path from entry to $n$. Natural loop defined by back-edge $m \to d$.
  6. Register allocation by graph coloring: $k$ registers = $k$-coloring of interference graph. Push degree $< k$ onto stack.
  7. Peephole 5 types: Redundant load/store, unreachable code, jump to jump, algebraic reduction in strength, machine idioms (INC/DEC).
