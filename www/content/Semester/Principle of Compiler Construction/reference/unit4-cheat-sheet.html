Unit IV — Exam Sheet

Intermediate Code Generation — SDD, SDT, Three-Address Code, Array Addressing, Backpatching, and Runtime Storage Administration.

Attributes: Synthesised vs Inherited guaranteed

Synthesised: Computed from children in parse tree. Bottom-up flow. Evaluated during LR parsing.
Inherited: Computed from parent and/or left siblings. Top-down/sideways flow. Terminals cannot have inherited attributes.

S-Attributed vs L-Attributed SDD comparison

PropertyS-AttributedL-Attributed
Attributes allowedOnly SynthesisedSynthesised + Inherited (restricted)
Inherited dependencyNone permittedOnly from left siblings or parent
Evaluation methodBottom-up (LR parse stack)Depth-first left-to-right (LL or DFS)
HierarchyS-Attributed ⊂ L-Attributed ⊂ General SDD

Three-Address Code (TAC) Forms definition

Each instruction has at most 3 addresses: x = y op z, x = op y, x = y, goto L, if x relop y goto L, x = y[i], x[i] = y, x = &y, x = *y, param x, call p, n.

Quadruples vs Triples vs Indirect Triples memorise

FeatureQuadruplesTriplesIndirect Triples
Fields(op, arg1, arg2, result)(op, arg1, arg2)(op, arg1, arg2) + Pointer array
TemporariesExplicit ($t_1, t_2$)Implicit (position index)Implicit (position index)
ReorderingEasy (names fixed)Disastrous (breaks indices)Extremely easy (swap pointers only)

Array Address Calculation guaranteed numerical

1D Array: $\text{Address}(A[i]) = Base + (i - low) \times w$.
2D Row-Major: $\text{Address}(A[i, j]) = Base + ((i - low_1) \times n_2 + (j - low_2)) \times w$.
2D Column-Major: $\text{Address}(A[i, j]) = Base + ((j - low_2) \times n_1 + (i - low_1)) \times w$.
(where $n_1 = high_1 - low_1 + 1$ is rows, $n_2 = high_2 - low_2 + 1$ is columns, $w$ is byte width).

Control Flow & Short-Circuit Evaluation template

If-Else: if E goto L_true; goto L_false; L_true: S1; goto L_after; L_false: S2; L_after: ...
While: L_start: ifFalse E goto L_exit; S; goto L_start; L_exit: ...
Short-Circuit OR ($B_1 \textbf{ or } B_2$): if $B_1$ true → jump to true label; evaluate $B_2$ only if $B_1$ is false.
Short-Circuit AND ($B_1 \textbf{ and } B_2$): if $B_1$ false → jump to false label; evaluate $B_2$ only if $B_1$ is true.

Backpatching Primitives algorithm

makelist(i): creates a new list containing quad index $i$.
merge(p1, p2): concatenates list $p_1$ and $p_2$.
backpatch(p, L): inserts target label $L$ into all incomplete gotos on list $p$.
$B_1 \textbf{ or } M\ B_2$: $backpatch(B_1.false, M.quad)$; $true = merge(B_1.true, B_2.true)$; $false = B_2.false$.
$B_1 \textbf{ and } M\ B_2$: $backpatch(B_1.true, M.quad)$; $true = B_2.true$; $false = merge(B_1.false, B_2.false)$.

Activation Record (Stack Frame) memorise 7 fields

  1. Return value: result returned to caller.
  2. Actual parameters: arguments passed by caller.
  3. Control link (Dynamic link): pointer to caller's frame (stack unwinding).
  4. Access link (Static link): pointer to lexical parent frame (nested scopes).
  5. Saved machine status: PC return address and CPU registers.
  6. Local variables: procedure's local data.
  7. Temporaries: expression evaluation temps.

Storage Allocation Strategies

Static: Compile-time fixed addresses. No recursion. (Fortran 77).
Stack: Runtime LIFO allocation on call/return. Supports recursion. (C/C++ locals).
Heap: Runtime dynamic allocation in arbitrary order (malloc/new). Garbage collection.

Parameter Passing Comparison exam trace

Call by Value: Copy r-value. Caller variables unaffected.
Call by Reference: Pass l-value (address). Aliased; caller variable changes immediately.
Call by Value-Result (Copy-Restore): Local copy modified; copied back to caller at return time.
Call by Name: Textual substitution via thunks; re-evaluated on every access.

Five-minute scan

  1. Synthesised: from children (bottom-up). Inherited: from parent/left siblings.
  2. S-attributed: only synthesised (LR). L-attributed: synth + left-inherited (LL/DFS).
  3. TAC: $x = y\ op\ z$ (at most 3 addresses).
  4. Quadruples vs Triples: Quads have explicit temporaries; Triples use position index (hard to reorder); Indirect triples reorder pointers.
  5. 2D Array Row-Major: $Base + ((i - low_1) \times n_2 + (j - low_2)) \times w$.
  6. Backpatching: fills forward goto holes in single pass. makelist, merge, backpatch.
  7. AR (7 fields): Return val, Params, Dynamic link, Static link, Saved regs, Locals, Temps.
  8. Dynamic link: caller (runtime). Static link: enclosing scope (lexical).
  9. Storage: Static (no recursion), Stack (recursion/LIFO), Heap (dynamic lifetimes).
  10. Parameter passing: Value (copy), Reference (address/alias), Value-Result (copy-in/copy-out).
  11. Static Checking (4 types): Type checks (compatibility), Flow-of-control (break/return), Uniqueness (no duplicate IDs/case labels), Name checks.
  12. Type Equivalence: Name Equivalence (equal iff same name, O(1)) vs Structural Equivalence (equal iff same constructors recursively).
  13. Translation of Declarations: Maintain global offset: for $D \to \mathbf{id} : T$, record $\text{offset}$ and advance by $T.\text{width}$.
  14. Display Mechanism: Array d[depth] pointing to active activation records; provides $O(1)$ constant-time non-local variable lookup vs $O(k)$ for static chains.
