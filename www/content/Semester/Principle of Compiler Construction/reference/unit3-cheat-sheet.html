Unit III — Exam Sheet

Syntax Analysis — CFGs, FIRST/FOLLOW, LL(1), shift-reduce, SLR, CLR, LALR, Yacc — the heaviest unit in this paper.

CFG definition

G = (V, T, P, S). Ambiguous = two distinct parse trees (or two leftmost derivations) for the same string.

Left recursion elimination memorise

Immediate: $A \to A\alpha \mid \beta$ becomes $A \to \beta A'$,   $A' \to \alpha A' \mid \epsilon$.

Indirect: Order non-terminals $A_1 \dots A_n$. Substitute earlier productions into later ones, then eliminate immediate left recursion.

Left factoring

$A \to \alpha\beta_1 \mid \alpha\beta_2$ becomes $A \to \alpha A'$,   $A' \to \beta_1 \mid \beta_2$.

FIRST set guaranteed

Terminal: {itself}. $\epsilon$-prod $X \to \epsilon$: add $\epsilon$. $X \to Y_1 Y_2 \dots Y_k$: add $FIRST(Y_1)\setminus\{\epsilon\}$; continue to $Y_{i+1}$ if $Y_i \Rightarrow^* \epsilon$.

FOLLOW set guaranteed

$\$\in FOLLOW(S)$. For $A \to \alpha B \beta$: add $FIRST(\beta)\setminus\{\epsilon\}$ to $FOLLOW(B)$. If $\beta \Rightarrow^* \epsilon$ or absent: add $FOLLOW(A)$ to $FOLLOW(B)$. $\epsilon$ is NEVER in any FOLLOW set!

LL(1) table guaranteed

For each $A \to \alpha$: put in $M[A, a]$ for all $a \in FIRST(\alpha)$. If $\epsilon \in FIRST(\alpha)$: put in $M[A, b]$ for all $b \in FOLLOW(A)$. No multiple entries = grammar is LL(1). No left-recursive or ambiguous grammar can be LL(1).

Shift-reduce parsing

Bottom-up. Constructs reverse rightmost derivation. Four actions: Shift (push token), Reduce (pop handle, push LHS), Accept (stack holds $ S, input $), Error.

SLR(1) table guaranteed

Augment with $S' \to S$. LR(0) items $[A \to \alpha \cdot \beta]$.
CLOSURE: If dot before NT $B$, add $B \to \cdot \gamma$.
GOTO: Move dot past $X$, take closure.
Table entries: Shift $s_j$ if dot before terminal $a$. Reduce $r_k$ on all terminals in $FOLLOW(A)$. Accept on $[S' \to S \cdot, \$]$.
Non-SLR conflict: $S \to L = R \mid R$ fails because $=\ \in FOLLOW(R)$, causing S/R conflict in state with $\{S \to L \cdot = R, R \to L \cdot\}$.

CLR(1) and LALR(1) comparison

LR(1) item: $[A \to \alpha \cdot \beta, a]$. Lookahead $b \in FIRST(\beta a)$ generated in closure. Reduces strictly on exact lookahead $a$.
LALR(1): Merge CLR states having the same core (same items ignoring lookahead). Number of states = SLR(1). Never introduces S/R conflicts; can introduce R/R conflicts.

Yacc / Bison memorise

Structure: 3 sections delimited by %%: (1) Declarations, (2) Rules & actions ($$ = $1 + $3), (3) C code (main() { yyparse(); }, yyerror()).
Directives: %token, %left, %right, %nonassoc, %prec.
Defaults: S/R conflict → Shift. R/R conflict → First-listed rule.

Five-minute scan

  1. CFG: $G = (V, T, P, S)$. Ambiguous = 2 parse trees.
  2. Left recursion: $A \to \beta A'$, $A' \to \alpha A' \mid \epsilon$.
  3. FIRST/FOLLOW: FOLLOW never has $\epsilon$. $\$ \in FOLLOW(S)$.
  4. LL(1) table: FIRST for columns, FOLLOW for $\epsilon$-productions.
  5. Shift-reduce: reverse rightmost derivation. Handle = RHS to reduce.
  6. SLR: LR(0) items, FOLLOW sets for reduces.
  7. CLR: LR(1) items, exact lookahead from $FIRST(\beta a)$.
  8. LALR: merge same-core states; state count = SLR; Yacc default.
  9. Hierarchy: $LL(1) \subset SLR(1) \subset LALR(1) \subset CLR(1)$.
  10. Yacc: 3 sections, yylex() producer, yyparse() consumer, y.tab.h header.
  11. LL(1) Error Recovery: Blank entries = errors. synch placed for terminals in $FOLLOW(A)$: pop $A$ on synch; skip token on blank.
  12. Viable Prefix & LR Recovery: Prefix of right-sentential form not extending past handle. LR parsers have viable prefix property; never shift invalid tokens. LR panic-mode pops stack to state with goto on $A$, skips input until $FOLLOW(A)$.
