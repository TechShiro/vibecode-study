Unit IV — Exam Sheet

Network Security — PGP, S/MIME, SSL/TLS, IPSec, IKE.

PGP memorise

5 services: auth (sign), confidentiality (session key + public key), compression (ZIP), compatibility (Base64), segmentation. Order: sign → compress → encrypt → Base64. Web of trust.

S/MIME

Same services as PGP but uses X.509 certificates + CA hierarchy. Built into email clients.

SSL/TLS guaranteed

4 protocols: Handshake, Change Cipher Spec, Alert, Record.

Handshake: ClientHello → ServerHello → Certificate → ServerKeyExchange → ServerHelloDone → ClientKeyExchange → [derive master secret] → CCS → Finished.

Record: Fragment → Compress → MAC → Encrypt → Header → Send.

IPSec guaranteed

Transport: payload only, host-to-host. Tunnel: entire packet, gateway-to-gateway (VPN).

AH: auth + integrity, no encryption. ESP: encryption + auth + integrity.

SA / SPD / SAD / IKE

SA = (SPI, dest IP, protocol). One-way. SPD: discard/bypass/protect. SAD: stores SAs.

IKE Phase 1: IKE SA (DH, main/aggressive). Phase 2: IPSec SAs (quick mode).

Five-minute scan

  1. PGP: sign → compress → encrypt → Base64. Web of trust.
  2. S/MIME: X.509 CA hierarchy. Same services.
  3. TLS handshake: CH → SH → Cert → SKE → SHD → CKE → CCS → Fin.
  4. Record: fragment → compress → MAC → encrypt.
  5. IPSec transport vs tunnel. AH = auth only. ESP = encrypt + auth.
  6. SA = (SPI, dest, protocol). IKE Phase 1 + Phase 2.
