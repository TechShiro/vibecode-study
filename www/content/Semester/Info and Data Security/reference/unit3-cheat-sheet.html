Unit III — Exam Sheet

Authentication and Key Management — entity authentication, passwords, challenge-response, ZKP, biometrics, KDC, Kerberos, Diffie–Hellman, certificates, hijacking — on one printable page.

Where the marks are

Kerberos three exchanges is the highest-probability question (10 marks). Then: challenge-response protocol (5 marks), four methods of public-key distribution (5 marks), zero-knowledge proofs (5 marks), biometrics comparison (5 marks). DH may appear here or in Unit IV.

Entity vs message authentication definition

Entity: proves identity in real-time (timeliness required). Message: proves origin/integrity of a message (can be verified later).

Three authentication factors memorise

Know (password) · Have (token) · Are (biometric). MFA = ≥2 from different categories.

Passwords

Attacks: eavesdropping, replay, dictionary, brute-force, file theft, phishing.

Defences: hashing, salting, key stretching (bcrypt), account lockout, TLS.

OTP: S/Key = hash chain used backwards; TOTP = HMAC(⌊time/30⌋); HOTP = HMAC(counter).

Challenge-response protocol

Symmetric unilateral B → A: RB    A → B: EK(RB)    B checks decryption.

Why it works: fresh nonce each time → old responses invalid. Reflection attack: attacker forwards challenge to second session; fix: directional keys / include IDs.

Zero-Knowledge Proofs definition

Completeness: honest prover always convinces. Soundness: dishonest prover fails. Zero-knowledge: verifier learns nothing.

Fiat–Shamir Setup: v = s² mod n. Round: commit x = r², challenge bit e, respond y = r·se. Check: y² = x·ve. Cheat prob = 2−t.

Biometrics comparison table

FAR = impostor accepted. FRR = genuine rejected. EER = FAR = FRR (lower = better).

Types: fingerprint, iris, retina, face, voice, hand geometry, signature dynamics.

Advantage: can’t forget/lose. Disadvantage: can’t change if compromised.

Symmetric-key distribution KDC

KDC shares master key with each user, generates session keys on demand. Needham–Schroeder: vulnerable to replay of old ticket. Fix: timestamps (Denning–Sacco) or Kerberos.

Kerberos v5 guaranteed question

Three exchanges 1. AS exchange: Client → AS: IDC. AS → Client: EKC(KC,TGS, TGT).
2. TGS exchange: Client → TGS: TGT + Auth. TGS → Client: EKC,TGS(KC,V, TicketV).
3. App exchange: Client → V: TicketV + Auth. V → Client: EKC,V(TS+1).

Password never sent. TGT = single sign-on. Timestamps prevent replay. Authenticator proves possession of session key.

Diffie–Hellman key agreement

DH A = ga mod p, B = gb mod p, K = gab mod p. Security: DLP.

MITM: no authentication → Mallory does DH with both sides. Fix: sign public values (STS protocol) or certificates.

Public-key distribution four methods

  1. Public announcement — no authentication
  2. Directory — tamper risk
  3. Online authority — bottleneck
  4. Certificates (CA) — standard, offline verification

X.509: version, serial, algorithm, issuer, validity, subject, public key, CA signature.

CRL: revoked certificates. OCSP: online status check.

Hijacking attacks

MITM: during key exchange. Session hijacking: takeover of live session after auth. Replay: resend old messages. All exploit gaps in freshness/authentication.

Five-minute scan before you walk in

  1. Entity = real-time identity. Message = origin + integrity.
  2. Know · Have · Are. MFA = different categories.
  3. Challenge-response: B sends nonce, A encrypts with K. Fresh nonce = no replay.
  4. ZKP: completeness, soundness, zero-knowledge. Fiat–Shamir: y² = x·ve.
  5. FAR/FRR/EER. Can’t change biometrics if compromised.
  6. Kerberos: AS → TGT → TGS → Ticket → Service. Password never sent. Timestamps.
  7. DH: gab mod p. MITM because no auth. Fix: sign the public values.
  8. Four PK distribution methods. Certificates = standard (X.509).
  9. Hijacking: MITM ≠ session hijacking ≠ replay. Know the differences.
  10. S/Key: hash chain backwards. TOTP: HMAC(time/30).

  2. Explain challenge-response protocol and how it prevents replay. 5 marks
  3. Compare four methods of public-key distribution. 5 marks
  4. What are zero-knowledge proofs? Explain Fiat–Shamir. 5 marks
