Unit V — Exam Sheet

System Security, Buffer Overflows, Malicious Programs (Viruses, Worms, Trojans), IDS, Firewalls & VPNs on one printable page.

1. Security Foundations & STRIDE threat model

  • Equation: $\text{Threat} + \text{Vulnerability} = \text{Risk}$. Assets require protection.
  • Policy vs Mechanism: Policy specifies what is permitted; mechanism provides how to enforce it.
  • STRIDE: Spoofing (Auth), Tampering (Integrity), Repudiation (Non-repudiation), Information Disclosure (Confidentiality), Denial of Service (Availability), Elevation of Privilege (Authorization).
  • Saltzer-Schroeder: Least privilege, Fail-safe defaults (default deny), Complete mediation, Open design, Defense in depth.

2. Buffer Overflow Mechanics & Defenses guaranteed 10-marker

  • Process Layout (Low → High): Text (code) → Data (init globals) → BSS (uninit) → Heap (grows ↑) → Stack (grows ↓) → Kernel.
  • Stack Frame (Top/Low to Base/High): Local Buffers → Saved Frame Pointer (EBP) → Saved Return Address (RET/EIP) → Parameters.
  • Exploit Flow: Unsafe string copy (strcpy, gets) fills buffer → overflows across EBP → overwrites RET → jumps to NOP sled (0x90) → executes shellcode.
  • Three Defenses:
    1. Stack Canaries: Random compiler integer before RET; checked before return. If modified → abort().
    2. ASLR: OS randomizes stack, heap, and library base addresses on every run.
    3. DEP / NX Bit (W^X): Hardware marks data pages (stack/heap) non-executable.

Polymorphic vs Metamorphic Virus: Polymorphic uses encrypted body + mutated decryptor loop. Metamorphic completely re-engineers instruction sequence via register swaps and equivalent instructions without encryption.

4. Intrusion Detection Systems (IDS) guaranteed

  • Signature-based (Misuse): Matches known attack regex/byte patterns. Fast, low false positives, cannot detect zero-day attacks.
  • Anomaly-based (Heuristic): Flags deviations from baseline normal profile. Detects zero-days, high false positive rate.
  • HIDS vs NIDS: HIDS monitors host logs/syscalls/file hashes (inspects TLS payloads, high host CPU). NIDS monitors raw switch traffic (one sensor covers subnet, blinded by TLS).
  • Honeypot: Decoy system with no production value; any activity is malicious.
  • Snort: alert tcp any any -> 192.168.1.0/24 80 (msg:"..."; content:"..."; sid:10001; rev:1;)

6. Virtual Private Networks (VPN)

  • Goals: Confidentiality (encryption), Integrity (HMAC), Authentication, Anti-Replay.
  • Remote Access (Client-to-Gateway): Employees connecting into intranet (SSL/TLS or client).
  • Site-to-Site (Gateway-to-Gateway): Branch interconnect over public Internet (IPSec).
  • IPSec vs SSL VPN: IPSec operates at Layer 3 (all IP traffic, tricky with NAT). SSL/TLS operates at Layer 4–7 (browser-friendly, traverses NAT over port 443).

Ten-Minute Exam Final Scan

  1. Stack layout: Local buffer → EBP → RET. Buffer grows up towards RET; stack grows down.
  2. Buffer overflow defenses: Stack Canaries (compiler), ASLR (OS address randomization), DEP/NX (hardware W^X).
  3. Virus 4 phases: Dormant → Propagation → Triggering → Execution.
  4. Virus vs Worm: Virus needs host executable and human launch; Worm is standalone and replicates autonomously across networks.
  5. HIDS vs NIDS: HIDS can see inside decrypted HTTPS; NIDS is blind to encryption but has zero host overhead.
  6. Firewall types: Packet filter (stateless), Stateful (tracks sessions in table), Application gateway (L7 proxy, terminates connections).
  7. DMZ: Public servers placed between two firewalls to prevent direct access to private internal LAN.
