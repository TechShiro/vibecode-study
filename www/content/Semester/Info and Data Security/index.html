How to use this

  • Lessons are HTML. They open in any browser with no internet needed, and print cleanly for revision — recall-card answers force open on paper.
  • Quizzes are one-shot. Answering locks the question so the answer cannot be fished for, and options are padded to near-equal length so length is not a tell.
  • Watch boxes name specific videos, not just playlists. Title, channel and duration were read off the live page on 4 September 2026 — none were recalled from memory.
  • Exam-shaped, not mastery-shaped. Where a topic could go deeper, the lesson says so and stops.
  • Every numerical is verified. Unit I works SHA-512 padding four ways. Unit II works twelve numericals — EC point arithmetic, ECDH, EC ElGamal, RSA signing, three RSA forgeries, ElGamal signing, nonce-reuse key recovery, Schnorr, DSA and ECDSA — each computed and checked before it was written down.
