Classification of Malicious Software

Malware encompasses any software purposely designed to cause damage to a computer, server, client, or computer network. It is categorized along two primary axes:

Computer Viruses

A computer virus is a piece of parasitic software code that infects host executables, modifying them to include a copy of the virus so that when the host runs, the virus executes first.

The Four Virus Lifecycle Phases

Lifecycle Progression
  1. Dormant Phase: The virus is idle. It has infected the machine but is waiting for a trigger event (e.g., a specific date, file creation count, or user action). Not all viruses have a dormant phase.
  2. Propagation Phase: The virus places an identical or mutated copy of itself into other programs, files, or disk sectors on the machine.
  3. Triggering Phase: The virus is activated by a predefined event (e.g., system clock reaching Friday the 13th, or 100 system reboots).
  4. Execution Phase: The payload executes, performing harmless pranks (messages on screen) or malicious harm (deleting files, corrupting BIOS, encrypting disks).

Virus Evasion Techniques

  • Encrypted Virus: The body of the virus is encrypted with a random key. A small, unencrypted decryption routine and key are prepended. When executed, the decryption routine decrypts the virus into memory.
  • Polymorphic Virus: To defeat signature-based antivirus scanners that detect the fixed decryption routine, a polymorphic virus mutates the decryption engine on every infection (using register renaming, random junk instructions, and different keys). The decrypted payload remains identical.
  • Metamorphic Virus: The most complex virus type. It has no fixed body or decryption loop. Upon each infection, it completely rewrites its own code using compiler techniques (instruction substitution, dead code insertion, register swapping, subroutine interleaving). Its binary appearance changes 100%, but its operational behavior remains identical.

Computer Worms

A computer worm is an independent, standalone self-replicating program that propagates across computer networks by actively scanning for vulnerable network services and injecting itself without human intervention.

Milestone Worm: Stuxnet (2010)

Stuxnet was the first cyber-weapon worm specifically targeting Industrial Control Systems (ICS / SCADA). It exploited four separate zero-day Windows vulnerabilities, hijacked Siemens Step7 software, and manipulated the rotational frequency of Iranian uranium enrichment centrifuges while transmitting normal telemetry to operator screens.

Other Critical Malicious Programs

1. Trojan Horse

Software that appears legitimate or desirable (e.g., a cracked video game or PDF reader) but secretly executes hidden unauthorized actions (e.g., opening a remote access backdoor or keylogging passwords).

2. Rootkits

A collection of software tools designed to maintain privileged access while actively hiding its presence from detection:

  • User-mode rootkit: Intercepts API calls (e.g., hooking Windows DLLs) to filter out malicious files from file listing APIs.
  • Kernel-mode rootkit (Ring 0): Replaces OS system calls and kernel drivers. It can hide active network sockets and processes directly from task managers.

3. Ransomware

Malware that encrypts user documents using strong hybrid cryptography (e.g., AES-256 for data files, with the AES key encrypted by an attacker's RSA-2048 public key) and demands payment (usually cryptocurrency) for the private decryption key.

4. Botnets and Zombies

A bot (or zombie) is an infected machine controlled remotely. A botnet is a collection of thousands of compromised bots orchestrated by a Botmaster via a Command and Control (C2) server (using IRC, HTTP, or P2P protocols). Used to launch massive Distributed Denial of Service (DDoS) attacks and spam campaigns.

Check yourself

Retrieval practice

1. What makes a computer worm fundamentally different from a computer virus?

Worms are standalone network-propagating programs requiring no host executable or human activation.

2. A virus that completely rewrites its machine instructions while preserving functionality on each infection is:

Metamorphic viruses recompile and restructure their entire codebase; polymorphic viruses only mutate the decryption wrapper.

3. In the virus lifecycle, which phase is characterized by payload detonation (e.g. encrypting files)?

Triggering activates the decision to strike; execution actually carries out the payload damage.

Recall without looking

Name the four phases of the virus lifecycle in order.

1. Dormant phase → 2. Propagation phase → 3. Triggering phase → 4. Execution phase.

Contrast polymorphic vs metamorphic viruses.

Polymorphic: identical encrypted body, mutated decryption routine. Metamorphic: entire code is rewritten using instruction substitution and register swaps without encryption.

What is a rootkit and why is kernel-mode worse than user-mode?

A rootkit maintains stealthy privileged access. A kernel-mode rootkit operates in Ring 0, subverting OS kernel data structures and system calls directly, making it invisible to standard security scanners.
