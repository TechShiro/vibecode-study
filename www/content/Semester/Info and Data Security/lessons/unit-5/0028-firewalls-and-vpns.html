What is a Firewall?

A firewall is a network security device or software system that monitors and filters incoming and outgoing network traffic based on an organization's previously established security policies. It creates a controlled barrier between a trusted internal network and an untrusted external network (such as the Internet).

Firewall Design Philosophies
  • Default Deny (Whitelisting): That which is not expressly permitted is prohibited. Recommended best practice. Blocks unknown attacks by default.
  • Default Allow (Blacklisting): That which is not expressly prohibited is permitted. Extremely vulnerable; any omitted rule leaves an open door.

The Four Types of Firewalls

Firewall TypeOSI LayerInspection MechanismPros & Cons
1. Packet Filtering (Stateless) Layer 3 & 4 (Network / Transport) Examines individual packet headers: Source/Dest IP, Source/Dest Port, Protocol (TCP/UDP/ICMP). Evaluates each packet in total isolation. Pros: Extremely fast, low latency, transparent.
Cons: No memory of connection state; vulnerable to IP spoofing; cannot inspect application payloads.
2. Stateful Inspection Layer 3, 4 & Session Tracks active TCP 3-way handshakes and connection states in a dynamic State Table. Packets are admitted only if they belong to an existing, validly initiated connection. Pros: Closes ports dynamically; blocks unsolicited incoming probes; high throughput.
Cons: Cannot detect attacks hidden inside legitimate application payloads (e.g., SQL injection over port 80).
3. Application-Level Gateway (Proxy) Layer 7 (Application) Acts as an intermediary/relay. Terminates incoming TCP connections, reconstructs application protocol data (HTTP, FTP, SMTP), inspects deep content, and re-initiates a new connection to destination. Pros: Deepest packet inspection, URL filtering, malware scanning, hides internal network structure.
Cons: High computational latency; requires proxy support or client reconfiguration.
4. Circuit-Level Gateway Layer 5 (Session / SOCKS) Validates TCP handshakes and circuit establishment without inspecting application payloads. Once established, it copies data back and forth without further parsing. Pros: Fast relay once circuit is open; protocol-independent.
Cons: No payload inspection after handshake; relies entirely on trust of endpoints.

Key architectural concepts:

  • Bastion Host: A publicly accessible computer located in the DMZ that has been systematically hardened (all non-essential services, compilers, and user accounts disabled; logging dialed to maximum).
  • DMZ (Demilitarized Zone): A neutral buffer subnet separating the external Internet from the internal corporate network. Even if an external hacker compromises the public web server, the internal firewall blocks them from penetrating the private database LAN.

Virtual Private Networks (VPN)

A Virtual Private Network (VPN) extends a private network across a public network by encrypting communication traffic, creating a private “tunnel” over the public Internet.

Core Security Goals of a VPN
  1. Confidentiality: Encrypts payload and header data so eavesdroppers on public Wi-Fi or ISPs see only ciphered bytes.
  2. Data Integrity: Uses HMAC to ensure packets have not been modified or corrupted in transit.
  3. Authentication: Cryptographically validates the identity of the client or peer gateway before allowing tunnel traffic.
  4. Anti-Replay: Uses monotonically increasing sequence numbers to prevent captured packets from being re-injected.

VPN Classifications

  • Remote Access VPN (Client-to-Site): Enables individual mobile employees to securely connect from home/travel into corporate intranet servers. Uses client software (e.g. AnyConnect, OpenVPN client).
  • Site-to-Site VPN (Gateway-to-Gateway): Connects branch offices to headquarters over the public Internet. Gateways at each site handle encryption/decryption transparently; end-user workstations require no special software.

Check yourself

Retrieval practice

1. How does a stateful inspection firewall prevent unauthorized incoming connections?

Stateful firewalls remember outbound requests and permit inbound return packets only if they belong to an established session.

2. In a screened subnet architecture, where should public web and mail servers reside?

The DMZ isolates public-facing servers from the internal private network, containing potential compromises.

3. Why do SSL/TLS VPNs traverse corporate firewalls more easily than IPSec VPNs?

Standard port 443 is universally allowed for web browsing, making SSL VPNs highly portable and NAT-friendly.

Recall without looking

Compare packet filtering, stateful, and application proxy firewalls in one line each.

Packet filter: fast Layer 3/4 header check, no state. Stateful: tracks connection states in dynamic table. Application proxy: Layer 7 deep content inspection, high latency.

What is a DMZ and a Bastion Host?

A DMZ is an isolated perimeter subnet between external and internal firewalls. A Bastion host is a hardened computer inside the DMZ that hosts public services (web, DNS, mail).

Site-to-site vs remote access VPN.

Site-to-site connects two network gateways (transparent to users; uses IPSec). Remote access connects an individual mobile user to the corporate gateway (uses client software or SSL/TLS).
