Elliptic Curve Cryptography — the Arithmetic

The curve equation, the group law, point addition and doubling over Zp with every step shown, finding all points on a curve, scalar multiplication by double-and-add, and the ECDLP that makes it hard.

Exam strategy

This is a numerical lesson — treat it like subnetting, not like theory. Three question shapes recur: “Find all points on the curve Ep(a,b)”, “Given P and Q on the curve, find P+Q and 2P”, and “Compute kP”. Learn the two λ formulas and the fact that division means multiply by the modular inverse; everything else follows mechanically. Write the formula before substituting — that alone carries marks even if the arithmetic slips.

Why elliptic curves at all

RSA rests on the difficulty of factoring; Diffie–Hellman on the discrete logarithm in Zp*. Both need large keys because index-calculus methods attack them sub-exponentially. The elliptic curve discrete logarithm problem has no known sub-exponential attack, so the same security needs a far smaller key — which is the entire commercial argument for ECC.

Smaller keys mean less storage, less bandwidth, less computation and less power — which is why ECC dominates on smart cards, mobile devices, IoT nodes and TLS.

The curve

Weierstrass form y2 = x3 + ax + b

It is non-singular (no cusps, no self-intersections) if and only if
4a3 + 27b2 ≠ 0.  Cryptography uses only non-singular curves.

Cryptography does not use the curve over the real numbers — that is only a picture to explain the group law. It uses the curve over a finite field, in one of two forms:

FieldWrittenEquationUsed because
Prime field — Zp, p primeEp(a, b)y2 ≡ x3 + ax + b (mod p)Simple modular arithmetic; the exam always uses this one
Binary field — GF(2m)E2m(a, b)y2 + xy = x3 + ax2 + bPolynomial arithmetic is fast in hardware

The group and the point at infinity

The points of the curve, together with a special element O — the point at infinity, form an abelian group under point addition:

  • O is the identity: P + O = O + P = P.
  • The inverse of P = (x, y) is −P = (x, −y mod p) — the reflection in the x-axis.
  • P + (−P) = O.
  • Addition is commutative and associative.

Geometrically over the reals: draw the line through P and Q, find the third point where it meets the curve, and reflect it in the x-axis. For P + P the line is the tangent at P. Everything below is that construction turned into algebra and taken mod p.

The two formulas — the whole of this lesson

Point addition and doubling on Ep(a, b) For P = (x1, y1) and Q = (x2, y2), with R = P + Q = (x3, y3):

λ = (y2 − y1)(x2 − x1)−1 mod p   when P ≠ Q   (ADDITION)
λ = (3x12 + a)(2y1)−1 mod p   when P = Q   (DOUBLING)

then, in both cases:
x3 = λ2 − x1 − x2 mod p    y3 = λ(x1 − x3) − y1 mod p
(for doubling, x2 = x1, so x3 = λ2 − 2x1)
The one skill everything depends on

There is no division mod p — multiply by the modular inverse. To compute 5/8 mod 11: find 8−1 mod 11 by inspection (8 × 7 = 56 = 55 + 1, so 8−1 = 7), then 5 × 7 = 35 ≡ 2 mod 11. For small primes, test multiples until you hit 1; for larger ones use the extended Euclidean algorithm. Also remember −k mod p = p − k.

Numerical 1 — find all points on the curve

Q. Find all points on E11(1, 6): y2 = x3 + x + 6 mod 11

Step 1 — check non-singularity. 4a3 + 27b2 = 4(1) + 27(36) = 976 ≡ 976 − 968 = 8 ≠ 0 mod 11. Valid curve.

Step 2 — list the quadratic residues mod 11. Square 1 to 5 (the rest repeat): 1, 4, 9, 5, 3. So QR = {1, 3, 4, 5, 9}, with square roots 1→(1,10), 3→(5,6), 4→(2,9), 5→(4,7), 9→(3,8).

Step 3 — for each x from 0 to 10, compute x3 + x + 6 mod 11 and check membership.

Sanity check — Hasse’s theorem: the number of points lies between p + 1 − 2√p and p + 1 + 2√p, i.e. between 12 − 6.6 = 5.4 and 12 + 6.6 = 18.6. Our 13 sits inside. Also, points come in ±y pairs, so the count of affine points is even — a fast way to spot a missed root.

Numerical 2 — point addition

Q. On E11(1, 6), with P = (2, 7) and Q = (3, 6), find P + Q

P ≠ Q, so use the addition formula.

λ = (y2 − y1)(x2 − x1)−1 = (6 − 7)(3 − 2)−1 = (−1)(1)−1 = −1 ≡ 10 mod 11

x3 = λ2 − x1 − x2 = 100 − 2 − 3 = 95 ≡ 95 − 88 = 7

y3 = λ(x1 − x3) − y1 = 10(2 − 7) − 7 = −50 − 7 = −57 ≡ −57 + 66 = 9

P + Q = (7, 9)

Sanity check: is (7,9) on the curve? y2 = 81 ≡ 4; x3+x+6 = 343 + 7 + 6 = 356 ≡ 4. Equal — the answer is a curve point. Always run this check; it catches every arithmetic slip.

Numerical 3 — point doubling

Q. On the same curve, find 2P where P = (2, 7)

P = Q, so use the doubling formula with a = 1.

λ = (3x12 + a)(2y1)−1 = (3·4 + 1)(14)−1 = 13 · 14−1 ≡ 2 · 3−1 mod 11

3−1 mod 11: 3 × 4 = 12 ≡ 1, so 3−1 = 4.   λ = 2 × 4 = 8

x3 = λ2 − 2x1 = 64 − 4 = 60 ≡ 60 − 55 = 5

y3 = λ(x1 − x3) − y1 = 8(2 − 5) − 7 = −24 − 7 = −31 ≡ −31 + 33 = 2

2P = (5, 2) — check: 22 = 4 and 125 + 5 + 6 = 136 ≡ 4. ✓

And one more, to build the chain: 3P = 2P + P = (5,2) + (2,7)

λ = (7 − 2)(2 − 5)−1 = 5 · (−3)−1 = 5 · 8−1.   8 × 7 = 56 ≡ 1, so 8−1 = 7.   λ = 35 ≡ 2

x3 = 4 − 5 − 2 = −3 ≡ 8;   y3 = 2(5 − 8) − 2 = −8 ≡ 3.   3P = (8, 3)

Numerical 4 — scalar multiplication by double-and-add

kP means P added to itself k times, but nobody computes it that way. Write k in binary and use double-and-add: the same square-and-multiply idea as RSA, with multiplication replaced by point addition.

Q. On E11(1, 6) with P = (2, 7), compute 7P

7 = 4 + 2 + 1, so 7P = 4P + 2P + P.

2P = (5, 2) — computed above.

4P = 2(2P) = 2(5, 2): λ = (3·25 + 1)(2·2)−1 = 76 · 4−1 ≡ 10 · 3 = 30 ≡ 8  (since 76 ≡ 10 and 4−1 = 3).
x3 = 64 − 10 = 54 ≡ 10;   y3 = 8(5 − 10) − 2 = −42 ≡ 2.   4P = (10, 2)

6P = 4P + 2P = (10,2) + (5,2): λ = (2 − 2)(5 − 10)−1 = 0; x3 = 0 − 10 − 5 = −15 ≡ 7; y3 = 0(10 − 7) − 2 = −2 ≡ 9.   6P = (7, 9)

7P = 6P + P = (7,9) + (2,7): λ = (7 − 9)(2 − 7)−1 = (−2)(−5)−1 = 9 · 6−1.   6 × 2 = 12 ≡ 1, so 6−1 = 2.   λ = 18 ≡ 7.
x3 = 49 − 7 − 2 = 40 ≡ 7;   y3 = 7(7 − 7) − 9 = −9 ≡ 2.   7P = (7, 2)

Sanity check: 6P = (7, 9) and 7P = (7, 2) share an x and their y values sum to 11 ≡ 0, so 7P = −6P — which forces 13P = O. Consistent with the group having order 13.

Every point of the curve appears exactly once, so P is a generator and the group is cyclic of order 13. The order of a point is the smallest n with nP = O — here 13. Note the symmetry: kP and (13−k)P are reflections of each other.

The hard problem: ECDLP

Elliptic Curve Discrete Logarithm Problem Given points P and Q = kP on the curve, find k.

Computing Q from k takes about log2k operations (double-and-add).
Recovering k from Q takes about √n operations (Pollard’s rho) — no sub-exponential algorithm is known.

That asymmetry is the trapdoor. It is the exact analogue of “multiplying is easy, factoring is hard” in RSA, and it is why a 256-bit ECC key matches a 3072-bit RSA key. In our toy curve n = 13, so k is found by inspection — real curves use n of 256 bits or more.

Common exam slips, in order of frequency

(i) Using the addition formula when P = Q — look at the points first. (ii) Dividing instead of multiplying by the inverse. (iii) Forgetting that −k mod p = p − k, giving a negative y. (iv) Writing y3 = λ(x3 − x1) − y1 — the bracket is (x1 − x3), in that order. (v) Not checking the result lies on the curve, which costs marks that a ten-second substitution would have saved.

2. On E₁₁(1,6) with P = (2,7), the value 2P is:

λ = 13 × 14⁻¹ ≡ 2 × 3⁻¹ = 2 × 4 = 8; x₃ = 64 − 4 ≡ 5; y₃ = 8(2 − 5) − 7 ≡ 2. Note (10,2) is 4P and (7,9) is 6P.

3. The inverse of the point P = (x, y) on a curve over Z_p is:

−P = (x, −y mod p). Adding P and −P gives a vertical line, which meets the curve nowhere else, so the sum is the point at infinity O.

Recall without looking

Give the elliptic curve equation and the non-singularity condition.

y² = x³ + ax + b, non-singular when 4a³ + 27b² ≠ 0. Over a prime field it is written E_p(a,b) with the equation taken mod p; over a binary field GF(2ᵐ) the form is y² + xy = x³ + ax² + b.

State the group properties of the points on an elliptic curve.

The points plus the point at infinity O form an abelian group. O is the identity, so P + O = P; the inverse of (x, y) is (x, −y mod p); P + (−P) = O; and addition is commutative and associative.

Write both λ formulas and the coordinate formulas.

Addition (P ≠ Q): λ = (y₂ − y₁)(x₂ − x₁)⁻¹ mod p. Doubling (P = Q): λ = (3x₁² + a)(2y₁)⁻¹ mod p. Then x₃ = λ² − x₁ − x₂ mod p and y₃ = λ(x₁ − x₃) − y₁ mod p.

How do you find all points on E_p(a,b)?

List the quadratic residues mod p by squaring 1 to (p−1)/2. For each x from 0 to p−1 compute x³ + ax + b mod p; if the result is a quadratic residue, its two square roots give two points (x, y) and (x, p−y). Add O. Check the total against Hasse’s bound p + 1 ± 2√p.

Explain scalar multiplication and the double-and-add method.

kP is P added to itself k times. It is computed by writing k in binary and repeatedly doubling, adding in P at each set bit — about log₂k operations rather than k. This is the additive analogue of square-and-multiply.

State the ECDLP and why it matters.

Given P and Q = kP, find k. Computing Q from k costs about log₂k operations, but recovering k costs about √n by Pollard’s rho, and no sub-exponential algorithm is known. That gap is the trapdoor, and it is why a 256-bit ECC key matches a 3072-bit RSA key.

Give the ECC-to-RSA key size equivalences.

160-bit ECC ≈ 1024-bit RSA; 224 ≈ 2048; 256 ≈ 3072; 384 ≈ 7680; 512 ≈ 15360. The ratio widens from about 6:1 to 30:1 as the security level rises.
