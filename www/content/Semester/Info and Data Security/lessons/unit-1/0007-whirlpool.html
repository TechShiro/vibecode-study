Whirlpool

The 512-bit hash built from a block cipher instead of from scratch — the Miyaguchi–Preneel scheme, the AES-like cipher W with its four round transformations, and the three-way comparison that closes Unit I.

Exam strategy

Usually a 5-mark short note: “Explain the Whirlpool hash function.” The marks are in four facts — 512-bit digest from a 512-bit block cipher W, the Miyaguchi–Preneel equation, 10 rounds of four AES-like transformations, and designed by Rijmen and Barreto, an ISO standard. If a longer question asks to compare MD5, SHA-512 and Whirlpool, the table at the end of this lesson is the answer in full.

The idea: build the hash out of a cipher

MD4, MD5 and SHA-512 are dedicated designs — their compression functions exist only to hash. Whirlpool takes the other route from Lesson 2: reuse a block cipher as the compression function. The advantage is that decades of cryptanalysis of the cipher carry over; the cost is speed, because a cipher must re-run its key schedule for every message block.

The Whirlpool compression function — memorise this line Hi = E(Hi−1, Mi) ⊕ Mi ⊕ Hi−1

The previous chaining value is the key; the message block is the plaintext;
the ciphertext is XORed with both inputs. That double XOR is what makes it one-way.

Padding and length

The Whirlpool padding rule — the same shape as SHA-512, halved Append a 1 followed by 0s until the length is congruent to 256 modulo 512,
then append a 256-bit field holding the original message length in bits.
Quick worked check

Q. A 1000-bit message is hashed with Whirlpool. Find the padding and the number of blocks.

r = 1000 mod 512 = 1000 − 512 = 488.   P = 256 − 488 = −232, negative, so add 512: P = 280 bits.

Total = 1000 + 280 + 256 = 1536 bits = 3 blocks of 512.

The cipher W — four transformations per round

W is AES with a bigger state: an 8 × 8 byte matrix instead of AES’s 4 × 4. Each of the 10 rounds applies the same four transformations, and an initial AddRoundKey precedes round 1.

TransformationWhat it doesPurposeAES equivalent
1. SubBytes (SB)Each of the 64 bytes is replaced using a fixed 16 × 16 S-boxConfusion — the only non-linear stepSubBytes
2. ShiftColumns (SC)Column j is rotated downwards by j bytes (column 0 unchanged, column 1 by one, … column 7 by seven)Diffusion between rowsShiftRows (Whirlpool works down the columns instead)
3. MixRows (MR)Each row is multiplied by a fixed 8 × 8 MDS matrix over GF(28)Diffusion within a row — one changed byte affects all eightMixColumns
4. AddRoundKey (AK)The state is XORed with the 512-bit round keyMixes in the key — here, the chaining valueAddRoundKey
The key schedule — the part that surprises students

The round keys are produced by running the very same round function on the key itself, with a round constant RC[r] taking the place of the round key at each stage. So W needs no separate key-expansion design: the cipher expands its own key. The round constants are drawn from the S-box, keeping the whole algorithm dependent on a single table.

Putting it together

Hashing a message with Whirlpool, end to end

1. Pad the message to 256 mod 512 and append the 256-bit length field.

2. Split into 512-bit blocks M1…Mt; set H0 = 0 (512 zero bits).

3. For each block: use Hi−1 as the key of cipher W, encrypt Mi through 10 rounds of SubBytes, ShiftColumns, MixRows and AddRoundKey, then form Hi = E(Hi−1, Mi) ⊕ Mi ⊕ Hi−1.

4. After the last block, Ht is the 512-bit digest.

Check yourself

1. Whirlpool's compression function is expressed as:

The chaining value is the key, the block is the plaintext, and the ciphertext is XORed with both inputs — the double XOR is the mark of Miyaguchi–Preneel.

2. The cipher W differs from AES chiefly in that it:

AES holds a 4 × 4 matrix; W holds 8 × 8. It is still a substitution-permutation network, and its key schedule reuses the round function with round constants.

3. In Whirlpool, ShiftColumns and MixRows respectively provide:

SubBytes is the only confusion step. ShiftColumns moves bytes across rows; MixRows spreads each byte across its whole row through the MDS matrix.

4. The main practical drawback of Whirlpool compared with SHA-512 is that it:

Both give 512-bit digests and neither is broken in full. Whirlpool's cost is speed and its limited deployment, not its security margin.

5. Whirlpool pads a message until its length is congruent to:

Each algorithm reserves exactly its length-field width at the end of the final block: 64 for MD5, 128 for SHA-512, 256 for Whirlpool.

Recall without looking

Give the parameters of Whirlpool.

512-bit digest, 512-bit blocks, messages up to 2²⁵⁶ − 1 bits, 10 rounds, an 8 × 8 byte state, and the underlying block cipher W with a 512-bit block and 512-bit key. Designed by Vincent Rijmen and Paulo Barreto in 2000, endorsed by NESSIE and standardised in ISO/IEC 10118-3.

Write the Miyaguchi–Preneel equation and explain each term.

H_i = E(H_{i−1}, M_i) ⊕ M_i ⊕ H_{i−1}. The previous chaining value H_{i−1} acts as the encryption key, the message block M_i is the plaintext, and the ciphertext is XORed with both the block and the chaining value — the double feed-forward that makes the compression function one-way.

Name the four round transformations of cipher W and what each does.

SubBytes substitutes each byte through a 16 × 16 S-box, providing the only non-linearity. ShiftColumns rotates column j downwards by j bytes, diffusing across rows. MixRows multiplies each row by a fixed 8 × 8 MDS matrix over GF(2⁸), diffusing within a row. AddRoundKey XORs the 512-bit round key into the state.

How are Whirlpool's round keys generated?

By running the same round function on the key itself, with a round constant RC[r] used in place of the round key at each stage. The round constants are derived from the S-box, so the whole algorithm depends on a single table and needs no separate key-expansion design.

State Whirlpool's padding rule.

Append a 1 bit followed by zeros until the length is congruent to 256 modulo 512, then append a 256-bit field giving the original message length in bits, so the padded message is an exact multiple of 512 bits.

Give the strengths and weaknesses of Whirlpool.

Strengths: a 512-bit digest giving 2²⁵⁶ collision resistance with no attack on the full function; a design inherited from the well-analysed AES; an independent lineage from MD/SHA; patent-free, an ISO standard and efficient in hardware. Weaknesses: slower in software because the key schedule runs for every block; rebound attacks exist on reduced rounds; far less deployed and field-tested than SHA-2; and its large state costs memory on small devices.

Compare MD5, SHA-512 and Whirlpool in one table.

Digests 128 / 512 / 512 bits; blocks 512 / 1024 / 512; 64 steps / 80 rounds / 10 rounds; length fields 64 / 128 / 256 bits; padding to 448 mod 512, 896 mod 1024 and 256 mod 512; dedicated compression functions for the first two, a block cipher under Miyaguchi–Preneel for Whirlpool; MD5 broken at 2⁶⁴, the other two secure at 2²⁵⁶; MD5 fastest, Whirlpool slowest in software.
