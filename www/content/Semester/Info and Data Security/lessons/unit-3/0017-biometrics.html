What is biometric authentication?

Authentication based on measurable physical or behavioural characteristics of a person. It is the third factor: “something you are.”

Physiological vs behavioural

The enrollment-verification pipeline

  1. Enrollment: user provides biometric sample → sensor captures → feature extraction → template stored in database.
  2. Verification (1:1): user claims identity + provides sample → extracted features compared against one stored template. “Is this person who they claim to be?”
  3. Identification (1:N): sample compared against all templates. “Who is this person?”

Error rates

FAR, FRR and EER FAR (False Acceptance Rate) = probability of accepting an impostor.
FRR (False Rejection Rate) = probability of rejecting a legitimate user.
EER (Equal Error Rate) = the point where FAR = FRR. Lower EER = better system.
The trade-off

Tightening the threshold lowers FAR (fewer impostors get in) but raises FRR (more genuine users locked out). Loosening does the opposite. The EER is where both errors are equal — a single number to compare systems.

The closing line

“A password can be changed; a fingerprint cannot.” This is why biometrics are best used as one factor in MFA, not as the sole authentication mechanism.

Check yourself

Retrieval practice

1. FAR in biometrics stands for:

FAR = impostor accepted. FRR = genuine user rejected. Lower is better for both.

2. EER is the point where:

Equal Error Rate: the threshold where false acceptance and false rejection are equal. Lower EER = more accurate system.

3. The most accurate biometric method is generally:

Iris patterns have extremely high uniqueness and stability. Retina scans are equally accurate but more intrusive.

4. The key disadvantage of biometrics compared to passwords is:

A compromised password can be reset. A compromised fingerprint template cannot — you cannot change your fingerprint.

5. Verification (1:1) differs from identification (1:N) in that:

Verification: “Am I who I claim?” (1:1). Identification: “Who am I?” (1:N search). Identification is computationally harder.

6. Keystroke dynamics is an example of:

Keystroke dynamics measures HOW you type (timing, pressure), not what you type. It is behavioural, not physiological.

Recall without looking

Define FAR, FRR and EER.

FAR = impostor accepted. FRR = genuine user rejected. EER = threshold where FAR = FRR. Lower EER = better system.

Name five biometric types.

Fingerprint, iris, retina, face, voice. Also: hand geometry, signature dynamics, keystroke dynamics, gait.

Enrollment vs verification vs identification.

Enrollment: capture + store template. Verification (1:1): compare against claimed identity. Identification (1:N): search all templates.

Two advantages and two disadvantages.

Advantages: cannot be forgotten/lost, difficult to forge. Disadvantages: cannot be changed if compromised, sensor errors are unavoidable.
