1 · The One Idea

OOP is not tied to any single syntax or runtime. Different languages made radically different engineering trade-offs when implementing objects: Java chose strict nominal class-based typing with garbage collection; C++ chose manual RAII memory control with multiple inheritance; Python chose dynamic duck typing with C3 Linearization MRO; and JavaScript chose prototypal inheritance.

Concept Java C++ Python JavaScript
Inheritance Model Single class inheritance + multiple interface implementation. Full multiple class inheritance (virtual base classes solve diamond). Multiple inheritance resolved via C3 Linearization MRO. Prototypal Inheritance (objects link to other objects via __proto__).

Memory Management Automatic Garbage Collection (G1GC / ZGC). RAII (Resource Acquisition Is Initialization: Stack destructors manage heap). Reference Counting + Cycle Detector GC. Automatic Garbage Collection (Mark-and-Sweep).
Data Hiding (Private) Strict private enforced by compiler and JVM. Strict private with friend class bypasses. Convention only: single underscore (_name) or name-mangling (__name). Historically closure-based; modern ES2022 private fields (#privateField).
