Looking behind the magic of Spring Boot, Hibernate, and Jackson JSON deserializers.

1 · The One Idea

Normally, software code operates on data (numbers, strings). Metaprogramming is software code that operates on other code. Through the Java Reflection API, a program can inspect its own classes, constructors, methods, and annotations at runtime, instantiate objects without using new, and even modify private variables! This is the engine behind modern frameworks like Spring, JUnit, and Jackson.

2 · Building a Mini Dependency Injection Container

import java.lang.annotation.*;
import java.lang.reflect.Field;

// 1. Custom Annotation
@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.FIELD)
public @interface AutoInject {}

// 2. Mini DI Injector
public class MiniInjector {
    public static void inject(Object target, Object dependency) throws Exception {
        Class<?> clazz = target.getClass();
        for (Field field : clazz.getDeclaredFields()) {
            if (field.isAnnotationPresent(AutoInject.class)) {
                field.setAccessible(true); // Bypass private access!
                field.set(target, dependency); // Injects the instance!
            }
        }
    }
}

3 · The Cost of Reflection

  • Performance Overhead: Reflective calls bypass JIT compiler inlining and type checks; roughly 2–10x slower than direct invocations.
  • Loss of Compile-Time Safety: Refactoring (renaming a method) breaks string-based reflective lookups silently until runtime crashes happen.
