Composing multiple design patterns into a decoupled, highly extensible production system.

1 · The One Idea

In low-level design, you rarely use one pattern in isolation. A well-designed production service weaves several patterns together: the Observer Pattern listens for domain events, the Factory Pattern instantiates the appropriate channel handlers, the Strategy Pattern swaps formatting algorithms, and the Decorator Pattern wraps network calls with automated retry and logging logic.

3 · Production Java Implementation

public interface NotificationSender {
    void send(String recipient, String message);
}

// Base implementation
public class EmailSender implements NotificationSender {
    public void send(String recipient, String message) {
        System.out.println("Sending Email to " + recipient + ": " + message);
    }
}

// Decorator adding Retry Logic
public class RetryNotificationDecorator implements NotificationSender {
    private final NotificationSender wrapped;
    private final int maxRetries;

    public RetryNotificationDecorator(NotificationSender wrapped, int maxRetries) {
        this.wrapped = wrapped;
        this.maxRetries = maxRetries;
    }

    public void send(String recipient, String message) {
        int attempts = 0;
        while (attempts < maxRetries) {
            try {
                wrapped.send(recipient, message);
                return;
            } catch (Exception e) {
                attempts++;
                if (attempts >= maxRetries) throw e;
            }
        }
    }
}
