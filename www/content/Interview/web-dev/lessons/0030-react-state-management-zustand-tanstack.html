Modern State Management: Zustand & TanStack Query

Separating client UI state from asynchronous server state without Redux boilerplate.

↑ Back to Course Index Module F — Advanced Frontend

1 · The One Idea

For a decade, React developers stuffed everything into Redux: UI modal toggles, user inputs, and API fetched data. This was a architectural mistake! In modern web applications, state divides cleanly into two categories:

  • Client State (Local UI): Dark mode toggle, sidebar collapsed, active tab. Best handled by Zustand (minimal, fast, zero boilerplate).
  • Server State (Remote Asynchronous Cache): User profiles, orders, fetched lists. Best handled by TanStack Query (React Query) (automatic caching, background refetching, deduping, and stale-while-revalidate).

2 · Zustand in Action (Clean Global Client State)

import { create } from 'zustand';

export const useCartStore = create((set) => ({
  items: [],
  addItem: (product) => set((state) => ({ items: [...state.items, product] })),
  clearCart: () => set({ items: [] }),
}));

// In any React component anywhere in the tree:
function CartCounter() {
  const count = useCartStore((state) => state.items.length);
  return <span>Cart: {count}</span>;
}

3 · TanStack Query (Handling Server State Elegantly)

import { useQuery, useMutation, useQueryClient } from '@tanstack/react-query';

function UserProfile({ userId }) {
  // Automatically caches, retries on failure, handles loading/error states
  const { data: user, isLoading, error } = useQuery({
    queryKey: ['user', userId],
    queryFn: () => fetch(`/api/users/${userId}`).then(res => res.json()),
    staleTime: 1000 * 60 * 5, // Fresh for 5 minutes (zero network refetch!)
  });

  if (isLoading) return <div>Loading user profile...</div>;
  if (error) return <div>Error loading user: {error.message}</div>;

  return <h1>Welcome back, {user.name}!</h1>;
}
