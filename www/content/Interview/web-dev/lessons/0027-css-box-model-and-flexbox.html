Mastering dimensional math and one-dimensional layout alignment from absolute scratch.

1 · The One Idea

In CSS, every single element rendered on a web page is an invisible rectangular box. The Box Model dictates how the element's Content, Padding, Border, and Margin combine to determine its physical size on screen. Flexbox (Flexible Box Layout) is the one-dimensional layout system designed to align, space, and distribute items across rows or columns, eliminating historic float hacks forever.

2 · The Box Model & The Mandatory CSS Reset

Under default browser CSS (box-sizing: content-box), if you declare width: 100px; padding: 20px; border: 5px;, the actual rendered width on screen is $100 + 40 + 10 = \mathbf{150 ext{px}}$! This unexpected expansion breaks responsive layouts.

The CSS Reset Every Developer Writes 
*, *::before, *::after {
  box-sizing: border-box; /* Padding and borders are included INSIDE width! */
  margin: 0;
  padding: 0;
}

3 · Flexbox: Main Axis vs Cross Axis

Flexbox operates along two perpendicular axes:

  • Main Axis: Determined by flex-direction: row (horizontal, left to right) or column (vertical, top to bottom). Controlled via justify-content!
  • Cross Axis: Perpendicular to the main axis. Controlled via align-items!

4 · Centering a Div in 2 Lines

.center-container {
  display: flex;
  justify-content: center; /* Centers along Main Axis */
  align-items: center;     /* Centers along Cross Axis */
  min-height: 100vh;
}

5 · Flex Sizing: Grow, Shrink & Basis

  • flex-basis: Initial size of item before extra space is distributed (e.g. 200px).
  • flex-grow: How much of the remaining empty space this item absorbs relative to sibling items (e.g. 1).
  • flex-shrink: How aggressively this item shrinks when container space runs out (e.g. 1 to shrink, 0 to never shrink).
