CSS Grid & Responsive Web Design

Building fluid, two-dimensional dashboard and card layouts that adapt to any screen size.

↑ Back to Course Index Module 0 — Web Foundations

1 · The One Idea

While Flexbox is designed for 1D content flows (either a row OR a column), CSS Grid is a true two-dimensional layout system that aligns items across rows AND columns simultaneously. By combining CSS Grid's repeat(auto-fit, minmax(...)) with Mobile-First Media Queries, you can construct layouts that gracefully reorganize from 4 columns on desktop to 1 column on mobile phones with zero JavaScript!

2 · The Magic Responsive Grid (No Media Queries Required!)

.card-grid {
  display: grid;
  /* Magic formula: automatically fits as many 250px+ cards as possible! */
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 1.5rem;
}

3 · Mobile-First Responsive Design & Media Queries

Always write default styles for mobile screens first (simplest 1-column layout), then use min-width media queries to layer on multi-column styles as screens get wider:

/* Base: Mobile phone (Default) */
.dashboard {
  display: flex;
  flex-direction: column;
}

/* Tablet breakpoint */
@media (min-width: 768px) {
  .dashboard {
    display: grid;
    grid-template-columns: 240px 1fr; /* Sidebar + Main content */
  }
}

/* Desktop breakpoint */
@media (min-width: 1024px) {
  .dashboard {
    grid-template-columns: 280px 1fr 320px; /* Sidebar + Main + Widgets */
  }
}
