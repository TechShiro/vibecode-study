HTML5 Semantics & Web Accessibility (a11y)

Why building with semantic elements matters for search engines, screen readers, and maintainability.

↑ Back to Course Index Module 0 — Web Foundations

1 · The One Idea

Too many developers suffer from "Div Soup" — building entire web applications using only unstyled <div> and <span> tags. A <div> conveys zero meaning to browsers, Google search crawlers, or blind users navigating with screen readers. Semantic HTML5 uses elements that describe their exact human purpose (<nav>, <main>, <article>, <button>), giving your application free accessibility (a11y), superior SEO rankings, and clean keyboard navigability.

2 · The Core Semantic Landmarks

  • <header>: Introductory content, site branding, global search bars.
  • <nav>: Major navigation blocks (screen readers allow blind users to jump directly past nav).
  • <main>: The dominant, unique content of the page (only one per document!).
  • <article>: A self-contained piece of content that could be syndicated alone (e.g., a blog post, tweet, or forum comment).
  • <section>: A standalone thematic grouping of content, typically with a heading.
  • <aside>: Indirectly related content (sidebars, related links, callout ads).
  • <footer>: Copyright notices, footer links, author bios.

3 · The Golden Rule: <button> vs <a>

Accessibility Rule of Thumb
  • Use an Anchor (<a href="...">) when navigating the user to a new URL, page, or document anchor.
  • Use a Button (<button>) when triggering an action on the current page (submitting a form, opening a modal, toggling dark mode).
  • Never write: <div onclick="...">! Divs cannot be focused by Tab keys, have no role, and cannot be pressed with Space or Enter keys!

4 · Accessible Forms & ARIA

<form action="/login" method="POST">
  <!-- Always link label to input using matching for / id attributes -->
  <label for="user-email">Email Address:</label>
  <input 
    type="email" 
    id="user-email" 
    name="email" 
    required 
    aria-describedby="email-help" 
    autocomplete="email"
  />
  <span id="email-help">We will never share your email.</span>

  <button type="submit">Sign In</button>
</form>
