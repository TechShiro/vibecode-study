1 · The One Idea

Building code on your laptop is only half the journey. Getting an application running securely, reproducibly, and continuously in production requires Multi-Stage Docker Builds (separating build tools from tiny production runtime images) and CI/CD Pipelines (automating linting, testing, and deployment whenever code is pushed to main).

2 · Production Multi-Stage Dockerfile for Node.js / Next.js

# Stage 1: Build & Compile
FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

# Stage 2: Minimal Production Runner (No devDependencies or build tools!)
FROM node:20-alpine AS runner
WORKDIR /app
ENV NODE_ENV=production
COPY --from=builder /app/package*.json ./
COPY --from=builder /app/node_modules ./node_modules
COPY --from=builder /app/dist ./dist

USER node
EXPOSE 3000
CMD ["node", "dist/main.js"]
