Web Performance & Core Web Vitals

Auditing and optimizing loading speed, interaction responsiveness, and visual stability.

↑ Back to Course Index Module F — Advanced Frontend

1 · The One Idea

Google directly ranks websites on search results using Core Web Vitals: real-world user experience metrics measuring three key areas: Loading Speed, Interactivity Responsiveness, and Visual Stability. A slow website loses 50% of mobile users within 3 seconds of waiting.

2 · The 3 Google Core Web Vitals

Metric What It Measures Target Goal How to Optimize
LCP (Largest Contentful Paint) How long until the main hero image or primary text block finishes rendering on screen. < 2.5 seconds Use WebP/AVIF modern images, set priority on hero image, CDN caching, SSR/Edge rendering.
INP (Interaction to Next Paint) How quickly the page visually responds when a user clicks a button or taps an input. < 200 ms Break up long JavaScript tasks using requestIdleCallback() or web workers; avoid heavy sync loops on main thread.
CLS (Cumulative Layout Shift) Measures unexpected visual jumps (e.g. text jumping down as an un-dimensioned image or ad suddenly loads). < 0.1 Always set explicit width and height attributes on images; reserve space for ads/embeds.
