Dutch National Flag & 3-Way Partitioning

Edsger Dijkstra's optimal one-pass in-place partitioning algorithm for three distinct categories.

Track goal: Master foundational data structures from 0 level. This is Lesson 3 of 5 in Arrays & Strings. Index

1 · The One Idea

Given an array containing only 0s, 1s, and 2s (e.g. [2, 0, 2, 1, 1, 0]), sort it in-place in a single pass without using extra counting arrays or library sort. Dijkstra's Dutch National Flag Algorithm divides the array into four zones using three pointers: low, mid, and high.

2 · The 4 Zone Invariants

  • [0 ... low - 1]: Contains strictly 0s (Red)
  • [low ... mid - 1]: Contains strictly 1s (White)
  • [mid ... high]: Unknown / unexamined elements
  • [high + 1 ... n - 1]: Contains strictly 2s (Blue)

3 · Java Implementation

public class DutchNationalFlag {
    public static void sortColors(int[] nums) {
        int low = 0;
        int mid = 0;
        int high = nums.length - 1;

        while (mid <= high) {
            if (nums[mid] == 0) {
                swap(nums, low, mid);
                low++;
                mid++;
            } else if (nums[mid] == 1) {
                mid++; // 1 is already in its correct zone
            } else { // nums[mid] == 2
                swap(nums, mid, high);
                high--; // Do NOT increment mid; swapped element is unexamined!
            }
        }
    }

    private static void swap(int[] arr, int i, int j) {
        int temp = arr[i];
        arr[i] = arr[j];
        arr[j] = temp;
    }
}
