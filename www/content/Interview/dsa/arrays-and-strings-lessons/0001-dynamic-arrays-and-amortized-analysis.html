Dynamic Arrays Under the Hood

Why arrays are the fastest data structure in physical hardware, and how ArrayList dynamically resizes without choking your CPU.

Track goal: Master foundational data structures from 0 level. This is Lesson 1 of 5 in Arrays & Strings. Index

1 · The One Idea

A static array is a contiguous block of physical RAM addresses: Address(index i) = BaseAddress + (i * elementSize). Because calculating an address takes exactly one multiplication and addition, looking up arr[i] takes O(1) time. Furthermore, because computer CPUs read memory in 64-byte chunks called Cache Lines, scanning an array sequentially is dramatically faster than traversing linked nodes scattered around the heap (Spatial Locality). A Dynamic Array (like Java's ArrayList or Python's list) wraps a fixed array, automatically allocating a double-sized array whenever it fills up.

2 · How Dynamic Resizing Works & Geometric Growth

When you initialize new ArrayList<>() in Java, it starts with an internal capacity of 10. When you append the 11th element:

  1. The JVM allocates a new array of size capacity * 1.5 (or $2 imes$ in many C++ std::vector implementations).
  2. It copies all existing elements over to the new array using high-speed native memory copying (System.arraycopy).
  3. It reassigns the internal pointer and discards the old array for garbage collection.

3 · Why Appending is Amortized O(1)

Beginners often ask: "If resizing copies $N$ elements (taking $O(N)$ time), why is add() considered $O(1)$?"

Because resizing happens exponentially less frequently as the array grows:

  • Cost to insert 1st to 8th element: $1 + 1 + 1 + 1 + 1 + 1 + 1 + 1 = 8$ operations.
  • Cost to resize at 8: Copy 8 elements + insert 9th = $8 + 1 = 9$ operations.
  • Next resize won't happen until element 16!

Sum of all copy costs over $N$ insertions is: $1 + 2 + 4 + 8 + \dots + N/2 = N - 1 < N$. Total work for $N$ insertions is: $N ext{ (regular inserts)} + N ext{ (copying)} = 2N$. Average cost per insert: $ rac{2N}{N} = \mathbf{O(1) ext{ Amortized Time}}$.

4 · Clean Java Implementation from Scratch

public class CustomArrayList<T> {
    private Object[] data;
    private int size = 0;
    private static final int DEFAULT_CAPACITY = 10;

    public CustomArrayList() {
        this.data = new Object[DEFAULT_CAPACITY];
    }

    public void add(T element) {
        if (size == data.length) {
            resize(data.length * 2); // Geometric doubling
        }
        data[size++] = element;
    }

    @SuppressWarnings("unchecked")
    public T get(int index) {
        if (index < 0 || index >= size) throw new IndexOutOfBoundsException();
        return (T) data[index]; // O(1) direct offset access
    }

    private void resize(int newCapacity) {
        Object[] newArray = new Object[newCapacity];
        System.arraycopy(data, 0, newArray, 0, size);
        this.data = newArray;
    }

    public int size() { return size; }
}
