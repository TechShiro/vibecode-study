Kadane's Algorithm & Subarray Mastery

Solving the contiguous maximum sum subarray in linear time with dynamic programming state reduction.

Track goal: Master foundational data structures from 0 level. This is Lesson 2 of 5 in Arrays & Strings. Index

1 · The One Idea

Given an array containing positive and negative integers (e.g. [-2, 1, -3, 4, -1, 2, 1, -5, 4]), find the contiguous subarray with the largest sum. Checking all possible start and end points takes $O(N^2)$ time. Kadane's Algorithm solves this in a single scan ($O(N)$ time, $O(1)$ space) based on a brilliant intuitive choice at every step: "Does adding the current number to the running sum help me, or is the previous running sum so negative that I am better off throwing it away and starting fresh from the current number?"

2 · The State Transition

At each index i, the maximum subarray ending at i is given by:

currentMax = Math.max(nums[i], currentMax + nums[i]);
globalMax = Math.max(globalMax, currentMax);

3 · Full Java Implementation (With Boundary Tracking)

public class KadaneSubarray {
    public static int maxSubArray(int[] nums) {
        int currentMax = nums[0];
        int globalMax = nums[0];

        for (int i = 1; i < nums.length; i++) {
            // Start fresh if previous sum is negative drag
            currentMax = Math.max(nums[i], currentMax + nums[i]);
            globalMax = Math.max(globalMax, currentMax);
        }
        return globalMax;
    }
}

4 · Variations: Maximum Product Subarray

What if the problem asks for the maximum product instead of sum? Multiplying two negative numbers produces a positive number! Therefore, you must track both maxProduct and minProduct at each step. When a negative number arrives, swap maxProduct and minProduct!
