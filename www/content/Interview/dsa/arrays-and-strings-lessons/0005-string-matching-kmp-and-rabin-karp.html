9.1 Knuth-Morris-Pratt KMP String Matching Algorithm — Abdul Bari The classic whiteboard explanation of the Longest Prefix Suffix (LPS) table.

1 · The One Idea

To check if pattern $P$ (length $M$) exists in text $T$ (length $N$), naive brute force compares character by character, resetting back to index 0 on mismatch ($O(N \cdot M)$ worst case). The Knuth-Morris-Pratt (KMP) algorithm precomputes an auxiliary LPS (Longest Proper Prefix which is also a Suffix) array in $O(M)$ time. When a mismatch occurs, instead of resetting the text pointer backward, KMP skips redundant comparisons using the LPS table, searching in guaranteed $O(N + M)$ time with zero text backtracking!

2 · Precomputing the LPS Array

public class KMPAlgorithm {
    public static int[] computeLPS(String pattern) {
        int m = pattern.length();
        int[] lps = new int[m];
        int len = 0; // Length of previous longest prefix suffix
        int i = 1;

        while (i < m) {
            if (pattern.charAt(i) == pattern.charAt(len)) {
                len++;
                lps[i] = len;
                i++;
            } else {
                if (len != 0) {
                    len = lps[len - 1]; // Fall back to shorter prefix
                } else {
                    lps[i] = 0;
                    i++;
                }
            }
        }
        return lps;
    }

    public static int search(String text, String pattern) {
        int[] lps = computeLPS(pattern);
        int i = 0, j = 0;

        while (i < text.length()) {
            if (pattern.charAt(j) == text.charAt(i)) {
                i++;
                j++;
            }
            if (j == pattern.length()) {
                return i - j; // Found match at index!
            } else if (i < text.length() && pattern.charAt(j) != text.charAt(i)) {
                if (j != 0) j = lps[j - 1];
                else i++;
            }
        }
        return -1;
    }
}

3 · Rabin-Karp: Rolling Hash

Rabin-Karp computes a hash value for the pattern and for each sliding window of length $M$ in the text. By using a Rolling Hash (where adding the next character and removing the oldest character takes $O(1)$ math), it checks potential matches in expected $O(N + M)$ time, making it ideal for multi-pattern searching (e.g. plagiarism detection).
