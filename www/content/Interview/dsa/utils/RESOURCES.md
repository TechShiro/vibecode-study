# DSA Patterns Resources

## Knowledge

- [NeetCode — Roadmap & Pattern videos](https://neetcode.io/roadmap)
  Pattern-organized problem set with clear video walkthroughs. Use for: seeing a canonical problem per pattern and a clean explanation. Highest-trust free interview resource. **NeetCode 150** is the curated pattern-coverage list to drill.
- [Striver's A2Z DSA Course / Sheet (takeUforward)](https://takeuforward.org/strivers-a2z-dsa-course/strivers-a2z-dsa-course-sheet-2/)
  India-standard, Java-friendly, fully ordered (basics → graphs → DP → trees). Use as the structured spine. Striver's **Graph** and **DP** YouTube series directly target the learner's gaps.
- [Aditya Verma — YouTube (DP, Sliding Window, Heaps, Stacks)](https://www.youtube.com/@adityaverma)
  Best free intuition-building for **Dynamic Programming** (recursion → memo → tabulation) and heaps. Use when DP recurrences feel like magic.
- [LeetCode](https://leetcode.com)
  The problem bank. Use for: timed practice and reading the "Editorial" + top discussion solutions for each pattern variation.
- [CP-Algorithms](https://cp-algorithms.com)
  Rigorous, competitive-programming-grade algorithm reference. Use for: the contest-strength version of a technique (e.g. binary search on the answer, monotonic stack proofs).
- [Codeforces — EDU section](https://codeforces.com/edu/courses)
  Free structured lessons (e.g. Binary Search, Two Pointers) with built-in problem steps. Use for: competitive-programming depth and proof intuition.
- [Book: *Cracking the Coding Interview* — Gayle Laakmann McDowell](https://www.crackingthecodinginterview.com/)
  Interview-focused. Use for: how patterns show up in interviews and how to talk through them.
- [Book: *Competitive Programmer's Handbook* — Antti Laaksonen (free PDF)](https://cses.fi/book/book.pdf)
  Use for: contest techniques and complexity discipline. Pairs with the CSES Problem Set.
- [Java docs: `java.util` Collections](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/package-summary.html)
  Use for: exact behavior of `Deque`, `PriorityQueue`, `TreeMap` used in templates.

## Wisdom (Communities)

- [r/leetcode](https://reddit.com/r/leetcode)
  Use for: interview experiences, which patterns are hot, debugging your approach.
- [Codeforces](https://codeforces.com)
  Use for: real contests to test pattern recognition under time pressure; editorials after each round.
- [LeetCode Discuss](https://leetcode.com/discuss/)
  Use for: alternative solutions and edge cases for a specific problem.

## Gaps
- No single source covers *all 15 patterns with Java templates + every case*. That gap is exactly what the `./reference/` cheat sheets in this workspace are filling.
