# Baseline: intermediate learner, Java, interview + CP goal

Established at workspace creation. Learner self-rates **intermediate**: comfortable
with arrays, strings, recursion, and core Java collections; can reason about Big-O.
Patterns like sliding window are known by name but not applied consistently.

Implications for teaching:
- Skip fundamentals. Start each pattern at the template + recognition level, then push into variations and edge cases.
- Dual goal (FAANG interviews **and** competitive programming) means each pattern should show both the interview-canonical case and at least one contest-strength variation.
- Pacing is learner-driven, one pattern at a time — do not pre-build all 15.
