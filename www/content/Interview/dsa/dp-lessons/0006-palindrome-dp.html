Palindrome DP

A palindrome is a palindrome wrapped in a matching pair: s[i..j] is one iff s[i] == s[j] and s[i+1..j-1] is. That nesting gives you an O(n²) table over substrings (i, j) — and a free O(1)-space alternative: expand around centers.

Mission link: DP is ~15% of Google intern questions and your self-identified gap. This is Lesson 6 of the 12-lesson DP track. Mission

1 · The one idea

Palindromes have recursive structure from the outside in: peel the matching outer pair and a smaller palindrome remains. So the natural state is a substring (i, j), and the table must be filled by increasing length — the inner substring (i+1, j-1) is strictly shorter, so it's already known. For substring questions there's a second weapon: every palindrome has a center, so expanding around all 2n−1 centers finds them all in O(n²) time and O(1) space.

Recognition trigger The word "palindrom-" plus longest / count / partition / insert / delete. Then one fork decides everything: substring (contiguous → isPal table or center expansion) vs subsequence (chars may be skipped → interval dp, Lesson 9's shape arriving early).

3 · Core template

The isPal table — filled by increasing length

// isPal[i][j] = true iff s[i..j] is a palindrome. O(n²) time and space.
boolean[][] buildIsPal(String s) {
    int n = s.length();
    boolean[][] isPal = new boolean[n][n];
    for (int i = 0; i < n; i++) isPal[i][i] = true;          // length 1
    for (int len = 2; len <= n; len++)                       // inner substrings already done
        for (int i = 0; i + len - 1 < n; i++) {
            int j = i + len - 1;
            isPal[i][j] = s.charAt(i) == s.charAt(j)
                       && (len == 2 || isPal[i + 1][j - 1]); // len 2 has an empty inside
        }
    return isPal;
}

Expand around center — the O(1)-space alternative for substrings (LC 5)

String longestPalindrome(String s) {
    int start = 0, len = 0;
    for (int c = 0; c < s.length(); c++) {
        int odd  = expand(s, c, c);              // odd-length: center ON character c
        int even = expand(s, c, c + 1);          // even-length: center BETWEEN c and c+1
        int best = Math.max(odd, even);
        if (best > len) { len = best; start = c - (best - 1) / 2; }
    }
    return s.substring(start, start + len);
}
int expand(String s, int l, int r) {
    while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) { l--; r++; }
    return r - l - 1;                            // pointers overshoot by one each side
}

Time O(n²) for both. Space: table O(n²), expansion O(1). Build the table when other dp layers will query "is s[i..j] a palindrome?" repeatedly (LC 132); expand when you only need the best window or a count (LC 5, 647).

Longest Palindromic Substring (5) — reading the answer off the isPal table

The table method for LC 5 is the core template with a two-line addition: whenever a cell turns true, compare its length against the best window so far. State is still isPal[i][j], the recurrence is unchanged, and because you iterate by increasing length, the first time you see a longer true cell it is automatically the leftmost one of that length. 

String longestPalindrome(String s) {
    int n = s.length();
    boolean[][] isPal = new boolean[n][n];
    int start = 0, maxLen = 1;                   // any single char is a valid fallback
    for (int i = 0; i < n; i++) isPal[i][i] = true;
    for (int len = 2; len <= n; len++)
        for (int i = 0; i + len - 1 < n; i++) {
            int j = i + len - 1;
            if (s.charAt(i) == s.charAt(j) && (len == 2 || isPal[i + 1][j - 1])) {
                isPal[i][j] = true;
                if (len > maxLen) { maxLen = len; start = i; }  // widest true cell so far
            }
        }
    return s.substring(start, start + maxLen);
}

Time O(n²) · Space O(n²). Same asymptotics as expansion but pays O(n²) memory — worth it only when the table gets reused (as in LC 132).

Classic bug Dropping the len == 2 || guard makes length-2 cells read isPal[i+1][j-1] = isPal[i+1][i] — a lower-triangle cell that is never set, so it's silently false and every "aa"-style pair gets marked non-palindrome. The bug hides on inputs with no adjacent duplicates.

Palindromic Substrings (647) — count by expanding every center

int countSubstrings(String s) {
    int count = 0;
    for (int c = 0; c < s.length(); c++) {
        count += countFrom(s, c, c);             // odd-length palindromes at this center
        count += countFrom(s, c, c + 1);         // even-length
    }
    return count;
}
int countFrom(String s, int l, int r) {
    int k = 0;                                   // each successful widening = one more palindrome
    while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) { k++; l--; r++; }
    return k;
}

The table route works too, because every true cell is exactly one palindromic substring — counting trues and counting palindromes are the same act. Same state and recurrence as the core template; only the answer changes from "widest true cell" to "number of true cells": 

int countSubstrings(String s) {                  // re-solve: table method
    boolean[][] isPal = buildIsPal(s);           // §3 core template, unchanged
    int count = 0;
    for (int i = 0; i < s.length(); i++)
        for (int j = i; j < s.length(); j++)
            if (isPal[i][j]) count++;            // one true cell = one palindrome
    return count;
}

Time O(n²) either way · Space: expansion O(1), table O(n²). Interviewers love hearing you name that trade-off unprompted.

Longest Palindromic Subsequence (516) — the interval-DP shape

// SUBSEQUENCE: characters may be skipped, so mismatches shrink one end, not fail.
int longestPalindromeSubseq(String s) {
    int n = s.length();
    int[][] dp = new int[n][n];
    for (int i = n - 1; i >= 0; i--) {           // i descending + j ascending = inner-first
        dp[i][i] = 1;
        for (int j = i + 1; j < n; j++)
            dp[i][j] = s.charAt(i) == s.charAt(j)
                     ? dp[i + 1][j - 1] + 2      // outer pair joins the inner LPS
                     : Math.max(dp[i + 1][j], dp[i][j - 1]);
    }
    return dp[0][n - 1];
}

Time O(n²) · Space O(n²) (a rolling pair of rows brings it to O(n) — same trick as Lesson 5).

The LCS-with-reverse equivalence. A common subsequence of s and reverse(s) is a sequence you can read forward through s and, simultaneously, forward through the reversal — i.e. backward through s. Reading the same thing forward and backward is precisely what a palindromic subsequence is, so LPS(s) = LCS(s, reverse(s)) and Lesson 5's template solves 516 with zero new code. State: dp[i][j] = LCS of s[0..i) and t[0..j); match → diagonal + 1; else max of dropping either prefix character; base case: row 0 and column 0 are 0. 

int longestPalindromeSubseqViaLCS(String s) {
    String t = new StringBuilder(s).reverse().toString();
    int n = s.length();
    int[][] dp = new int[n + 1][n + 1];          // Lesson 5's LCS table, verbatim
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= n; j++)
            dp[i][j] = s.charAt(i - 1) == t.charAt(j - 1)
                     ? dp[i - 1][j - 1] + 1      // match: extend the diagonal
                     : Math.max(dp[i - 1][j], dp[i][j - 1]);
    return dp[n][n];                             // = LPS(s)
}

Time O(n²) · Space O(n²), rollable to O(n).

Classic bug This equivalence is for the subsequence only. LCS(s, reverse(s)) does not find the longest palindromic substring: on "abacdfgdcaba" the LCS with its reversal is "abacd…"-shaped — length 7 and not a palindrome at all — while the true longest palindromic substring is "aba" (3). Copied characters can come from mismatched, mirror-image regions.

Palindrome Partitioning II (132) — isPal table + 1D cut dp on top

int minCut(String s) {
    int n = s.length();
    boolean[][] isPal = buildIsPal(s);           // O(n²) precompute — the core template
    int[] cut = new int[n];                      // cut[j] = min cuts for prefix s[0..j]
    for (int j = 0; j < n; j++) {
        if (isPal[0][j]) { cut[j] = 0; continue; } // whole prefix already a palindrome
        cut[j] = j;                              // worst case: cut between every pair
        for (int i = 1; i <= j; i++)             // last piece = s[i..j]; O(1) lookup, not O(n) recheck
            if (isPal[i][j]) cut[j] = Math.min(cut[j], cut[i - 1] + 1);
    }
    return cut[n - 1];
}

Time O(n²) (table build + the double loop) · Space O(n²) for the table. Without the precomputed table, re-checking "is s[i..j] a palindrome?" inside the loop costs O(n³) — the whole point of the two-layer design is turning that check into an O(1) lookup.

Minimum Insertions (1312) — arithmetic on LPS

No new dp at all. The LPS characters already sit symmetrically inside s; every one of the remaining n − LPS characters breaks symmetry and needs exactly one mirrored partner inserted — and you can never do better, since whatever survives un-mirrored must itself be a palindromic subsequence. Sister fact: minimum deletions to reach a palindrome is also n − LPS (delete the non-skeleton characters instead of mirroring them). 

int minInsertions(String s) {
    return s.length() - longestPalindromeSubseq(s);  // 516's method — reuse it as-is
}

Time O(n²) — all of it inside the 516 call · Space O(n²).

Worked example — dry run

s = "babad" (indices 0–4). Fill isPal by increasing length; only the upper triangle j ≥ i exists. The answer window for LC 5 is the widest true cell:

length 1: isPal[i][i] = T for all five i — 5 palindromes banked length 2: "ba" "ab" "ba" "ad" → no adjacent pair matches → all F length 3: (0,2) "bab": s[0]==s[2] and inner (1,1) is T → T; (1,3) "aba" → T; (2,4) "bad": b≠d → F length 4: (0,3) "baba": b≠a → F; (1,4) "abad": a≠d → F (outer chars fail — inner never consulted) length 5: (0,4) "babad": b≠d → F widest T = (0,2) → LC 5 returns "bab"; total trues = 7 for LC 647

5 · Edge-case checklist

  • Fill order: iterate by length (or i descending, j ascending). Filling i ascending, j ascending reads an unfilled isPal[i+1][j-1] — silently false, silently wrong.
  • Length-2 base case: (i+1, j-1) is an inverted/empty range — guard with len == 2 || ... (or j - i < 3), don't index it.
  • Even centers: expansion needs all 2n−1 centers — forgetting expand(s, c, c+1) misses "abba" entirely.
  • Substring vs subsequence: "bbbab" → longest palindromic substring "bbb" (3) but subsequence "bbbb" (4). Misreading this one word sinks the interview.
  • Empty / single-char input: length ≤ 1 is trivially a palindrome — return it before any table work.
  • 132 already-palindrome prefix: if isPal[0][j], cut[j] = 0 — skipping this guard costs both correctness and speed.
  • Substring extraction: s.substring(start, start + len) — the end index is exclusive in Java; off-by-one here returns a chopped palindrome.
