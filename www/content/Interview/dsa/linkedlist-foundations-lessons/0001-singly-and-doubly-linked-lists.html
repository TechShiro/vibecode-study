LinkedList Pointer Mechanics & Sentinel Nodes

Mastering memory node links, handling edge cases gracefully, and eliminating NullPointerExceptions.

Track goal: Master foundational data structures from 0 level. This is Lesson 1 of 2 in LinkedList Foundations. Index

1 · The One Idea

Unlike arrays which live in a contiguous memory block, a Linked List is a collection of individual objects (Nodes) scattered anywhere in computer heap memory. Each node holds its data and a reference (pointer) to the next node. While accessing the $k$-th element requires sequentially traversing $k$ pointers ($O(N)$ time), inserting or deleting a node at the head or after a known pointer takes O(1) time with zero element shifting.

2 · The Secret Weapon: Sentinel (Dummy) Head Nodes

Writing linked list code is notorious for nasty edge cases: inserting into an empty list, deleting the head node, or updating the tail pointer.

The Universal Fix Always introduce a Dummy (Sentinel) Node at the start: ListNode dummy = new ListNode(0); dummy.next = head;. Now, every real node (even the original head) has a predecessor! You will never have to write special-case if (head == null) logic again!

3 · Doubly Linked List from Scratch

public class DoublyLinkedList {
    public static class Node {
        int val;
        Node prev, next;
        Node(int val) { this.val = val; }
    }

    private final Node head = new Node(-1); // Dummy head
    private final Node tail = new Node(-1); // Dummy tail

    public DoublyLinkedList() {
        head.next = tail;
        tail.prev = head;
    }

    public void insertAtHead(Node node) {
        node.next = head.next;
        node.prev = head;
        head.next.prev = node;
        head.next = node;
    }

    public void remove(Node node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }
}
