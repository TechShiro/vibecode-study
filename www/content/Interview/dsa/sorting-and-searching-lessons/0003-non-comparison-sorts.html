Non-Comparison Sorts: Breaking O(N log N)

Linear-time sorting using integer keys, digit bucketing, and prefix frequencies.

Track goal: Master sorting and searching foundations from 0 level. This is Lesson 3 of 3 in Sorting & Searching. Index

1 · The One Idea

The $\Omega(N \log N)$ lower bound applies only when sorting by element-to-element comparisons. If elements are integers within a known bounded range, we can use their numerical properties as direct array indices to achieve O(N) linear-time sorting!

2 · The 3 Linear-Time Sorts

  • Counting Sort: Creates a frequency array of size $K = \max - \min + 1$. Computes running prefix sums of counts to place elements into output array stably in $O(N + K)$ time. Optimal when $K \le O(N)$.
  • Radix Sort (LSD): Sorts numbers digit by digit from least significant digit (1s place) to most significant digit using stable Counting Sort as an intermediate subroutine. Runs in $O(d \cdot (N + b))$ where $d$ is number of digits.
  • Bucket Sort: Distributes numbers into $K$ uniformly spaced buckets over interval $[0, 1)$, sorts individual buckets, and concatenates.
