Disjoint Set Union (Union-Find) Mastery

Tracking connected components in nearly O(1) time using path compression and union by rank.

Track goal: Master advanced competitive structures from 0 level. Lesson 1 of 1 in DSU. Index

1 · The One Idea

Given a network of computers or friends, how do you determine whether two nodes belong to the same connected group, or dynamically add connections between groups? BFS/DFS takes $O(V + E)$ per query. Disjoint Set Union (DSU) maintains partition sets supporting two operations: find(x) (find the leader/root of $x$'s group) and union(x, y) (merge the groups of $x$ and $y$) in virtually O(1) amortized time ($lpha(N) < 5$ for all atoms in the universe)!

2 · The Two Essential Optimizations

  1. Union by Rank / Size: When merging two trees, always attach the shorter tree underneath the root of the taller tree. This prevents the tree from becoming a long chain.
  2. Path Compression: During find(x), point every node visited along the path directly to the root: parent[x] = find(parent[x])! The next lookup on any of those nodes is instant $O(1)$!

3 · Complete Java Implementation

public class DisjointSetUnion {
    private final int[] parent;
    private final int[] rank;
    private int components;

    public DisjointSetUnion(int n) {
        this.parent = new int[n];
        this.rank = new int[n];
        this.components = n;
        for (int i = 0; i < n; i++) parent[i] = i; // Self-parent initially
    }

    public int find(int i) {
        if (parent[i] == i) return i;
        return parent[i] = find(parent[i]); // Path Compression
    }

    public boolean union(int i, int j) {
        int rootI = find(i);
        int rootJ = find(j);
        if (rootI == rootJ) return false; // Already connected (Cycle detected!)

        // Union by rank
        if (rank[rootI] < rank[rootJ]) {
            parent[rootI] = rootJ;
        } else if (rank[rootI] > rank[rootJ]) {
            parent[rootJ] = rootI;
        } else {
            parent[rootJ] = rootI;
            rank[rootI]++;
        }
        components--;
        return true;
    }

    public int getComponents() { return components; }
}
