1 · The One Idea

A Stack is a linear data structure operating on the Last In, First Out (LIFO) principle. It is identical to a stack of cafeteria dinner plates: the plate placed on top last is the first plate taken off. Stacks mirror computer recursion and function calls (the CPU Call Stack). Core operations are push(x), pop(), and peek(), all operating in strictly O(1) time.

2 · Designing a MinStack in O(1) Time and O(1) Auxiliary Space

Problem: Design a stack that supports push, pop, top, and retrieving the minimum element (getMin()) in $O(1)$ time.

Solution: Maintain an auxiliary minStack alongside the main stack. When pushing $X$, push $\min(X, ext{currentMin})$ onto minStack. 

import java.util.ArrayDeque;
import java.util.Deque;

public class MinStack {
    private final Deque<Integer> stack = new ArrayDeque<>();
    private final Deque<Integer> minStack = new ArrayDeque<>();

    public void push(int val) {
        stack.push(val);
        if (minStack.isEmpty() || val <= minStack.peek()) {
            minStack.push(val);
        }
    }

    public void pop() {
        if (stack.pop().equals(minStack.peek())) {
            minStack.pop();
        }
    }

    public int top() { return stack.peek(); }
    public int getMin() { return minStack.peek(); }
}
