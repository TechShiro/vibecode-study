Fenwick Tree (Binary Indexed Tree)

Peter Fenwick's mathematical marvel: range prefix sums in 12 lines of code and O(N) space.

1 · The One Idea

A Fenwick Tree (or Binary Indexed Tree / BIT) answers prefix sum queries and point updates in O(log N) time like a Segment Tree, but uses only O(N) space (a simple 1D array of size $N+1$) and requires no tree pointers or recursion. It is based on a beautiful bit manipulation insight: every positive integer can be decomposed into a unique sum of powers of 2.

2 · The Magic Lowbit Trick: x & (-x)

In two's complement binary representation, x & (-x) isolates the lowest set bit (rightmost 1-bit) of integer $x$!

  • $6 = (0110)_2 \implies -6 = (1010)_2 \implies 6 \ \& \ (-6) = (0010)_2 = 2$.
  • To find the parent or next index to update: i += i & (-i).
  • To find the previous interval for prefix sum: i -= i & (-i).

3 · Complete 15-Line Java Implementation

public class FenwickTree {
    private final int[] tree;

    public FenwickTree(int size) {
        this.tree = new int[size + 1]; // 1-based indexing
    }

    public void add(int i, int delta) {
        for (; i < tree.length; i += i & (-i)) {
            tree[i] += delta;
        }
    }

    public int queryPrefix(int i) {
        int sum = 0;
        for (; i > 0; i -= i & (-i)) {
            sum += tree[i];
        }
        return sum;
    }

    public int queryRange(int l, int r) {
        return queryPrefix(r) - queryPrefix(l - 1);
    }
}
