Content Delivery Networks (CDNs)

Placing content physically close to your global users so images, videos, and APIs load in milliseconds.

↑ Back to Course Index Module D — Caching

1 · The One Idea

Light in fiber optic cables travels at roughly 200,000 km/s. If your origin server is in Virginia (US) and a user is browsing from Sydney (Australia), a network round trip takes a physical minimum of 150–200 milliseconds just for the packets to cross the ocean. A CDN solves this by deploying thousands of Edge Servers (Points of Presence / PoPs) in cities all over the world, caching your static assets right next to the user.

2 · How CDNs Route Traffic: Anycast DNS

How does a user in Tokyo automatically connect to the Tokyo CDN edge while a user in London connects to the London edge? Modern CDNs use Anycast Routing.

  • The exact same IP address (e.g., 1.1.1.1) is advertised by hundreds of CDN servers across the entire world via BGP (Border Gateway Protocol).
  • Internet Service Providers automatically route packets along the shortest physical network path to the nearest geographic node advertising that IP.

3 · Push vs Pull CDN

Type How It Works Best For
Pull CDN (Origin-Pull) The CDN edge starts empty. When a user requests logo.png, the edge pulls it from your origin server, caches it locally for future users, and returns it. Websites with high traffic, blogs, e-commerce catalogues with millions of images. (Most common).
Push CDN Your deployment pipeline explicitly uploads (pushes) new files to the CDN edge storage whenever you release new code or assets. Software release downloads, OS updates, apps with predictable release cycles.

4 · Cache Invalidation: The Hard Problem

What happens when you update your CSS file or product price, but the CDN edge has cached the old file for 24 hours?

  1. URL Fingerprinting / Versioning (Recommended): Instead of styles.css, name the file styles.a8f29c.css. When code changes, the HTML references a brand new URL, causing an immediate instant pull with zero stale cache bugs.
  2. Purge API: Issue an API call to Cloudflare or CloudFront to purge /api/products/*. Can take 1–30 seconds to propagate worldwide.
