HTTP vs HTTPS & Protocol Evolution

How web communication evolved from plain text to encrypted, multiplexed streams.

↑ Back to Course Index Module E — Networking

1 · The One Idea

HTTP (HyperText Transfer Protocol) transmits data in clear, unencrypted plain text. Anyone snooping on your Wi-Fi network (or any router along the path) can read passwords, session cookies, and credit card numbers. HTTPS (HTTP Secure) wraps HTTP inside an encrypted TLS (Transport Layer Security) tunnel, providing three ironclad guarantees: Encryption (nobody can snoop), Integrity (nobody can tamper with data), and Authentication (proves you are connecting to the real server, not an impostor).

2 · The TLS 1.3 Handshake (How HTTPS Works)

Modern HTTPS uses TLS 1.3, which completes encryption setup in just 1 network round-trip (1-RTT):

  1. Client Hello: Browser sends supported cipher suites and its public key share.
  2. Server Hello + Certificate: Server validates, sends its SSL/TLS Certificate (signed by a trusted Certificate Authority), and its public key share.
  3. Shared Secret Generation: Both sides independently derive a shared symmetric encryption key (using Diffie-Hellman Key Exchange) without ever sending the secret key over the wire!
  4. Encrypted HTTP Traffic Begins: All subsequent requests and responses are encrypted using ultra-fast symmetric AES-GCM or ChaCha20.

3 · The Evolution: HTTP/1.1 vs HTTP/2 vs HTTP/3

Version Transport Multiplexing Key Characteristics
HTTP/1.1 (1997) TCP No (1 request per TCP connection at a time) Suffered from Head-of-Line Blocking at application level. Browsers opened 6 parallel TCP connections per domain to work around this.
HTTP/2 (2015) TCP Yes (Binary framing layer) Single TCP connection allows hundreds of concurrent bidirectional request/response streams. Header compression (HPACK). Still suffered from TCP packet-loss blocking.
HTTP/3 (2022) UDP (via QUIC) Yes (Native independent streams) Zero Head-of-Line blocking! Dropping a packet in Stream A has zero impact on Stream B. 0-RTT connection resumption.
