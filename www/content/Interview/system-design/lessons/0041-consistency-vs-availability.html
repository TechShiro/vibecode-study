Consistency vs Availability: Conflict Resolution

How distributed systems merge conflicting writes across the globe without central locks.

↑ Back to Course Index Module K — System Design Trade-offs

1 · The One Idea

In highly available, multi-region systems (like collaborative Google Docs, Amazon shopping carts, or Apple Notes), users must be allowed to write data even while offline on an airplane or disconnected from other regions. When connections resume, multiple replicas will hold conflicting versions of the same document. Conflict Resolution algorithms allow distributed systems to automatically converge on a single, mathematically sound version without human intervention.

2 · Conflict Resolution Strategies

1. Last-Write-Wins (LWW) — Simple but Dangerous

  • Every write attaches a physical wall-clock timestamp (NTP). The replica with the highest timestamp overwrites all others.
  • Major Flaw: Computer clocks drift! Due to hardware clock skew, Server B's clock might be 200ms behind Server A's clock, silently deleting legitimate newer writes (Silent Data Loss).

2. Vector Clocks (Causality Tracking)

  • Instead of physical clocks, each node maintains an array of logical counters: [NodeA: 2, NodeB: 1, NodeC: 4].
  • Allows the database to detect whether Write 2 happened after Write 1 (causally related), or if Write 1 and Write 2 occurred concurrently.
  • If concurrent, the database preserves both versions as siblings and forces the application (or user) to resolve the merge (e.g., Git merge conflicts or Amazon shopping cart items combining).

3. CRDTs (Conflict-free Replicated Data Types) — The Holy Grail

Data structures engineered with mathematical properties (associative, commutative, idempotent) such that any two replicas can merge their state in any order at any time and are guaranteed to reach the exact same state with zero coordination!

  • P-N Counter: Distributed upvote/downvote counter.
  • ORSet (Observed-Remove Set): Distributed shopping cart or tag list.
  • RGA / Yjs / Automerge: Real-time collaborative text editing in Figma and Google Docs.
