Encryption & Cryptography in System Design

Protecting data-at-rest, data-in-transit, and managing encryption keys without human compromise.

1 · The One Idea

In modern systems, security operates under the principle of Zero Trust: assume the perimeter has already been breached. If a hacker steals your raw database backup hard drive or sniffs your cloud network cables, all data must be completely unintelligible gibberish without the cryptographic decryption keys. Security requires protecting data in two states: In-Transit (moving over networks) and At-Rest (stored on disks).

2 · Hashing vs Symmetric vs Asymmetric Encryption

Cryptographic Primitive Directionality Speed Core Use Cases
Cryptographic Hashing
(SHA-256, bcrypt, Argon2)		 One-Way (Irreversible). Cannot decrypt. Fast (SHA) or Intentionally Slow (bcrypt for passwords) User passwords, digital checksums, content addressing (Git).
Symmetric Encryption
(AES-256, ChaCha20)		 Two-Way (Same secret key encrypts and decrypts). Blazing Fast (Hardware accelerated on CPU chips). Database disk encryption, S3 object encryption, bulk data payloads.
Asymmetric Encryption
(RSA, ECC / Curve25519)		 Two-Way (Public key encrypts; Private key decrypts). Slow (Heavy mathematical operations on prime numbers). TLS handshakes, digital signatures, SSH key authentication.

3 · Envelope Encryption (AWS KMS / Vault Pattern)

How do you encrypt a 10 GB database table without sending 10 GB of data over the network to a central Key Management Service (KMS)? Use Envelope Encryption:

  1. Your app asks KMS to generate a new Data Encryption Key (DEK).
  2. KMS returns two copies: a Plaintext DEK and an Encrypted DEK (encrypted by KMS's master Key Encryption Key).
  3. Your application uses the Plaintext DEK to encrypt the 10 GB database table locally in milliseconds using fast AES-256.
  4. Your application deletes the Plaintext DEK from RAM and stores the Encrypted DEK right alongside the encrypted table on disk!
  5. To read the data later, your app asks KMS to decrypt only the tiny 32-byte Encrypted DEK!
