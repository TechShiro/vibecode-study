1 · The One Idea

In low-level compiled languages like C and C++, memory safety is not managed by a garbage collector or bounds checker. Programmers directly allocate raw bytes. When an unsafe function (like strcpy(), gets(), scanf()) writes more data into a fixed-size stack buffer than it can hold, the surplus bytes spill over, overwriting adjacent memory variables, the Saved Base Pointer (EBP), and crucially, the Saved Return Address (EIP/RIP). An attacker controls the Return Address to hijack the CPU's execution flow and execute arbitrary machine code.

3 · Linux Process Memory Layout & Stack Frame Anatomy

A running process in 32-bit/64-bit Linux is structured into distinct segments:

  • Text Segment (.text): Read-only compiled machine code instructions.
  • Data Segment (.data / .bss): Global and static variables.
  • Heap: Dynamically allocated memory (malloc() / free()); grows upward toward high memory.
  • Stack: Local function variables, parameters, and return addresses; grows downward toward low memory.

4 · Crafting the Exploit Payload: Pattern & Offset

  1. Fuzzing: Send increasing lengths of input (100, 200, 500 bytes) until program crashes with Segmentation Fault (SIGSEGV).
  2. Finding Exact Offset: Generate a cyclic De Bruijn pattern using Metasploit tool: msf-pattern_create -l 200.
  3. Inspect the crashed register value in GDB: EIP = 0x35624134.
  4. Determine exact offset: msf-pattern_offset -q 35624134 → Exact match at offset 76.
  5. Payload Structure: [76 bytes padding] + [4 bytes new EIP address] + [NOP Sled:  * 32] + [Shellcode].

5 · Modern Binary Exploit Mitigations

MitigationHow It DefendsAttacker Bypass Technique
NX / DEP (No-Execute) Marks the stack as non-executable. CPU refuses to run shellcode placed in memory buffers. Return-Oriented Programming (ROP): Chaining existing tiny machine code snippets ending in ret ("gadgets") already present in executable libraries.
Stack Canaries Places a secret random integer before the return address. Checked prior to function return; if altered, aborts immediately. Information leak (format string bug) to leak canary value, or brute-forcing canary byte-by-byte on forking daemons.
ASLR Address Space Layout Randomization: Randomizes base addresses of stack, heap, and shared libraries (libc) on every execution. Memory disclosure leak to calculate base address offset.
