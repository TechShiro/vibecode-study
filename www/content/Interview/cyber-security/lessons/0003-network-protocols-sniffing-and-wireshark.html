1 · The One Idea

Every digital conversation—from browsing a webpage to an attacker exfiltrating credit card numbers—is broken down into discrete binary packets transmitted across copper wire, optical fiber, or radio waves. A network interface card (NIC) normally ignores packets not addressed to its MAC address. By switching the NIC into Promiscuous Mode and executing ARP Poisoning, an attacker or forensic investigator intercepts and inspects every byte traversing the local network using tools like Wireshark and Tcpdump.

3 · ARP Poisoning: Man-in-the-Middle (MITM)

The Address Resolution Protocol (ARP) maps Layer 3 IP addresses to Layer 2 MAC addresses. ARP is completely stateless and has zero authentication:

Victim (192.168.1.10)
Attacker: "I have IP 192.168.1.1 (Gateway)!"
Router Gateway (192.168.1.1)

By blasting unsolicited Gratuitous ARP replies, an attacker tricks the Victim into sending all outbound internet traffic to the Attacker's MAC address, and tricks the Gateway into sending inbound traffic to the Attacker. All traffic is intercepted before being forwarded.

4 · Essential Wireshark Display Filters

Filter SyntaxWhat It FiltersInvestigative Use Case

tcp.flags.syn == 1 && tcp.flags.ack == 0Initial SYN packets.Detects incoming TCP port scans or SYN flood DDoS attacks.
http.request.method == "POST"All HTTP POST requests.Uncovers unencrypted login forms and submitted credentials.
dns.flags.response == 0Outbound DNS queries.Detects malware beaconing to Command & Control (C2) domains or DNS tunneling data exfiltration.
tcp.analysis.retransmissionRetransmitted TCP segments.Indicates network congestion, packet drops, or active RST attacks.

5 · Command-Line Forensics: Tcpdump

# 1. Capture 100 packets on interface eth0 and write to file
sudo tcpdump -i eth0 -c 100 -w capture.pcap

# 2. Sniff plain-text HTTP traffic on port 80 showing ASCII payloads
sudo tcpdump -i eth0 -A -s 0 'tcp port 80 and (((ip[2:2] - ((ip[0]&0xf)<<2)) - ((tcp[12:1] & 0xf0)>>2)) != 0)'

# 3. Filter specific IP and capture credentials
sudo tcpdump -i eth0 host 192.168.1.10 and port 21 -X
