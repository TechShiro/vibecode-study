Reconnaissance, OSINT & Network Scanning with Nmap

Information gathering methodologies: passive intelligence, Shodan, DNS enumeration, and active port scanning with Nmap.

← Back to Course IndexModule A – Foundations & Reconnaissance

1 · The One Idea

In penetration testing and ethical hacking, Reconnaissance (Information Gathering) takes up 70% of an assessment. Before launching an exploit, an engineer must map out the target's entire digital footprint: IP blocks, subdomains, open ports, operating systems, running service versions, and exposed misconfigurations. Recon is split into Passive Recon (OSINT) (gathering publicly available intelligence without touching target servers) and Active Recon (directly sending packets to target machines, e.g. with Nmap).

2 · Passive Reconnaissance & OSINT Tools

1

WHOIS & DNS Enumeration

Queries registrar databases for domain owner contact, name servers, and IP allocations. Tools like sublist3r, amass, and dig uncover hidden subdomains (e.g. dev.target.com, staging-api.target.com).

2

Shodan & Censys

Search engines for internet-connected devices. Continuously scans the entire IPv4 address space, indexing exposed industrial control systems, open cameras, database ports (MongoDB 27017, Redis 6379), and unpatched servers without sending a single packet yourself.

3

Google Dorking

Advanced search operators that unearth unintentionally exposed sensitive files: filetype:env "DB_PASSWORD" or site:target.com inurl:admin.

3 · Active Scanning: Nmap (Network Mapper)

Nmap is the definitive tool for network inventory, port scanning, and vulnerability detection. It operates by crafting custom raw IP packets and analyzing the response flags.

Scan TypeNmap FlagHow It WorksPros & Cons
TCP SYN Stealth Scan -sS Sends SYN. If target responds SYN-ACK, port is OPEN. Nmap immediately sends RST to tear down connection without completing 3-way handshake. Default & Most Popular. Faster; historically evaded basic connection logging. Requires root/admin privileges.
TCP Connect Scan -sT Completes the full 3-way handshake (SYN → SYN-ACK → ACK) using OS connect() syscall. Works without root privileges. Noisier; logged by application servers.
UDP Scan -sU Sends empty UDP packets. If ICMP Port Unreachable received → CLOSED. If no response → OPEN | FILTERED. Much slower due to OS ICMP rate limiting, but vital for finding DNS (53), SNMP (161), DHCP (67).
Service Version Detection -sV Connects to open ports and probes them to determine exact software and version (e.g. Apache 2.4.49). Crucial for matching known CVE vulnerability databases.
OS Detection -O Sends TCP/UDP probes and compares TCP window size, TTL, and DF bits against Nmap's OS fingerprint database. Pinpoints whether target runs Linux, Windows Server, Cisco IOS, etc.

4 · Practical Nmap Recipes for Pen-Testers

# 1. Fast Full-Port Stealth Scan with Service Versions and Default Scripts
sudo nmap -sS -sV -sC -p- -T4 --min-rate 1000 192.168.1.50 -oA initial_scan

# Flags explained:
# -sS : TCP SYN Stealth Scan
# -sV : Probe open ports for service version information
# -sC : Run default Nmap Scripting Engine (NSE) safe scripts
# -p- : Scan ALL 65,535 TCP ports (not just top 1,000)
# -T4 : Aggressive timing template for faster completion
# -oA : Output results in 3 formats (normal, XML, grepable)

# 2. Automated Vulnerability Scanning using NSE
sudo nmap -sV --script vuln 192.168.1.50

# 3. Banner Grabbing via Netcat
nc -nv 192.168.1.50 22
# Output: SSH-2.0-OpenSSH_8.2p1 Ubuntu-4ubuntu0.5
