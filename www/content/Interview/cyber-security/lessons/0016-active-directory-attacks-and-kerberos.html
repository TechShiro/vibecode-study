1 · The One Idea

Over 90% of Fortune 500 corporations run on Microsoft Active Directory (AD) to manage users, computers, permissions, and single sign-on across the enterprise. In enterprise penetration testing, compromising a single workstation is just the beginning. The ultimate prize is compromising the Domain Controller (DC) to attain Domain Admin control over every computer and email account in the organization.

2 · The Kerberos Authentication Protocol

Client requests TGT (AS-REQ)
KDC issues Ticket Granting Ticket (TGT)
Client requests Service Ticket (TGS-REQ)
KDC issues TGS encrypted with Service Account Hash

3 · Famous Active Directory Attacks

Attack NameMechanismWhy It Works
Kerberoasting Any authenticated domain user requests a TGS service ticket for an account with a Service Principal Name (SPN) (e.g. MSSQL service). The returned TGS is encrypted with the service account's NTLM password hash. Attacker extracts the ticket from memory and cracks the plaintext password offline using Hashcat with zero detection on the DC!
AS-REP Roasting Targets accounts with "Do not require Kerberos pre-authentication" enabled. Attacker requests an AS-REP ticket without sending user credentials. KDC returns encrypted ticket, which is cracked offline.
Pass-the-Hash (PtH) NTLM authentication uses the raw password hash directly without needing plaintext. If an attacker dumps local LSASS memory and grabs a Domain Admin's NTLM hash, they authenticate directly across the network!
Golden Ticket Attacker compromises the krbtgt account hash on the Domain Controller. The attacker can now forge valid TGT tickets for ANY user, inject arbitrary Group SIDs (Domain Admin), and grant themselves permanent undetectable access.

4 · Attack Path Mapping with BloodHound

Active Directory contains convoluted permission graphs (nested security groups, GPOs, local admin rights). BloodHound uses graph theory (Neo4j database) to uncover non-obvious attack paths (e.g. User A ∈ Helpdesk → Can Reset Password of User B → User B is Admin on FileServer → FileServer has Domain Admin Session in Memory → Domain Admin Compromised).
