Convolutional Neural Networks & ResNets

Why MLPs fail on pixels, spatial convolutions, pooling, and how ResNet skip connections conquered deep gradient vanishing.

1 · The One Idea

Feeding a high-resolution image (e.g. 1000 × 1000 pixels with 3 RGB channels = 3,000,000 values) into a standard Fully Connected MLP causes two fatal problems: parameter explosion (billions of weights for a single layer) and loss of 2D spatial locality (flattening pixels destroys local edge and shape relationships). Convolutional Neural Networks (CNNs) solve this via parameter sharing and local receptive fields using small learnable filters (e.g. 3 × 3 matrices) that slide across the image.

2 · Anatomy of a Convolutional Layer

Input Image (C, H, W)
Conv2D (Filter Kernel)
ReLU Activation
MaxPool (Downsampling)
  • Kernel / Filter: Small matrix (typically 3×3) that slides over inputs computing dot products. Learns low-level edge detectors in early layers, and semantic objects in deep layers.
  • Stride: Number of pixels the filter shifts per step (stride 1 = dense scan; stride 2 = halving spatial dimensions).
  • Padding: Adding border zeros around inputs. "Same" padding preserves input spatial dimensions (H_out = H_in).
  • Pooling (MaxPool2d): Takes maximum value in a 2×2 window, providing translation invariance and reducing memory footprint.

3 · The ResNet Breakthrough: Skip Connections

Why Deep Networks Failed Before ResNet (2015)

Before Kaiming He et al. introduced Residual Networks, stacking more than 20 layers caused training accuracy to degrade rapidly. Deep backpropagation suffered from vanishing gradients: multiplying 30 small numbers together drives gradients to absolute zero.

The Residual Block Solution: Instead of learning a direct mapping H(x), the network learns the residual F(x) = H(x) - x, and outputs H(x) = F(x) + x via a Skip Connection (Identity Shortcut).

Calculus proof: ∂H/∂x = ∂F/∂x + 1. The "+ 1" term guarantees that gradients can flow straight backward through hundreds of layers without vanishing!

4 · Complete Custom ResNet Block Implementation in PyTorch

import torch
import torch.nn as nn

class ResidualBlock(nn.Module):
    def __init__(self, in_channels, out_channels, stride=1):
        super(ResidualBlock, self).__init__()
        self.conv1 = nn.Conv2d(in_channels, out_channels, kernel_size=3, 
                               stride=stride, padding=1, bias=False)
        self.bn1 = nn.BatchNorm2d(out_channels)
        self.relu = nn.ReLU(inplace=True)
        self.conv2 = nn.Conv2d(out_channels, out_channels, kernel_size=3, 
                               stride=1, padding=1, bias=False)
        self.bn2 = nn.BatchNorm2d(out_channels)

        # Shortcut connection for matching dimensions if stride > 1
        self.shortcut = nn.Sequential()
        if stride != 1 or in_channels != out_channels:
            self.shortcut = nn.Sequential(
                nn.Conv2d(in_channels, out_channels, kernel_size=1, stride=stride, bias=False),
                nn.BatchNorm2d(out_channels)
            )

    def forward(self, x):
        residual = self.shortcut(x)
        out = self.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        out += residual  # The magic skip connection!
        return self.relu(out)
