1 · The One Idea

While NumPy is perfect for mathematical intuition on CPU, deep learning requires GPU acceleration (thousands of CUDA cores) and Automatic Differentiation (Autograd). PyTorch is the industry-standard deep learning framework. Its core superpower is the Dynamic Computation Graph (Define-by-Run): every operation on a tensor with requires_grad=True dynamically builds a directed acyclic graph (DAG) in memory, allowing loss.backward() to compute exact gradients automatically without manual calculus derivations.

2 · Tensor Foundations & CUDA Acceleration

import torch
import torch.nn as nn
import torch.optim as optim

# 1. Device Agnostic Setup
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
print(f"Using compute device: {device}")

# 2. Tensor Creation & Gradient Tracking
x = torch.tensor([2.0, 3.0], requires_grad=True, device=device)
y = x ** 2 + 3 * x + 5  # y = x^2 + 3x + 5
loss = y.sum()

# 3. Autograd Backward Pass
loss.backward()
print(f"Gradients dy/dx: {x.grad}")  # dy/dx = 2x + 3 -> [7.0, 9.0]

3 · Building Custom Models with nn.Module

Every neural network in PyTorch inherits from nn.Module and implements two methods:

  • __init__(): Instantiates parameterized layers (weights and biases).
  • forward(x): Defines how input tensors pass through the layers.
class DeepMLP(nn.Module):
    def __init__(self, in_features, hidden_dim, num_classes, dropout_rate=0.2):
        super(DeepMLP, self).__init__()
        self.net = nn.Sequential(
            nn.Linear(in_features, hidden_dim),
            nn.BatchNorm1d(hidden_dim),
            nn.ReLU(),
            nn.Dropout(dropout_rate),
            nn.Linear(hidden_dim, hidden_dim // 2),
            nn.ReLU(),
            nn.Linear(hidden_dim // 2, num_classes)
            # Note: No Softmax here! CrossEntropyLoss applies it internally with log-sum-exp
        )

    def forward(self, x):
        return self.net(x)

4 · The Canonical PyTorch Training & Validation Loop

The 5 Mandatory Steps of Every PyTorch Epoch

  1. optimizer.zero_grad(): Clears old gradients from previous iterations (PyTorch accumulates gradients by default!).
  2. outputs = model(inputs): Forward pass computing predictions.
  3. loss = criterion(outputs, targets): Computes scalar discrepancy.
  4. loss.backward(): Backpropagates gradients through computation graph.
  5. optimizer.step(): Adjusts model weights using calculated gradients.
def train_one_epoch(model, dataloader, criterion, optimizer, device):
    model.train()  # Activates Dropout & BatchNorm training behavior
    running_loss = 0.0
    correct = 0
    total = 0

    for inputs, targets in dataloader:
        inputs, targets = inputs.to(device), targets.to(device)

        optimizer.zero_grad()
        outputs = model(inputs)
        loss = criterion(outputs, targets)
        loss.backward()
        optimizer.step()

        running_loss += loss.item() * inputs.size(0)
        _, predicted = outputs.max(1)
        total += targets.size(0)
        correct += predicted.eq(targets).sum().item()

    epoch_loss = running_loss / total
    epoch_acc = correct / total
    return epoch_loss, epoch_acc

@torch.no_grad()  # Disables gradient tracking to save massive VRAM
def validate(model, dataloader, criterion, device):
    model.eval()  # Freezes BatchNorm running stats and disables Dropout
    running_loss = 0.0
    correct = 0
    total = 0

    for inputs, targets in dataloader:
        inputs, targets = inputs.to(device), targets.to(device)
        outputs = model(inputs)
        loss = criterion(outputs, targets)

        running_loss += loss.item() * inputs.size(0)
        _, predicted = outputs.max(1)
        total += targets.size(0)
        correct += predicted.eq(targets).sum().item()

    return running_loss / total, correct / total
