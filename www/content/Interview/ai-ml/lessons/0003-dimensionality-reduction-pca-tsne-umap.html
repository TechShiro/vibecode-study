Compressing hundreds of noisy features into informative orthogonal components without catastrophic information loss.

1 · The One Idea

In modern machine learning, datasets often contain hundreds or thousands of features (e.g. genomic sequences, image pixels, text embeddings). This triggers the Curse of Dimensionality: high-dimensional space is overwhelmingly empty, distances between points become uniformly equidistant, and models overfit exponentially. Dimensionality Reduction projects high-dimensional data into a lower-dimensional subspace while preserving the most vital variance and geometric manifold structure.

3 · Principal Component Analysis (PCA) Mechanics

PCA is an unsupervised, linear technique that finds orthogonal axes (Principal Components) that maximize data variance:

  1. Standardize the dataset (mean = 0, variance = 1).
  2. Compute the Covariance Matrix: Σ = (1/N) XTX.
  3. Perform Eigenvalue Decomposition: Σv = λv (or Singular Value Decomposition SVD on X).
  4. Sort eigenvectors by their corresponding eigenvalues (λ) in descending order.
  5. Select the top k eigenvectors to form projection matrix W.
  6. Transform data: X_reduced = X @ W.

4 · PCA Implementation from Scratch in NumPy

import numpy as np

def pca_from_scratch(X, n_components=2):
    # Step 1: Center the data (mean = 0)
    X_centered = X - np.mean(X, axis=0)
    
    # Step 2: Compute Covariance Matrix
    cov_matrix = np.cov(X_centered, rowvar=False)
    
    # Step 3: Compute Eigenvalues & Eigenvectors
    eigenvalues, eigenvectors = np.linalg.eigh(cov_matrix)
    
    # Step 4: Sort in descending order
    sorted_idx = np.argsort(eigenvalues)[::-1]
    top_eigenvectors = eigenvectors[:, sorted_idx[:n_components]]
    
    # Step 5: Project data onto top k components
    X_projected = np.dot(X_centered, top_eigenvectors)
    
    explained_variance_ratio = eigenvalues[sorted_idx[:n_components]] / np.sum(eigenvalues)
    return X_projected, explained_variance_ratio

5 · PCA vs t-SNE vs UMAP

AlgorithmTypeGlobal vs Local StructurePrimary Use Case
PCA Linear Preserves Global Variance; fast $O(D^3)$ or $O(N D^2)$. Feature compression, removing multicollinearity before regression/SVM.
t-SNE Non-linear (Probabilistic) Preserves Local Neighborhoods; slow $O(N^2)$. Pure 2D/3D visual cluster exploration (e.g. MNIST clusters). Cannot transform new unseen test data.
UMAP Non-linear (Riemannian Geometry) Preserves both Local & Global Structure; fast $O(N \log N)$. Large-scale visualization, single-cell genomics, document clustering. Supports transform() on new test points.
