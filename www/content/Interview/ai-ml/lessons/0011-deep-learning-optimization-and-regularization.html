Deep Learning Optimization & Regularization

AdamW, learning rate schedules, BatchNorm vs LayerNorm, and fighting the battle against overfitting.

← Back to Course IndexModule C – Deep Learning Foundations

1 · The One Idea

Vanilla Stochastic Gradient Descent (SGD) struggles with saddle points, noisy gradients, and ravine-like loss surfaces. Modern deep learning relies on Adaptive Optimizers (Adam, AdamW) that maintain per-parameter learning rates using exponential moving averages of first (momentum) and second (variance) moments. Concurrently, deep networks have millions of parameters capable of memorizing noise; Regularization techniques (Dropout, LayerNorm, Weight Decay) ensure networks generalize to unseen real-world data.

2 · Evolution of Optimizers

OptimizerCore MechanismAdvantage & Industry Verdict
SGD with Momentum v = βv + α∇L; acts like a heavy ball rolling downhill. Dampens oscillations across ravines; great asymptotic generalization for Vision.
RMSprop Divides gradient by running root-mean-square of recent gradients: √(v + ε). Adapts learning rate per parameter; stabilizes training in RNNs.
Adam Combines Momentum (1st moment) + RMSprop (2nd moment) with bias correction. Fast initial convergence; robust default across diverse architectures.
AdamW Decouples Weight Decay from gradient updates (L2 regularization bugfix in Adam). The universal default for Transformers, LLMs, and modern vision models.

3 · Normalization: BatchNorm vs LayerNorm

BN

Batch Normalization (BatchNorm)

Normalizes activations across the mini-batch dimension for each individual channel independently. Highly effective in Convolutional Neural Networks. Fails when batch size is small (< 8) or in sequential data with variable lengths.

LN

Layer Normalization (LayerNorm)

Normalizes across all features/channels for a single training example independently. Independent of batch size. The undisputed standard for NLP, Transformers, and Large Language Models.

4 · Overfitting Defenses in Deep Networks

  • Dropout: Randomly zeroes out a fraction (e.g. 20%–50%) of neuron activations during training. Prevents complex co-adaptations between neurons, forcing the network to learn robust redundant features.
  • Weight Decay: Penalizes large weights, preventing individual inputs from exerting disproportionate influence.
  • Gradient Clipping (clip_grad_norm_): Caps gradient norms at a maximum threshold (e.g. 1.0) to prevent Exploding Gradients from destabilizing training.
  • Learning Rate Warmup & Cosine Annealing: Linearly ramps learning rate up during the first few epochs (preventing divergence), then smoothly anneals down following a cosine curve.

5 · Complete PyTorch Setup

import torch
import torch.nn as nn
import torch.optim as optim
from torch.optim.lr_scheduler import CosineAnnealingLR

model = MyDeepModel()

# 1. AdamW with decoupled weight decay
optimizer = optim.AdamW(model.parameters(), lr=1e-3, weight_decay=1e-2)

# 2. Cosine Annealing Scheduler with 50 epochs
scheduler = CosineAnnealingLR(optimizer, T_max=50, eta_min=1e-6)

# Inside training loop:
for epoch in range(50):
    for inputs, targets in train_loader:
        optimizer.zero_grad()
        loss = criterion(model(inputs), targets)
        loss.backward()
        
        # Gradient clipping prevents exploding gradients
        torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
        
        optimizer.step()
        
    scheduler.step()  # Updates learning rate per epoch
