1 · The One Idea

In Unsupervised Learning, there are no target labels y. The model must autonomously discover natural structure, clusters, and boundaries within feature space. Use cases include customer market segmentation, recommendation engines, fraud anomaly detection, and detecting cyber intrusion attacks.

2 · K-Means Clustering & Lloyd's Algorithm

K-Means partitions N observations into K clusters such that each observation belongs to the cluster with the nearest centroid (minimizing within-cluster sum of squares inertia):

  1. Initialization: Pick K initial centroids. (K-Means++ selects centroids probabilistically far apart, avoiding poor local minima).
  2. Assignment Step: Assign each data point to its closest centroid using Euclidean distance.
  3. Update Step: Recalculate centroids as the mathematical mean of all points assigned to that cluster.
  4. Repeat steps 2 & 3 until centroids stabilize (convergence).

4 · Production Anomaly Detection: Isolation Forests

How do you catch zero-day cyber attacks or credit card fraud when anomalous examples make up less than 0.01% of traffic? Isolation Forests isolate anomalies instead of profiling normal points:

  • Anomalies are "few and different"—they exist in sparse regions of feature space.
  • When building random binary decision trees, an anomaly requires significantly fewer random splits to isolate into a leaf node than a normal point nestled inside a dense cluster.
  • Anomaly Score: Points with short average path lengths across random trees are flagged as anomalies.
from sklearn.ensemble import IsolationForest
import numpy as np

# Generate normal data + 5 synthetic anomalies
np.random.seed(42)
X_normal = 0.3 * np.random.randn(1000, 2)
X_outliers = np.random.uniform(low=-4, high=4, size=(20, 2))
X = np.vstack([X_normal, X_outliers])

# Train Isolation Forest
iso_forest = IsolationForest(contamination=0.02, random_state=42)
predictions = iso_forest.fit_predict(X)

# 1 = Inlier (Normal), -1 = Anomaly
n_anomalies = np.sum(predictions == -1)
print(f"Detected Anomalies: {n_anomalies} out of {len(X)} records.")
