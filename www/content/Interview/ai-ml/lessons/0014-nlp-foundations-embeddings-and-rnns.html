1 · The One Idea

Computers do not read words; they process numbers. The oldest approach (One-Hot Encoding: "cat" = [1, 0, 0, ...], "dog" = [0, 1, 0, ...]) failed catastrophically: the dot product between every pair of words was zero, meaning the computer had no notion that a cat is closer to a dog than to a submarine. Dense Semantic Embeddings map words into continuous geometric vector spaces where semantic similarity corresponds to geometric distance: Vector("King") - Vector("Man") + Vector("Woman") ≈ Vector("Queen").

2 · Subword Tokenization: Byte-Pair Encoding (BPE)

Modern LLMs (GPT-4, Llama) do not tokenize by whole words (which creates infinite vocabulary sizes and breaks on typos). They use Byte-Pair Encoding (BPE):

  1. Start with all individual characters/bytes as base vocabulary.
  2. Iteratively count the most frequently co-occurring adjacent pairs of tokens in the corpus.
  3. Merge that pair into a single new token. Repeat until reaching target vocabulary size (e.g. 32,000 to 128,000 tokens).
  4. Result: Common words ("the") are single tokens, while rare or misspelled words ("unconstitutionally") decompose into subwords (["un", "constitut", "ion", "ally"]). Zero out-of-vocabulary errors!

3 · Recurrent Neural Networks (RNN) & The Hidden State

Text is sequential: the meaning of word t depends on preceding words. A Recurrent Neural Network processes tokens sequentially, passing an internal memory vector called the Hidden State (ht) forward across time steps:

ht = tanh(Whh ht-1 + Wxh xt + b)

The Vanishing Gradient Bottleneck of Vanilla RNNs

Backpropagating errors through 100 time steps requires repeatedly multiplying by weight matrix Whh. If eigenvalues of W are < 1, gradients decay exponentially to 0 (cannot remember context from 20 words ago). If > 1, gradients explode.

4 · LSTMs & GRUs: The Gated Highway

Hochreiter & Schmidhuber (1997) solved vanishing gradients in sequences via the Long Short-Term Memory (LSTM) network. An LSTM introduces a separate constant error carousel called the Cell State (Ct) regulated by three neural gates:

ft

Forget Gate

ft = σ(Wf·[ht-1, xt] + bf)
Decides what percentage of old information to discard from the cell state (0 = completely forget, 1 = preserve).

it

Input Gate

it = σ(Wi·[ht-1, xt] + bi)
Decides which new values to write into the cell state.

ot

Output Gate

ot = σ(Wo·[ht-1, xt] + bo)
Filters the cell state through tanh to emit the new hidden state ht.

5 · PyTorch Sequential LSTM Implementation

import torch
import torch.nn as nn

class SentimentLSTM(nn.Module):
    def __init__(self, vocab_size, embed_dim, hidden_dim, output_dim, n_layers=2):
        super(SentimentLSTM, self).__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim, padding_idx=0)
        self.lstm = nn.LSTM(embed_dim, hidden_dim, num_layers=n_layers, 
                            batch_first=True, dropout=0.2, bidirectional=True)
        # Bidirectional outputs 2 * hidden_dim
        self.fc = nn.Linear(hidden_dim * 2, output_dim)

    def forward(self, text_tokens):
        # text_tokens shape: (batch_size, seq_len)
        embedded = self.embedding(text_tokens)
        
        # out: (batch, seq_len, 2*hidden_dim), (hidden, cell)
        lstm_out, (hidden, cell) = self.lstm(embedded)
        
        # Concatenate forward and backward final hidden states
        final_hidden = torch.cat((hidden[-2,:,:], hidden[-1,:,:]), dim=1)
        return self.fc(final_hidden)
