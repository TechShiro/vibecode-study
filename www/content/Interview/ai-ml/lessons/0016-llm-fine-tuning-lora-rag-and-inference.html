1 · The One Idea

Pre-training a base Large Language Model from scratch requires hundreds of millions of dollars and thousands of H100 GPUs. In practical engineering, developers take existing open-weight models (Llama 3, Mistral) and customize them via two dominant paradigms: Fine-Tuning with LoRA/QLoRA (teaching the model new styles, instruction formats, or task behaviors) and Retrieval-Augmented Generation (RAG) (grounding the model with private corporate documents without changing weights).

2 · Parameter-Efficient Fine-Tuning: LoRA & QLoRA

Full fine-tuning of a 70B parameter model requires over 1.2 Terabytes of VRAM to store optimizer states (Adam stores 8 bytes per parameter!). Low-Rank Adaptation (LoRA) freezes the original weight matrix W0 ∈ Rd×k and injects two low-rank trainable decomposition matrices B ∈ Rd×r and A ∈ Rr×k where rank r ≪ d (e.g. r = 16):

The LoRA Invariant

W = W0 + ΔW = W0 + (B × A) × (α / r)

  • Reduces trainable parameters by 99.9% (from 7 billion to a few megabytes!).
  • QLoRA (Dettmers et al.): Quantizes the frozen base model to 4-bit NormalFloat (NF4) while keeping LoRA adapters in 16-bit. Allows fine-tuning a 70B LLM on two consumer GPUs!

4 · KV Caching: Accelerating Autoregressive Generation

When an LLM generates text token-by-token, naively recomputing Keys and Values for all past tokens at every step results in $O(N^2)$ redundant matrix multiplications. KV Caching stores previously computed Key and Value tensors in GPU VRAM, so each new token only computes a single new vector. Production inference engines like vLLM implement PagedAttention to manage fragmented KV cache memory like OS virtual memory paging.

5 · Practical PEFT / LoRA Code with Hugging Face

from transformers import AutoModelForCausalLM, AutoTokenizer, TrainingArguments, Trainer
from peft import LoraConfig, get_peft_model, TaskType

# 1. Load Base Model and Tokenizer
model_id = "mistralai/Mistral-7B-v0.1"
tokenizer = AutoTokenizer.from_pretrained(model_id)

# 2. Configure Low-Rank Adaptation (LoRA)
lora_config = LoraConfig(
    r=16,                           # Low rank dimension
    lora_alpha=32,                  # Scaling factor
    target_modules=["q_proj", "v_proj"], # Target attention layers
    lora_dropout=0.05,
    bias="none",
    task_type=TaskType.CAUSAL_LM
)

# 3. Wrap Model with Trainable Adapters
base_model = AutoModelForCausalLM.from_pretrained(model_id, torch_dtype=torch.float16, device_map="auto")
model = get_peft_model(base_model, lora_config)
model.print_trainable_parameters()
# Output: trainable params: 6.8M || all params: 7.2B || trainable%: 0.094%
