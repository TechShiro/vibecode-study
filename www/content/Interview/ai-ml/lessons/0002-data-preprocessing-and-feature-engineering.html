Data Preprocessing & Feature Engineering

Turning noisy raw tables into clean, scaled mathematical representations without catastrophic data leakage.

1 · The One Idea

In industry, 80% of machine learning success comes from data preparation and feature engineering, not tuning hyperparameter knobs. Garbage in, garbage out: feeding unscaled features, unencoded categorical strings, or missing values into an algorithm guarantees failure. More dangerously, Data Leakage (accidentally letting test information contaminate training transforms) creates models that score 99% in local validation but crash completely in live production.

2 · The Core Preprocessing Pipeline

StepProblem SolvedIndustry Best Practice / Technique
Missing Values Linear models and Neural Nets crash on NaN. Median for skewed numeric; Mode for categories; KNN / Iterative Imputer for correlated features.
Categorical Encoding Algorithms only compute on numbers, not strings. One-Hot Encoding for nominal (low cardinality ≤ 10); Target / Frequency Encoding for high cardinality; Ordinal for ranked data.
Feature Scaling Variables with large magnitude (Salary $100,000) dominate small ones (Age 25). StandardScaler (μ=0, σ=1) for Gaussian/linear models; MinMaxScaler ([0, 1]) for image pixels and neural nets; RobustScaler when outliers exist.
Class Imbalance Fraud detection: 99.9% legit, 0.1% fraud. Naive model predicting all legit achieves 99.9% accuracy! SMOTE (Synthetic Minority Over-sampling), Random Under-sampling, or class-weighted loss functions (class_weight='balanced').

3 · Data Leakage: The Silent Model Killer

The Golden Rule of ML Splits

NEVER fit a scaler, imputer, or encoder on the full dataset before splitting! If you compute scaler.fit(X) across all data, the test set's mean and variance leak into the training process.

Correct Protocol:

  1. Split raw data into X_train and X_test first.
  2. Fit transforms ONLY on X_train: scaler.fit(X_train).
  3. Apply fitted parameters to both: scaler.transform(X_train) and scaler.transform(X_test).

4 · Production Scikit-Learn Pipeline Implementation

Using Pipeline and ColumnTransformer guarantees leak-free training and deployment reproducibility:

import pandas as pd
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.compose import ColumnTransformer
from sklearn.pipeline import Pipeline
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.ensemble import RandomForestClassifier

# 1. Sample Realistic Data
data = pd.DataFrame({
    'age': [25, 45, np.nan, 35, 52, 23],
    'income': [50000, 120000, 85000, np.nan, 140000, 48000],
    'city': ['NYC', 'London', 'Paris', 'NYC', 'London', 'Tokyo'],
    'purchased': [0, 1, 1, 0, 1, 0]
})

X = data.drop(columns=['purchased'])
y = data['purchased']

# 2. Strict Train/Test Split (Stratified to maintain class ratio)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.33, random_state=42
)

# 3. Define Pipeline Transformers by Feature Type
numeric_cols = ['age', 'income']
categorical_cols = ['city']

numeric_transformer = Pipeline(steps=[
    ('imputer', SimpleImputer(strategy='median')),
    ('scaler', StandardScaler())
])

categorical_transformer = Pipeline(steps=[
    ('imputer', SimpleImputer(strategy='constant', fill_value='missing')),
    ('encoder', OneHotEncoder(handle_unknown='ignore', sparse_output=False))
])

preprocessor = ColumnTransformer(transformers=[
    ('num', numeric_transformer, numeric_cols),
    ('cat', categorical_transformer, categorical_cols)
])

# 4. Assemble Full Leak-Free Pipeline
model_pipeline = Pipeline(steps=[
    ('preprocessor', preprocessor),
    ('classifier', RandomForestClassifier(n_estimators=100, random_state=42))
])

# 5. Fit strictly on train, evaluate on test
model_pipeline.fit(X_train, y_train)
test_accuracy = model_pipeline.score(X_test, y_test)
print(f"Test Accuracy: {test_accuracy:.2f}")
