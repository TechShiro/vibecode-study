1 · The One Idea

Every Machine Learning model—from simple linear regression to a 405-billion parameter Large Language Model—is fundamentally a mathematical function. Data (images, audio, text) is represented as multidimensional arrays of numbers (Tensors). Training a model means using Calculus (gradients) to adjust Linear Algebra weights until a Probability distribution over outcomes is optimized. Without mathematical intuition, ML feels like magic; with it, ML becomes pure engineering optimization.

2 · Core Mathematical Pillars

1

Linear Algebra

Scalars (0D), Vectors (1D: magnitude & direction), Matrices (2D: linear maps), and Tensors (N-D). Key operation: Matrix Multiplication (C = A @ B where (m, k) @ (k, n) → (m, n)) and Dot Product measuring geometric alignment.

2

Multivariable Calculus

Partial Derivatives (∂f/∂x) calculate the rate of change along one variable. The Gradient Vector (∇f) points in the direction of steepest ascent. Gradients guide optimization by stepping in the opposite direction (steepest descent).

3

Probability & Statistics

Expectation (μ) and Variance (σ2). Bayes' Theorem (P(A|B) = P(B|A)P(A) / P(B)). Maximum Likelihood Estimation (MLE) finds parameter weights that maximize the likelihood of observing the training data.

3 · NumPy Vectorization vs Python For-Loops

In Python, iterating over 1,000,000 elements with a for loop incurs interpreter overhead and dynamic type checking. NumPy executes operations in compiled C using SIMD (Single Instruction Multiple Data) CPU registers. Vectorization is 50x–100x faster.

import numpy as np
import time

# Create two arrays of 1,000,000 floats
a = np.random.randn(1_000_000)
b = np.random.randn(1_000_000)

# 1. Slow Python Loop
start = time.time()
dot_loop = 0.0
for i in range(len(a)):
    dot_loop += a[i] * b[i]
loop_time = time.time() - start

# 2. Fast Vectorized NumPy Dot Product
start = time.time()
dot_vec = np.dot(a, b)  # or a @ b
vec_time = time.time() - start

print(f"Loop time: {loop_time:.4f}s | Vectorized time: {vec_time:.6f}s")
# Result: Vectorized is ~80x faster!

4 · NumPy Broadcasting Rules

Broadcasting allows NumPy to perform arithmetic operations on arrays of different shapes without copying data in memory:

  1. Compare array shapes element-wise, starting from the trailing (rightmost) dimensions.
  2. Two dimensions are compatible if:
    • They are equal, OR
    • One of them is 1 (which is automatically stretched along that axis).
# Shape (3, 4) + Shape (4,) -> Valid! (4 matches 4, stretches across 3 rows)
A = np.ones((3, 4))
b = np.array([10, 20, 30, 40])
result = A + b  # Adds row b to each of the 3 rows in A

5 · Implementing Core Math Functions from Scratch

# 1. Numerical Gradient Computation (Finite Differences)
def numerical_gradient(f, x, h=1e-5):
    grad = np.zeros_like(x)
    for i in range(x.size):
        idx = np.unravel_index(i, x.shape)
        old_val = x[idx]
        
        x[idx] = old_val + h
        fx_plus = f(x)
        
        x[idx] = old_val - h
        fx_minus = f(x)
        
        grad[idx] = (fx_plus - fx_minus) / (2 * h)
        x[idx] = old_val  # restore
    return grad

# 2. Softmax with Numerical Stability (subtracting max to prevent overflow)
def stable_softmax(z):
    shift_z = z - np.max(z, axis=-1, keepdims=True)
    exps = np.exp(shift_z)
    return exps / np.sum(exps, axis=-1, keepdims=True)
