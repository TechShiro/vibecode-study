Linear Regression & Gradient Descent

The fundamental supervised learning algorithm: analytical closed-form Normal Equations vs iterative numerical optimization.

← Back to Course IndexModule B – Classical Machine Learning

1 · The One Idea

Linear Regression models the relationship between independent input features X and a continuous target variable y as a linear equation: y_pred = Xw + b. To find the optimal weights w and bias b, we minimize the Mean Squared Error (MSE) cost function. We can solve this either mathematically in one shot via the Normal Equation, or iteratively step-by-step using Gradient Descent (which scales to billions of records).

2 · Mathematical Formulation

Given N training examples with D features:

  • Hypothesis: ŷ = w1x1 + w2x2 + ... + wDxD + b = Xw (with bias absorbed into X).
  • Cost Function (MSE / L2 Loss):
    J(w) = (1 / 2N) ∑i=1..N (ŷ(i) - y(i))2 = (1 / 2N) ||Xw - y||2
  • Analytical Closed-Form (The Normal Equation):
    Setting gradient ∇J(w) = 0 yields: w* = (XTX)-1 XTy.
    Limitation: Matrix inversion of XTX takes $O(D^3)$ time—computationally infeasible when features $D > 10,000$.

3 · Optimization: Gradient Descent Variants

Instead of inverting large matrices, Gradient Descent takes iterative steps proportional to the negative of the cost function's gradient:

w ← w - α ∇J(w) where ∇J(w) = (1/N) XT(Xw - y) and α is the Learning Rate.

4 · Complete NumPy Implementation from Scratch

import numpy as np

class LinearRegressionScratch:
    def __init__(self, learning_rate=0.01, epochs=1000):
        self.lr = learning_rate
        self.epochs = epochs
        self.weights = None
        self.bias = None
        self.loss_history = []

    def fit(self, X, y):
        n_samples, n_features = X.shape
        self.weights = np.zeros(n_features)
        self.bias = 0.0

        for epoch in range(self.epochs):
            # 1. Forward Pass (Prediction)
            y_pred = np.dot(X, self.weights) + self.bias
            
            # 2. Compute MSE Loss
            loss = (1 / (2 * n_samples)) * np.sum((y_pred - y) ** 2)
            self.loss_history.append(loss)

            # 3. Compute Gradients
            dw = (1 / n_samples) * np.dot(X.T, (y_pred - y))
            db = (1 / n_samples) * np.sum(y_pred - y)

            # 4. Gradient Descent Update
            self.weights -= self.lr * dw
            self.bias -= self.lr * db

    def predict(self, X):
        return np.dot(X, self.weights) + self.bias

# Verification on synthetic data
X = 2 * np.random.rand(100, 1)
y = 4 + 3 * X.squeeze() + np.random.randn(100) * 0.2  # True w=3, b=4

model = LinearRegressionScratch(learning_rate=0.1, epochs=500)
model.fit(X, y)
print(f"Learned Weight: {model.weights[0]:.3f} (True: 3.0) | Bias: {model.bias:.3f} (True: 4.0)")

5 · Regularization: Ridge vs Lasso

L2

Ridge Regression

Adds squared magnitude penalty: λ ∑ wj2. Shrinks weight coefficients smoothly towards zero, preventing multicollinearity without completely removing features.

L1

Lasso Regression

Adds absolute magnitude penalty: λ ∑ |wj|. Drives unimportant feature weights exactly to zero, acting as an automatic feature selection mechanism.
