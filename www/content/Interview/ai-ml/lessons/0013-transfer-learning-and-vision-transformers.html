Standing on the shoulders of giants: pretrained backbones, fine-tuning recipes, and attention applied to image patches.

1 · The One Idea

Training a deep vision model from scratch requires millions of labeled images (ImageNet) and weeks of cluster compute. In industry, 95% of computer vision tasks are solved via Transfer Learning: taking a model pre-trained on ImageNet that already knows universal visual representations (textures, edges, shapes) and fine-tuning only the final classification head on your specific domain dataset (e.g. medical X-rays or manufacturing defects).

2 · Transfer Learning Strategies

StrategyWhen to UseImplementation Mechanism
Feature Extraction (Linear Probing) Small custom dataset (< 1,000 images); target domain similar to ImageNet. Freeze all backbone weights (param.requires_grad = False); replace and train only the final linear classification layer.
Full Fine-Tuning Medium to large custom dataset; target domain differs from ImageNet. Unfreeze entire network, but use a very small learning rate (e.g. 1e-5) to avoid catastrophic forgetting of learned visual features.
Differential Learning Rates Gold standard for high accuracy. Apply lr=1e-5 to early layers, lr=1e-4 to middle layers, and lr=1e-3 to the newly initialized classifier head.

3 · Production PyTorch Transfer Learning Code

import torch
import torch.nn as nn
from torchvision import models

def get_finetuned_resnet(num_classes):
    # 1. Load weights pretrained on ImageNet
    model = models.resnet50(weights=models.ResNet50_Weights.DEFAULT)

    # 2. Freeze all convolutional backbone layers
    for param in model.parameters():
        param.requires_grad = False

    # 3. Replace final fully connected layer (model.fc)
    in_features = model.fc.in_features
    model.fc = nn.Sequential(
        nn.Linear(in_features, 256),
        nn.ReLU(),
        nn.Dropout(0.3),
        nn.Linear(256, num_classes)
    )
    # Note: Only model.fc parameters will have requires_grad = True!
    return model

model = get_finetuned_resnet(num_classes=5)
# Pass only trainable parameters to optimizer
optimizer = torch.optim.Adam(filter(lambda p: p.requires_grad, model.parameters()), lr=1e-3)

4 · Vision Transformers (ViT): An Image is Worth 16x16 Words

Introduced by Dosovitskiy et al. (Google Brain, 2020), Vision Transformers (ViT) discard convolutions entirely and treat images like sequences of text tokens:

Image (224 × 224 × 3)
Cut into 16 × 16 Patches (196 Tokens)
Linear Projection + Positional Embed
Standard Transformer Encoder

CNN vs ViT Trade-offs

  • CNNs have built-in Inductive Bias: translation equivariance and local spatial awareness. They train exceptionally well on small-to-medium datasets.
  • ViTs have almost zero inductive bias; they must learn spatial relationships from scratch using Global Self-Attention. When pre-trained on massive datasets (JFT-300M), ViTs outperform CNNs significantly.
