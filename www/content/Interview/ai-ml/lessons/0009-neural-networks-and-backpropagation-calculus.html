1 · The One Idea

An Artificial Neural Network is a universal function approximator composed of layers of artificial neurons. Each neuron performs a linear combination followed by a non-linear activation function. Without non-linear activations, stacking 100 layers would mathematically collapse into a single linear matrix multiplication. Backpropagation is the algorithmic application of the Calculus Chain Rule that efficiently computes the gradient of the loss function with respect to every single weight in the network in a single reverse sweep.

3 · The Calculus of Backpropagation Derived

Consider a neuron where z = W·aprev + b and a = σ(z), producing total loss L:

The Multivariable Chain Rule

How does a change in weight Wjk affect final Loss L?

∂L / ∂Wjk = (∂L / ∂a) × (∂a / ∂z) × (∂z / ∂Wjk)

  • ∂z / ∂Wjk = aprev (the incoming activation).
  • ∂a / ∂z = σ'(z) (the derivative of the activation function).
  • δ = (∂L / ∂a) × σ'(z) is called the error term for the layer.
  • Therefore: ∂L / ∂W = δ × (aprev)T and ∂L / ∂b = δ.

4 · Complete 2-Layer Neural Network from Scratch in NumPy

import numpy as np

class NeuralNetworkFromScratch:
    def __init__(self, input_dim, hidden_dim, output_dim, lr=0.1):
        self.lr = lr
        # He initialization for ReLU activation
        self.W1 = np.random.randn(input_dim, hidden_dim) * np.sqrt(2.0 / input_dim)
        self.b1 = np.zeros((1, hidden_dim))
        self.W2 = np.random.randn(hidden_dim, output_dim) * np.sqrt(2.0 / hidden_dim)
        self.b2 = np.zeros((1, output_dim))

    def _relu(self, z):
        return np.maximum(0, z)

    def _relu_deriv(self, z):
        return (z > 0).astype(float)

    def _softmax(self, z):
        shift = z - np.max(z, axis=-1, keepdims=True)
        exps = np.exp(shift)
        return exps / np.sum(exps, axis=-1, keepdims=True)

    def forward(self, X):
        self.X = X
        self.z1 = np.dot(X, self.W1) + self.b1
        self.a1 = self._relu(self.z1)
        self.z2 = np.dot(self.a1, self.W2) + self.b2
        self.a2 = self._softmax(self.z2)
        return self.a2

    def backward(self, y_true):
        N = self.X.shape[0]
        # 1. Output error (Softmax + Cross-Entropy derivative simplifies to: a2 - y_true)
        dz2 = (self.a2 - y_true) / N
        dW2 = np.dot(self.a1.T, dz2)
        db2 = np.sum(dz2, axis=0, keepdims=True)

        # 2. Backpropagate error into hidden layer
        da1 = np.dot(dz2, self.W2.T)
        dz1 = da1 * self._relu_deriv(self.z1)
        dW1 = np.dot(self.X.T, dz1)
        db1 = np.sum(dz1, axis=0, keepdims=True)

        # 3. Update Weights via SGD
        self.W2 -= self.lr * dW2
        self.b2 -= self.lr * db2
        self.W1 -= self.lr * dW1
        self.b1 -= self.lr * db1

    def train(self, X, y_one_hot, epochs=500):
        for epoch in range(epochs):
            probs = self.forward(X)
            loss = -np.mean(np.sum(y_one_hot * np.log(probs + 1e-9), axis=1))
            self.backward(y_one_hot)
            if epoch % 100 == 0:
                print(f"Epoch {epoch:03d} | Loss: {loss:.4f}")
