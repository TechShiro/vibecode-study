Logistic Regression & Classification Metrics

Binary and multiclass probability modeling, Log-Loss derivation, and comprehensive evaluation beyond naive accuracy.

← Back to Course IndexModule B – Classical Machine Learning

1 · The One Idea

Linear Regression cannot be used for classification: a line unbounded from -∞ to +∞ produces nonsensical probabilities like P(spam) = 2.4 or -0.8. Logistic Regression passes the linear combination through the Sigmoid function σ(z), smoothly mapping any real-valued number into the valid probability range (0, 1).

2 · The Sigmoid Function & Odds Ratio

Linear Score: z = w·x + b
Sigmoid: σ(z) = 1 / (1 + e-z)
Probability: P(y=1 | x) ∈ [0, 1]

The Odds Ratio is the ratio of probability of success to failure: Odds = p / (1 - p). Taking the natural log gives the Logit: ln(p / (1 - p)) = w·x + b. Logistic Regression is a linear model in the log-odds space!

3 · Loss Function: Binary Cross-Entropy (Log-Loss)

Because the Sigmoid function is non-linear, using MSE would create a non-convex cost surface with dozens of local minima. Instead, we derive the cost function using Maximum Likelihood Estimation (MLE):

Loss = - (1 / N) ∑ [ y(i) log(σ(z(i))) + (1 - y(i)) log(1 - σ(z(i))) ]

  • When true y = 1: loss = -log(ŷ). If model predicts 1.0, loss = 0. If model predicts 0.0, loss → ∞.
  • When true y = 0: loss = -log(1 - ŷ). Highly penalizes confident wrong predictions.

4 · Complete NumPy Implementation

import numpy as np

class LogisticRegressionScratch:
    def __init__(self, lr=0.01, epochs=1000):
        self.lr = lr
        self.epochs = epochs
        self.weights = None
        self.bias = None

    def _sigmoid(self, z):
        # Clip to prevent numerical overflow in exp(-z)
        z = np.clip(z, -500, 500)
        return 1.0 / (1.0 + np.exp(-z))

    def fit(self, X, y):
        n_samples, n_features = X.shape
        self.weights = np.zeros(n_features)
        self.bias = 0.0

        for _ in range(self.epochs):
            # 1. Forward Pass
            linear_model = np.dot(X, self.weights) + self.bias
            y_pred = self._sigmoid(linear_model)

            # 2. Compute Gradients
            dw = (1 / n_samples) * np.dot(X.T, (y_pred - y))
            db = (1 / n_samples) * np.sum(y_pred - y)

            # 3. Update Parameters
            self.weights -= self.lr * dw
            self.bias -= self.lr * db

    def predict_proba(self, X):
        return self._sigmoid(np.dot(X, self.weights) + self.bias)

    def predict(self, X, threshold=0.5):
        return (self.predict_proba(X) >= threshold).astype(int)

5 · Comprehensive Classification Metrics

MetricFormulaWhen to Prioritize
Precision TP / (TP + FP) When False Positives are costly (e.g. Spam filter: never mark an urgent business email as spam).
Recall (Sensitivity) TP / (TP + FN) When False Negatives are fatal (e.g. Cancer diagnosis, fraud detection: never miss a positive case).
F1-Score 2 × (Precision × Recall) / (Precision + Recall) Harmonic mean balancing both; essential for imbalanced datasets where accuracy is deceptive.
ROC-AUC Area under True Positive Rate vs False Positive Rate curve Measures model's ranking ability across all possible classification thresholds (0.0 to 1.0). 0.5 = random guess; 1.0 = perfect.
