1 · The One Idea: The Traditional 4-Copy Nightmare

When a web server reads a file from disk and sends it over a network socket, traditional code uses read() and write(). This requires 4 context switches and 4 buffer copies (Disk → OS PageCache → User Buffer → Socket Buffer → Network NIC)!

2 · Zero-Copy with sendfile() (The Secret to Kafka's Speed)

The Linux sendfile() system call tells the kernel: "Transfer this file descriptor directly to this network socket via Direct Memory Access (DMA)".

  • The data never enters user-space memory!
  • CPU context switches are cut from 4 down to 2!
  • CPU usage drops to near zero, operating at hardware line rate. This is how Apache Kafka and Nginx stream terabytes of data effortlessly.
