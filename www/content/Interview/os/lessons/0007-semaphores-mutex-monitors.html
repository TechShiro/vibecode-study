Semaphores, Mutex & Monitors

High-level synchronization primitives provided by the operating system kernel.

1 · The One Idea

A Mutex (Mutual Exclusion Lock) is a locking mechanism: only the thread that locked it can unlock it (Ownership). A Semaphore (invented by Dijkstra) is a signaling mechanism: an integer variable accessed only through atomic operations wait() (or $P$) and signal() (or $V$). Semaphores control access to a finite pool of resources.

3 · Linux Futex (Fast Userspace Mutex)

Why are modern locks fast? In Linux, a Futex attempts an atomic CAS lock in userspace memory in 1 nanosecond without asking the kernel! Only if there is active contention does it execute a system call to put the calling thread to sleep in the kernel queue.
