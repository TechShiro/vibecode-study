Page Replacement Algorithms

Deciding which memory page to evict to disk when RAM is 100% full.

↑ Back to Course IndexModule C — Memory & Virtual Memory

1 · The Algorithms

  • FIFO (First In First Out): Evicts oldest page. Suffers from Belady's Anomaly (giving the system MORE physical RAM frames can paradoxically INCREASE total page faults!).
  • Optimal (OPT / MIN): Replace the page that will not be used for the longest period of time in the future. Mathematically unbeatable, but impossible to implement in real life (requires predicting the future). Used as a benchmark.
  • LRU (Least Recently Used): Replaces the page that has not been accessed for the longest time. Stack algorithm; immune to Belady's Anomaly.
  • Clock (Second Chance): Circular buffer approximation of LRU using a single reference bit.
