Multi-Level Paging & The TLB Cache

Scaling page tables to 64-bit systems and caching translations in hardware.

↑ Back to Course IndexModule C — Memory & Virtual Memory

1 · The One Idea

In a 32-bit system with 4KB pages, a single flat page table requires 4 MB of RAM per process. In a 64-bit system, a flat table would require petabytes! Multi-Level Paging breaks page tables into a tree hierarchy so empty memory ranges allocate zero tables. To eliminate the performance penalty of multi-level memory lookups, the CPU uses a high-speed hardware associative cache called the TLB (Translation Lookaside Buffer), resolving 99% of translations in < 1 nanosecond!
