File System Architecture & UNIX Inodes

How operating systems organize files on persistent disks and map filenames to disk blocks.

1 · The One Idea

In UNIX/Linux, "Everything is a file". A file name is just a human-friendly label. Under the hood, every file is represented by an Inode (Index Node): a metadata record containing file size, ownership, permissions, timestamps, and pointers to the disk blocks storing the actual content. A directory is simply a special file containing a list of (filename, inode_number) pairs!
