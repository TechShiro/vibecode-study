Deadlocks & The Banker's Algorithm

Characterization, prevention, avoidance, and mathematical safety verification.

1 · The One Idea

A Deadlock is a permanent freeze state where every process in a set is waiting for an event that can only be caused by another process in the set. A deadlock can only occur if all 4 Coffman Conditions hold simultaneously: 1) Mutual Exclusion, 2) Hold and Wait, 3) No Preemption, 4) Circular Wait.

2 · The Banker's Algorithm (Deadlock Avoidance)

Invented by Edsger Dijkstra for banks handling credit lines. When a process requests resources, the OS simulates granting them. If the resulting state is Safe (there exists at least one sequence $\langle P_1, P_2, \dots, P_n angle$ where every process can finish), the request is granted. If Unsafe, the process must wait.

Key Matrices $ ext{Need}[i][j] = ext{Max}[i][j] - ext{Allocation}[i][j]$. If $ ext{Need} \le ext{Available}$, the process can complete and return all its allocated resources to the pool!
