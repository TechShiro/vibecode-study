Memory Management, Paging & The MMU

How hardware converts virtual memory addresses into physical RAM frames in nanoseconds.

↑ Back to Course IndexModule C — Memory & Virtual Memory

1 · The One Idea

Processes do not see physical RAM addresses. Every process runs inside its own private Virtual Address Space (0 to $2^{64}-1$). The CPU's hardware Memory Management Unit (MMU) translates virtual addresses to physical RAM addresses on the fly using a Page Table. This eliminates external fragmentation and prevents processes from snooping on each other's memory.

2 · Paging Mechanics

  • Pages: Virtual memory divided into fixed-size blocks (typically 4 KB).
  • Frames: Physical RAM divided into identical fixed-size blocks (4 KB).
  • Virtual Address split: [Page Number (p) | Offset (d)]. The MMU looks up $p$ in the Page Table to get Frame Number $f$. Physical Address = [Frame Number (f) | Offset (d)].
