Virtual Memory, Demand Paging & Thrashing

Running programs larger than physical RAM and recovering from page faults.

↑ Back to Course IndexModule C — Memory & Virtual Memory

1 · The One Idea

Virtual Memory allows a computer to execute programs that require 32 GB of memory on a machine with only 8 GB of physical RAM! It loads pages into memory on demand (Demand Paging). When code accesses a page not currently in physical RAM, the MMU triggers a Page Fault interrupt: the OS halts the thread, reads the 4KB page from SSD swap space into an empty RAM frame, updates the Page Table, and restarts the instruction!

2 · Thrashing & The Working Set Model

When physical RAM is completely exhausted, the OS spends 99% of its CPU time swapping pages in and out of disk rather than executing user code. System throughput drops to zero! This catastrophe is Thrashing. Solved by Peter Denning's Working Set Model: only schedule processes whose active working set of pages fits entirely in RAM.
