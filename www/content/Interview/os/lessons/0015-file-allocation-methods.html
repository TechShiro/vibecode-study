File Allocation Methods & Inode Pointers

How disk blocks are allocated to growing files without fragmentation.

1 · The 3 Allocation Strategies

  • Contiguous Allocation: File occupies consecutive disk blocks. Fast sequential reads, but suffers from severe external fragmentation and files cannot easily grow.
  • Linked Allocation (FAT): Each block contains a pointer to the next block. Zero fragmentation, but random seeking is terrible ($O(N)$ seeks).
  • Multi-Level Indexed Allocation (UNIX Inode): Uses 12 Direct pointers, 1 Single Indirect pointer, 1 Double Indirect pointer, and 1 Triple Indirect pointer, supporting files from 4KB up to 16 Terabytes with fast random seeking!
