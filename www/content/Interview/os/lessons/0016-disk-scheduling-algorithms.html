Disk Scheduling Algorithms

Minimizing mechanical disk arm seek time across read/write track queues.

↑ Back to Course IndexModule D — Storage, File Systems & I/O

1 · The One Idea

On rotational hard drives (HDDs), Seek Time (physically moving the disk arm across tracks) is the slowest operation in computing (~5-10ms). Disk Scheduling orders pending disk read requests to minimize total head movement.

2 · The Core Algorithms

  • SSTF (Shortest Seek Time First): Services request closest to current arm position. Low average seek, but risks starving distant cylinders.
  • SCAN (Elevator Algorithm): Arm sweeps continuously from one end of disk to the other, servicing requests along the way, then reverses direction.
  • C-SCAN (Circular SCAN): Sweeps in one direction only. When it reaches the end, it immediately returns to the beginning without servicing requests on the return trip, providing uniform wait times.
